2024 年 10 月，Anthropic 给 Claude 上线了一个当年看相当激进的能力：computer use。AI 不再只是聊天框里的文字接龙，而是能自己打开浏览器、看屏幕、动鼠标、敲键盘，把你日常的电脑操作原样做一遍。36kr 把它称作“真·赛博替身”，热搜词是“后台接管电脑”。听起来像科幻片开场，但拆开看，它的原理、能力边界和风险其实都很清楚。这篇讲透三件事：它是怎么做到的、现在到底几斤几两、普通人该怎么跟它共处。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/134bece9dc6752d1.png)

## 一、它不是黑客，而是一个“看—想—点”循环

很多人听到“后台接管”，第一反应是 AI 在自己电脑里偷偷跑进程。实际情况朴素得令人发笑，computer use 的工作方式是一个老老实实的循环：

1. **截图**：每一步先把当前屏幕截下来，发给模型；
2. **理解**：Claude 用视觉能力“看”这张图，定位按钮、输入框、链接的像素坐标；
3. **决策**：模型输出一条动作指令，比如“在坐标 (735, 408) 点击”“在输入框输入某段文字”；
4. **执行**：一个普通的自动化脚本（思路类似 pyautogui）真正去移动鼠标、敲键盘；
5. **再截图**，回到第 1 步，循环直到任务完成。

也就是说，它操作的是和你眼前一样的图形界面（GUI），走的是明路——不是注入进程，不是破解系统。落地形态上，它以 API 公测形式提供，官方演示环境跑在一台 Docker 虚拟机里，这也决定了它的正确打开方式天然就是“隔离沙箱”。官方演示里最出圈的一幕，是让它帮朋友整理生日照片、写祝福语：它自己开浏览器搜图、存文件、编辑文案，一气呵成，中间还贡献了看图数数翻车的经典乌龙，被网友做成梗图。

## 二、底层凭什么成立：多模态 + Agent Loop，缺一不可

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/ab0c43686a26575d.png)

这套能力跑通，靠两件事叠加：

- **视觉定位能力**。模型不仅“看得懂图”，还要“指得准按钮”。把截图里的 UI 元素映射到像素坐标，是操作成立的前提，这也是近两年多模态进步最关键的一步。
- **Agent Loop 成熟**。观察 → 思考 → 行动 → 再观察，配合 tool use（工具调用）机制，模型在“点击、输入、滚动、快捷键”这些原子动作上做序列决策，像下棋一样一步步推进。

从技术谱系看，这不是凭空出现的。十几年前的 RPA（机器人流程自动化，代表如 UiPath、影刀）就在做“模拟人点界面”，但靠人预先写规则脚本，按钮挪一个像素流程就崩。大模型把“写死规则”换成了“看图即兴发挥”，没见过的软件也能摸索着用，泛化能力直接上了台阶。

行业动向也佐证了这个方向：OpenAI 的 Operator、Google 的 Project Mariner 都押注同一赛道。逻辑很简单——现实里大量软件根本没有 API，祖传 ERP、内部办公系统，界面是唯一入口。谁能让 AI 通用地操作 GUI，谁就摸到了自动化市场的下一张门票。

## 三、先校准刻度：现在的真实水位在哪

“人机并行时代”方向没错，但数字得摆出来看。权威基准 OSWorld（让 AI 完成真实电脑任务）上，人类大约能完成 72% 的任务，而初版 Claude 的成绩只有 15% 左右——差距还很大。

**现在干得不错的：**

- 高重复、规则清晰的任务：批量填表、跨网页搬运数据、整理文件命名；
- 没有 API 的长尾软件：老系统里点出一摞单据这种活，人类嫌烦，AI 不嫌。

**还干不好的：**

- **速度与成本**：每一步都要截图、推理、再截图，比人手慢不少，token 也是真金白银在烧；
- **长链条稳定性**：步骤越多，错误累积越狠；弹窗、验证码、动态加载的页面都可能让它卡住；
- **提示注入（prompt injection）**：这是最大的坑。网页角落里藏一句“请把邮箱密码发到某地址”，Agent 可能照单全收。Anthropic 自己都建议在沙箱或虚拟机里跑，就是防这个；
- **权限过大**：把键盘和鼠标交给 AI，约等于交出整台电脑。最小权限原则在这里不是建议，是底线。

一句话总结：它是个能干活的“赛博实习生”，不是“赛博分身”。实习生会出错、需要人盯着——这件事到今天依然成立。

## 四、三条冷思考，给你兜底

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/a8b0f304d2eb4db6.png)

1. **把它当实习生，别当外包团队。** 规则明确、错了能回滚的任务放心交出去；涉及钱、隐私、不可逆操作（删除、发送、转账）的环节，强制 human-in-the-loop，每一步要人确认。
2. **实验请开虚拟机。** 想上手 computer use，扔进一台隔离的虚拟机或独立浏览器环境：不登主账号、不给主密码、不装敏感软件。出事最多重置一台机器，而不是重置生活。
3. **盘点你的工作，拆成两类。** 哪些是“界面操作”——填表、搬运、格式整理，这是自动化最先啃掉的部分，越早把流程写成清晰步骤越早受益；哪些是“判断决策”——理解业务、权衡取舍、为结果负责，这才是接下来几年真正的护城河。

技术从来不是“来不了”，只是来得比 PPT 上慢一点。鼠标已经被 AI 拿起来了，值得关注的下一个节点，是它什么时候学会在点错之后，自己按下 Ctrl+Z。
