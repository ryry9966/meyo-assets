2025 年 1 月，DeepSeek R1 登顶美区 App Store 免费榜，全球科技媒体集体刷屏。很多人以为那是“中国大模型出海”的开始，其实那只是露出水面的一角。更庞大的部分一直在水下：Hugging Face 的趋势榜、OpenRouter 的调用日志、成千上万个海外应用的推理后端里，都跑着中国团队训练的模型。36kr 把这波浪潮概括为“集体隐形出海”，没有海外发布会，没有买量投放，模型却已经渗进了全球 AI 应用的地基。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/8df31d6eaf9b5dda.png)

## 先定义：隐形出海的三条暗线

传统出海是 TikTok 式的：一个 App、一个品牌，直接面对用户。大模型的出海走的是完全不同的三条暗线：

1. **权重出海**：Qwen、DeepSeek、Kimi K2、GLM 等系列把模型权重直接开源，任何开发者都可以下载、微调、再部署。Qwen 系在 Hugging Face 上的衍生模型已超过 10 万个，数量上一度反超 Meta 的 Llama 系。
2. **API 出海**：模型通过 OpenRouter、Together AI、Fireworks 这类聚合平台被转售。海外开发者用美元充值，可能压根没注意底层是哪家中国模型。
3. **白牌出海**：海外应用给中国模型套一层壳，换名字、改系统提示词、重做前端，用户看不到任何来源信息。

这三条线的共同点是：不需要本地化团队和广告预算，只需要三样东西，一个宽松的 license、一份能打的 benchmark、一张有杀伤力的价目表。

## 技术底牌：许可证是船票，架构是发动机

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/dc2ecf9813a00b5a.png)

**先看许可证。** Meta 的 Llama 用的是自定义社区许可证：月活超 7 亿要单独授权，衍生模型必须冠名"Llama"。而 Qwen 主力版本用 Apache 2.0，DeepSeek R1 干脆用 MIT。对工程师来说，前者是“带条件的免费”，后者是“随便用、随便改、随便卖”。许可证的差异，直接决定了开发者的第一选择。

**再看架构。** DeepSeek V3 是 671B 总参数的 MoE 模型，每个 token 只激活约 37B 参数，配合 MLA（多头潜在注意力）和 FP8 混合精度训练，把推理成本压到同级闭源模型的几分之一。论文口径的正式训练约 278.8 万 H800 GPU 小时、约 557 万美元——虽不含前期研究投入，但成本量级依然震动了硅谷。

**最后是性价比。** 接近第一梯队的跑分，低一个数量级的价格，对成本敏感的创业者来说，这道选择题不难做。开源榜的逻辑很朴素：谁便宜、谁好用、谁许可干净，开发者就用谁。

## 地下水系：那些“用而不说”的海外应用

真正有意思的，是“隐形”二字是怎么实现的：

- **大厂托管**：微软 Azure、AWS Bedrock 都上线了 DeepSeek 等模型的托管版本，美国云巨头亲自帮中国模型分发，大概是整条航线上最耐人寻味的一站。
- **白牌改造**：Perplexity 对 R1 做了内容合规方向的微调，命名为 R1-1776，部署在自己的美国基础设施上对外服务。模型还是那个模型，只是“船籍”换了。
- **随时切换**：OpenRouter 允许应用在多家模型间热切换。2025 年上半年 DeepSeek R1 的调用量长期位居前列，很多调用来自“今天 Claude、明天 R1”的应用，用户完全无感。
- **端侧渗透**：Ollama、LM Studio 的用户拉取榜上，Qwen 的小尺寸版本（0.5B~14B）是常客。它们在多语言、数学、代码上“同体积最能打”，正好适合手机、车机、机器人这类算力受限场景。
- **蒸馏底座**：R1 官方蒸馏系列里有 4 个版本（1.5B/7B/14B/32B）直接基于 Qwen 底座；海外大量推理小模型也把 Qwen 当默认底座。你的模型里住着我的模型，这算不算出海？算，而且是嵌套式的。

## 商业账本：为什么集体选择这条路



这笔账其实很简单：

1. **国内卷不动**：2023–2024 年国内 API 价格战打到地板，头部厂商轮番降价甚至免费，纯卖 token 在国内几乎无利可图。
2. **海外有空间**：同样的模型能力，海外 token 单价高出一截，聚合平台转售还有加价空间，模型厂按调用量分成。
3. **开源换生态**：Meta 用 Llama 验证过这套逻辑，模型免费，生态归你，云服务和企业订单赚钱。中国团队把打法用得更彻底：开源建立全球开发者依赖，再反哺自家云业务。
4. **摩擦真实存在**：美国部分政府机构禁用 DeepSeek，欧洲有数据保护机构问询过数据合规问题，一些企业客户会做“隔离部署、数据不回流”的改造。隐形出海不等于没有风浪，只是船开得低调。

## 冷思考：三个值得记住的判断

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/77f50f580be7fcf1.png)

1. **看后端，别看前端。** 评估任何 AI 应用，去翻它的 API 供应商、模型版本号和第三方调用统计，比看官网叙事靠谱得多。“贴牌”是这个时代的常态，品牌与模型早已解耦。
2. **开源 ≠ 免费午餐。** 自部署有隐性成本：GPU、运维、安全补丁、合规审计。小团队先用托管 API 跑通业务，规模上来再考虑私有化，是更稳的路径。
3. **盯三个指标：许可证、激活参数量、真实调用数据。** 许可证决定能不能商用；MoE 激活参数决定推理账单；第三方平台的调用统计（而非跑分）决定生态的真实热度。跑分可以刷，账单不会说谎。

隐形出海不是什么阴谋，是工程理性与商业理性叠加后的自然结果：好用的东西，自己会找到路。船队已经出海，看懂航线，比争论船籍更重要。
