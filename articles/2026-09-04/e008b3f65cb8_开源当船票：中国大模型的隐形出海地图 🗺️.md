2025 年 1 月，DeepSeek 的 App 冲上美区 App Store 免费榜第一，很多人以为那是一次性的热闹。真正的故事藏在更安静的地方：Hugging Face 上，通义千问（Qwen）的衍生模型超过 10 万个，是全球最大的开源模型家族；DeepSeek-R1 被 Perplexity、Groq、Azure 等海外平台争相托管。没有铺天盖地的广告投放，中国大模型已经把"营业网点"开进了全球开发者的代码仓库。36kr 把这称作"集体隐形出海"——出海的不是招牌，而是权重、API 和无数衍生模型。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/6d6e57b44cabd2f6.png)

## 先看清现象：出海的是"内核"，不是招牌

- 榜单只是冰山一角。DeepSeek、Qwen 的国际版应用确实在海外拿到了千万级用户，但更大的量发生在看不见的层。
- Hugging Face 数据：Qwen 系列衍生模型数突破 10 万，超过 Meta 的 Llama 成为第一大开源家族，累计下载量以亿计。
- 聚合 API 平台 OpenRouter 的用量榜上，DeepSeek、Qwen 长期位居开源模型前列；很多海外应用前台是自己的 UI，后台调用的却是"中国权重"。
- 更隐形的一层：Perplexity 托管 R1、微软 Azure AI Foundry 上架 R1、英伟达 NIM 打包 DeepSeek——用户点开的是硅谷产品，跑的可能是杭州训练出来的模型。

一句话总结：这一轮出海，渗透率靠开源生态，存在感靠白标。

## 路线一：开源权重，把模型"寄存"进全球开发者的工作流

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/b294ef71dda8e483.png)

机制拆开是三件事：

1. **许可证开门**。DeepSeek-R1 采用 MIT，Qwen 主线采用 Apache 2.0，都允许商用；而 Llama 早期许可证还带地区限制条款，社区自然用脚投票。
2. **蒸馏生态滚雪球**。社区拿 Qwen/DeepSeek 当基座做微调、量化、蒸馏，各大开源榜单上大量前排模型的血统都能追溯到中国基座。衍生模型每多一个，分发网络就多一条毛细血管，而基座方不用花一分推广费，获客成本趋近于零——市场部看了沉默，工程师看了狂喜。
3. **工程友好**。Qwen 提供 0.5B 到 7B 的多档小模型，DeepSeek 放出蒸馏版，一张消费级显卡就能跑起来，"先试再买"的门槛被压到最低。

这套打法的本质：不是把产品推给用户，而是把火种交给开发者，让当地人自己微调补齐本地语言和行业知识——这比任何本地化团队都快。

## 路线二：C 端与 API 双线并行，但常换"马甲"

- **C 端**：MiniMax 的 Talkie、Genspark 等产品在欧美市场积累了可观的稳定用户；Qwen 也上线了国际版对话应用。共同特点是前端高度本地化，不刻意强调出身。
- **API 与云**：通过阿里云国际版，以及 Azure、AWS Bedrock 等第三方云上架，中国模型变成全球企业账单里的一个普通 SKU。
- **机构合作**：一些中东、东南亚的国家级 AI 项目直接选 Qwen 做基座——这属于"地基级"渗透，最隐形，也最牢固。

## 底层账本：为什么这一次能"游"出去

- **架构效率**：MoE（混合专家）+ MLA（多头潜在注意力）+ FP8 训练。DeepSeek-V3 论文披露，预训练算力约 278.8 万 H800 GPU 小时，折合约 557 万美元，是同代旗舰里的地板价。
- **性能追平**：斯坦福 AI Index 2025 指出，中美头部模型在主流基准上的差距已缩小到接近持平；开源榜单上 Qwen3、DeepSeek-R1、Kimi K2 长期霸榜。
- **价格优势**：API 定价长期只有同级闭源模型的几分之一，对成本敏感的创业团队是降维打击。
- **时机窗口**：闭源 API 涨价、部分开源许可收紧，中间空出的生态位正好被接住。

一句话：便宜大碗、文档齐全、许可证宽松，开发者最在意的三样它全占了。在省钱这件事上，全球工程师的偏好高度一致。

## 冷思考：隐形是优势，也是软肋

- **品牌不沉淀**：用户记住了 Perplexity 和 Azure，却没记住背后的模型是谁。白标换来渗透率，牺牲了品牌溢价。
- **变现链路长**：开源本身不赚钱，要靠云服务、企业版和 API 走量回血，对商业闭环的要求更高。
- **合规与供应链**：GDPR、数据驻留要求抬高运营成本；算力供应链的不确定性是长期变量，只能靠架构效率去对冲。
- **生态质量**：衍生模型参差不齐，劣质微调泛滥会反噬基座口碑。

## 三条实用建议

1. **开发者**：成本敏感、任务边界清晰的应用，先用 Qwen/DeepSeek 的小尺寸开源版做原型，用 OpenRouter 做 A/B 对比；注意许可证条款，量化部署从 4-bit 起步试水，关键链路换 8-bit 或原精度。
2. **技术决策者**：开源还是闭源，看数据飞轮——数据能回流自训练，就开源换生态；数据是核心壁垒，就闭源自持。
3. **行业观察者**：少盯发布会，多盯 Hugging Face Trending 的衍生模型增速和 OpenRouter 用量榜，这两个指标比跑分更能预测下一年的格局。

隐形出海的上半场靠技术红利，下半场比的是把"隐形"做成"被记住"的能力。
