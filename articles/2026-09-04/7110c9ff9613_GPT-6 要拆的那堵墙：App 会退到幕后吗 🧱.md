最近，“GPT-6 强拆 App 的墙”登上了科技媒体的热议榜。大意是：当下一代模型具备足够强的 Agent（智能体）能力，用户可能不再逐个点开 App，而是把一句意图交给 AI，由它跨应用把事情办完——手机桌面那一排图标，第一次显得像“中间商”。这里说的墙，不只是屏幕上的图标格子，更是移动互联网花了十几年砌起来的“围墙花园”（walled garden）。这篇文章把它拆开看：墙从哪来、AI 打算怎么拆、墙内的人为什么急、这堵墙会不会真的倒。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/fd1868bc00323098.png)

## 墙从哪来：入口即权力

- 围墙花园不是新词。上世纪 90 年代 AOL 就靠“内容+服务全在自家院里”起家，后来开放互联网把它拆过一次。
- 2008 年 App Store 上线，正式开启 App 经济。到 2022 年，第三方机构测算 App Store 生态带动的开发者交易与销售已超 1.1 万亿美元——这是一堵用真金白银砌起来的墙。
- 入口一直在换主人：门户 → 搜索引擎 → 信息流 → 超级 App。每换一次，旧入口就被“管道化”一次，当年浏览器也曾被认为会取代操作系统。
- 逻辑很简单：谁掌握入口，谁就掌握分发权与定价权——应用商店的 30% 抽成、信息流的广告竞价、开屏广告的价格，全都建立在“用户必须经过我”之上。

AI 眼下的机会，恰恰是让“用户必须经过 App”这件事不再成立。

## AI 从三个方向拆墙

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/5e073216a11de49a.png)

1. **意图直连：Function Calling / API。** 模型不“看”界面，直接调用结构化接口。2023 年 6 月 OpenAI 推出 function calling 后，这条路径迅速成为主流。订机票从“开三个 App 来回比价”，变成一句话触发一组 API 调用。
2. **屏幕操作：Computer Use / GUI Agent。** 模型像人一样看截图、挪鼠标、点按钮。Anthropic 的 computer use、OpenAI 的 Operator 走这条路线。好处是不需要对方配合，坏处是慢、且容易点错。
3. **协议标准化：MCP。** Model Context Protocol 把“模型—工具”的对接变成通用插座，2024 年底开源后很快被多家主流厂商采纳。协议一旦统一，App 的 UI 就从必需品降级为可选装饰。

举个身边例子：报销。你拍一张发票，Agent 自动识别金额、归类目、填表单、走审批流，全程没打开过任何办公应用——流程还在跑，只是“界面”这层皮被剥掉了。

## 墙内的人为什么急：注意力生意的地基松了

- 移动互联网的盈利闭环是：入口 → 用户时长 → 广告与抽成。Agent 直接抽掉了“时长”这一环。
- 没有人的眼睛看信息流，广告曝光就失效；没有 DAU，开屏广告就卖不出价。对纯注意力生意，这是釜底抽薪。
- 反击已经发生：Reddit 对 API 调用收费、Cloudflare 上线默认拦截 AI 爬虫的选项、多家平台开始要求 Agent 自报身份。数据持有方的新姿态是：从“免费换流量”转向“授权换订阅费”，把 Agent 当成 B 端客户来报价。
- 换句话说，拆墙不是单向的拆除，而是一场关于“接口定价权”的长期谈判。

## 冷静看：墙不会一夜倒，但会变薄

- **可靠性仍是短板。** 在 OSWorld 这类真实电脑操作基准上，早期模型的任务成功率只有百分之十几，而人类大约七成。GUI Agent 一步点错、全链路作废，Agent 犯错的单位成本比人高得多。
- **信任与责任没解决。** 付款、签合同、提交有法律效力的文件，出了错算谁的？身份验证、支付授权、操作回滚，每一项都是硬摩擦。
- **平台可以不开门。** 超级 App 完全可以选择不给 Agent 接口，或者只开一扇收费的门。博弈焦点会从“广告位竞价”换成“API 价格与服务质量”。
- 更可能的终局不是墙塌了，而是墙后移：UI 这层墙变薄，数据与支付那层墙变厚。分发逻辑从“抢用户时长”，变成“抢被 Agent 调用的优先级”。

## 写在最后：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/c9e11f40a969627b.png)

1. **对开发者：** 把核心能力做成干净、幂等、机器可调用的服务，而不是只打磨 UI。当 Agent 替用户挑选供应商时，“能被稳定调用”就是新时代的上架审核。
2. **对产品人：** 开始设计“没人看的界面”——结构化、低延迟、结果可校验。北极星指标从 DAU 和时长，逐步迁移到任务完成率与 Agent 调用量。
3. **对普通用户：** Agent 的权限就是你的权限。授权前想清楚三件事：它能读哪些数据、能动多少钱、出了错谁兜底。便利的另一面，是把一部分判断力外包了出去。

墙会不会塌，其实没那么重要。重要的是：当获取服务的方式从“我去找 App”变成“服务来找我”，价值会重新流向握住意图、数据和信任的那一层。这一轮，值得提前想清楚自己站在哪。
