最近一条热搜把三个关键词焊在了一起：Meta 旗舰模型翻身、比 DeepSeek 还便宜、排行榜上压过 Gemini。翻译成工程师语言，这其实是三件不同的事：**架构换了**（从稠密转向 MoE）、**定价逻辑变了**（开放权重 + 托管商价格战）、以及一次**教科书级的评测争议**（LMArena 打榜风波）。把这三件事拆开看，比看十遍标题都有营养。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/fc981e301af9cc60.png)

## 一、翻身的底层逻辑：从“大力出奇迹”到 MoE 稀疏架构

- Llama 3.1 时代，Meta 的旗舰是 405B 稠密模型：每个 token 都要唤醒全部 4050 亿参数，像全公司加班接一个订单，电费账单可想而知。
- Llama 4 全面转向 **Mixture of Experts（MoE）**：
  - **Scout**：总参数约 109B，每次只激活 17B，含 16 个专家，标称 1000 万 token 上下文（有效长度社区仍有争议）；
  - **Maverick**：总参数约 400B，激活 17B，128 个专家；
  - **Behemoth**：总参数约 2T、激活 288B，定位是“老师”，专门给小模型做蒸馏。
- MoE 的核心是一个 **Router（路由器）**：每个 token 进来，只被派给最相关的少数几位“专家”，其余专家原地睡觉。
- 类比：稠密模型是全员到岗的大锅饭，MoE 是按需派单的专家小组，**队伍总编制看总参数，单笔订单的人力成本看激活参数**，这两个数第一次可以分开谈。训练侧还用了 early fusion 的原生多模态，文本和图像从一开始就一起喂。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/9a223e1caf12ef11.png)

## 二、“比 DeepSeek 便宜”的账本

- 先看对手：DeepSeek V3 是 671B 总参、37B 激活的 MoE，叠加 FP8 训练、MLA 注意力压缩等工程优化，把 API 价格打成了行业地板，也顺带给全行业演示了 MoE 的性价比。
- Maverick 的激活参数只有 17B，比 DeepSeek V3 的 37B 还少，单 token 理论计算量更低。在多家第三方托管平台上，它的价格一度进入“每百万 tokens 输入约 0.2 美元、输出约 0.6~0.9 美元”的区间，低于 DeepSeek V3 当时约 0.27 / 1.10 美元的官方牌价。价格随行情波动，但量级差是真实存在的。
- 不过便宜有三个前提，别只看单价：
  1. **显存不便宜**：400B 权重即使量化后也要 200GB 量级显存伺候，MoE 省的是算力，不是显存；
  2. **部署门槛高**：跑满 MoE 通常要上专家并行（expert parallelism），这是托管商的看家本领，个人玩家本地部署基本无缘；
  3. **便宜由竞争摊销**：Meta 自己不发 API，价格战打的是 Together、Fireworks、DeepInfra、Groq 这些托管商的钱。

## 三、“骑脸 Gemini”的排行榜，含金量要打个问号

- LMArena（原 Chatbot Arena）的机制是盲测对战：用户同时问两个匿名模型，投票定胜负，再用 Elo 类算法排名。听起来很公平。
- 今年 4 月，一个叫 Maverick-Experimental 的版本冲上榜单第二，压过当时一批旗舰。但社区很快发现：**这个实验版和公开发布的版本不是同一个东西**。公开版补测后掉到 30 名开外，Meta 承认提交时出现了“意外的质量问题”；LMArena 随后更新规则，要求打榜模型与公开模型一致。
- 技术上这不奇怪：针对“人类偏好投票”做优化，模型可以学会回答更长、更讨喜，在盲测里涨分——但这是教科书级的 **Goodhart's Law**：当指标成为目标，它就不再是好指标。
- 客观说一句：实验版至少证明了这套权重的上限不低，问题出在宣传时没把版本差异讲清楚。

## 四、开放权重这门生意的真实算盘

- Meta 不靠 API 赚钱，它的闭环是：开放权重 → 托管商互相卷价格 → Llama 成为大量应用的默认基座 → **生态标准和开发者心智握在手里**。
- 组织层面也动了手术：Meta 以 140 多亿美元投资 Scale AI，其华裔联合创始人 Alexandr Wang 加入 Meta 负责新组建的超级智能业务。钱和人指向同一个判断：开放路线继续下注，且算力预算再加码。
- 开放权重还允许下游自由蒸馏和微调——Behemoth 到小模型的蒸馏路径，等于把前沿能力的“溢出效应”批量发给生态。
- 竞争格局由此分成两条线：闭源前沿（GPT、Gemini、Claude）拼上限，开放权重（Llama、DeepSeek、Qwen）拼渗透率。“比 DeepSeek 便宜”本质上是两条开放路线在同一市场的贴身肉搏，赢家是所有下游开发者。

## 五、冷思考：怎么用数据挑模型，而不是挑标题

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/2c82c54e5bf02c7c.png)

1. **看三件套而不是名次**：激活参数、总参数、上下文长度。激活参数决定单价量级，总参数决定知识容量，上下文决定场景边界，三者要一起读。
2. **算 TCO（总拥有成本）而不是单价**：把显存占用、并发吞吐、量化损失、专家并行的运维复杂度都折成钱。很多“便宜”在规模化之后，会被工程复杂度悄悄吃回去。
3. **用自己的任务集复测**：哪怕只有 50 条真实业务样本，跑一遍公开可用版本，也比 10 个榜单名次可靠。看榜单挑模型，就像看照片挑龙虾，图片仅供参考，虾线得自己挑。

一句话收尾：MoE 把“容量”和“成本”拆开定价，是这一轮所有价格战的技术地基；而谁能把这地基真正交到开发者手里，谁才算翻身。
