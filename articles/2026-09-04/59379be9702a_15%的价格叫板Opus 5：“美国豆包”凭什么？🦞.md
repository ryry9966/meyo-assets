这几天 AI 圈的热搜被一条消息刷屏：被网友戏称为“美国豆包”的 Google Gemini 系列又更新了，这次的关键词不是跑分，而是价格——大约只有 Anthropic 旗舰 Opus 5 的 15%，能力却向旗舰梯队看齐，连姚顺宇都公开给出了相当高的评价。一次看起来寻常的版本迭代，为什么能同时搅动定价体系、研究圈口碑和开发者生态？这篇把三个问题拆开讲清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/413ac9dcf57c54f3.png)

## 一、“美国豆包”是个什么梗？

这个外号不是嘲讽，而是对一种打法的精准概括：

- **豆包在国内的标签**：免费或超低价、消费级定位、迭代极快，靠 AI 写真、虚拟角色合照这类图像玩法病毒式出圈，QuestMobile 等机构的口径里月活早已过亿；
- **Gemini 在美国的路径几乎是镜像**：Nano Banana 图像编辑刷屏社交媒体、Gemini App 冲上美区 App Store 榜首，官方口径的月活一度达到六亿量级，API 定价长期是同档位里最低的一档；
- **一句话总结**：用消费级产品的思路做 AI——先做大用户盘子，再靠规模摊薄成本，最后用价格换生态。

所以当“美国豆包”更新时，值得关注的从来不只是模型本身，而是它背后的商业策略又往前挪了一步。

## 二、15% 的价格：不是促销，是定价逻辑换了

先建立参照系。Anthropic 在 Opus 4.5 上把旗舰价格从上一代的 $15/$75（每百万 tokens 输入/输出）直接砍到 $5/$25，市场普遍预计 Opus 5 会延续这一档位。15% 折算下来，输入价大约在 $0.75/百万 tokens——一年前，这个价位对应的还是轻量级小模型。

为什么敢定这个价？三个技术支点：

1. **MoE 与稀疏激活**：总参数做得很大，但每个 token 只激活一部分专家网络，算力开销不随参数量线性上涨；
2. **蒸馏与专业化**：旗舰模型当“老师”生成高质量训练数据，“学生”模型在主流任务上逼近老师，推理成本却低一个量级；
3. **推理工程**：量化、KV cache 复用、投机解码、大批量调度，把单位 token 成本一压再压。

Google 还有一张别人短期学不来的底牌：**自研 TPU**。芯片、框架、数据中心全栈自持，意味着它不必把“英伟达税”算进定价里——低价不是亏本换吆喝，而是垂直整合换来的真实毛利空间。

算笔直观的账：一个日均处理 1000 万 tokens 的中型应用，输入侧按 $5 计价一年要花约 $18,250；按 15% 计价只要 $2,700 出头，省下的钱差不多是一名工程师小半年的工资。

顺带一提经济学里的 Jevons 悖论：单价下降会刺激用量暴涨，最后总账单反而更高。这对厂商成立，对开发者同样成立——模型便宜之后，你会不自觉把它塞进更多边缘场景。

## 三、姚顺宇的点赞，该怎么读？

先说他为什么有分量：清华本科，普林斯顿博士期间一作提出 ReAct 和 Tree of Thoughts——前者几乎是今天所有 Agent 框架的地基；2024 年加入 OpenAI，2025 年转投 Anthropic（据公开报道）。在中文 AI 社区，他的名字约等于“模型品味”这个玄学词的具象化。

据 36 氪报道，他对这次更新给出了很高的评价。这类评价值钱的地方在于：他一贯关注的不是榜单，而是模型在真实编码与 Agent 任务里的“手感”——这类反馈比跑分难掺水。

但记得打三个折扣：

- 研究员评价的是自己关心的 workload；你的场景可能是长文档、多模态或中文语料，参考系并不相同；
- 大厂研究员之间的公开互赞带有一定社交礼仪成分，点赞不等于基准测试；
- 发布周的能力叙事历来偏乐观，“旗舰杀手”这个词历史上已经出现过很多次。

一句话：**把好评当信号，别当结论。**

## 四、“又又又更了”：快节奏背后的竞争结构

- **迭代周期按周/月计**。自研芯片、搜索与 YouTube 的数据入口、大规模自建机房，让 Google 的边际迭代成本极低——“小步快跑”是结构优势，不是姿态；
- **三家的卡位越来越清晰**：Anthropic 守高端编码与 Agent 市场，OpenAI 守消费入口与生态，Google 用“够好 + 超便宜 + 全家桶”打渗透战；
- **对开发者的直接影响**：国际一线模型的单位智能价格持续下探；间接影响是国产模型也面临继续降价的外部压力——2024 年国内那场 API 价格战，正在全球市场重演。

再补一个观察：当各家旗舰的能力差距缩到个位数百分点，跑分叙事的边际价值在下降，真正拉开体验的是延迟、稳定性、工具调用可靠性和价格——而这恰恰是这次更新的主战场。

## 五、三条冷思考

1. **按折旧曲线做预算**：今天旗舰模型的能力，12 个月后大概率以五分之一的价格出现在中档模型里。技术选型时请把这条曲线算进去，别为“当前最强”支付长期溢价。
2. **把架构做成模型无关**：价格战红利期最适合抽象一层 provider，用统一接口隔离各家的独有 feature。便宜是真便宜，但锁定也是真贵。
3. **别让价格重新定义问题边界**：以前因为 token 成本砍掉的 idea——全量代码审查、逐条客服质检、超长上下文分析——值得捡回来重新算一笔账。降价最大的价值不是让你省钱，而是让某些生意第一次成立。
