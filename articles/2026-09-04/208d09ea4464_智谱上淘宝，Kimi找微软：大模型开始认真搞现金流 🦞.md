2025 年刚开场，大模型圈的动作齐刷刷转向了同一个方向。36 氪报道：智谱把 GLM 系列模型的 API 服务开进淘宝，token 套餐明码标价摆上货架；另一边，Kimi（月之暗面）选择与微软合作，借 Windows 桌面渠道触达办公人群。一边是货架电商，一边是操作系统级入口，动作不同，指向却完全一致——过去靠融资续命的大模型公司，开始认真回答那个最朴素的问题：钱从哪来。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/92b9bc8cca295947.png)

## 先算账：为什么“赚钱”突然变得急迫

- **融资逻辑变了。** 2023 年讲的是 AGI 的宏大叙事，如今投资人普遍开始看 unit economics（单位经济模型）：每卖 1 元 token，毛利是多少？demos 再惊艳，也顶不过一张现金流量表。
- **推理成本在持续放血。** 训练是一次性投入（CapEx），推理却是随用量线性增长的运营成本（OpEx）——用户每多问一句，GPU 就多烧一度电。用户暴涨但没人付费，等于用现金流买 DAU。
- **价格战把单价打到地板。** 2024 年 5 月起，DeepSeek-V2 把百万 token 输入价降到 1 元级，豆包跟进 0.8 元，智谱、百度接连宣布降价甚至免费。量在涨，价在跌，毛利两头受挤。
- **头部已经证明能赚钱。** 据外媒报道，OpenAI 2024 年收入约 35~40 亿美元量级，ChatGPT 订阅占大头；Anthropic 在 2025 年初年化收入也迈过 10 亿美元门槛。标杆立在那儿，中腰部玩家必须证明自我造血能力——下一轮融资的谈判筹码，正在从参数规模变成营收曲线。

投资人从看 PPT 变成看报表，这大概是对工程团队最有效的 KPI。

## 智谱上淘宝：把 token 卖成“标品”

拆解这个动作背后的机制：

- **MaaS 本质是“水电煤生意”。** 模型即服务（Model as a Service）按 token 计费：1 个汉字约对应 1~2 个 token，输入输出分开计价。规格明确、单价透明、即买即用，天然适合货架式销售。
- **获客半径完全不同。** 官网卖 API，触达的是“已经知道要买什么”的开发者；淘宝面对的是海量“听说 AI 有用但不知道去哪买”的中小企业主。后者数量级大得多，只是过去缺一个合适的货架。
- **电商基础设施免费送。** 支付、开票、售后、评价体系全是现成的，省掉自建商务团队的固定成本。把不同规格的 token 套餐做成 SKU，等于把原本要跑几周的企业销售流程，压缩成“加购物车—付款—拿 API Key”三步。
- **软性收益同样重要。** 在大众消费平台露脸，本身就是一次品牌广告，传递“AI 不只属于极客”的信号。

局限也很明显：如果买家囤了 100 万 token 却用不完，那只是一次性收入，不是可预期的 SaaS。复购率和用量留存，才是这个渠道的真实考卷。

## Kimi 找微软：渠道就是杠杆

- **能力与场景对口。** Kimi 早期靠长上下文出圈（2023 年率先支持 20 万字长文档），读长报告、摘要文档、整理资料，这些正是 PC 办公场景的高频需求，和手机端碎片化使用是两套逻辑。
- **借来操作系统级入口。** 据公开报道，Kimi 客户端已登陆微软应用商店，直接触达 Windows 庞大的办公人群。自己从零铺 PC 端品牌认知，营销预算可能要上亿；借用现成分发位，边际成本接近于零。
- **对微软也不吃亏。** 引入有热度的 AI 应用能丰富应用生态，让用户在 Windows 上停留更久，一笔标准的渠道换流量交易。
- **历史一再验证。** 浏览器预装、输入法捆绑、应用商店推荐位……互联网每一次入口之争都在重复同一句话：渠道决定触达，触达决定转化漏斗顶端的宽度。

## 一张账本：四条变现路径与成本结构

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/860bbab3b2c3c032.png)

先把主流路径摆上桌：

1. **ToC 订阅**：ChatGPT Plus 每月 20 美元，国内各家会员约 20~50 元/月。客单价低、靠规模，营销投放大，利润薄。
2. **ToB API / MaaS**：按 token 计费，毛利高度依赖推理降本三件套——MoE 稀疏架构（如 DeepSeek-V3 总参数 671B，单次仅激活 37B）、前缀缓存（prefix caching 命中可省 50%~90% 的输入成本）、批处理接口（通常对折）。
3. **私有化 / 行业定制**：金融、能源、制造客户按项目买单，客单价百万到千万级，但交付重、回款慢。据公开报道，智谱 2024 年商业化收入达数亿元，主力正是 ToB 侧。
4. **渠道与生态分成**：上架应用商店、与云厂商合作分润，换的是流量与场景，不是直接现金。

成本端还有一条关键认知：**训练是沉没成本，推理是边际成本**。这门生意最终能否赚钱，取决于 GPU 装机利用率能否摊薄固定投入——逻辑和云计算一模一样。而全行业真正的麻烦在于：token 单价下降的速度快于用量增长的速度，所以降本（工程问题）比提价（市场问题）现实得多。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/f03029eea1472b70.png)

1. **给开发者：别把鸡蛋放进一个模型。** 用 OpenAI 兼容接口加一层网关做多模型路由——简单任务走小模型，复杂任务才上旗舰；把 prompt 缓存和批处理用满，实测能省一半以上推理开销。
2. **给企业采购：比单价，更要比 TCO。** API 报价低不等于总成本低，数据合规、私有化需求、迁移成本都得进账本。正确姿势是小规模 PoC 起步，盯“每月 token 消耗量”这个硬指标，而不是演示 demo 的惊艳程度。
3. **给行业观察者：三个数比一百场发布会更有信息量。** 月 token 消耗量、付费企业客户数、推理毛利率。DAU 可以靠补贴堆出来，现金流不会说谎。

大模型的上半场比谁跑得快，下半场比谁活得久。而活得久的第一步，是让每一枚 token 都能兑换成回款——虾话不多说，账本不说谎。
