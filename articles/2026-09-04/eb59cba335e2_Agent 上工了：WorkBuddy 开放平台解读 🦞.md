36 氪报道，腾讯 WorkBuddy 开放平台上线，Agent 能力开始向更多工作场景延伸。消息本身不算炸裂，但方向值得拆：大模型卷完参数、卷完对话之后，下一站是“替你干活”。这篇分三层聊——Agent 到底是什么、“开放平台”开放了什么、以及它伸进企业工作场景时会踩到哪些坎。

## 先补课：Agent 和聊天机器人差在哪

很多人把 Agent 理解成“更聪明的客服”，其实差得远。

- **Chatbot**：一问一答，输出止于文本。你问它答，它不碰你的任何系统。
- **Agent**：一个“感知 → 规划 → 调用工具 → 执行 → 反馈”的闭环。LLM 是大脑，Function Calling 是手，Memory 是记性，Planning 是做事的套路。

举个例子：你对它说“把这周三次会议的纪要整理成周报，发给项目组”。Chatbot 会给你一段模板让你自己填；Agent 会真的去读会议文档、抽取待办、生成周报、调 API 发出去——每一步都有工具在跑。

学术界常用的 ReAct 模式（Reasoning + Acting）就是这个思路：模型先想一步、再做一步，看结果、再决定下一步。所以判断一个产品是不是真 Agent，有个朴素标准：**它能不能替你完成“跨系统”的动作，而不只是生成一段话。**

## “开放平台”，开放的是什么

这次的关键词不是 WorkBuddy 本身，而是“开放平台”四个字。这类平台的开放一般分三层：

1. **模型层**：底层接入大模型能力（比如混元），企业可按需选型；
2. **工具与连接层**：通过 MCP 这类协议、插件、API 连接器，让 Agent 能“伸手够到”企业现有系统——OA、CRM、日历、文档库；
3. **构建层**：企业用低代码方式自己搭 Agent，开发者也能把做好的 Agent 上架，供别人订阅使用。

为什么这比“又发布一个 AI 助手”重要？因为**工作场景的长尾太长了**。财务的对账、HR 的入离职流程、销售的客户跟进……官方团队不可能每个都做精。平台化等于让千千万万懂业务的人，帮自己把场景铺满。

历史参照很直白：iPhone 的护城河从来不是触摸屏，而是 App Store。操作系统本身谁都能做，难的是让开发者愿意来。Agent 平台的逻辑一模一样——协议越标准（MCP 干的就是这件事），工具接入成本越低，生态滚动得越快。

## 伸进工作场景：具体能干什么

结合公开信息和企业落地的一般路径，Agent 在办公场景大致覆盖四类活：

- **知识与文档**：跨文档检索、总结、条款比对，本质是 RAG（检索增强生成），把企业私有知识喂给模型；
- **会议与协作**：纪要生成、待办抽取、自动跟进任务状态；
- **数据与分析**：自然语言查数、生成报表初稿，把“问 IT 排期”变成“问 Agent”；
- **流程自动化**：审批流转、周报汇总这类重复性流程的粘合剂。

注意这些场景的共同点：**高频、规则相对清晰、容错成本可控**。Agent 先吃的是“软任务”——出初稿、做初筛、跑流程，人做最后确认。腾讯做这件事有个天然优势：企业微信、腾讯文档、腾讯会议本身就是现成的入口和工具箱，Agent 不用从零建连接。



## 冷思考：企业级 Agent 的三道坎

别被 demo 迷惑，企业级落地有三道实打实的坎：

1. **幻觉与准确率**。周报里错一个数字无所谓，合同里错一个条款就是事故。目前主流做法是 human-in-the-loop 加引用溯源——Agent 给结论时附带出处，人在关键节点复核。
2. **权限与安全**。Agent 拿到企业数据权限，相当于给实习生发了一把万能钥匙。细粒度权限、审计日志、数据不出域，这些是企业采购前的必答题。
3. **ROI 度量**。很多 Agent 项目死在“演示很惊艳，上线没产出”。省下的人时 vs 搭建维护成本，这笔账得算得过来。

再看一眼竞争格局：钉钉、飞书都在做同类平台化。入口之争的本质是生态之争，谁的连接器多、谁的构建门槛低，谁就能把场景滚起来。对用户这是好事，充分竞争总比一家独大强。

## 收尾：三条实用建议

1. **从“高频低险”场景切入**。先让 Agent 干“错了也改得回来”的活——纪要、初稿、数据汇总，别一上来就碰核心决策和对外输出。
2. **选平台看连接器，不看 demo**。能不能接你现有系统、权限模型细不细、日志全不全，这三条比界面炫不炫重要十倍。
3. **把人留在回路里**。Agent 是副驾驶，不是自动驾驶。关键节点人工确认跑上一两个月，准确率稳了再谈放手，这是目前性价比最高的姿势。

一句话收束：Agent 平台化的意义，不是让 AI 会聊天，而是让“会聊天的 AI”终于接上了你的工作台。至于它能接管多少活，取决于生态铺多快——以及你敢给它多少权限。
