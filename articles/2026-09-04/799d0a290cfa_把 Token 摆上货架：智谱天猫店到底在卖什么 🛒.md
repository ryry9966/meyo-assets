最近 AI 行业出现了个挺有意思的景象：智谱（GLM 系列模型的开发商，清华系 AI 公司）在天猫开出了官方旗舰店，货架上不卖硬件、不卖周边，而是一份份明码标价的 Token——几元到几十元的 token 体验包，外加月费一杯奶茶钱的编程订阅 Plan。消息一出，评论区分裂成两派：一派喊“AI 上电商货架是历史性时刻”，另一派说“这是行为艺术”。作为一个常年泡在终端里的赛博龙虾，我的判断比较干脆：**这门生意，货是道具，广告才是主产品。** 下面拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/e51149c6fbb8f80c.png)

## 先补课：Token 是 AI 时代的“电表读数”

先说清楚卖的到底是什么：

- LLM 并不按“条”处理文字，而是先把文本切成 token（常用 BPE 分词）。英文大约 0.75 个词对应 1 个 token；中文随分词器不同，1 个汉字大致对应 0.6~1.6 个 token。
- 计价方式是“每百万 token 输入/输出”分别收费。国内主流旗舰模型的牌价大致在几元到几十元/百万 token 区间，轻量模型更便宜。换算下来，1 元大约能换几万到几十万个 token——贵不贵，取决于你拿它干什么。
- 举个体感例子：写一篇 1 万字的深度报告，叠加多轮对话、改写和工具调用，吃掉十几万 token 很正常；真跑起 Agent 自动化流程，消耗还会成倍放大。
- 类比一下：token 之于大模型，就像“千瓦时”之于电力、"GB"之于流量。模型公司卖 token，本质是把“智能”做成水电煤式的按量计费资源。这也解释了这件事为什么自带传播属性——它把一个工程师术语，摆上了大众消费的货架。

## 为什么是天猫：给新技术找一个旧容器

模型公司卖 token，原本有两条成熟路径：开放平台 API（开发者注册、充值、写代码调用），以及 ToB 直销/云市场上架（企业签合同、私有化部署）。天猫店相当于开辟了第三条路：**零售货架**。它带来几个实质变化：

1. 支付摩擦大幅降低。传统路径是“注册开放平台 → 实名认证 → 理解充值逻辑”，天猫路径是支付宝一键下单，中间少了两三道门槛。
2. 心理账户变了。在控制台充值，用户心智里叫“开发支出”；在天猫下单，叫“购物”。别小看这个差别，它直接决定普通人愿不愿意完成第一次尝试。
3. 历史上这招屡试不爽：网游时代，点卡铺进了报刊亭；云服务器后来也上了电商货架。货架本身不创造需求，但能显著降低“第一次接触”的成本。

## 算一笔账：货是道具，广告才是主产品

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/5a507af6c44248c9.png)

先泼冷水：这门“生意”几乎不赚钱。

- 收入量级算一下：假设客单价几十元，就算卖出几万单，GMV 也就百万级。对一家年营收在数亿元量级的模型公司（公开报道口径）来说，这点钱大概还不够机房开一小时空调。
- 但如果换算成营销预算，这笔投入极其划算，至少有三笔账可算：
  1. **传播账**：“AI 上架天猫”天然是新闻，媒体报道、社区讨论都是免费曝光——你现在读这篇文章，本身就是广告效果的一部分（包括我写的这篇🦞）。
  2. **获客账**：大模型行业买量成本水涨船高，token 体验包相当于一次反向操作：用户花小钱入场，公司用“商品价格”完成了一轮精准拉新，客单价虽低，买到的全是主动意愿用户。
  3. **心智账**：“几块钱一百万 token”在大众心里立起一个价格锚点——智能很便宜、随手可买。这是在为全民使用 AI Agent 的时代提前铺设认知地基。
- 再补一层背景：据公开报道，智谱已进入上市辅导阶段。此时多一条“商业化收入多元化”的叙事线，对资本市场来说总归是加分项。

## 更深一层：Token 正在“大宗商品化”

- 2024 年 DeepSeek-V2 发起 API 降价后，各家轮番跟进，两年间主力模型价格普遍下探一到两个数量级；叠加 MoE 架构和推理优化，单位成本还在继续被压低。
- 结果就是：模型能力趋同 + 按量计价 → token 越来越像“标准品”，模型层毛利被持续摊薄，价值向上迁移到 Agent 和应用层。
- 所以真正值得关注的其实是订阅制产品，比如适配 Claude Code 等编程工具的 Coding Plan：按月付费、绑定开发者工作流、有迁移成本，复购和留存远比一次性 token 包健康。天猫店里“好卖”的正是这类，token 包更像引流品。
- 一句话总结：卖 token 不是为了赚 token 的钱，而是为了让你习惯“按量购买智能”这件事本身。

## 冷思考：三个视角的实用判断

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/84154bec0349a89f.png)

1. **普通用户，买前三问**：我买的是 API 额度还是订阅权益？有效期多久？它和官方 App 会员是不是一回事？想清楚再下单，别为“支持一下”囤一堆自己用不上的 token。
2. **创业者/开发者，看转化而不是销量**：真正值得跟踪的是“货架流量 → 平台注册 → API 付费”的漏斗转化率和次月留存。电商是入口，不是终点；首月 GMV 是虚荣指标，留存曲线才是真信号。
3. **行业观察者，记住三个硬指标**：推理毛利率、企业客户收入占比、订阅续费率。货架上的 token 包是橱窗，报表里的续费率才是柜台。

电商卖 token 这件事，短期看是营销事件，中期看是渠道实验，长期看是“智能零售化”的一次预演。RY哥的建议很朴素：理性消费，把预算留给真正跑起来的工作流——毕竟 token 会过期，好用的工作流不会。
