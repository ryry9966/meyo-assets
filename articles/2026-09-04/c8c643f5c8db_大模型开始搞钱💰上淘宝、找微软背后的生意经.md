大模型行业讲了两年多的"技术叙事"，正在切换成"商业叙事"。据 36 氪等媒体报道，智谱把自家的 API 服务和会员权益搬进了淘宝开店，月之暗面的 Kimi 则被报道与微软推进合作、借渠道出海。两个动作方向不同，指向却是同一件事：烧钱换规模的红利期过去了，收入曲线正在成为新的生死线。这篇就拆一拆——它们为什么选这两个渠道，大模型公司到底靠什么赚钱，以及这件事对普通开发者和企业用户意味着什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/a9dc2e3affe3db24.png)

## 一、两条路线，一个共同信号

先看现象本身：

- **智谱上淘宝**：在电商平台上架 API 调用包、会员服务等"数字商品"，把原本需要商务对接、签合同才能买到的模型能力，变成"搜索—下单—拿到 Key"的货架式购买。目标客户很明确：中小企业、独立开发者和学生党。
- **Kimi 找微软**：月之暗面被报道与微软推进合作，借助微软的云基础设施与企业渠道走向海外。国内 C 端卷不动，就去订阅意愿和客单价更高的市场找增量。
- **共同信号**：两家头部公司同时从"卷参数、卷榜单"转向"卷获客、卷收入"。当融资不再自动续期，商业化就从选答题变成了必答题。

## 二、为什么是现在：成本、融资、价格战三重压力

商业化提速不是巧合，而是三股力量同时收紧的结果：

1. **成本端压顶**。GPT-4 级别的模型，一次训练成本据公开访谈估算超过 1 亿美元；推理成本则随用户量线性上涨——每多一个活跃用户，GPU 账单就多一行。收入不上量，账就算不平。
2. **融资端退潮**。一级市场对 AI 叙事趋于理性，投资人从"看 demo"转向"看 ARR（年经常性收入）和毛利率"。虽然月之暗面 2024 年仍拿到了 10 亿美元级融资，但估值与收入数据的挂钩越来越紧。
3. **价格战绞杀**。2024 年国内 API 迎来降价潮，主力模型价格一度下探到每百万 tokens 几块钱的量级，个别厂商直接宣布旗舰模型免费；同时 DeepSeek、Qwen 等开源模型快速逼近闭源水平，闭源溢价被压薄。当"卖水"的价格被打下来，就必须去找新的水源。

一句话总结：成本在涨、钱在变贵、单价在跌——唯一的出路是把收入盘子做大。

## 三、智谱上淘宝：把 MaaS 当"商品"卖

这套操作的本质，是把大模型服务的**交易成本**打下来。

- **传统 To B 卖 API 的链路**：销售找线索 → 商务对接 → POC 验证 → 合同法务 → 回款，周期以月计，单客获取成本极高。服务一个 5 人小团队的收入，可能覆盖不了对接成本，长尾客户一直是被放弃的。
- **淘宝店的链路**：搜索看到 → 下单付款 → 拿到 API Key → 旺旺当客服。把"项目制"变成了"货架制"，交易周期从月压缩到分钟。
- **算一笔账**：一单几十上百元的 API 包，利润薄得像纸，但获客成本接近于零——蹭的是平台的自然流量和搜索心智。真正的价值在于：用极低门槛筛出种子用户，其中总会有人长成下一个大客户。
- **风险也直白**：电商是价格透明的地方，比价文化会进一步压缩毛利；能不能留住复购，最终还是要回到模型本身的产品力。

这就像云计算早年从"卖关系"走向"官网自助开通"，电商只是把自助化又往前推了一格。



## 四、Kimi 找微软：借船出海的渠道杠杆

- **为什么要出海**：ChatGPT Plus 每月 20 美元的订阅被市场验证过，海外 C 端付费意愿和企业预算都更充足；而国内 C 端订阅单价低、转化难，长文本的差异化窗口又在被同行快速追平。
- **微软手里有什么**：Azure 的全球算力网络、覆盖大型企业的销售体系、成熟的合规框架，以及 Office 这样的超级入口——微软自家 Copilot 靠 Office 渠道卖出每人每月 30 美元，就是渠道杠杆的教科书案例。
- **历史参照**：中国应用出海借 Google Play 和 App Store 的分发，电商卖家借 Amazon 的流量，逻辑一脉相承——用一部分分成，换一张成熟的信任与渠道网络。
- **挑战同样明显**：与 OpenAI 同台竞技、GDPR 级别的数据合规、品牌信任从零起步，每一项都是硬仗。

## 五、商业模式全景：大模型的四种赚钱姿势

把视野拉远，目前大模型公司的收入结构大致有四类：

1. **C 端订阅**：会员、增值功能。免费转付费的比例通常只有个位数百分比，胜负手在用户规模。
2. **API / MaaS**：按量计费。规模效应最强，但正被价格战挤压毛利，拼的是推理成本控制和工程效率。
3. **私有化部署与行业方案**：金融、制造、政企买单，客单价从几十万到数千万，但交付重、周期长、难复制。
4. **渠道与生态分成**：手机厂商预装、办公套件嵌入、出海借道巨头，本质是让渡一部分利润，换取规模和信任背书。

参考坐标：据外媒报道，OpenAI 2024 年营收约 37 亿美元、主要来自订阅和 API，但预计亏损仍高达数十亿美元。这说明收入规模 ≠ 商业健康，毛利率和收入结构才是更诚实的指标。

## 六、三条冷思考

1. **给选型的人**：评估模型别只看榜单，用"单位任务成本 × 稳定性 × 生态配套"算总账。电商化和渠道开放让小规模试用变得空前便宜——先拿 1% 的流量灰度验证，再决定迁移，是当下性价比最高的姿势。
2. **给从业者**：商业化浪潮会把需求从"训练大模型的人"外溢到"把模型卖出去、跑起来的人"。解决方案架构师、推理优化、定价与增长，这些岗位的窗口正在打开。
3. **给观察者**：融资额和参数规模是最容易被放大的叙事，订阅占比、复购率、毛利率才是值得盯的硬指标。渠道是加速器，不是护城河——真正的护城河，是持续下降的单位成本和滚起来的数据飞轮。

大模型从"讲故事"走进"做生意"，未必更性感，但一定更真实。
