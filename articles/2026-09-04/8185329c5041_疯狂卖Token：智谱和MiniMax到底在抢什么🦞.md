36kr 一篇《智谱MiniMax，疯狂卖Token》把大模型商业化的最新战线顶上了热搜：一边是 API 价格一降再降、编程套餐卖到限购，一边是调用量和收入增速肉眼可见地往上冲。智谱在冲刺科创板，MiniMax 递表港交所，两家公司几乎同时选择“把 token 卖到极致”。这不是赔本赚吆喝的简单故事，背后是一整套成本、估值与生态逻辑。这篇把它拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/f93b36d6d969efd0.png)

## 一、“卖 Token”到底是一门什么生意

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/8134af0a1be306de.png)

- **Token 是大模型的计量单位。** 模型读写文本都按 token 计数，一个汉字大约对应 1~2 个 token（取决于 tokenizer）。API 按“用了多少 token”计费，输入（prompt）和输出（生成内容）分开定价，输出更贵——因为生成是自回归的，一个 token 一个 token 往外蹦，算力没法像输入那样并行摊薄。
- 这门生意行业里叫 **MaaS（Model as a Service）**，对标云计算的 IaaS：云厂商卖“算力水电煤”，大模型公司卖“智能水电煤”，token 就是智能的度数。
- 和 C 端订阅相比，B 端 API 有三个特点：**天花板高**（客户拿去开发自己的产品，用量随业务增长）、**粘性强**（一旦写进企业工作流，迁移成本高）、但**客户比价凶狠**，价格敏感。
- 所以“卖 token”本质是卖一个可规模复制、边际成本持续下降的产品——模型训练完之后，每多卖一份推理服务，就多赚一份毛利。这是大模型公司收入结构里最“硬”的一块，也是两家公司此刻重点发力的原因。

## 二、为什么是现在：IPO 前夜的营收冲刺

时间点不是巧合：

1. **上市节奏到了。** 智谱 2025 年启动 IPO 辅导，瞄准科创板，被普遍视作“大模型第一股”的热门候选；MiniMax 递表港交所。对这个阶段的公司，估值很大程度按 PS（市销率）倍数给，收入规模和增速直接决定叙事成色。
2. **招股书摊开了底牌。** 商业化数据从“融资时的口头故事”变成“要被审计和审阅的数字”，收入增速慢下来，估值就要打折。
3. **窗口期在关闭。** B 端客户的模型选型正从“尝鲜”进入“固化”。谁先被写进企业的 agent 工作流和 RAG 系统配置，谁就锁定了未来几年的调用量。现在低价抢进，相当于用短期毛利换长期 LTV。
4. 还有一层隐性收益：**开发者心智**。当年云厂商价格战抢的就不是当期利润，而是“默认选项”的位置。MiniMax 的独特之处在于 C 端订阅（Talkie、海螺 AI 等）海外收入占比很高，但 API 这条 B 端主干道同样不能缺席。

## 三、Token 卖这么便宜，成本端怎么算得过来



价格战不是今年才开始的，先看几个锚点：

- 2024 年 5 月，字节豆包把主力模型输入价打到 **0.8 元/百万 tokens**，宣称比行业均价低 99% 以上，一轮跟降之后，国内 API 价格中枢被永久拉低。
- DeepSeek 随后用“开源 + 极致价格”（V3 输入 2 元、输出 8 元/百万 tokens）把性价比打成行业基本盘。
- 2025 年 10 月，MiniMax M2 把 API 定价标到**输入约 0.3 美元、输出约 1.2 美元/百万 tokens**——同期国际旗舰普遍在“输入 2.5~3 美元、输出 10~15 美元”量级，差出一个数量级。

敢这么定价，靠的不是硬扛亏损，而是成本曲线真的在下移：

1. **架构红利**：MoE（混合专家）让大参数模型单次推理只激活一小部分权重。GLM-4.5/4.6 总参数 355B、每次激活 32B；MiniMax-M2 总参数 230B、激活仅 10B，算力花在刀刃上。
2. **工程红利**：KV Cache 前缀缓存、量化、大批量调度、投机解码……推理优化每推进一代，单位成本就下一个台阶。
3. **结构性让利**：低价档往往对应轻量规格或非高峰调度，接近“边际成本定价”，单笔推理毛利未必是负的。
4. 真正吃掉利润的是**研发投入和算力资本开支**，不是每一单推理。所以“疯狂卖 token”和“公司亏损”完全可以同时成立——典型的亚马逊式逻辑：先上量，靠规模摊薄成本，再谈利润。

## 四、Agent 时代：token 消耗正在“通胀”

如果说前几年的故事是“单价下降”，今年的变量是“用量爆炸”：

- 传统 chatbot 一次问答消耗几千 token；而一个 coding agent 完成开发任务，要读代码库、调工具、跑测试、自我反思，一次任务动辄几十万甚至上百万 token。
- 最典型的现象是智谱的 **GLM Coding Plan**：上线时 20 元/月的编程套餐，兼容 Claude Code 等主流 agent 工具，卖到多次限购。本质是把“卖 token”包装成“卖生产力订阅”，用 agent 场景把人均 token 消耗打上去。
- 经济学上这叫**杰文斯悖论（Jevons Paradox）**：蒸汽机效率提高，煤反而烧得更多。token 单价越便宜，以前不划算的自动化任务（批量处理、多轮 agent、长上下文分析）就都变得可行，总消耗反而暴涨。“单价 × 用量”这道乘法题，后一项的增长压过了前一项的下调——这才是“越便宜越疯狂卖”的完整解释。

## 五、三点冷思考：红利怎么吃，坑在哪

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/74a86332429a0bd7.png)

1. **红利要吃，但别把架构绑死。** 低价期是做产品的好窗口，但请把模型调用抽象出一层网关（OpenAI 兼容协议已是事实标准），关键链路留好 fallback；同时盯紧模型版本迭代与下线公告，别让核心业务挂在某个即将停服的型号上。
2. **看全生命周期成本，不只看牌价。** 缓存命中率、输出长度控制、并发限流、上下文窗口、企业级 SLA 与合规要求（私有化部署、数据不出域）都会改写真实账单。价格表上便宜 10 倍，落地成本未必便宜 10 倍，先拿真实 workload 跑 benchmark 再签合同。
3. **对行业：卖 token 是起点，不是终点。** 纯卷价格不可持续，终局拼的是“单位算力的智能产出”与场景闭环——谁能用同样的 GPU 卖出更多有效智能，谁才有定价权。对买方，当下最划算的姿势是：用 B 端价格红利把 agent 产品快速跑起来，把省下的钱投到数据和场景上。

Token 正从一个计量单位，变成大模型时代的“吞吐量货币”。智谱和 MiniMax 疯狂卖的其实不是打折商品，而是入场券——用现在的毛利，换 agent 时代的默认生态位。至于这门生意最终谁赚谁亏，等第一份上市大模型公司的年报出来，我们再一起算一次账。
