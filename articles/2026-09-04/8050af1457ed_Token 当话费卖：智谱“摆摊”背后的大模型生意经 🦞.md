过去想用上大模型，你得去开发者平台注册账号、读文档、写代码调 API；现在，智谱把 GLM 系列模型的 token 打成充值套餐，直接摆上了天猫货架，选套餐、付款、到账，体验和充话费一模一样。36kr 把这形容为“上天猫摆摊”。摆摊只是姿态，真正值得琢磨的是：token 这个抽象的计量单位，正在被当成话费一样的日用品，进入大众消费的货架时代。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/96bdd9b02d4631fb.png)

## Token 是什么：AI 界的“度”和“分钟”

- **最小计价单位**：大模型并不直接“读”文字，而是先用 tokenizer 把文本切成一个个 token（主流方法是 BPE，字节对编码）。粗略换算：英文 1 个 token ≈ 0.75 个单词；中文因分词器而异，一般 1 个汉字折 0.7~1.5 个 token。
- **为什么按它收费**：模型推理的边际成本——GPU 算力、显存带宽、电费，随处理 token 数近似线性增长。token 是可精确计量、可公开定价的最小单元，天然适合当“计价单位”。
- **类比电信和电力**：话费按分钟、流量按 GB、电按千瓦时，AI 按 token。输入和输出分别计价，输出单价通常更高；推理型模型（reasoning model）的“思考过程”同样消耗 token，照常计费。
- 所以“token 当话费卖”并非新发明——OpenAI 从 2020 年开放 GPT-3 API 起，就是按 token 计价。真正的变化在于收费场景：从开发者后台，搬到了电商货架。

## 去“货架”上卖 token，图的是什么？

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/8befc4eca453f971.png)

算三笔账就清楚了：

1. **获客账**。开发者平台有一整套门槛：注册、实名、生成 API key、预付费充值，足以劝退大量轻量用户。天猫店意味着支付宝一键下单、付款即到账，把“路过的好奇者”低成本转化成试用者。
2. **现金流账**。预充值等于先收钱、后服务，和话费、油卡是同一个逻辑：改善现金流，还天然提升留存，余额没花完，用户就懒得换厂商。
3. **心智账**。模型能力进入电商货架，等于宣告 token 是日用品而非极客玩具。这与英伟达近年把 AI 数据中心称作“token 工厂”的叙事一脉相承：AI 服务正在公用事业化。预付费换折扣在云计算行业早有先例，AWS 的 Savings Plans、国内云厂商的“资源包”，本质都是同一套玩法。

## 价格战两年：从“用不起”到“值得摆摊”



摆摊的底气，是两年价格战打出来的：

- 2024 年 5 月，字节跳动把豆包主力模型的输入价打到 0.0008 元/千 tokens（合 0.8 元/百万）；阿里云随即宣布 Qwen-Long 降价 97%，至 0.5 元/百万 tokens，各家迅速跟进。主力模型单价两年内下降了 1~2 个数量级。
- 2025 年，DeepSeek 用开源加极低 API 价格进一步搅局；智谱自己也发布了 GLM-4.5——总参数 355B、激活 32B 的 MoE 架构，MIT 协议开源，并长期提供免费的 GLM-4.5-Flash 档位。
- 当“一百万 token”便宜到个位数人民币，零售化的最小交易额才成立。就像流量便宜到按 G 卖之前，没人会开“流量超市”。货架上的低价套餐，是成本结构先降下来的结果，不是营销噱头。

## 套餐制与订阅制：两条商业路线的分野

- **订阅制**（ChatGPT Plus、Claude Pro 这类 C 端会员）：固定月费、上手简单，适合高频对话用户；但重度用户会“吃穿”成本上限，厂商要么限流、要么贴钱。
- **计量制**（按 token 付费）：对用量波动大的开发者和 Agent 场景更公平。一个 Agent 挂机跑一晚上，消耗千万级 token 很常见，订阅制兜不住，计量制才对得上。
- **套餐制**是折中方案：用折扣换预付锁仓。用户拿到确定性折扣，厂商拿到确定性现金流——这正是电信行业验证了几十年的模型，现在被搬进了大模型行业。

## 三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/b5877ba3c36f2b02.png)

1. **算“到手单价”，别看包装**。下单前把套餐折算成“每百万 token 多少钱”，分清输入/输出价差、思考 token 是否计费、套餐是否限定模型版本；再按你的任务量换算——比如一次带检索的问答通常消耗几千 token，估算能跑多少次。
2. **先免费跑通，再付费囤量**。用免费档（如 GLM-4.5-Flash）或开源自部署验证工作流，估出月均消耗，再选套餐档位。记住：预充值是被厂商锁定的预付款，中途换模型，余额就是沉没成本。
3. **省 token 比买 token 更值**。控制上下文长度、裁剪检索内容、用 prompt caching 复用前缀、限制 max_tokens，Agent 场景里大头消耗往往来自重复上下文和思考冗余，工程手段省下的钱常常超过套餐折扣。

从“百模大战”到“货架时代”，token 零售化标志着大模型正在变成水电一样的基础商品。对用户是好消息：可以像比话费套餐一样货比三家；对厂商是新考题：当 token 成为大宗商品，竞争将回到毛利、留存与生态。下次在电商货架看到“充 token”的套餐，你会知道，那背后是一个行业的定价方式，正在完成大众化的最后一跃。
