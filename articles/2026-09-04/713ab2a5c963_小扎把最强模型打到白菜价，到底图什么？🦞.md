最近的科技热搜里有条消息火药味十足：Meta 发布了迄今最强的 Llama 系列模型，第三方托管价格直接卷到同行零头，官方 benchmark 表格里把 Gemini、GPT 逐项对标，媒体形容为“贴脸开大”；标题里还提到“北大校友立大功”。这篇文章把三层问题拆开讲：Meta 到底放了什么？免费和白菜价背后的商业账本是什么？以及“人才”那条线，该怎么理性看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/b7b97804ee16e10c.png)

## 一、先把事实捋清楚：Meta 放出来的到底是什么

按时间线看 Meta 这几年的开源牌：

- 2023 年 7 月，Llama 2 开放权重并允许商用，第一次把“能自部署的强模型”摆上货架；
- 2024 年 7 月，4050 亿参数的 Llama 3.1 405B 发布，被称为第一个开放权重的 frontier 级模型；
- 2025 年 4 月，Llama 4 Scout 与 Maverick 登场：原生多模态 + 混合专家（MoE）架构，Scout 号称支持 1000 万 token 上下文；更大的 Behemoth（总参数约 2 万亿）预告中。

价格卷到什么程度？以下是第三方托管平台的大致报价（单位：每百万 token）：

- GPT-4o：输入约 $2.5，输出约 $10；
- Llama 4 Maverick：输入约 $0.27，输出约 $0.85，Scout 更低；
- 自己买卡部署，还能再往下压。

同级能力下，价格差出一个数量级。另注意一个细节：Meta 的“开源”严格说是 open weights（开放权重），license 里留了口子——月活超 7 亿的产品需要单独谈授权。免费是真的，主导权也确实在 Meta 手里。

## 二、价格战的账本：模型是商品，还是获客工具？

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/61ca61920dc58bda.png)

Meta 敢这么打，根子在商业模式不同：

- OpenAI 靠 API 和订阅直接赚钱，模型本身就是商品，定价是生命线；
- Google 广告为主，但云业务和 Gemini 生态都要靠模型撑门面；
- Meta 的主业是广告，模型对它是基础设施 + 获客工具，而不是收入来源。

于是整套逻辑链变成：

1. 开放权重 → 全球托管商互相卷价格 → 推理成本被市场打下来；
2. Meta AI 助手嵌进 WhatsApp、Instagram、Messenger 这个月活合计 30 亿以上的 App 矩阵，用极低成本铺开 AI 入口；
3. 用户停留更久、广告投放更精准，广告收入把训练成本赚回来；
4. 副作用更狠：对手的 API 没法卖贵——货架上永远摆着一个“免费、可自部署”的替代品。

这套打法在软件业有经典出处：把互补品变成大路货（commoditize your complement），让自家核心资产更值钱。Android 之于手机系统、Chrome 之于浏览器，都是同一个剧本。叠加 DeepSeek 等低成本模型已把行业 API 价格整体打下来的大背景，Meta 等于顺势把桌子掀了。

## 三、白菜价的技术底座：MoE、长上下文和蒸馏

价格战打得起，前提是推理真的便宜了，背后是三项技术：

- **MoE（混合专家）**：Maverick 总参数约 4000 亿，但每个 token 只激活约 170 亿参数，成本近似只跟激活量挂钩——相当于“大模型的容量，小模型的开销”；
- **超长上下文**：Scout 号称 1000 万 token 上下文，检索类任务可以一次读完全部资料，省掉多轮调用和 RAG 拼接；
- **蒸馏（distillation）**：用大模型当老师教小模型，把能力压进低成本小模型。这也是开放权重让闭源阵营紧张的原因——任何人都能拿它蒸馏出自家模型。

结果就是行业竞争维度变了：从“谁的模型最强”变成“每美元能买到多少智能”（intelligence per dollar）。顺带一个翻车提醒：Llama 4 发布时，官方跑分用的“实验版”与实际放出的权重并不一致，榜单方后来修改了规则。跑分可以看，但一定要问清楚测的是哪个版本。

## 四、“北大校友立大功”：理性看人才这条线

多家媒体统计过 Llama 系列技术报告的署名名单：核心作者中华人研究者占比相当高，其中不乏本科出自北大等国内高校的学者，热搜里那句“立大功”即源于此。与其感叹个体，不如看懂背后的结构性原因：

1. 国内理工科教育体量大，数学与编程基本功扎实，AI 顶会论文中华人作者占比常年领先；
2. 头部实验室的算力、薪酬和自由研究文化，持续吸引全球人才流动；
3. 开源时代，顶会论文和 GitHub 记录就是简历，个人贡献能被全世界看见。

客观地说，AI 竞争的本质是“人才密度 × 算力密度”的乘积，人才流动本就是全球产业分工的一部分。真正值得关注的不是某个人来自哪所学校，而是：谁能源源不断地供给高质量研究者，谁就握着长期筹码。

## 五、收尾：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-04/5e489056ea770cf5.png)

1. **免费 ≠ 零成本。** 开放权重意味着推理、微调、合规的成本自己扛。选型先算 TCO：调用量小直接用托管 API；日均 token 上到一定规模，再评估私有化部署的回本点；
2. **别被跑分绑架。** 官方 benchmark 只是一个切面，用自己业务的真实数据做 50~100 条小评测，比盯榜单靠谱得多，还能顺便摸清模型的长短板；
3. **把降价当红利。** 推理价格一年降一个数量级已是行业趋势，产品护城河应建在数据、场景和分发上——赌“某家模型永远不被追平”，是这个行业里最不稳的一张牌。

价格战打到白菜价，受益的是所有把 token 当原材料的人。至于 Meta 图什么？图的是让“智能”变成水电煤——而它自己，继续守在水电站旁边卖广告位。
