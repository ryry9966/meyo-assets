最近 AI 圈有个不大不小但值得琢磨的信号：MiniMax 传出的新动作，不再是押注一个“超级应用”，而是把重心转向开放平台，卖 token。很多人第一反应是：模型公司不做 C 端产品了？更准确地说，是 AI 商业化开始从“抢入口”转向“卖智能容量”。这背后不是一家公司的忽发奇想，而是模型成本、开发者需求和企业付费意愿一起推动的路线切换。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-28/9bd60a96f32fe2fc.png)

## 先搞清楚：Token 到底在卖什么

Token 不是“字”，也不是“词”，而是模型处理和计费的最小单位。它更接近电表上的度数，或者出租车的里程。

- 模型看到文本时，会先用 tokenizer 把句子切成一串 token，再映射成词表中的 ID。BPE、WordPiece 这类算法会把高频词保留，低频词拆成子词。
- 中文的切分并不固定：同一个汉字，在不同模型里可能被切成 1~3 个 token。英文单词通常也会被拆成 1~2 个 token。
- 调用 API 时，输入 prompt 和输出 completion 都按 token 计费。输出一般更贵，因为生成是串行 decode，推理资源占用更高。
- 上下文长度会显著影响成本。长上下文会让 KV cache 显存占用快速上升，所以“每百万 token 单价”不等于最终账单。

换句话说，卖 token 本质上是把模型能力拆成可计量、可调用的标准单位。这让 AI 从“产品”变成“原材料”。

## 超级应用 vs 卖 Token：两条路线

超级应用和卖 token，背后是两套完全不同的商业逻辑。

- 超级应用逻辑：一个 App 尽可能吃掉用户所有需求，形成入口、数据、网络效应。它像“建商场”：先聚人流，再收租金、卖增值服务。
- 卖 Token 逻辑：把模型封装成 API，按调用量收费。它像“开电厂”：不管用户用空调还是开工厂，按度结算，不关心具体场景。
- MiniMax 之前做过一批面向 C 端的对话、陪伴类产品，在海外也有一定声量。但 C 端留存和生态壁垒并不天然，尤其是助手类产品，用户用完即走。
- 两条路线对组织能力的要求不同：超级应用重产品、运营、增长和内容生态；卖 Token 重推理成本、稳定性、开发文档、客户支持和定价体系。

移动互联网的超级应用是微信、支付宝、美团；生成式 AI 时代是否会出现新的 super app，一直有争论。MiniMax 的转向，等于暂时把筹码从“一定会出现”挪到了“先赚确定性的钱”。

## 为什么 MiniMax 改卖 Token？

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-28/7f04bfe09ab86540.png)

这不是一句“不做 C 端了”那么简单，有几个更实际的原因。

1. 超级应用投入大、周期长。C 端产品需要长期买量、运营、做留存，但模型能力迭代太快，产品体验很容易被基础模型追平。
2. AI 助手和陪伴类产品缺乏强网络效应。用户换一个聊天工具的成本很低，不像微信有社交关系链沉淀。海量用户不等于护城河。
3. 企业侧付费意愿更明确。客服、营销、代码辅助、知识库、Agent 等场景都有真实预算，客户关心的是效果和成本，而不是是否多一个 App。
4. Token 现金流更直接。按量计费，客户开通即可产生收入，不用先砸钱买用户、等规模效应。
5. 模型能力提升后，API 可以覆盖越来越多场景。“卖水”虽然不一定性感，但比“孤注一掷挖金矿”更稳。

这也是当前大模型创业公司普遍面临的商业化压力。融资环境从看故事转向看收入，开放平台是更快的收入证明。

## 卖 Token 的账怎么算？

卖 token 看起来简单，但收入和成本两端都有很多细节。

- 收入端：一般分为输入 token 和输出 token，输出单价往往是输入的 2~4 倍。多模态、语音、嵌入等能力还可能按不同单位计费。
- 成本端：GPU 采购或租赁是大头，推理优化决定毛利。量化、蒸馏、MoE、批处理、KV Cache 优化，都会直接影响单位 token 成本。
- 单任务成本公式：`输入 token 数量 × 输入单价 + 输出 token 数量 × 输出单价`。开发者在估算时，输出长度往往是容易被低估的变量。
- 长上下文的成本不是线性的。一个 128K 上下文的请求，KV cache 显存占用可能比 4K 高一个数量级，所以“长上下文很便宜”要谨慎判断。
- 价格战之下，低价 token 不等于综合成本低。并发上限、限流、错误率、安全合规、服务等级，都会成为隐性成本。

所以，卖 token 并不是没有门槛的生意。真正能活下来的，是推理成本和模型能力同时领先的厂商。

## 冷思考与实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-28/6199a218e16a823e.png)

超级应用和卖 token 其实并不完全对立。未来的 AI 入口可能不是一个大而全的 App，而是被 Agent 化、插件化，嵌入到现有软件和流程里。对普通人来说，感知只是 AI 功能跑进更多产品里，入口反而更分散。

最后给三条务实建议：

1. **开发者先算单次任务 token 量**。不要只看每百万 token 标价，先把典型任务的输入和输出平均 token 数测出来，再倒推月账单。
2. **企业选模型要做综合压测**。并发能力、时延、错误率、安全合规和数据隔离，往往比单价更影响业务结果。
3. **判断一家模型公司，别只问有没有超级应用**。开放平台收入占比、推理毛利率、开发者生态和客户留存，才是更硬的口碑。

AI 这行，热闹的口号很多，但能让客户按 token 持续付费的，才算真正跑通了商业闭环。
