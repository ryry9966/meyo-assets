上周，DeepSeek Harness 团队负责人崔添翼在海外社交平台 X 上发了一条直球帖：**团队严重缺人，每天都在面试，各处贴小广告，仍然填不满坑位。**

这不是普通的 HR 发布岗位，而是技术负责人亲自下场 Boss 直聘——一个手握 6 枚 ACM 亚洲区域赛金牌、在 Jane Street 待了 9 年、后联合创办量化公司的硬核选手，现在每天的工作是面试。

这件事本身就值得聊聊。

## 先搞清楚一个概念：Harness 是什么

很多同学看到 "Agent Harness" 这个岗位名称会一脸问号——Harness 不是驯马的意思吗？

在大模型语境下，**Harness 指的是「模型驾驭层」**——它是连接底层大模型和上层 Agent 产品之间的中间件。DeepSeek 内部的公式写得很直白：

> **Model + Harness = Agent**

举个具体例子：你用 Claude Code 写代码，它能自动读文件、调终端、跑测试、修 bug。Claude 本身只是一个语言模型，**让它变成一个能动手干活的 Agent 的那套机制——上下文管理、工具调用、记忆系统、多智能体协作——就是 Harness。**

所以 DeepSeek 在做的事情，用大白话说就是：

- 模型层已经有了（V4 已发布，还专门针对 Agent 场景做了优化）
- 现在要做的，是**把模型能力包装成一个能打的产品**
- 这个产品对标的是 Anthropic 旗下的 Claude Code

简单说：**上半场大家在卷模型，下半场开始卷 Agent 产品化。** DeepSeek 正在从研究型实验室转型为产品型公司，这个转折点上，人是最稀缺的资源。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-06-23/c3bd08e7a9c12830.jpeg)

## 三类岗位，每一类都指向同一个方向

崔添翼明确说了，团队长期开放三类核心岗位。我们逐个拆解看看它们到底在招什么样的人。

### 1. Agent Harness 研究员

- 2 年以上计算机科学相关科研经验（特别优秀可放宽）
- 硕士及以上学历
- 深耕方向：多智能体协作、长期记忆、超长上下文管理
- 要求有顶会论文发表（含金量得硬）
- 熟悉 LLM + Agent 的底层机制：KV Cache、Agent Loop、Tool Use、MCP、Subagent 等
- 需要能从 0 到 1 独立推进研究并快速产出原型

**翻译一下：** 这不是普通的算法研究员，而是要「既能发论文，又能写代码，还能定义问题」的三栖选手。

### 2. Agent Harness 研发工程师

- 负责将前沿研究工程化落地
- 稳定支撑桌面端 Agent 产品的迭代
- 核心要求：深度使用 AI Agent 工具（Claude Code、Cursor、Copilot 等），并且把它融入日常工作
- 对开发者体验有强感知

**关键词：** 不是只会写代码的码农，而是要把研究变成产品的工程师。

### 3. Agent Harness 产品经理

- 仅招全职，2 年以上产品经验
- 需深度使用多款海外主流 Agent 工具（Claude Code、Codex、Cursor、Manus、OpenClaw 等）
- 兼顾技术理解和国内开发者需求洞察
- 协助定义产品技术架构与选型

**注意：** 这个岗位的要求里没有写「会画原型图」，而是写了「深度使用 Agent 工具并融入工作和生活」。**换句话说，DeepSeek 要的是自己就是重度用户的产品经理，不是只会写 PRD 的那种。**

三类岗位指向一个共同结论：**DeepSeek 需要的是「算法 + 工程 + 产品」的复合型人才。** 这种人在行业里本来就稀缺，而 Agent 赛道的爆发让供需缺口急剧放大。

## 为什么是现在？时间窗口背后的逻辑

DeepSeek 的着急不是无缘无故的。梳理一下时间线就能看明白：

- **2026 年 3 月**：崔添翼加入 DeepSeek，挂帅 Harness 团队负责人
- **2026 年 3 月 25 日**：首批 17 个 Agent 相关岗位上线
- **2026 年 4 月**：DeepSeek V4 预览版发布，专门针对 Claude Code 等 Agent 工具做了优化
- **2026 年 5 月**：崔添翼开始在 X 上公开摇人
- **2026 年 6 月**：Harness 研究员岗位上线，招聘力度持续加码
- **同期**：据 The Information 报道，DeepSeek 完成了首轮超 500 亿元人民币（约 74 亿美元）的外部融资

几个关键信号拼在一起：**钱到位了、模型准备好了、产品方向确定了，现在差的就是人。**

再看竞争格局：

- **国内**：字节跳动的 Trae、阿里的通义灵码、腾讯的 CodeBuddy、百度的文心快码——Agent 编程赛道已经是红海
- **海外**：Anthropic 的 Claude Code、OpenAI 的 Codex——这些产品的 Harness 团队规模和迭代速度都远超国内
- **市场数据**：全球 AI 编程工具市场 2025 年规模约 296 亿美元，预计 2030 年增长至 647 亿美元（CAGR 约 17%）

**这不是要不要做的问题，是再不做就来不及的问题。**

## 「外国人也要」到底是什么意思

社交媒体上有人传 DeepSeek 不招外籍人员。崔添翼专门做了澄清：

> "就像同类型的美国公司要求员工能够用英语工作一样，DeepSeek 也要求员工能够用中文工作。并没有规定禁止聘用外国人。"

翻译过来就是：**不是不招外国人，是要求能用中文工作。**

这个要求其实很合理——

- Harness 团队需要深度参与产品开发全流程，沟通成本是核心考量
- 国内开发者的需求洞察、用户社群维护、竞品分析都需要中文语境
- 这和硅谷公司要求英语工作是同一个逻辑，只是换了个语言方向

**但这个澄清本身也透露出一个信号：** DeepSeek 的视野已经不局限在国内人才池了。当一家公司开始讨论「要不要招外国人」的时候，说明它的业务触角已经足够长，长到需要跨语言、跨文化的人才来支撑。

## 一个容易被忽略的细节：防挖人条款

在公开招聘的另一面，DeepSeek 还在做一件反向的事——**把人留住。**

据 The Information 等外媒报道，DeepSeek 在首轮超 500 亿元融资中向投资方提出了「禁挖人」条款：

- 投资方不得从 DeepSeek 挖走员工
- 不得资助 DeepSeek 员工独立创业
- 把「禁挖人」写进了投资协议

**一边疯狂招人，一边堵住人才流失的口子。** 这种「开源 + 节流」的人才策略，说明 DeepSeek 很清楚：在 Agent 这个赛道上，挖走一个人可能比招到一个人的损失更大——因为 Harness 领域的人才本就极度稀缺，培养一个需要大量时间和实战积累。

## 冷思考：三个值得留心的问题

最后，作为一个长期关注 AI 赛道的观察者，提三点冷静的思考。

**第一，复合型人才的供给不会因为需求增加而快速放大。**

DeepSeek 要的是「研究 + 工程 + 产品」三位一体的人，但国内高校培养体系是分轨的——搞研究的不做工程，做工程的不碰产品，做产品的不懂算法。这个人才缺口不是多开几个招聘岗位就能填上的，需要整个行业的人才培养模式跟上。

**第二，Harness 的产品化落地比模型训练更难。**

模型训练是确定性更高的工程——数据、算力、训练策略都有相对成熟的范式。但 Harness 产品化要面对的是用户需求的模糊性、开发者体验的细节打磨、竞品之间的差异化——这些是「软功夫」，需要时间和用户反馈来迭代，急不来。

**第三，500 亿融资的「禁挖人」条款是一把双刃剑。**

留住了人，但也意味着投资方的资金流动性受限。如果 Agent 赛道的窗口期比预期短，DeepSeek 可能面临「钱够但人不够」和「人够但窗口已过」的双重风险。

**总结一句话：** DeepSeek 的这次大规模招聘，本质上是中国 AI 产业从「模型竞赛」转向「产品竞赛」的一个标志性事件。谁能最快组建起一支既懂研究又懂产品的复合型团队，谁就能在 Agent 时代的起跑线上抢到先机。

而 DeepSeek 正在告诉我们：**这个先机，现在还差人。**
