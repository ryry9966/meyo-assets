最近一条来自考古语言学圈的消息在技术社区里转得很欢：有研究团队用 Claude Code 辅助破译了一种沉睡 3500 年的古代语言文字，被一些媒体称为「74 年来最大的考古语言学突破」。标题党味道有点冲，但抛开夸张修辞，这件事背后的方法论确实值得拆开来看一眼——大模型到底是怎么参与到这种「冷门到极致」的工作里的，它解决了什么、又没解决什么。

## 死语言到底「死」在哪里

聊破译之前，先把「死语言」这个概念说清楚，不然容易把它和「失传方言」「小众语种」混为一谈。

- **没有母语者**：拉丁语、古埃及语、苏美尔语、赫梯语都属于此类。没人把它当日常交流工具，意味着没有「直觉」可以校验。
- **文字载体稀缺**：能流传下来的，大多是刻在泥板、石碑、莎草纸上的零碎文本，且常有破损。一种语言可能只剩几百到几千条铭文样本。
- **语料极度不平衡**：现代英语语料动辄上万亿 token，而像古埃兰语这种死语言，全部已知文本拼起来可能也就几十万词，相当于一本中等厚度的小说。
- **缺乏「对照本」**：罗塞塔石碑之所以传奇，是因为它同时刻了古埃及圣书体、世俗体和古希腊文，相当于现成的「平行语料」。绝大多数死语言没有这种运气。

这就是死语言破译的根本困境：**样本少、噪声大、没有 ground truth**。任何一种 ML 任务，遇到这三条都会头疼，何况是组合在一起。

## 大模型在这件事里到底干了什么

这次被报道的工作流程，从公开信息看，大致可以拆成几层。说「Claude Code 破解了死语言」其实是简化叙事，更准确的说法是：**研究者把大模型作为一个可编程的语言学助手嵌入到了破译 pipeline 里**。

具体的环节包括：

1. **符号聚类与拆分**：楔形文字一类的文字，单个符号既可能是音节、也可能是表意符。大模型被用来辅助判断哪些符号组合可能是固定词、哪些是变形后缀。
2. **跨语言比对**：把已知的近亲语言（比如同语系的其他古语）作为参照，让模型尝试发现规则性的音变、词根对应。这本质上是一个「带先验的对齐任务」。
3. **假设生成与打分**：传统做法里，语言学家手工提出假设，再去文本里验证，慢且容易陷入局部最优。大模型可以一次生成几十种可能的解读，并配合脚本去全语料里检索一致性证据。
4. **代码化验证**：这是 Claude Code 出场的关键。研究者不是把泥板照片丢给模型让它「看图说话」，而是写脚本——清洗转写文本、做频次统计、跑形态切分、对比候选词典。模型既写代码也读代码结果，形成一个闭环。

换句话说，大模型在这里扮演的不是「天才破译者」，而是一个**永不疲倦、能同时跑出几百种语言学假设的研究助理**。最后拍板的依然是人类专家。

## 为什么传统方法卡了几十年

那个「74 年」的说法，对应的大概是这种语言最近一次实质性进展的时间。死语言破译为什么慢？不是研究者不努力，是问题本身的结构决定的。

- **组合爆炸**：一种文字有几百个符号，每个符号有 3~5 种可能读法，组合起来的解读空间是天文数字。人脑一辈子能枚举的假设数量有限。
- **长程依赖难捕捉**：判断某个符号的含义，往往要参考几行甚至几块泥板之外的上下文。人类研究者翻索引卡片的速度，跟模型在向量空间里检索完全没法比。
- **学术传承断层**：死语言的专家全球可能就十几个人，培养一个合格的研究者要十几年。一旦核心学者退休或离世，进度可能直接停滞。
- **发表周期长**：一个假设从提出到发论文、被同行评议、被广泛接受，少说五年。整个领域的迭代节奏天然就慢。

大模型介入后改变的不是「智力上限」，而是**枚举速度和验证密度**。原本一个博士生半年才能跑完的对齐实验，现在可能一周就有初步结果。这种 10~50 倍的效率提升，叠加在一个停滞了几十年的领域上，看起来就像「突破」。

## 这件事对 AI 应用的启发

抛开考古本身，这个案例对做 AI 应用的人来说，参考价值其实更大。它演示了一种非常典型的「人机协作范式」。

- **小数据 + 强先验 ≠ 不能做**：很多人觉得大模型只在大数据场景下有用，这次破译用的训练样本可能就几千条。关键是把领域知识（语言学规则、历史背景）作为 prompt 的一部分喂进去。
- **Code 是最好的接口**：让模型直接输出「答案」往往不靠谱，但让模型写脚本、跑统计、再读结果，可信度高得多。可执行的代码就是天然的验证机制。
- **专家不可替代，但工作流被重塑**：语言学家依然是这次工作的核心，但他们的角色从「亲手枚举假设」变成了「定义问题 + 评审候选答案」。这跟程序员用 Copilot 之后的变化是一个道理。
- **可复现性是底线**：所有大模型生成的解读，都必须能用脚本在原始文本里复现验证，否则就是幻觉。研究团队据说为此专门做了一套验证工具链。

## 也别太上头：几个冷静的提醒

这类新闻最容易引发两种极端反应：一种是「AI 要取代所有学者了」，一种是「不过是炒作」。两个都不对。

- 这次成果还没经过完整同行评议。考古语言学的惯例是，一个破译方案要被广泛接受，往往需要数年时间的反复挑刺。现在下「板上钉钉」的结论为时尚早。
- 「破解」这个词在媒体语境和学术语境里差距很大。学术上的「破解」可能指搞清楚了某个语法范畴或一组词的含义，而不是「这门语言完全读懂了」。
- 模型的贡献是真实的，但它的能力边界也是真实的。换一种证据更少、和已知语系更孤立的死语言（比如古印度河流域文字），同样的方法可能完全跑不通。

## 实用建议 / 冷思考

1. **遇到「小数据 + 高专业度」的任务，别急着否定大模型**。先看能不能把它降维成「假设生成 + 代码验证」的循环，很多时候这种范式比 fine-tune 更划算。
2. **把可执行性作为提示工程的第一原则**。让模型产出能跑的代码、能查的引用、能复现的步骤，而不是看似流畅的自然语言结论。在严肃场景下，「能验证」比「说得对」更重要。
3. **警惕「N 年最大突破」式叙事**。任何跨越式成果，背后都站着几代研究者的工作积累。大模型是放大器，不是凭空创造者；放大器用得好不好，取决于你给它接的是什么信号源。
