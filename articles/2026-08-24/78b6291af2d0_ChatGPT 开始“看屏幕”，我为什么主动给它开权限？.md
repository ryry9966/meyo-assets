最近，ChatGPT 桌面端被推上热搜，原因不是聊天变聪明了，而是它开始“看”你的电脑屏幕：读窗口、点按钮、填表单、跨应用操作。很多人第一反应是“这不是监控吗？”我体验了几轮后，决定让它多看两眼——但前提是，我先看清了它的能力边界和权限逻辑。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-24/049a6d22b7100b75.png)

## 一、它到底“看”到了什么？

先划清边界。这个能力的内核不是后台静默录像，而是一个可见、可停的屏幕会话。

- 读取对象：通常是你当前共享或授权的窗口截图，不是整个桌面无差别采集。macOS 上涉及“屏幕录制”和“辅助功能”两类权限：前者管“看”，后者管“操作”。
- 交互方式：模型把截图作为图像输入，理解界面后输出点击坐标、滚动距离、输入文本等动作建议。
- 生命周期：手动开启，会话结束即停止。多数桌面 Agent 在删除、支付、提交等高风险动作前会弹确认。

所以它更像一个坐在你旁边、偶尔看一眼屏幕的实习生，而不是藏在系统角落里的监控探头。

## 二、从聊天机器人到“有眼睛的 Agent”

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-24/31ee140cbd3aa91f.png)

这次变化的技术本质，是 Agent 从“只读对话”走向“计算机使用”（Computer Use）。它背后的工作流可以拆成四步：

1. 观察（Observe）：桌面端低频截取授权窗口，将图像缩放或裁剪后送入多模态模型；
2. 计划（Plan）：模型结合用户指令、当前屏幕和历史动作，生成下一步操作；
3. 执行（Act）：应用层把模型意图转成真实点击、键盘输入或应用切换；
4. 反馈（Feedback）：执行后再截一次图，确认结果是否符合预期，不符合就修正。

这个循环并不新鲜。RPA（Robotic Process Automation）早期就能让软件按固定规则操作界面，Selenium 这类工具也让测试脚本能自动点按钮。区别在于：过去每一步都要工程师写死选择器，现在多模态 LLM 可以直接理解“把表格里重复的行删掉”这类模糊自然语言指令。

为什么这件事现在才发生？原因有三：一是多模态模型已经能读界面截图；二是推理能力足以做多步规划；三是桌面端权限与沙箱机制成熟到可以限制操作范围。三者缺一，要么看不懂屏幕，要么只会说不会做，要么做了收不住。

一个常被忽略的工程细节是：它处理的不是视频流，而是低频截图和坐标序列。如果每两秒截一张高分辨率图，token 消耗和延迟都会快速膨胀。工程上通常会做变化检测、区域裁剪、分辨率压缩，只把关键区域交给模型。这既省钱，也变相减少了隐私暴露面。

## 三、体验里最像“同事”的三个瞬间

真正让我愿意继续用的，不是“自动操作”这个概念，而是它解决了一些高频小麻烦。

- 跨应用搬运：把网页会议纪要里的行动项整理到表格，保留负责人和截止时间；
- 表单填充：面对十几项的报名或报销表单，它按屏幕标签逐个对应填入，不再需要人工复制粘贴；
- 报错定位：遇到弹窗报错，它把错误码、界面上下文和操作路径拼起来，给出排查步骤，而不是只回一句“请检查网络”。

当然，它也会犯错。有一次它把“导出”看成了“删除”，好在执行前弹了确认，被我发现后拦下。至少目前，确认机制是必要的底线，而不是可跳过的动画。

## 四、安全与隐私：授权不是无底洞

把屏幕交给模型之前，有三个风险必须摊开说。

- 屏幕内容可能包含密码、验证码、聊天记录、内部系统数据；
- 截图可能上传到云端处理，数据保留策略要看产品说明；
- 模型可能误操作，尤其在界面相似、按钮密集的情况下。

给权限之前，我会先问三个问题：这个窗口有没有不能外传的信息？下一步操作是否可逆？我离开时会话会不会自动停？三个问题里有一个不明确，就不开。

风险不来自“AI 有恶意”，而来自“权限开太大 + 注意力不在场”。如果你把整个桌面共享给模型，同时人离开工位，那确实等于把键盘和屏幕都借了出去。

## 五、把权限给出去之前，我会守住的 3 条线

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-24/e8ce492fa3059de3.png)

最后给三条可以立刻执行的建议。

1. 最小权限原则：只共享必要窗口，不共享整个桌面；用完立即结束会话，并在系统设置里长期关闭不需要的辅助功能权限。
2. 专用环境隔离：处理敏感信息时，切到另一个浏览器 Profile 或虚拟机，避免模型读到不该读的内容。
3. 敏感信息遮挡：涉及密码、验证码、银行卡号时，手动遮挡或选择“执行前确认”，不要全自动放行。

总的来说，屏幕 Agent 的价值不在“监控”，而在“可监督地替你操作”。它越能看清任务边界，你越敢把重复劳动交出去；但授权线一旦模糊，便利就会变成新的攻击面。多看两眼，不是因为它绝对安全，而是因为你看清了它什么时候该停。
