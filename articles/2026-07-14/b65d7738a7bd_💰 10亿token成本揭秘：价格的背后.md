当“10亿token多少钱”登上热搜，人们才发现大模型时代的基础计量单位已从“字”、“词”悄然变成了“token”。它不是字，却比字更让开发者揪心，因为每生成一个回答、翻译一段话、解读一份合同，都在以毫秒为单位消耗着名为 token 的燃料。这笔账，不仅关乎开发成本，更折射出整个 AI 产业的定价逻辑与未来走向。

## 什么是token？藏在模型肚子里的货币

如果让模型直接咀嚼汉字，它会消化不良。token 就是喂给模型的“颗粒饲料”，大小介于字母和单词之间，却比两者都更高效。

- 英文里，1 个 token 约等于 0.75 个单词。比如“ChatGPT”会被拆成["Chat", "G", "PT"]，共 3 个 token；而“tokenization”可能是["token", "ization"]，2 个 token。
- 中文就稍显“奢侈”。一个汉字常被编码为 1~2 个 token，特殊词汇甚至更多。“人工智能”四个字可能消耗 6~8 个 token。中英混输时，消耗量需要乘以系数。
- 输入(input)和输出(output) token 是分开计费的。API 收到你的 prompt，是输入 token；模型吐出的每一个字，都是输出 token。通常输出定价比输入贵，因为生成过程消耗更多算力，需要逐词解码。
- 为什么要用 token 而非字数？因为 token 与模型矩阵运算直接相关。模型看到的不是“我爱你”，而是[2435, 4562, 318]，每个数字背后是一个向量计算。按 token 计价，相当于用最原始的计算量进行结算，公平且透明。

## 10亿token在不同模型上到底花多少钱

先建立尺度感：10 亿 token 听起来天文数字，其实在 API 调用中并不罕见。一个活跃的电商客服机器人，每月轻松吃掉几亿 token。我们直接拉几款主流模型，看看真金白银差多少。

- **极端对比**：用 GPT-4o 以 1:3 的输入输出比处理 10 亿 token，需花费 $6,250（约 4.5 万元人民币）；同样的工作交给 DeepSeek-V3，仅需 $747（约 5400 元），价格只有前者 1/8。
- **国产模型的价格内卷**更是惊人。Qwen-Turbo 输入低至每百万 token 0.3 元人民币，10 亿 token 仅需 300 元，已是白菜价。

- 提示缓存（prompt caching）能进一步压缩成本。GPT-4o 对命中的缓存 token 只收半价，Claude 的缓存折扣更激进，这会让长系统提示的重复调用成本骤降。

## 为什么价格能从天上掉到泥里

看似简单的数字背后，是技术架构、硬件利用率和商业策略的合谋。

- **模型瘦身与 MoE 架构**：GPT-4 被猜测是 1.8 万亿参数的巨型模型，而 GPT-4o 优化后推理效率大增。DeepSeek-V3 采用 MoE（混合专家）架构，总参数 671B，但每次推理仅激活 37B 参数，用更少算力完成近似效果，成本自然跳水。就像需要跑车时只启动 V6 引擎，而不用一直开 V12。
- **硬件利用率魔咒**：H100 GPU 跑大模型，如果调度不优，算力利用率（MFU）可能只有 30%~50%。DeepSeek 等团队通过自研推理引擎、定制 kernel，将 MFU 推至 60% 以上，同样硬件能装更多并发，单 token 成本就被摊薄。
- **开源模型的成本优势**：闭源 API 需要养团队、付电费、赚利润；开源模型（如 Llama 3.1、Qwen）虽然训练成本不菲，但部署在自己的 GPU 集群上后，边际成本几乎只是电费和带宽。这也是为什么很多中小企业宁愿买几台服务器跑开源模型，也不愿长期支付 API 费用。
- **商业策略的阳谋**：大厂把价格拉低，是为了抢入口、积累数据、培养生态。Google Gemini、阿里通义千问频频降价，甚至部分模型免费，背后的算盘是让你把应用粘在它的云上，后续的推理服务、存储、安全等才是利润奶牛。
- **长尾优化**：量化（从 FP16 降到 INT8/INT4）、KV 缓存压缩、投机解码（speculative decoding）等技术，都在从每个 token 上抠出微秒级的延迟和分毫的成本。工程师们把节省成本玩成了艺术。

## 10亿token的实际消耗感：从小说到代码

数不落地的成本只是数字，让我们把 10 亿 token 转化为你熟悉的内容，感受一下它的真实份量。

- **长篇小说**：一本 70 万字的《三体》三部曲，中文大约需要 140 万 token（按每字 2 token 估算）。10 亿 token 可以生成 700 部《三体》的文本量。如果用来做书籍翻译，足够处理 5000 本中等长度的英文小说。
- **客服对话**：一条用户消息平均 20 token，客服助手生成回复约 80 token，一次完整对话 100 token。10 亿 token 可以支撑 1000 万次客服问答，够一个中型电商平台连续跑好几个月。
- **代码补全**：GitHub Copilot 一次建议约 15 token，10 亿 token 能给出 6600 万次代码提示。按平均每个开发者每天接受 30 次计，足以武装一支 70 人的工程团队全年无休。
- **视频理解**：Gemini 1.5 Pro 处理一小时 1080p 视频约需 1 万 token（视帧率和分辨率而定）。10 亿 token 可以用来分析 10 万小时的视频，相当于连续观看超过 11 年的内容。
- **现实吐槽**：如果你用 GPT-4o 写一首十四行诗（约 150 token 输出），成本大约 $0.0015。10 亿 token 可以产出约 670 万首这样的诗，比莎士比亚所有作品的总词数还多出几个数量级。

## 冷思考与实用建议

价格透明化的今天，10 亿 token 多少钱已然不是秘密，但真正聪明的人早已从“关心价格”转向“经营成本”。

1. **利用缓存和短输出，成本不是写死的**  
   很多应用重复发送相同的长系统 prompt，这部分 token 完全可以通过 prompt caching 半价甚至更低重用。同时，在设计 prompt 时明确要求模型“用 30 字简要回答”，能大幅砍掉输出 token。一个小小的 engineering 习惯，能让月度账单下降 40%。

2. **别只盯着旗舰模型，按场景选型才是王道**  
   如果你只是做文本分类、摘要提取，GPT-4o mini、Qwen-Turbo 的准确率完全够用，但价格只有旗舰模型的几十分之一。建立模型路由层，简单任务自动降级到小模型，复杂推理再上大模型，这是当下最成熟的成本优化范式。

3. **认清趋势：token 成本仍会以年为单位腰斩**  
   回顾过去两年，同等模型的 API 价格已下降超过 10 倍，且这一趋势没有刹车迹象。在规划产品时，用今天的成本去预估半年后的运营支出是安全的，因为到时候很可能又便宜了一半。真正该焦虑的不是 token 多贵，而是你的应用是否在模型价格归零的那一天，还有不可替代的价值。
