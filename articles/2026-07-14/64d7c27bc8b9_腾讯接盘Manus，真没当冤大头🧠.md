一夜之间，Manus 从全网邀请码一码难求，到被质疑“套壳炒作”，再到最终以一条“核心团队加入腾讯”的消息再次炸开科技圈。评论区两极分化：“腾讯又来当接盘侠了”和“这可能是今年最划算的一笔AI人才收购”。真实情况到底如何？从技术本质、商业逻辑和战略卡位三个角度拆解之后你会发现，腾讯这次非但没冤，反而把一张半明半暗的牌打出了明面价值。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-14/3dab475e9efa3277.png)

## 一、Manus 真正的技术底牌是什么？

很多讨论把 Manus 简单归为“又一个聊天机器人”，这是对它最大的误解。Manus 的定位是通用 AI Agent，其技术栈至少包含三层关键能力，远超传统对话式 AI。

- **多模型协作调度层**：Manus 并没有从头训练一个超大参数模型，而是在底层灵活调用 Claude、GPT-4 等不同基座模型的 API，上面再搭建一个“规划器+执行器”系统。这就像一位项目经理，自己不做具体图纸，却能调配不同的专家干活。官方在 GAIA 基准测试中拿下的 SOTA 成绩，恰恰证明了这套调度架构的有效性，而不是单一模型的强力。
- **计算机使用与工具调用**：在演示视频里，Manus 能自主打开浏览器、操作表格、编写和执行代码、生成报表。这背后依赖的是对屏幕像素的视觉理解、对鼠标键盘操作的抽象映射，以及长久以来困扰业界的“长链任务稳定性”问题。能够连续 50 步不出错的拆解简历、分析股票、规划旅行，工程化难度远高于生成一段文本。
- **异步任务与记忆体**：用户可以关闭电脑，几个小时后再回来收取一份完整报告。Agent 在云端持续运行，这需要可靠的任务队列、状态持久化，以及一个能记住进度和偏好的记忆模块。这已经不是 demo，而是准产品化的雏形。

可以说，Manus 团队拿出来的不是一个模型，而是一套让 AI 从“动嘴”进化到“动手”的系统框架。这正是大厂内部很难快速复刻的工程积累。

## 二、从全网爆火到被“收编”，中间发生了什么？

任何现象级产品都有“魔力期”，也有“祛魅期”，Manus 的轨迹十分典型。

- **裂变式传播背后的产能困境**：初期靠“完全自主完成复杂任务”的惊艳效果刷屏，邀请码被炒到数万元。但极度受限的算力与强依赖人类兜底流程的服务模式，使其用户留存率迅速回落。大量用户憋着一口气想“试试真本事”，结果三天拿不到码，热情自然消退。
- **成本与商业化之间的断层**：一个多步骤的深度任务，底层可能要消耗数十万甚至上百万 token 的推理成本，远超 C 端用户愿意支付的每月订阅费。如果无法快速并入一个拥有算力红利和海量成熟场景的平台，独立活下去就是一道算术题。
- **竞争对手的集体冲锋**：几乎在同一时期，OpenAI 推出 Operator，Google 发布 Project Mariner，国内各个大模型厂商也纷纷亮出 Agent 框架。在没有独家数据飞轮和大规模用户沉淀的情况下，独立 AI Agent 初创公司很快就会陷入“通用能力被巨头覆盖，垂直场景被 SaaS 吞食”的夹缝。

因此，与其说 Manus 是“被迫卖身”，不如说这是一次清醒的团队选择：把手里的技术实现在一个可以瞬息触达十亿用户的生态里，比独自挣扎在商业模式黑箱中要理性得多。

## 三、腾讯的算盘：这绝不是一次简单的收购

当外界盯着“是不是买贵了”的时候，腾讯内部可能正在划另一套 ROI 表格。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-14/1f72a8d49bbbbb8d.png)

- **人才密度胜过产品外壳**：Manus 的现有产品随时都可能被新技术迭代掉，但一支完整经历过“从 0 到 1 搭建通用 Agent”全过程的团队极其稀缺。这些人明白 base model 的边界在哪里，知道长链任务怎么拆解、错误怎么回滚、记忆如何持久化。这种工程直觉没办法靠读论文速成，只能靠真金白银的试错换回来。把这支团队放进腾讯混元大模型的体系里，等于直接给基座模型安上了一双能干活的手。
- **补足腾讯 AI 生态最关键的一环**：腾讯不缺模型能力，混元大模型在图文生成、视频理解等方面已有不错口碑；也不缺场景，微信、腾讯文档、企微、腾讯会议都是天然的 Agent 试验场。最缺的是一个可以直接面向用户的“全自动执行者”产品形态。Manus 的加入，恰好可以在 ima.copilot、元宝等产品之上，快速补出一个“替你做”而不是“告诉你”的层级。想象一下，在腾讯文档里直接说一句“把这个季度的销售数据做成汇报 PPT，风格简洁，顺便把同比异常的数字标红”，Agent 默默操作表格、生成图表、排版导出——这才是让用户真正买单的体验。
- **时间窗口比估值更重要**：2025 年已经被业界视为 Agent 商业化元年。腾讯在 C 端需要抢在字节的豆包、阿里的通义系列之前，树立一个“最听话、最能干”的 Agent 心智；在 B 端也需要为云服务、企业微信客户提供一个 plug-and-play 的数智员工方案。花几个亿买到一整年的加速时间，同时锁定一个无法从市场上短期复制的完整团队，在战略采购的账本上绝对是划算的。

## 四、算清楚三笔账，就知道冤不冤

任何收购都可以拆成人才、技术和时间成本来算。

- **人才账**：想从零组建一支 50 人规模、有过完整 Agent 工程落地经验的团队，至少需要 12–18 个月，猎头费、薪酬和试错成本加起来可能就要数千万。Manus 团队相当于一个直接可用的“特种部队”，还自带产品嗅觉。
- **技术账**：如果选择自研，要把 Agent 长链任务的完成率从 60% 提到 90% 以上，需要海量真实场景反馈和反复的强化学习微调。Manus 已经跑通了部分数据闭环，这些现成的 pipeline 和调优经验，替换成本极高。
- **时间账**：据测算，晚一个季度推出成熟的 Agent 产品，可能意味着在移动端丢失数百万潜在活跃用户，在企业服务侧丢掉数个标杆客户。腾讯用可量化的现金换来了不可量化的先发优势，捡起了一张原本需要自己慢慢攒的好牌。

## 五、三条冷思考：别被热度冲昏头

作为关注技术的普通人或从业者，这件事带来的启发远比吃瓜更有价值。

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-14/8ac502b6b9d4cd60.png)

- **关心能力，而不是产品名称**：Manus 这个品牌名或许会消失，但它身上体现出的“规划-执行-反馈”架构，以及多模型协同、计算机使用等范式，会在接下来一年内渗透到所有主流 AI 应用中。下次看到一个新工具，先问它背后的核心能力是什么，而不是看谁的 logo 贴在前面。
- **警惕“一键搞定”式的诈骗信号**：Agent 越是往前迈一大步，越容易被包装成直接收割“懒人经济”的镰刀。凡是声称“不用思考，AI 全包”的付费课程或产品，大概率是拿公开的工具改头换面。真正的 Agent 落地仍然需要人类设定目标、校验结果、处理边界情况。
- **重新审视自己的不可替代性**：当 AI 不再只是“问一句答一句”，而是能连贯地执行事务时，职场里重复性的数据搬运、简单的报告生成、标准化的流程操作，价值会进一步下跌。尽早打磨自己在某一领域的判断力、跨系统设计能力，把 Agent 当成外挂而不是敌人，才是未来两到三年最稳的护城河。
