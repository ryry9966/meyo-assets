最近，36氪一篇报道把智谱AI推上热搜：营收同比涨了约4倍，但2024年亏损约20亿元，同时公司已启动上市辅导备案。一边是漂亮的增长曲线，一边是刺眼的亏损数字，这不是智谱一家的处境，而是几乎所有大模型公司的共同考题。这篇文章把这道算术题拆开算一算：钱花在哪了、为什么越卖越亏、所谓“还没证明自己”到底指什么。

## 20亿亏在哪：大模型公司的三张账单

大模型公司的成本结构其实很“古典”，主要三块：

1. **算力**。训练一次旗舰模型，需要数千张 GPU 连续跑数周，电费和折旧都是硬支出；上线之后推理侧还要长期“养”一批卡，用户每问一句话都在烧电。
2. **人才**。能训前沿模型的算法工程师，市场价是百万年薪起步，核心团队动辄数百人，这是最刚性的人力成本。
3. **研发节奏**。这个行业有个残酷设定：上一代的投入还没回本，下一代就必须开训。停下来，就会被甩开。

打个比方：这像一家每桌都免费送招牌硬菜的餐厅，客人越多，后厨亏得越快。增长和亏损，完全可能是同一件事的两面。

## 营收×4，为什么反而越卖越亏

关键在单位经济（unit economics）还没跑正：

- **价格战把技术溢价打没了**。2024年5月，字节豆包把主力模型 API 定价压到 0.0008元/千 tokens，比当时主流价格低约99%。此后全行业 token 单价一路跳水，厂商普遍“以价换量”，收入涨4倍的同时，成本可能涨得更多。
- **推理是边际成本不为零的生意**。传统 SaaS 卖软件，多一个用户几乎不多花钱；模型公司每多卖一个 token，都是真金白银的 GPU 时间，毛利天然被压薄。
- **收入结构里混着低毛利资产**。API 和 C 端订阅的毛利相对健康，但政企大单往往是私有化部署加定制开发：交付重、回款慢、毛利率低。营收数字好看，利润表就难看。

## 全世界都在亏，但亏法不一样

给智谱“定罪”之前，先看看全球同行。据公开报道，OpenAI 2024年收入约37亿美元、亏损约50亿美元；Anthropic 同样在亏损，只是据测算毛利率略好。可见“做大模型必然亏钱”是全行业现象，亏损本身并不构成判死刑的证据。

真正的分水岭有三个：

1. **毛利率的走向**：随着推理优化、模型蒸馏、缓存等手段推进，毛利能不能逐步转正？
2. **烧钱的方向**：钱花在前沿训练（未来资产），还是花在补贴获客（消耗品）？前者是 capex，后者只是燃烧。
3. **续航能力**：账上现金加融资能力，能不能撑到模型变成现金流的那一天？

还有一个变数必须提：DeepSeek。它以论文口径约558万美元的最终训练成本（注：仅最后一次正式训练的开销，不含全部前期实验）做出了接近一线水平的模型，并且开源。这一拳同时打掉了“技术稀缺性”和“成本壁垒”——闭源模型想继续收溢价，难度陡增。牌桌规则变了，所有人的算术题都更难了。

## “还没证明自己”，指的是三件事

标题里那句“还没证明自己”，可以翻译成三个具体指标：

- **收入质量没证明**：大客户集中度多高？续约率如何？收入是可持续订阅，还是一次性项目款？涨4倍里有多少是靠降价换来的？
- **护城河没证明**：开源模型遍地走的时代，“我们模型更强”越来越难支撑持续溢价。差异化要靠 agent 能力、行业 know-how 和工程交付，这些目前都还在早期。
- **独立生存没证明**：据公开报道，智谱累计融资已超200亿元，但融资不是商业模式。启动上市辅导意味着，接下来要用更硬的财务模型去面对公开市场，而不是面对愿意“赌未来”的一级市场。

当然，反例一直存在：AWS 亏了很多年，最后成了亚马逊的利润引擎。但区别在于，云卖的是长期增值的基础设施，而模型权重是随技术迭代快速贬值的资产——折旧速度更快，留给“证明自己”的时间窗口也更短。

## 冷思考：三步读懂数字背后的信号

最后给三条观察框架，适用于所有 AI 公司的同类新闻：

1. **先看毛利率，再看增速**。营收×4但毛利为负，本质是用融资补贴扩张；营收×2但毛利转正，反而更健康。
2. **把估值叙事和商业跑通分开**。一家公司可以同时是“了不起的技术团队”和“还没跑通的生意”，这两句话并不矛盾，不必二选一。
3. **盯住收入含金量三件套**：续约率、大客户集中度、订阅收入占比。它们比总营收数字诚实得多。

大模型这局牌还没到终局，亏损是入场费，但入场费不能一直交下去。智谱们的下一份成绩单，值得继续盯。
