最近 36kr 一篇报道把智谱送上了热议：据称其单月收入达到约 9 亿元。在一个"大模型公司普遍亏损、靠融资续命"的行业叙事里，这个数字像一杯突然端上来的酒——有人举杯，也有人怀疑杯里兑了水。这篇不站队，把这 9 亿拆开看：钱从哪来、为什么是现在、数字里哪些是干货哪些是水分，以及从业者和普通用户能从中读出什么信号。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-02/23916d281c5b3bb1.png)

## 一、先对齐量级：9 亿到底是个什么概念

先做小学数学：单月 9 亿，如果这个节奏能维持，年化就是百亿人民币出头，折算约 15 亿美元量级。放进行业坐标系：

- OpenAI 2024 年全年收入约 37 亿美元（据多方报道），2025 年仍在高速增长；
- Anthropic 的年化收入在 2025 年也爬到了数十亿美元量级，主要靠企业 API；
- 国内其他大模型创业公司，公开可查的收入大多还在年度几亿到十几亿人民币区间（各家口径不一）。

如果数字属实，智谱一举跳进了国内大模型商业化第一梯队。但注意三个口径：一是"单月"不等于"稳态"，可能含项目制收入的集中确认；二是 9 亿是收入不是利润；三是高增长阶段的单月数据波动极大，下个月回落 30% 也不奇怪。

补一句背景：智谱 2019 年从清华 KEG 实验室体系孵化，靠 GLM 预训练架构起家，2023 年开源 ChatGLM-6B，让"消费级显卡也能跑大模型"出圈，2025 年已进入上市辅导程序，是"大模型第一股"最有力的候选之一。所以它的收入数据，天然会被放进招股书式的放大镜下看。

## 二、钱从哪来：一份大模型公司的收入拼图

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-02/a6302d70fb107c12.png)

一家大模型公司的收入，通常由四块拼成，智谱大概率也跑不出这个框架：

1. **MaaS / API 调用**：开发者按 token 付费，是最"互联网"的一块，边际成本低、可规模化。GLM-4.6 在代码能力上的进步直接带动了 agent 类工作流的调用量——coding agent 是眼下 token 消耗最快的场景之一。
2. **C 端订阅**：比如面向开发者的 GLM Coding 套餐，把前沿模型的编程能力打到每月一杯奶茶的价位，用低价换用户基数和使用习惯。
3. **To B 项目与私有化部署**：金融、政企客户买"模型 + 交付 + 定制"，单笔金额大，但毛利低、有账期，是典型的重活儿。
4. **海外业务**：国际版 Z.ai 走 API + 订阅路线，客单价和毛利率通常更好看，也是资本市场爱听的故事。

还有一个常被误解的点：**开源不是做慈善**。从 ChatGLM 到 GLM-4 系列的开源，本质是获客漏斗——开源版本降低尝鲜门槛，攒下开发者口碑，再转化成云上调用和企业订阅。开源是市场费用的一种形态，只是结算单位从钱变成了权重。

## 三、为什么"能赚钱"突然成了硬指标

2023 到 2024 年，行业主旋律是卷参数、卷榜单、卷融资，评价体系里 score 比 revenue 值钱。2025 年风向明显变了，原因有三：

1. **资本市场的考题换了**。一级市场开始看 ARR、毛利和续约率；要走 IPO，招股书里总得有真实的收入曲线。上市辅导与收入爆发几乎同时出现，不是巧合。
2. **价格战把单价打穿了**。过去两年 API 单价降了不止一个数量级，"以价换量"成了唯一选项——单价上没故事可讲，只能讲规模。
3. **需求结构变了**。随着 agent 兴起，推理（inference）消耗的算力首次超过训练成为大头。谁承接的 token 多，谁就站在新水龙头旁边。

再加一层 DeepSeek 效应：高质量开源 + 极致性价比，把闭源厂商逼到墙角——要么有场景，要么有规模，"只会刷榜"这条路基本封死了。

## 四、收入 ≠ 利润：先别急着开香槟

工程师看数字有个习惯：收入是虚荣，利润是理智，现金流是氧气。9 亿流水的另一面是成本表：

- **训练成本**：一次前沿模型训练，GPU、数据和人力加起来动辄数千万到数亿元；
- **推理成本**：每个 token 背后都是电费和 GPU 折旧，MoE 架构、量化、prompt caching 这些降本手段直接决定毛利；
- **To B 隐性成本**：账期长、定制多、交付重，报表上收入很美，回款可能还在路上。

所以真正该盯的不是"单月流水"，而是毛利率、经营性现金流和客户续约率。这三个数字健康，9 亿才有资格进入"趋势"的讨论范围。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-02/e25149811f05c82f.png)

1. **看数字先拆结构**。下次再看到"某公司收入创新高"，先问三个问题：收入构成是什么？毛利多少？是单月峰值还是可持续节奏？结构比总额诚实。
2. **对从业者**：大模型公司的人才需求正从"炼丹"向"工程化 + 行业交付"倾斜，agent 工程、推理优化、行业解决方案的岗位在变多。选团队时，看它的商业化管线，比看榜单名次靠谱。
3. **对普通用户**：这场竞争最大的红利在我们这边——token 越来越便宜，agent 越来越能干。与其围观融资新闻，不如动手把 coding agent 或自动化工作流跑起来，尝鲜成本已经低到一杯奶茶钱。

酒可以敬，但下一杯的酒钱，得靠毛利和续约率来续。
