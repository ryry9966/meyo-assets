大模型创业公司最近交出两份风格迥异的成绩单：智谱的招股材料显示，其开放平台及API收入三年翻了27倍；MiniMax的上市材料则显示，公司一年净亏损约21亿元。舆论很快分成“一个起飞、一个失血”两派。但把两份报表并排放着看，你会发现它们其实是同一场考试的两道大题：一道路径题——模型怎么变成收入；一道成本题——前沿研发到底有多烧钱。这篇把数字拆开，讲讲怎么读。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-02/fc0bf7892b2a08d0.png)

## 先把两个数字翻译成“人话”

- **27倍的正确打开方式。** 口径是“开放平台及API收入”，也就是 MaaS（Model as a Service）业务。翻27倍的前提是基数小：假设起点在千万量级，27倍也只是接近三亿的量级——倍数吓人，绝对值还在爬坡阶段。
- **21亿亏损不等于“一年白干”。** 净亏损的大头通常是三类：研发费用（GPU算力 + 高薪算法团队）、推理成本（每一次API调用、每一段视频生成都要过显卡）、以及ToC产品的获客投放。
- **容易被忽略的一条：亏损 ≠ 现金流烧光。** 会计口径里有股权激励、折旧摊销这类非现金项目。看到亏损先多问一句：现金亏多少？账上还剩多少？下一轮融资接不接得上？

## 两条路线：API批发 vs 应用零售

两家公司的商业化路径差异很大，这直接决定了报表的“长相”：

- **智谱：偏 ToB 的“卖水”模式。** 核心收入是 token 调用费和行业解决方案（私有化部署、企业Agent项目）。优点是客户一旦接入，用量随业务自然增长，收入可持续性强；缺点是项目制定制重、交付成本高，毛利容易被打薄。
- **MiniMax：模型 + 自营应用的“卖水也开奶茶店”模式。** 自研基座模型，同时运营面向用户的C端产品——AI对话陪伴、视频生成等，其中海外产品占相当比重。有机会吃到应用端溢价，但要同时扛起买量成本和内容运营成本。
- **没有优劣，只有估值逻辑不同。** 前者资本市场看 API 调用量曲线和续费率，后者看 DAU、留存和 ARPU。两张报表，不能用同一把尺子量。



## 亏损的物理学：钱到底烧在哪儿

把大模型公司的成本拆成三层，就明白21亿是怎么来的：

1. **训练成本**：一次前沿模型训练，动辄数千张GPU连续跑数周到数月。这是“资本性投入”性质——花出去的是现金，产出的是模型权重这份“资产”。当然，资产能不能保值，取决于下一次技术迭代什么时候来。
2. **人才成本**：头部算法工程师年薪普遍百万级，核心团队几百人，研发费用占到收入的数倍，是这个阶段公司的常态。
3. **推理成本**：每生成一个 token 都要过一遍显卡。麻烦在于行业价格战——同等能力的模型，API单价这两年降了不止一个数量级。“卖得越多、单笔越亏”的剪刀差，要靠量化、KV cache 优化、MoE 推理架构这些工程手段一点点弥合。

放眼全球，这个阶段烧钱不是哪一家的特产：OpenAI、Anthropic 的年亏损同样以十亿美元计。前沿模型研发本质上是一场资本密集型竞赛，亏损是入场券，不是意外。真正的分水岭是**毛利率**：谁能把“单位token成本”降得比“单位token价格”跌得更快，谁先走出剪刀差。

## 招股书阅读框架：三步拆掉数字滤镜

以后再看到“收入翻XX倍”或“巨亏XX亿”，可以套这个三步法：

1. **看收入质量**：API/订阅这类经常性收入占比多少？一次性项目收入占比多少？前者是资产，随用量复利增长；后者更接近工程外包，做完一单还要再找下一单。
2. **看亏损结构**：亏损主要花在研发上，是“买未来”，可以辩护；花在获客补贴上，是“买当下”，一旦融资断档就危险。
3. **看收敛速度**：收入翻倍的同时亏损在收窄，说明单位经济模型在跑通；收入翻倍但亏损同步扩大，说明还在换挡期，赌的是算力摊薄和规模效应最终能兑现。

另外一个提醒：**倍数必须配基数一起读**。“从0.1亿到2.7亿”和“从10亿到27亿”，是完全不同的两种故事。

## 三条冷思考

1. **给开发者和企业用户**：现在处于大模型“供给侧价格战”窗口期，API被竞争压得很便宜，算历史级红利期。务实做法是多模型适配——在业务层和模型层之间加一层抽象，同时接两三家供应商，把议价权和容灾能力留在自己手里，别把业务绑死在单一供应商上。
2. **给看热闹的人**：判断一家AI公司的健康度，别只记“翻了几倍”和“亏了多少”，动手算三个数：收入增速、毛利率趋势、亏损收窄速度。三条线交叉验证，才接近真相。
3. **给行业观察者**：比收入更诚实的指标是 token 消耗量——价格在降、收入还在涨，说明真实用量在涨。接下来值得盯的是“推理成本下降速度”与“调用量上涨速度”的赛跑：哪天前者跑赢后者、且收入仍在增长，行业才算真正跨过商业化的拐点。
