湖南卫视黄金档最近排上了一部特别的《西游记》：据报道，从画面、运镜到场景，主体镜头由AI视频生成模型完成。这件事的意义不在“又多一个翻拍版本”，而在信号本身——黄金档是电视台单位时长广告价值最高、排播纪律最保守的时段，它愿意排一部AI生成的剧，意味着这条生产管线已经同时满足两个硬指标：**成本算得过来，观众看得下去**。下面拆三件事：它到底怎么做的，为什么偏偏是《西游记》，以及热闹背后真实的门槛。

## 管线换底层：从“一秒画24张”到“抽卡+修复”

传统2D动画是典型的人力密集型工业：

1. 剧本 → 分镜（storyboard）；
2. 原画师画关键帧；
3. 中间画师补 in-between，一秒动画按 12~24 张计；
4. 上色、合成、摄影、剪辑。

一集20分钟的动画，按每秒12张算就是1.4万多张画稿，几十人团队干上数周是常态。作为参照，86版《西游记》用一台摄像机拍了六年，才交付25集。

生成式管线把这条流水线大幅压缩：

- **文生图/图生图**出分镜概念稿；
- **图生视频（image-to-video）**：给定首帧（有时加尾帧），让扩散模型“脑补”中间的运动过程——本质上是把中间画的活儿交给了模型的去噪过程；
- **角色一致性**靠参考图 + LoRA 微调：把猴脸、服装纹样、金箍棒喂进模型做定制化训练，锁住跨镜头形象不崩；
- **后期依旧离不开人**：同一镜头反复“抽卡”择优、修手部穿帮、统一调色配乐。

所以准确的说法不是“AI一键成片”，而是：**中间画人力被算力替代，部分导演执行环节被 prompt 和参考图接管**。显卡风扇转起来的声音，就是新时代的铅笔声。

## 为什么第一个吃螃蟹的是《西游记》

选材不是偶然，是工程判断：

- **公版IP，零授权成本**：原著早已进入公有领域，没有版权谈判，试错代价最低；
- **奇幻场景是生成模型的主场**：腾云驾雾、七十二变、妖气冲天——实拍拍不了、手绘最烧钱的内容，恰好落在扩散模型最强的“想象力区间”里；
- **单元剧结构友好**：一集一关、一关一妖，场景与情节相对独立，对长程叙事一致性的要求远低于连续剧，正好绕开当前模型的短板；
- **观众自带先验**：每个观众脑内都有一版孙悟空，AI画到七分像，大家会自动脑补剩下三分，认知成本低、容错率高。

一句话：挑了个生成模型最不容易露怯的题材，打的样板仗。

## 黄金档的分量：这笔账怎么算

- **成本层**：按行业公开口径，传统三维动画单秒成本常在数百到数千元级；生成式管线把单镜头素材成本打下来约一个量级。但注意，省掉的是原画与中间画人力，新增的是显卡推理的算力费、反复抽卡的时间和后期修复工时。真正的红利在于“试错变便宜”：一个镜头不满意，重新生只花几分钟电费；
- **周期层**：小团队加几个月，就能交付过去需要大团队加一两年的体量，排播响应速度完全不同；
- **话题层**：“AI上黄金档”本身就是流量事件，宣发自带新闻点，一鱼两吃。

对平台而言这是一笔确定性很高的买卖：成了是标杆，没成是试验，横竖有话题。



## 别急着吹：目前迈不过的三道坎

- **长程一致性**：跨镜头维持同一张猴脸、同一套纹样，仍要靠参考图、LoRA 加大量人工修，集数一多漂移会累积；
- **动作与物理**：打斗、手部、毛发、流体依旧是重灾区，金箍棒抡起来变形、手指穿模的镜头只能靠抽卡硬筛，废片率高；
- **叙事控制力**：模型擅长“好看”，不擅长“讲对”。景别、节奏、情绪这些导演语言，目前只能通过 prompt 粗粒度下发，精确运镜还得靠首尾帧控制和分镜拆解来曲线救国。

还有一条隐性成本叫“AI味”：观众对生成画面的审美疲劳速度极快，第一波新鲜感红利是一次性的，第二次出现就不再加分。

## 给想入场的创作者：三条冷思考

1. **把AI当“中间画部门”，别当导演**：现阶段最稳的用法是“传统分镜思维 + 生成素材 + 人工精修”的混合管线；纯 prompt 直出，短期内只适合短内容；
2. **选题比堆料重要**：优先挑奇幻、风格化、单元结构、观众有先验认知的题材；写实、长程连续叙事、强情感特写，先绕着走；
3. **盯住修复人力这个成本黑洞**：评估一个项目能不能做，别看生成多快，先算抽卡比例和修图工时——那才是决定盈亏的分母。工具会一直迭代，但“人机分工的边界在哪”才是你真正的护城河。



86版《西游记》用六年和一台摄影机，把“穷”拍成了经典；AI版用算力把制作门槛打了下来。工具变了，不变的仍是那句老话：**技术决定下限，叙事决定上限**。黄金档最终收留的不是AI，是终于算得过账的好故事。
