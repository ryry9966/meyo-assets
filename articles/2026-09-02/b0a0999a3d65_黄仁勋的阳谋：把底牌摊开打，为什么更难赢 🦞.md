36kr 把黄仁勋这几年的打法概括为「阳谋」：路线图公开、产品节奏公开、毛利公开，甚至连互连接口都向潜在对手开放。有意思的地方在于——牌越明，对手反而越难受。阴谋靠信息不对称，阳谋恰恰靠「全部摊开」。这篇文章按「四张明牌 + 三道护城河」的框架拆一遍，最后给开发者、采购决策者和行业观察者各留一条能带走的东西。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-02/2d5c8a3a0dfd533d.png)

## 先说清楚：什么叫「阳谋」

判断一个策略是不是阳谋，看两条就够了：

1. **对手能否预见？** 能。黄仁勋每年在 GTC 主题演讲、财报电话会、新闻稿里把未来几年的计划讲得明明白白。
2. **对手能否不跟？** 很难。每一步棋都自带「立刻兑现」的时间压力，不应对的代价马上落在账上。

类比下棋里的当头炮：意图写在脸上，但你必须接，因为不接下一手就输子。NVIDIA 的狠之处在于，它把「接招」变成了别人的默认动作。

## 明牌一：一年一代，路线图直接贴在墙上

- **过去的节奏**：Kepler（2012）→ Maxwell（2014）→ Pascal（2016）→ Volta → Ampere（2020），大致两年一代，中间还跳过票。
- **现在的节奏**：Hopper（2022）→ Blackwell（2024）→ Blackwell Ultra（2025）→ Rubin（2026），再往后排到 Feynman，全部提前公开宣讲，节奏压缩到一年一代。

这张明牌有三重效果：

1. **冻结客户决策**：客户知道下一代性能大幅提升，预算周期直接锚定 NVIDIA 的年历。采购同学的排期表，从此跟着别人的 roadmap 走。
2. **压缩对手窗口**：竞争产品研发周期两三年，等上市时对标的是 NVIDIA 的上一代，性价比这笔账天然算不赢。
3. **倒逼供应链**：提前锁定 CoWoS 先进封装和 HBM 内存产能，竞争对手去抢产能时，发现排期表已经被占满了。

## 明牌二：不卖芯片了，卖「AI 工厂」

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-02/d0dbe8c27a65df26.png)

- **产品形态在升级**：H100 单卡几万美元，到 GB200 NVL72 整机柜——72 颗 GPU 加 CPU，靠 NVLink 互连对外呈现为「一块巨大的 GPU」，公开报道口径约 300 万美元一个机柜。客单价直接上了一个数量级。
- **全栈拼图**：GPU 算力 + NVLink/NVSwitch 互连 + 2019 年宣布以约 69 亿美元收购的 Mellanox（InfiniBand 与 Spectrum-X 以太网）+ CUDA 和 NIM 等软件栈 + DGX Cloud 租赁服务。客户买的不再是器件，而是「从机房到 token 的整条产线」。
- **话术也在升级**：黄仁勋把数据中心重新定义为「AI 工厂」，token 是它的产量。采购决策从「买服务器」被翻译成「建工厂」，议价逻辑完全变了。
- **为什么毛利 70% 以上客户还买单？** 因为算的是 TCO：每瓦性能、每 token 成本、上线时间。对手必须在整条链路上同时占优才能破局，只赢芯片一环远远不够。再叠加面向各国政府的「主权 AI」算力订单这个新市场，需求端被进一步摊宽。

## 明牌三：CUDA，一条修了二十年的河

- 2006 年 CUDA 发布时，华尔街是看不懂的：一家显卡公司为什么要自建编程模型？股价在低位趴了很多年。
- 二十年积累的结果：数百万开发者、cuDNN/TensorRT/NCCL 等一整套组件，以及 PyTorch、TensorFlow 等主流框架的默认后端。全世界的开源 AI 框架都「默认会讲 CUDA」，等于整个社区在替 NVIDIA 修路。
- **阳谋之处不在硬件参数，而在软件资产**：代码重写、算子调优、精度对齐，每一项都是实打实的工程师工时。对手可以造出参数相当甚至更强的芯片，却造不出二十年的沉没工时。
- 更关键的是，这条河不是静态的：每一代新硬件上线，旧代码自动获得加速，生态价值随硬件迭代复利增长。

## 明牌四：把门打开，让对手变成租客

- 2025 年 Computex 公布 **NVLink Fusion**：把 NVLink 互连接口开放给第三方 CPU 和自研 ASIC 厂商，公开披露的合作方包括联发科、Marvell、富士通、高通等。
- 逻辑很妙：想自研芯片的大厂，最难搞定的从来不是单芯片，而是大规模组网和软件栈。与其让对方在墙外另起炉灶，不如让它们接进 NVIDIA 的机柜生态——算力可以是你的，互连和软件按我的来。挑战者进门的那一刻，先交了「入场租金」。
- 同样公开的还有**投资-采购闭环**：对 OpenAI 高达千亿美元级的投资承诺（与 10GW 算力部署绑定），以及参与多家 AI 公司的融资轮，而这些公司同时是算力大买家。市场对「循环交易」有质疑，但所有协议都摆在明面上——这正是阳谋的典型特征：质疑归质疑，节奏没被打乱。

## 三道护城河叠加，阳谋才立得住

摊牌之所以敢摊，是因为底下垫着三层别人短期拿不走的东西：

1. **软件生态（时间壁垒）**：二十年开发者资产，追赶周期以十年计。
2. **系统工程（能力壁垒）**：芯片、互连、网络、软件四条线协同设计，需要四个团队同时强。
3. **供应链（位置壁垒）**：先进封装与 HBM 产能的多年期占位。

麻烦在于三者互相增益：生态带来订单，订单养起研发投入，工程能力又反过来锁住供应链。单独攻击任何一道，另外两道会立刻补位。这就是「看得懂、学不会、拆不开」。

## 冷思考：三条能带走的

1. **开发者**：CUDA 优先没问题，但把可移植性留在架构里——用 vLLM、Triton、ONNX 这类抽象层隔离核心逻辑，关键算子跑完基准测试再决定绑定深度。all-in 单一后端的技术债，通常在续约谈判桌上才显形。
2. **企业采购**：评估看每 token 成本和每瓦性能，别只看峰值 FLOPS；合同里写清数据出口与迁移条款，给替代方案留一个试点位。
3. **观察者**：判断需求真伪时盯两个指标——推理侧收入占比，以及「投资-采购」闭环之外的第三方订单比例。阳谋的韧性来自真实的 token 消耗增长，这一项一旦放缓，明牌也会变重。

阳谋的最高境界，不是对手看不见，而是看见了也不得不配合。理解这一点，比争论「领先还能持续多久」有用得多。
