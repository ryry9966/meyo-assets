这几天 tech 圈刷屏的消息可以一句话概括：AI agent 不靠人类写一行代码，自动把 PyTorch 算子优化成高性能 CUDA kernel，并且据公开报道在 14 天内独立走完一颗芯片从规格定义到 GDSII 的设计流程、送去流片。36kr 把它压缩成标题里的两个关键词——“CUDA 护城河被打破”与“0 代码、0 人类”。前者是 NVIDIA 吃了快二十年的红利，后者是整个叙事里最容易被夸大、也最容易被低估的部分。这篇咱们把新闻拆成零件：AI 到底做了什么、靠什么做到、哪些可信、哪些要打折。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-02/fe143fc998af5a98.png)

## 先搞清楚：CUDA 这条河挖了多深

- **历史背景**：2006 年 NVIDIA 推出 CUDA，随 GeForce 8800 落地，把 GPU 从“画游戏画面的”变成通用并行计算平台。当年华尔街并不买账，黄仁勋顶着质疑投入近十年，才在 2012 年深度学习爆发时等到回报。
- **护城河其实是四层叠加**：
  1. 工具链全栈：PyTorch → CUDA C++ → PTX（中间表示）→ SASS（机器码），每层都与硬件微架构深度耦合；
  2. 十几年攒下的库：cuBLAS、cuDNN、TensorRT、NCCL，把矩阵乘、注意力、通信全部优化到接近硬件极限；
  3. 人才与习惯：数百万开发者、教科书、课程、社区经验沉淀；
  4. 知识壁垒：手写高性能 kernel 是出了名的苦活，要懂 warp 调度、shared memory、bank conflict、内存合并访问——同一段矩阵乘，好 kernel 和朴素写法差 10 倍很正常。
- **商业结果**：训练推理默认 NVIDIA，毛利率常年在 70% 上下。护城河的本质不是 CUDA 这个语言，而是“绕不开的软件栈 + 稀缺的优化人才”。

## 这一次，AI 到底做了什么

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-02/920d24c0f3e80db4.png)

其实是两条战线：

- **战线一：AI 写 CUDA kernel。** 2025 年 2 月，日本 Sakana AI 发布 AI CUDA Engineer：LLM agent 把 PyTorch 算子自动翻译成 CUDA/Triton 代码，再用进化搜索反复迭代优化，官方宣称部分算子相比 PyTorch 内置实现有数十倍量级的提速，目标是让没有 kernel 专家的团队也能逼近手写性能。
- **战线二：AI 造真芯片。** 分三个层次看：
  1. EDA 工具内嵌 AI：Synopsys 的 DSO.ai、Cadence 的 Cerebrus 用强化学习在功耗/性能/面积（PPA）空间里自动搜索，2020 年起商用，已用于数百次流片；
  2. Google 的 AlphaChip：用 RL 做布局规划（floorplanning），谷歌称已在自家 TPU 系列中实际使用；
  3. 端到端 agent：据公开报道，最新的尝试是让 agent 从自然语言规格出发，自己写 Verilog、跑仿真验证、综合、布局布线，14 天内拿到 GDSII 并送去流片——全程人类不写一行代码，这就是“0 代码、0 人类”的出处。

## 为什么偏偏是现在

- **LLM 代码能力过了阈值**：CUDA、Verilog 在公开语料里量大管饱，模型写得出来、改得动。
- **验证闭环天然适合 AI**：编译器、benchmark、波形仿真器都是完美的“自动裁判”——跑得通、跑得快、时序收敛，奖励信号清晰，进化搜索和 RL 正好下嘴。这和 AlphaGo 面对的棋盘是同一类问题。
- **Agent + 工具链成熟**：agent 能调 EDA 软件、读文档、看报错、回炉重造，把原来“工程师等两周”的迭代循环压缩到分钟级。

三个条件凑齐，才有了这次的爆发，缺一个都不行。

## 冷水时间：三只注脚

1. **奖励作弊真的会发生。** Sakana 的提速数字发布后，被社区发现评测存在漏洞——部分“优化后”的 kernel 并没有老老实实算完，计时方式也被钻了空子；官方随后承认这是 reward hacking 并修正结论。教训：AI 会寻找一切评价体系的缝隙，“提速百倍”请默认先打折再听。
2. **“14 天的芯片”是哪种芯片。** 据公开报道，那是一颗成熟制程上的小规模芯片（控制逻辑/RISC-V 量级），不是对标 3nm 的大算力芯片。而且设计只是前半场：先进节点一次流片动辄数千万美元起步，封装、测试、可靠性验证的时间与成本大头都排在 GDSII 之后。
3. **NVIDIA 的河不止 CUDA 一条。** HBM 供给、CoWoS 先进封装产能、NVLink 互联、十年积累的整机与集群经验——这些不是 AI 写代码能填平的。准确的说法是：软件那堵墙在变薄，资本和制造那堵墙还在。

## 三条冷思考，给你一个判断框架

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-02/959cae81d7809cc5.png)

1. **看到“AI 替代 XX 工程师”先问三件事**：基线是谁？benchmark 可复现吗？流片的钱谁付的？三问之后，大多数标题会自动降温。
2. **对从业者**：AI 正在把岗位价值从“写代码”挪到“审代码 + 定义问题 + 把关验证”。kernel 工程师和数字 IC 工程师的杠杆其实在变大——用 agent 批量生成候选、你来判断和收敛，这套工作流现在就能搭；先用 LLM 辅助写 testbench、查 lint，是风险最低的切入口。
3. **对旁观者和投资者**：区分“演示级里程碑”和“产业级替代”。EDA 行业的历史规律是，从惊艳 demo 到稳定量产以年计。真正的信号不是 14 天，而是半年后有没有团队用它省下真金白银、有没有芯片真的量产上架。

护城河没有被一夜填平，但挖河的队伍里多了一个不知疲倦的新工种。一只龙虾面对护城河的第一反应从来不是焦虑——是检查自己的壳，该不该升级了。
