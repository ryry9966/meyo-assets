过去几周，一个叫“牛来”的匿名模型在盲测社区里引起了不小讨论。它没有官方主页，没有技术报告，只靠用户随机提问后的投票分数一路爬升。36kr 最新的报道把谜底揭开：这是智谱 GLM 系列的新版本，而且有两个值得注意的标签——首个原生多模态，训练用的是国产算力卡。这三个信息叠加在一起，比单纯跑分更有解读价值。

## 一、匿名打榜：为什么大模型要“蒙面”测试

“牛来”最早出现在盲测平台时，很多人只是把它当成又一个神秘选手。事实上，匿名测试已经成为大模型发布前的常见操作，原因有三点：

- **避免品牌光环**：如果用户知道模型来自哪家公司，很容易带着既有印象打分。匿名能更纯粹地衡量回答质量。
- **贴近真实对话**：盲测题目不是固定 benchmark，而是用户随手提出的各种任务，从写代码到解数学题，再到多轮中文对话，覆盖面更广。
- **快速暴露短板**：匿名模型会被用户用提示词攻击、诱导、追问，很多对齐和鲁棒性问题在公测前就能被发现。

这种测试通常采用 Elo 评分机制，类似棋类排名：系统随机给用户两个匿名模型，用户选择更好的回答，模型分数随胜负动态调整。此前 GPT-4o、Claude 3.5 Sonnet、DeepSeek-R1 等模型都经历过类似“蒙面”阶段。“牛来”这个名字本身没有技术含义，更像一个测试马甲。它能引起关注，是因为在数学、代码、中文理解等多项任务上进入第一梯队，不是靠单一数据集刷分。

## 二、原生多模态：不只是“能看图”

多模态这个词已经被用得很泛，但“原生多模态”和“拼接多模态”有本质区别。

**传统的拼接式多模态**，通常是这样工作的：

1. 视觉编码器（如 ViT）先把图片转成一组特征向量；
2. 通过一个投影层，把这些特征映射到文本大模型的 token 空间；
3. 文本模型再基于映射后的向量继续生成回答。

这种方案训练快、容易复用现有语言模型，但图像信息像是“外挂插件”。它在跨模态空间推理、图表数值读取、细粒度视觉定位等任务上容易出错，因为模型并没有在统一表示空间里同时学习文本和图像。

**原生多模态**则不同：

- 从预训练阶段开始，文本、图像、音频等模态就被统一成 token 序列；
- 模型使用同一套 next-token prediction 目标训练，文本 token 和图像 token 共享同一个词表和 Transformer 主干；
- 训练数据中包含大量交错出现的图文内容，模型很早就学会在一个统一表示空间中对齐语义。

一个直观类比：拼接式像“先把图片翻译成文字，再交给语言模型理解”；原生式更像“直接用多模态母语思考”。

举个例子：给模型一张复杂图表，问“2024 年 Q3 毛利最高的业务，与 2023 年同期相比，增长主要来自价格还是销量？”拼接模型可能把图表转成一段描述后丢失结构，而原生模型可以保留视觉布局与数值关系，直接进行跨模态推理。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-27/461dc5ee316d4495.png)

智谱这次把 GLM 称为“首个原生多模态”，意味着它很可能在预训练阶段就使用了大量交错图文数据，而不是简单给现有 LLM 加一个视觉编码器。当然，具体 tokenization 方案和预训练数据配比，还需要等公开技术报告确认。

## 三、国产算力卡：从“能用”到“能训前沿模型”

大模型训练长期依赖英伟达 GPU，CUDA 生态、cuBLAS、NCCL 通信库等已经非常成熟。国产 AI 芯片过去更多在推理侧落地，大规模训练对集群稳定性、互联带宽、显存容量、算子覆盖率的要求要高得多。

如果 36kr 报道属实，GLM 的新版本使用国产卡完成至少一轮大规模训练，至少说明三件事：

1. **训练框架和编译器已能支持主流并行策略**：包括数据并行、张量并行、流水线并行、序列并行等，这些是训千亿参数模型的基础。
2. **通信库在数千卡规模下能稳定跑完长任务**：大规模训练最怕的是通信卡死或节点掉线，能训完本身就有工程价值。
3. **混合精度、FlashAttention、KV Cache 等优化在国产卡上已有可用实现**：否则训练效率会低到无法接受。

但也要保持冷静：国产卡在单卡算力、HBM 容量、软件生态丰富度上，与 H100/B200 仍然存在差距。训练“能跑通”和“效率、成本、可复现性全面对标”是两件事。目前报道没有披露具体卡型、集群规模、MFU（模型算力利用率）等关键指标，所以不宜过度拔高。

## 四、三个可验证的信号

这波“牛来”揭面，最重要的不是模型名字，而是背后三个可以持续跟踪的信号：

1. **架构信号**：原生多模态不是营销词，它直接影响模型在 Agent、GUI 操作、文档理解、视频分析等场景的能力上限。
2. **算力信号**：国产训练集群进入前沿模型训练，减少单一供应依赖。但需要观察后续是否稳定、成本是否可控、是否具备可复制性。
3. **评测信号**：匿名打榜分数提升，说明综合能力进入第一梯队。不过盲测分数受用户群体和题目分布影响，不能替代垂直场景评测。

## 冷思考：三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-27/0e0e83f91f0e4863.png)

1. **开发者先做小范围实测，别只看跑分。** 重点测多模态文档解析、图表问答、中文长文本和 API 延迟。如果业务是手机端实时交互，还要看首 token 延迟与并发成本，而不是只看 benchmark 分数。
2. **把“原生多模态”当一个架构问询项。** 采购或选型时，可以要求厂商说明：图像 token 怎么生成？预训练数据里图文交错占比多少？能否给出跨模态空间推理的失败案例？这比看 demo 视频更有效。
3. **关注国产算力的迁移路径。** 如果团队未来要在国产卡上部署，建议先从推理开始，选一个中等规模模型做算子覆盖与性能评估，不要一上来就重构训练栈。

一个匿名模型揭开面纱，真正值得跟踪的不是名字，而是架构和算力这两条慢变量。
