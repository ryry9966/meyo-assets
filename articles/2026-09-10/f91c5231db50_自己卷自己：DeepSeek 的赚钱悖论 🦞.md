2025 年初，DeepSeek-R1 一发布就把 App 推上了中美应用商店免费榜第一，英伟达单日跌掉约 17% 市值；随后几个月，它的 API 价格一降再降，便宜到让同行怀疑人生。36kr 那篇《DeepSeek 想赚钱，最大的对手却是自己》点出了一个很有意思的悖论：这家把模型开源到"随便用、不用谢"的公司，卡住自己商业化脖子的，恰恰是它自己最擅长的那些动作。这不是修辞，而是一个可以拆开看的商业机制问题。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-10/fa4b06fc324051e1.png)

## 「对手是自己」的三层含义

1. **开源即让利**：R1 采用 MIT 协议，权重、技术报告全开放，连蒸馏都明牌允许。任何云厂商都可以部署同款模型卖 API——你的商品别人免费拿得到，定价权天然归零。R1 发布后，各大云厂商抢着上线，不少以免费额度甚至贴钱引流，把自己的 API 直接架在火上烤。
2. **迭代即淘汰**：V3 → R1 → 后续版本，每一次升级都让上一代的付费需求贬值。手机厂商最怕的是自家新品，模型厂商同理，只是周期从一年压缩到几个月。
3. **效率即通缩**：MLA（多头潜在注意力）、MoE 架构、FP8 训练、后来的稀疏注意力……每一项工程优化都在压低推理成本，而省下来的钱以降价形式还给用户。2025 年 9 月的 V3.2-Exp 靠稀疏注意力直接把 API 价格再砍一半以上。

一句话总结：它同时扮演三个角色——模型厂商、价格屠夫、以及自己的"平替供应商"。

## 算一笔账：成本与价格的剪刀差

- **训练成本**：V3 论文披露正式训练约 278.8 万 H800 GPU 小时，按每小时 2 美元计约 557.6 万美元（注意这是论文口径，不含前期实验、硬件折旧和人力）。
- **API 定价**：R1 发布初期，每百万输入 token（缓存未命中）约 0.55 美元、输出约 2.19 美元；同期 OpenAI o1 是 15 美元和 60 美元，差出一个数量级。
- **错峰折扣**：北京时间凌晨时段最高打 2.5 折，本质是把闲置算力变现，顺手再压一次行业价格线。
- **C 端免费**：App 免费、用户量暴涨，意味着推理成本直线上升。

这笔账的另一面在资产负债表上：DeepSeek 背后是幻方量化，模型业务现阶段更像战略资产而非利润中心。所以准确的说法不是"不会赚钱"，而是"现阶段不靠赚钱"。



## 参照系：开源玩家的三种结局

- **Android / Red Hat 型**：开源换生态，靠服务、渠道或广告间接变现。前提是握有分发入口或配套服务能力——Google 靠搜索广告兜底，Red Hat 靠企业订阅。
- **Mistral 型**：先用开源换声量和开发者心智，再逐步把旗舰模型闭源收费。窗口期短，转身要快。
- **Elastic / MongoDB 型**：被云厂商用开源版本"白嫖"到受不了，修改协议收紧授权，代价是社区信任受损。

DeepSeek 目前是哪种？更接近一个特殊样本：**用母公司资产负债表补贴开源**——量化交易负责赚钱，模型负责技术理想主义。但这个模式的隐含前提很硬：母公司现金流持续为正，且人才和算力供给不能断。

## 真正的护城河与可能的出路

权重已经送出去了，护城河只能建在权重之外：

1. **能力领先窗口期**：只要最强模型持续出自 DeepSeek，"最新能力"就有稀缺性，溢价只在窗口期内有效——这既是机会也是倒计时。
2. **工程能力的复利**：能写出逼近硬件极限的优化代码，意味着同等算力下成本更低，成本优势是它敢于持续降价的底气。
3. **生态位置**：当开发者的工具链、微调数据、工作流都围绕它的模型沉淀，切换成本会自然出现——Android 的免费从来不是免费的。

判断框架可以简化成一张二维表：横轴是"能力领先窗口期能维持多久"，纵轴是"商业化组织能力能否长出来"。只有右上角才有真金白银，左下角就是纯公益。

## 冷思考

- **对开发者**：把开源模型的 API 价格当作行业地板价来规划成本，但别把长期架构绑死在任何一个模型上——下一代发布，可能让你的适配工作一夜归零。
- **对创业公司**：权重公开意味着"套壳"没有壁垒，真正的价值捕获在数据回流、场景理解和分发渠道，而这三个都不在模型文件里。
- **对观察者**：与其争论 DeepSeek 是否"亏本"，不如盯三个信号——MIT 协议是否保留、企业级服务产品是否出现、API 价格与能力曲线的剪刀差走向。这三个信号比任何分析文章都诚实。

开源不是商业模式，开源是竞争策略；商业模式，藏在策略的下一手。
