最近 36kr 一篇关于 MiniMax 的报道，把一个老问题又顶上了热搜：一家 2021 年底才成立、2025 年 7 月才在港交所挂牌的公司，凭什么公开把 AGI 挂在嘴边？把它近两年的技术动作摊开看——开源千亿级 MoE 模型、自研线性注意力、强化学习推理模型、全模态产品矩阵——会发现它其实在下三步棋：**把架构做省、把模型训得会思考、把应用做成飞轮**。这篇文章把这盘棋拆开讲。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-10/d02ad30f1c4e7750.png)

## 先对齐定义：MiniMax 眼里的 AGI 不是"机器人觉醒"

- 在创始人闫俊杰的公开表述里，AGI 被翻译成一个工程问题：让 agent 像一个靠谱同事那样，端到端交付任务，而不是只负责陪聊。
- 具体拆成三个可度量的能力：超长上下文的记忆与理解、可靠的多步推理与工具调用、跨模态的感知与表达（听得懂、看得见、说得出）。
- 这个定义的价值在于"可验证"：不陷入哲学争论，只看任务成功率。写代码、改 bug、办流程这类有明确对错的任务，成了衡量智能的尺子——这也解释了为什么最近两年各家都在卷 agent 基准。

## 底牌一：架构效率——不把算力当无限资源

Transformer 自 2017 年诞生以来有两个老大难：softmax attention 的计算量随序列长度平方增长（O(n²)），dense 激活的推理成本随总参数量线性上涨。MiniMax 的第一张牌就是"省钱"：

1. **MoE 稀疏化**：Mixture of Experts 思路很老（1991 年就有论文，2017 年被 Google 用于大模型），核心是"全公司 456 人，每来一单只叫 46 人上岗"。MiniMax-Text-01 总参数 456B、每次仅激活 45.9B，把推理成本压到同规模 dense 模型的零头。
2. **Lightning Attention（线性注意力）**：把 attention 复杂度从 O(n²) 压到 O(n)。线性注意力的学术原型 2020 年就有了（Transformers are RNNs），但把它稳定跑到千亿参数并用于商用模型，MiniMax 是最早一批。纯线性注意力会"记性变差"，所以 Text-01 用 7:1 的比例把线性块与 softmax 块混合，换来百万级 token 的上下文窗口。
3. **更激进的 M2**：总参数 230B、激活仅 10B，API 价格只有同级模型几分之一。

为什么效率是 AGI 问题？因为前沿模型的迭代本质是一场"搜索"：你能负担多少次实验、多少 test-time compute，决定你试错的速度。省下来的算力，就是多出来的迭代次数。

## 底牌二：强化学习——从"会说话"到"会干活"

- **路线共识**：预训练吃的是互联网文本，模型只能学到"人类怎么写"；要学"怎么把事做成"，得靠强化学习加可验证奖励（RLVR）去真实试错。o1 和 R1 已经验证了这条路。
- **M1 的算法贡献**：这是 MiniMax 的开源推理模型。传统 RL 训练里，importance sampling 权重一旦跳变，整个梯度就会崩；M1 提出 CISPO 算法，用截断的 IS 权重保住那些小概率但关键的推理步，技术报告称训练效率比同类方案大约翻倍。
- **M2 走向 agent**：引入交错思考（interleaved thinking），模型边干边想、边调工具、读报错、改代码。在 SWE-bench Verified 这类真实仓库修 bug 基准上进入开源第一梯队，同时刻意压低生成 token 量——追求"想得精"，而不是"想得长"。
- **开源本身也是策略**：权重开放下载，等于让全球开发者免费帮它做压力测试和生态绑定，口碑与反馈再反哺下一代模型。

## 底牌三：全模态 + 产品飞轮——智能要有出口

1. **模态栈齐全**：语音合成（Speech 系列）、视频生成（海螺 Video）、图像、音乐，文本之外的"感知器官"一个不缺。视频生成尤其关键——它是"世界模型"的练兵场，一个物体下落时符不符合物理规律，骗不了人。
2. **产品反哺模型**：早期的 Talkie/星野积累了海量多轮情感对话数据，海螺 AI 面向生产力场景，MiniMax Agent 直接做任务交付。真实用户交互产生的反馈，构成了数据飞轮：更好用的产品 → 更多交互数据 → 更强的模型。
3. **一致的赌注**：既然 AGI 的验收标准是"能替人做事"，那么应用层就不是模型的下游，而是模型的训练场和试金石。

## 冷思考：离 AGI 还有多远？

- **基准 ≠ 现实**：SWE-bench 高分不等于能独立顶住生产环境八小时值班；长程任务的可靠性，至今是所有实验室的共同短板。
- **算力差距客观存在**：与最头部实验室的资本开支相比，MiniMax 走的是"以小博大"，效率路线既是技术判断，也是现实约束下的最优解——这两者并不冲突。
- **AGI 没有公认判据**：何时算实现，学界至今没有共识。与其追问时间表，不如跟踪可验证指标：长任务成功率、工具调用可靠率、单位智能的推理成本。

## 给关注者的三条实用建议

1. **看模型别只看总参数**：激活参数量、上下文长度、每百万 token 价格、agentic 基准分数，这四项比一个"大"字的信息量大得多。
2. **技能栈押注 RL + Agent 工程**：工具调用编排、记忆管理、评测体系（evals）设计，是当前供需缺口最大的方向，比单纯堆 prompt 技巧更有长期价值。
3. **对任何 AGI 时间表保持冷静**：包括这家公司自己给出的。判断依据永远是可复现的能力增量，而不是发布会上的形容词。

AGI 不是一句口号，而是一条由效率、算法和应用共同铺出来的工程路径。至于这条路通向哪里——让任务成功率说话。
