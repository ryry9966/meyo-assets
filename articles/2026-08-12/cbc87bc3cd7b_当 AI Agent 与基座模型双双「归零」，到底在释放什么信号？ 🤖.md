这一个月，AI 圈子被两个看似相反、实则同频的消息刷了屏。一边，开源大模型 InternLM 的核心人物林俊旸宣布将重心从模型规模竞赛转向基础能力的长期打磨；另一边，通用 Agent 产品 Manus 在爆火后又迅速进入沉默期，团队表态要回到「让浏览器真正干活」的最原点。表面看是收敛，深层看更像一次集体「冷启动」。



## 林俊旸的「回归」：当扩展法则不再是一切

林俊旸是上海 AI 实验室 InternLM 系列大模型的关键技术推动者。在过去的两年里，InternLM 从几B参数一路冲到百B级别，在开源社区积攒了可观的影响力。但他的最新表态透露出一个明显转向：不再把 Evaluation 榜单上的分数翻新当成第一目标，而是回到模型理解力、推理可解释性、长上下文记忆等基础能力的深水区。

- **扩展红利逐渐见顶**：从 Chinchilla 定律到 Llama 3、Mixtral 的架构创新，单纯堆参数和数据的边际收益正在下降。开源社区发现，70B 模型精调后的实用表现，与某些 200B 模型不相上下。此时再去追逐下一个「千亿」，ROI 并不高。
- **长尾失效比高分更难治**：企业内部测试发现，模型在处理 100 轮以上多步推理任务时，即便第一步正确率 95%，串联后也只剩 60%。这种「连锁遗忘」现象不是靠堆参数就能解决的，必须在 Attention 机制和训练范式上做手术。
- **从 Benchmark 到真实场景的鸿沟**：MMLU、HumanEval 上的高分，并不等于能在合同条款审查、数控代码生成中平稳运行。林俊旸团队开始大量引入真实工作流数据，将训练目标从 Token 预测转向 Outcome Reward Modeling，让模型理解指令的「最终目的」而非仅仅拟合模式。



## Manus 的「回到原点」：Agent 狂热后的反直觉冷静

Manus 是 Monica 团队推出的全自动浏览器 Agent，能在购物、报销、数据抓取等场景自主操作网页。产品一经内测就引爆了社交网络，邀请码被炒到上千元。然而一个月后，团队并没有急着扩量，反而宣布「回到底层，重新打磨核心执行单元」。这个决定虽然让不少投资人皱眉，却暴露了当下 Agent 产品的三处硬伤。

- **沙盒里的完美与生产环境的脆弱**：绝大部分 Agent 演示都在可控、低干扰的测试页面进行。一旦进入真实互联网环境，遇见验证码、非标准弹窗、AJAX 异步渲染，任务失败率就从 5% 飙升到 30% 以上。Manus 团队发现，解决 80% 的网站覆盖不难，最后 20% 的长尾网站却消耗了 80% 的工程资源。
- **浏览器自动化仍然没有「银弹」**：Playwright、Puppeteer 等工具虽然强大，但它们本质还是 DOM 操作的机械执行。Agent 需要理解页面语义、预判元素状态变化，甚至要像人一样「猜测」某些不可见操作。Manus 选择回到原点，就是将视觉语言模型（VLM）与脚本执行器做更深度的耦合，而不是简单调用 GPT 做规划。
- **成本与延迟的钟摆平衡**：一次完整的跨网站操作，如果每一步都调用大模型做决策，Token 消耗可达数万，延迟超过 20 秒。Manus 希望把高频操作固化成确定性脚本，只在异常时才求助模型，从而把每次任务成本压到 $0.1 以下。



## 两条路，同一种底色：工程化是第一性原理

林俊旸的「回归基础」和 Manus 的「回到原点」，看似一个向上游，一个向下游，实际上共享同一套工程哲学：不再迷信大一统的通用智能叙事，而是把每一个细节问题都当成硬骨头来啃。

- **模型侧**：业界正在从「训练一个全能模型」转向「训练一个易于分工的模型基座」。例如将 RAG（检索增强生成）、Function Calling、Tool Use 等能力内化到模型底层，而不是简单外挂。这要求模型在 Attention 层面就理解结构化知识与实时信息的区别。
- **Agent 侧**：主流路线不再是让 Agent 自己决策出所有步骤，而是引入「人机共谋」的混合执行模式。关键步骤（如支付、提交）由人确认，机械步骤（如填充表单）由 Agent 完成。这看起来不那么「酷」，却是目前唯一能落地的安全方案。
- **共同难题——评估体系缺失**：模型有标准 Benchmark，Agent 却没有。一个任务到底算 80% 完成还是 100% 完成？Manus 团队正在自研一套基于任务路径覆盖率的评价框架，这与林俊旸团队的低层干预评估（比如分析隐藏状态中的知识回路）形成镜像，都在尝试把黑盒变成灰盒。



## 冷思考：AI 的「慢变量」时代来了吗？

这一轮「归零」远不是悲观信号，更像是把行业从漂浮态拉回重力场。对于关注 AI 的工程师和产品人，三个清醒认知也许值得收藏。

1. **模型能力不再是唯一瓶颈，系统化能力才是**。就算 GPT-5 明天发布，要让它在你的公司里真正读取内部 ERP、发送审批邮件，仍然需要解决鉴权、流程适配、异常回滚等一整套工程问题。不要等「更强模型」来拯救，现在就可以开始构建 Agent 中间件和工具链。
2. **从炫技到降本，商业逻辑在翻转**。过去一年 AI 融资项目可以容忍 Demo 级别的不稳定，2025 年的客户却开始问「ROI 多少」「减少几个工时」。这倒逼团队把资源砸向可靠性，而不是功能列表。
3. **回归基础的团队更有可能抓到下一个奇点**。OpenAI 的 GPT 系列、DeepMind 的 AlphaFold，无不是在基础能力上反复锤炼多年后突然迎来涌现。基础枯燥，但它会筛选出真正有耐心的人。



把时钟拨慢，或许更能听清齿轮咬合的声音。LLM 的 Scalin Laws 正在被 Reliability Laws 修正，Agent 的自动化狂想也在向「可控执行」妥协。这不是退步，而是整个行业对「智能」有了更诚实的定义——它能稳定解决的真实问题，远比它能震撼世界的 Demo 更重要。
