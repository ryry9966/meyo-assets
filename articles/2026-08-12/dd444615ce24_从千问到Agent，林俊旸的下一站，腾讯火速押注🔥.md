那条让 AI 圈集体转发的消息，像一颗石子扔进本就滚烫的湖面。前阿里巴巴达摩院千问大模型负责人林俊旸正式宣布回归，成立新公司并全力投入 AI Agent 赛道。而更让业内嗅到不同寻常气味的是，腾讯早已悄然跟投。从亲手搭建千问底层技术栈，到如今 All in Agent，这位曾在大厂深处埋头苦干的工程师，正把自己的下一站推向浪尖。



## 林俊旸是谁？千问背后的技术布道者

要读懂这次创业的份量，得先认识林俊旸身上那个标签：千问（Qwen）系列大模型的核心推动者。

- 在达摩院期间，他带领团队从零搭建了 Qwen 基础模型，并连续迭代出 Qwen-7B、14B、72B 到多模态版本，在国内开源社区里积累了实打实的口碑，Hugging Face 下载量曾一度冲进全球前三。
- 与许多头部实验室不同，林俊旸团队一直坚持将模型权重和训练细节同步开源，甚至公开了 RLHF（人类反馈强化学习）全流程技术报告，这种“透明做派”为他赢得了开发者群体的信任。
- 他个人的技术嗅觉也十分敏锐，早在 2023 年初的多次公开分享中，就反复推演“大模型要从对话走向行动”，预言单纯文本交互的 chatbot 会快速同质化，而能调用工具、完成多步任务的 Agent 才是释放模型价值的正确姿势。

可以说，林俊旸不仅懂怎么训模型，更清楚训出来的能力该用在哪里。这种背景下的出走创业，自然不止是“再做一个大模型”那么简单。



## AI Agent：从“聊天”到“干活”，为何是下一站

很多人还把 Agent 当作更聪明的聊天机器人，这其实是一种危险的误解。

- 传统 chatbot 遵循“提问-回答”的单轮交互，即便多轮对话，也只是被动填充上下文。而 Agent 的核心差异在于“自主规划-执行-反馈”闭环。它会拆解目标、制定步骤、调用外部工具（搜索引擎、API、代码解释器），甚至在遇到错误时自我修正。
- 举个直观的例子：你让 Agent 帮你整理一份行业研报。它可能先去搜索引擎爬取最新新闻，再用 Python 分析公开财报数据，提取关键指标做成表格，最后生成一份 PPT 大纲。整个过程类似一个初级分析师在工作，而不是一个只吐文字块的对话框。
- 技术上，这依赖大模型的推理、记忆和工具使用三大能力。以 AutoGPT、MetaGPT 等项目为代表，社区已经验证了原型跑通的可能性。微软、谷歌、OpenAI 也相继推出 Copilot、Project Mariner 等 Agent 类产品，Gartner 甚至预测到 2028 年，15% 的日常工作决策将由 AI Agent 自主完成。

正是在这个节点上，资本开始重新计算软件形态的变量。如果 Agent 能吞掉一部分重复性脑力工作，那么整个 SaaS 和应用层的估值逻辑都可能被改写。



## 腾讯火速入局：入口焦虑与生态野望

腾讯对林俊旸新公司的跟投，不能简单看作是财务投资，背后深藏着一部“连接器”的续集。

- 微信月活已超 13 亿，小程序生态积累了数百万第三方服务，但这些服务目前仍依赖被动触达。Agent 的介入，可能让微信从一个“静态工具盒子”变成“主动代办平台”。比如用户不必点开外卖小程序再手动选餐，而只需告诉 Agent 偏好，它就能跨多个小程序比价、下单、跟踪进度。
- 企业微信侧同理，Agent 可以成为每个员工的数字同事，自动处理审批、会议预约、报表生成，企业服务软件的交互方式将从“GUI 鼠标点击”向“自然语言指令+自动化执行”迁移。这是腾讯在产业互联网故事中原本就想完成的一环。
- 此外，腾讯云急需差异化的 AI 原生计算负载。千问出身的团队对模型训推成本、Agent 流程编排有极深的理解，无论是在内部场景落地，还是对外输出解决方案，都能与腾讯的云底座形成协同。

这笔跟投，本质上是腾讯在买一张通往 Agent 操作系统级入口的船票——一旦 Agent 成为新的软件分发渠道，谁拥有最活跃的 Agent 生态，谁就捏住了下一代流量的水龙头。



## Agent 创业潮：技术难点与商业化冷思考

然而，就像所有被推上风口的技术，Agent 从实验室 Demo 跑到生产环境，中间还隔着好几道硬坎。

**技术难点**

- **可靠性无法保障**：目前主流 Agent 在多步任务中的端到端成功率普遍低于 60%，尤其在需要复杂推理和多次外部调用的场景下，step 越多，出错的概率呈指数放大。一次幻觉可能导致整个任务链断裂，无法直接交付给非技术人群使用。
- **推理成本高得可怕**：Agent 单次任务往往需要几十甚至上百次 API 调用，按 token 计费模式下，商业闭环难度极大。即便用上 MoE（混合专家）架构和缓存压缩，推理成本仍是普通 chatbot 的 5 倍以上。
- **安全与权限边界模糊**：给 Agent 开放邮件、日历、支付接口后，一旦遭受 prompt injection 攻击，风险将呈连锁反应。如何在自主行动与最小权限之间画线，目前全行业尚无标准答案。

**三条冷思考**

1. **别急着 All in，先找“容忍度高的窄场景”**。Gmail 的自动补全可以出错，因为用户会纠正；但自动购买机票的 Agent 一旦失误，就是直接的经济损失。从医疗文书、代码辅助、报表生成这类“有校对环节”的垂直领域切入，比一上来就宣称通用超级助理更踏实。
2. **守住数据护城河，别给大厂“当佃农”**。林俊旸的项目有腾讯加持，但大多数创业公司无法绑定巨头。Agent 的价值高度依赖私有业务数据和交互反馈，只有沉淀自己场景里的飞轮，才能避免重蹈“XX 小程序就靠微信流量，规则一改全军覆没”的覆辙。
3. **盯紧端侧和边缘计算的结构性机会**。Agent 的高频推理终将倒逼模型小型化和端云协同。能提前在手机、PC、IoT 设备上布局 Agent 轻量级运行环境的团队，可能抓住下一波硬件换机潮的钥匙，就像触屏交互催生 iPhone 一样。

Agent 不是万能灵药，但确实是目前能看见的最接近“数字劳动者”的形态。这轮创业浪潮里，理性远比口号重要。
