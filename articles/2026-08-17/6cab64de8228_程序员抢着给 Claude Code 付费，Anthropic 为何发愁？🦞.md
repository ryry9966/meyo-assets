最近科技圈有个话题很反直觉：全球开发者都在争着给 Anthropic 充钱，甚至主动从 Pro 升级到 Max，但 Anthropic 官方反而开始限流、提示用户别乱烧额度。很多人第一反应是：付费用户多了，平台不应该开心吗？

这恰恰是大模型商业里最值得聊的一课：当用户觉得自己在“薅羊毛”，平台看到的却可能是单位经济学倒挂。今天不聊八卦，只从技术、成本与商业逻辑拆解这件事。



## 一、Claude Code 是怎么让程序员主动掏钱的

Claude Code 不是传统意义上的代码补全工具，而是一个 agentic coding tool，能在终端里读代码、跑命令、改文件、写测试，像一个常驻在仓库里的结对程序员。

- 传统 Copilot 类工具主要在编辑器里补全若干行。
- Claude Code 可以接受一个模糊任务，例如“把旧 React class 组件迁移到 hooks，并补齐 Jest 测试”，然后自己跨十几个文件执行修改。
- 它依赖 Claude 系列模型的长上下文能力，能把整个 repo 或大型模块一次性塞进上下文。
- 订阅制定价降低了心理门槛：Pro 每月 20 美元，Max 套餐则提供更多用量，相比雇佣一个初级工程师，每月几百美元显得很便宜。

于是很多开发者把“月费”当成了“固定成本”，用起来非常大方。问题也正出在这里。

## 二、为什么说这是“白送钱”：token 账本与 agentic loop



“白送钱”这个说法有两层意思：用户觉得花小钱办大事；平台看到的是重度用户消耗的算力远超月费收入。核心原因在于，AI 编码不是按次收费，而是按 token 消耗量结算的。

- token 是大模型处理文本的基本单位，中文一个字通常对应 1 到 2 个 token，代码字符、符号和空格也会被切分。
- 一个 agentic loop 远不止“问一句、答一句”。它会读取文件、规划步骤、生成修改、运行测试、失败后重试，每一次循环都重新带上之前的大量上下文。
- 举例来说，一次跨文件重构，输入可能是 8 万 token，输出单次只有 1.5 万 token，但如果模型反复尝试 12 轮，总消耗很容易超过 120 万 token。
- 按公开 API 常见价格粗算，输入每百万 token 几美元，输出每百万 token 十几美元。一次重度任务的真实算力成本，可能已经超过用户一个月的订阅费。

换句话说，Claude Code 的订阅套餐像健身房月卡，但 agentic loop 把它变成了按里程计费的出租车。月费把计价器藏了起来，用户越用越觉得划算，平台则看到账单在悄悄膨胀。

## 三、Anthropic 为什么“看不下去”：单位经济学与算力瓶颈

如果每个用户都只是轻度使用，订阅制当然划算。但 AI 编程工具的画像极度分化：少数重度用户可能贡献了大部分 token 消耗。

- 固定订阅收入与变动推理成本之间容易出现倒挂。用户付 20 美元，但可能烧掉几十美元的 GPU 推理成本。
- 大模型推理不是无限的，高峰期需要排队调用 GPU 集群。需求激增会直接推高排队时间、限流概率和整体服务质量。
- Anthropic 的应对并不是“不欢迎用户”，而是把消费结构往可持续方向引导：限制高峰期限速、鼓励重度用户走 API 按量计费、推出 prompt caching 和 batch API 降低峰值成本。
- 历史上云服务商早有类似教训：早年的无限流量云盘、无限带宽 CDN，最终都因为 1% 的重度用户拖垮了服务，改成按量计费或公平使用政策。

所以官方“看不下去”，本质不是嫌用户付钱太多，而是怕低价套餐吸引来的重度使用把服务质量和成本结构一起打穿。

## 四、理性“送钱”的三条建议



对普通开发者来说，真正要关心的不是“要不要给 Anthropic 付费”，而是该怎么付、怎么用，才能让工具长期可用。

1. **把一次性探索与持续生产分开**  
   偶尔体验用订阅套餐没问题；高频任务、团队协作或生产环境，更适合走 API 按量计费，并设置速率限制和预算告警。

2. **减少 agentic loop 里的无效消耗**  
   拆分任务，不要让模型反复读取全量文件夹；能用 prompt caching 就尽量缓存固定上下文；测试失败时先看日志，而不是直接让模型重跑整个任务。

3. **把 AI 编码当耗材，而不是无限会员**  
   定期查看 token usage，建立月度成本观测。月费只是入口，真正的单位成本由你的使用强度决定。搞清楚自己的典型任务会消耗多少 token，比比较套餐价格更重要。

一个冷思考是：所有“包月 AI”最终都会向按量计价、阶梯限速或混合定价收敛。因为推理成本就摆在那里，任何平台都不可能长期用固定月费覆盖重度用户的无限消耗。开发者越早理解 token 账本，越不容易被“月费很便宜”的错觉带着走。
