“中间商”到底能值多少钱？最近科技圈的一条消息让不少开发者重新审视 AI 基础设施：OpenRouter 这家专门做模型 API 路由的公司，被传出以约 70 亿美元的价格“卖身”。对于不熟悉基础设施的人，它既不训练大模型，也不生产 GPU，更像一个模型世界的“路由器”和“收银台”。但正是这个位置，让它成为 AI 应用起飞阶段最典型的“卖水人”生意之一。本文从技术逻辑、商业机制和基础设施演进三个角度，拆一下这件事到底意味着什么。



## 一、OpenRouter 干的事：模型世界的“路由器”

先把它做的事情翻译成容易理解的话。

- 统一 API：开发者用一个 key、一套接口格式，调用 OpenAI、Anthropic、Google、Meta、Mistral 等不同厂商的模型。
- 统一计费：平台按 token 或请求量统一结算，开发者不用在每家模型厂商后台分别充值、对账。
- 智能路由：按价格、延迟、上下文长度、多模态能力、可用区、uptime 等规则，把请求分到合适的模型。
- Fallback 与冗余：当一个模型超时、限流或返回异常，自动切到备用模型。
- 可观测性：提供日志、用量统计、成本分析和模型效果对比，方便团队做 FinOps 和评测。

类比一下，它类似于支付行业里的聚合支付、通信行业里的 CPaaS、旅行行业里的聚合机票平台。它不创造模型能力，但显著降低多模型接入和切换的成本。

## 二、为什么“路由层”会值钱：碎片化催生中间层

如果模型只有一家独大，中间层价值有限。但现实是模型供给高度碎片化。

- 开源与闭源长期并存：Llama、Qwen、Mistral 等开源模型，与商业 API 模型各有优势场景。
- 不同模型差异很大：上下文窗口、价格、推理速度、多模态支持、代码能力、合规要求都不相同。
- 企业不想被单一模型锁死：当某个模型涨价或某些任务表现退步，企业希望快速切换。
- 应用形态在变复杂：从聊天到 Agent，单次任务可能连续调用几十次模型，涉及规划、检索、工具调用、反思等多个步骤，路由和编排的价值随之上升。

更重要的是，路由层掌握着真实调用数据和分发权。它相当于需求侧的入口：模型厂商需要通过它获得开发者，开发者需要通过它获得选择和冗余。调用量越大，平台越能积累“哪个模型在什么任务上更稳、更便宜”的真实数据，从而优化路由策略。这种数据网络效应，是普通 API 转发服务不具备的。

## 三、70 亿美元是怎么估出来的：买的是“AI 入口税”



70 亿美元在任何行业都不是小数字。市场买的核心不是 OpenRouter 的代码，而是它的结构性位置。

- 抽成模式：平台从每笔模型调用中赚取一定比例的差价或服务费。即使 take rate 不高，当 AI 调用量指数增长，收入规模也会被放大。
- 企业级增值：私有部署、优先路由、审计日志、成本预算控制等，可以支撑更高毛利。
- 可比参照：通信聚合、支付聚合在高速扩张期都曾被给予高估值。它们的共性是：处在供需双方之间，掌握流量入口，吃行业增长红利。
- 收购动机猜测：云厂商想补齐 AI 生态入口；算力或模型厂商想获得分发渠道；基础设施方想绑定开发者流量。

但风险同样明显。薄毛利、模型厂商自建分销、云厂商推出原生聚合、价格战，都可能压缩中间层的空间。换句话说，70 亿美元买的是“AI 应用继续爆发、模型供给继续分散”的预期，而不是当下已经锁定的利润。

## 四、开发者视角：模型路由器到底解决了什么

对开发者来说，OpenRouter 这类服务有很实际的用处。

- 多供应商冗余：一家模型宕机或临时限流，应用不会跟着挂。
- 动态成本优化：简单任务路由到便宜、快速的模型，复杂任务才用贵模型。
- 快速验证：一个接口跑多个模型，方便做 A/B 测试和产品原型。
- 集中观测：统一日志和成本分析，团队不用在多个控制台之间跳。

但它也不是没有代价。第三方路由会增加一个故障点，日志与数据合规需要更谨慎，长期依赖某个路由商也可能形成新的锁定。开发团队要在“自建代理”和“使用第三方路由”之间做判断：规模小、模型少的时候，自建更可控；规模大、模型多、需要复杂策略的时候，第三方路由的优化价值才会体现出来。

## 五、实用建议与冷思考



围绕这个事件，比起“要不要追热点”，更值得做的是三组判断。

- 给开发团队：选择模型路由服务时，优先看模型覆盖度、fallback 能力、日志审计、数据驻留、SLA 和退出成本。不要只看单价，全链路成本才是真实成本。
- 给创业者：不要只做“API 包一层”的薄中介。长期壁垒在策略引擎、企业级信任和数据网络效应，而不是简单转发。
- 给普通用户：你正在用的 AI 产品，背后很可能经过了多层路由。选择至少能说明模型版本和数据流向的产品，减少“出了问题不知道找谁”的情况。

三条冷思考：

1. **聚合层繁荣，说明上游供给分散。** 一旦某个模型形成事实标准，中间层的价值可能被压缩。
2. **70 亿美元买的是预期。** AI 调用量增长一旦放缓，估值会剧烈修正。
3. **不要用路由把锁定从模型厂商换成路由商。** 保持可迁移性，才是使用第三方基础设施的第一原则。

OpenRouter 的故事至少说明一件事：AI 竞争已经进入应用爆发、基础设施分层的阶段。模型能力当然重要，但把能力稳定、低成本、可替换地送到开发者手里，同样是一门值得重估的生意。至于这个价格是不是泡沫，市场会给出答案。
