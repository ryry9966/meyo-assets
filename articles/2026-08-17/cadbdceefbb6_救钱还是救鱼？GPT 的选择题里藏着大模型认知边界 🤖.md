最近，微博上一条“问GPT钱和鱼同时掉水里先救哪个”的话题被玩坏了。不同网友晒出的回答差异很大：有的一本正经选鱼，有的先调侃“鱼本来就会游泳”，还有人把问题拆成“纸币、硬币、观赏鱼、食用鱼”四种组合。同样的模型，答案却能翻出好几种画风。这不是 GPT 道德分裂，也不是它故意逗你，而是这道题恰好踩中了大语言模型最不擅长处理的那类问题：变量模糊、文体混杂、价值排序不明确。它戳中的是模型如何生成文本、如何被提示词影响，以及“看起来会思考”和“真的在思考”之间的差距。



## 一、这题为什么能让大模型“卡住”

表面上是二选一，实际上叠了至少四层语言陷阱。

- 语义多义：钱可以是纸币、硬币、存款、电子红包；鱼可以是观赏鱼、食用鱼、野生鱼，甚至“鱼”在中文网络语境里还可能是谐音梗。不同对象对应的道德权重和常识前提完全不一样。
- 前提冲突：鱼掉进水里通常不需要救，它本来就在水里；钱掉进水里的问题不是生命危险，而是财产损失。“救”这个动词被硬套在两件性质完全不同的事情上。
- 价值排序缺失：如果题目隐含“生命优先于财产”，答案似乎很确定；但如果鱼会游泳、钱会沉底，“先捞钱”反而是最优操作。模型需要判断出题人到底在问道德困境、脑筋急转弯，还是钓鱼玩梗。
- 文体识别困难：严肃伦理题和网络段子使用的语言模板不同。模型需要在缺乏明确文体标记的情况下，从“钱和鱼”“掉水里”“先救哪个”这些词里猜你到底要一个正经答案还是一句俏皮话。

所以这不是知识题，也不是纯逻辑题，而是一道“未定义清楚变量 + 混合文体 + 价值权重缺失”的开放题。它很适合用来检验模型如何处理模糊输入，而不是检验模型有没有良心。



## 二、GPT 到底在“想”什么：概率，不是道德

很多人以为 GPT 先判断“钱重要还是鱼重要”，再输出结论。实际过程更接近：模型逐 token 地预测下一个词的概率分布，然后采样生成。它没有想救谁，它只是在给定前缀后，预测一段最像合格回答的文本。

- 语言模型的训练目标是最大化下一个 token 的预测准确率。比如输入“钱和鱼同时掉水里先救哪个？先救”，模型会计算后面接“鱼”“钱”“人”“火”等的概率。最终接的是哪个，取决于训练语料里类似语境的频率，以及当前输入带来的上下文约束。
- GPT 为什么说话像人：它从海量人类文本中学到了回答伦理题的模板，包括“先考虑生命”“分情况讨论”“结论要温和”等模式。所以它不会只蹦一个词，而会给出带解释的长句。
- RLHF 让回答更“安全”。人类标注者往往更喜欢有同理心、不冒犯、不愿简单牺牲生命的回答，因此模型学会在类似两难题里先强调“生命优先”，再补一句“分情况”。但这个安全倾向有时会与常识冲突，比如忽略鱼本来会游泳。
- 解码随机性也不可忽视。temperature 等采样参数会影响输出多样性。温度越高，低概率 token 被选中的机会越大，答案越容易从严肃滑向段子。所以不同截图里 GPT 看似变了立场，很多时候只是同一概率分布的多一次采样。

一句话概括：它不是在回答“应该救哪个”，而是在回答“一个像 ChatGPT 的模型，在类似问题下会怎么说话”。



## 三、联网搜索和系统提示如何改变答案

同一模型、同一问题，也能长出多种“人格”。决定最终画风的主要是三个变量。

- 是否联网：关闭搜索时，模型主要靠训练记忆和系统预设，回得比较标准；打开搜索后，它可能读到这个话题在微博已经变成梗，从而识别出“这是一道网络段子题”，回答会更机灵，甚至反过来调侃用户。
- 系统提示：如果你用 API 或自定义 GPT，把系统提示写成“你是一个严谨的伦理学教授”，它会从功利主义、义务论、美德伦理逐条分析；写成“你是一个毒舌网友”，它可能直接说“鱼：你礼貌吗？我本来就会游泳”。
- 上下文诱导：多轮对话会把模型拉向不同方向。先聊“宠物鱼养了五年，每天换水”，再问救哪个，模型大概率把鱼当情感对象；先聊“钱包里有一张明天到期的支票”，结论又会偏钱。上下文越强，模型越难保持中立。
- 输出格式要求：要求“只回一个字”会逼出极端答案；要求“写 600 字说明”会激活分情况讨论；要求“用讽刺语气”会激活段子模式。提示词的每一个细节都在改概率分布。

所以热搜中答案五花八门，不代表模型集体精神分裂，而说明大模型是一个对提示词极其敏感的系统。你稍微挪动一下提问环境，它的输出分布就跟着变。



## 四、这道题照出的大模型能力边界

这道荒诞题最值钱的不是结论，而是它照出了当前大模型的几块短板。

- 没有真实世界体验，只有文本常识。模型没见过纸币泡水，也没观察过鱼在水里是否需要救援。它依赖训练语料中的统计共现，因此会忽略“鱼本来就会游泳”这种人类凭经验一眼就能看穿的事实。
- 严肃与幽默的切换不可靠。同一个问题可能触发脑筋急转弯模式，也可能触发严肃伦理模式。模型没有稳定形式判断机制，只能靠语境概率。于是它在梗题上时而聪明，时而尴尬。
- 对齐目标之间存在张力。有用、诚实、无害三者经常冲突：直接说“先救钱”可能被判定为缺乏同理心；直接说“先救鱼”又可能在常识上不诚实。最终，模型往往给出非常谨慎、分情况、先说前提的回答，显得“高情商但没立场”。
- 语言流畅不等于事实可靠。模型非常擅长编织听起来合理的解释，哪怕前提站不住脚，也能头头是道。这在心理学上接近“流利性偏差”：人容易把说得顺的内容当作更可信。面对模糊、歧义、价值排序题，AI 输出的流畅感反而会放大错误。

理解这些边界，比追问“先救哪个”更有用。



## 最后：三条冷思考

1. 别让大模型替你背道德判断题。它可以帮你梳理变量、提供不同伦理框架，但最终价值和责任仍要人来承担。把它当“文本生成器”而不是“道德裁判”，会少很多误解。
2. 问荒诞题前，先定义清楚变量。钱是纸币还是电子资产？鱼是宠物还是水产？会不会游泳？救人者的能力如何？变量越清楚，答案越有参考价值；否则得到的只是训练数据里的平均答案。
3. 把同一问题多跑几次、换几种 prompt。单次回答也许只是概率采样中的一次波动。改系统提示、调整温度、开关搜索、给几个示例，能看到模型在多大范围内变化，这比纠结某次截图更能理解它的能力边界。

一条热搜看似在问钱和鱼谁更重要，实际是在问：我们到底把大模型当成什么？当成会游泳的鱼，还是当成需要被小心打捞的钱？这个差别，比答案本身更值得想。
