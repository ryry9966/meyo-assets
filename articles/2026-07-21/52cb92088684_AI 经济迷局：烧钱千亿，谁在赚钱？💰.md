2024 年秋天，OpenAI 以 1500 亿美元估值完成史上最大一轮融资，同时被曝出今年可能亏损 50 亿美元；国内大模型 API 价格一降再降，部分场景甚至无限逼近免费；另一边，英伟达的 GPU 依然供不应求，数据中心营收同比翻了三倍。AI 无疑是当下最强劲的资本风暴眼，但它离「健康的生意」究竟还有多远？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-21/20e249db045e650d.png)

## 一、钱流向了哪里：三条泾渭分明的赛道
观察 AI 经济的资金去向，基本可以归纳为三层，每一层的回报逻辑完全不同。

- **算力基础设施层**
  以英伟达为代表，包含 GPU、网络设备、定制芯片。英伟达 2025 财年第二季度数据中心营收 263 亿美元，同比增长 154%。这部分几乎不承担应用风险，只要模型还在变大、训练需求还在增长，卖铲子就永远是确定性最高的生意。
- **模型平台层**
  OpenAI、Anthropic、Google DeepMind，以及国内的百度、阿里、字节、智谱等，都在争夺基础模型的入口。它们靠 API 调用和企业级授权获取收入，但目前普遍处于「增收不增利」的状态。OpenAI 的 ARR 已超过 34 亿美元，但推理和训练成本吃掉绝大部分毛利，再加上激进的人才开支，距离盈亏平衡还有巨大缺口。
- **应用层**
  直接在模型之上构建用户产品的公司，如 Midjourney、Character.AI、各种 Copilot 类工具。这一层离用户最近，理论上离钱也最近，但除了极少数找到了强付费场景的玩家，大多仍在摸索产品市场匹配（PMF）。Character.AI 在用户量极高的情况下依然被 Google 收购，正是因为独立商业化的难度远超预期。

## 二、烧钱的三种经典姿势
行业烈火烹油，但钱烧得也格外快。按成本结构拆解，主要有三个吞金兽。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-21/3e459b8a09110ed8.png)

1. **训练成本指数级膨胀**
   从 GPT-3 到 GPT-4，单次训练的费用从几百万美元跃升至上亿美元。更大规模的万亿参数模型和多模态对齐，意味着需要万卡甚至十万卡级别的集群持续运行数月。每一次 Scaling Law 的验证，背后都是一笔巨额支票。
2. **推理成本被严重低估**
   热门应用每天处理数亿次请求，每一次 token 生成都要消耗算力。虽然量化、投机采样等优化手段不断涌现，但面对超高并发，推理集群的规模依然恐怖。很多大模型公司给出的 API 定价根本覆盖不了实际推理成本——尤其是被迫跟进价格战之后。
3. **免费与亏损换规模**
   国内大模型 API 从每百万 token 上百元打到几乎白送；海外虽然没那么极端，但 OpenAI 的免费版 ChatGPT 也为数亿用户承担着推理账单。这种「先圈地，再找收钱办法」的互联网逻辑，在面对高昂的边际成本时显得格外脆弱。

## 三、真正赚到钱的是谁？
把 AI 产业链扒开看，现阶段实实在在赚取超额利润的，主要是三类角色。

- **算力供应商：英伟达，以及云厂商的 GPU 租赁业务**
  微软 Azure 的 AI 服务收入连续多个季度增长超过 30%，很大一部分来自出租 OpenAI 同款 GPU 集群。AWS 和 Google Cloud 同样在大规模扩容 AI 实例。只要模型公司继续烧钱训练，它们就持续收租。
- **「闷声发财」的垂直应用**
  Midjourney 至今未拿外部融资，通过订阅制在 2023 年就实现超过 2 亿美元营收，团队只有几十人。GitHub Copilot 也已成为微软增长最快的企业订阅服务之一。它们的共同特点是：钉在一个高频、高价值的场景里，用可控的成本实现用户甘愿付费的体验，而不去拼通用大模型的刺刀见红。
- **新型数据与工具商**
  围绕模型训练，数据标注、合成数据生成、MLOps 工具链、安全对齐等细分赛道涌现了一批小而美的公司。Scale AI 估值已超 130 亿美元，这类企业在产业链中处于「卖水」位置，利润率虽然远不如英伟达，但胜在确定性高。

## 四、爆款应用为何迟迟不来？
资本市场盼着「AI 界的抖音」出现，但现实中大多数 AI 应用仍停留在对话式玩具或效率工具的阶段。

- **幻觉与可控性瓶颈**：越是需要高可靠性的企业场景，AI 越难落地。金融、医疗、法律等行业对错误的容忍度极低，而当前模型远未达到完全可信赖的标准。
- **用户留存与付费意愿割裂**：很多 AI 产品的访问量高得惊人，但用户把 AI 当成搜索引擎的补充，周回访率远低于社交、短视频类产品。当产品开始收费，大量用户转身就走。
- **生态依赖过重**：大量应用本质上是「套壳 GPT」，几乎零护城河。OpenAI 一座小小的功能更新，就能让一批创业公司瞬间失去存在的理由。

## 五、冷思考：怎样避开泡沫陷阱？
越是宏大叙事的时刻，越需要沉下心做几个简单的判断。对于关注 AI 经济的朋友，有三条务实框架可以参考。

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-21/1682b5758ac829fa.png)

1. **死磕单位经济模型**
   不管多性感的 Demo，最终要回答一个问题：每服务一个用户或处理一次请求，到底赚不赚钱？如果毛利为负，用户越多窟窿越大，最终只会沦为资本催熟的牺牲品。
2. **分清「技术好」与「生意好」**
   训练出业界第一的模型固然值得尊敬，但如果不能转化为可持续的现金流，那它更像是一台昂贵的研究设备。历史上，技术最优的公司不一定是商业赢家，这一点在 AI 领域同样适用。
3. **盯着现金流，而不是融资额**
   融资估值只是阶段性信号，自由现金流才是真正的血条。在关注一家 AI 公司时，少看它击鼓传花般上涨的估值，多看它能否在剔除预付款和融资后，靠主营业务活下来。

AI 的长期价值毋庸置疑，但经济规律从未失效：没有一家公司能靠讲故事穿越周期的冬天。退潮之后，穿泳裤的一定是那些把 AI 做成真正生意的人。
