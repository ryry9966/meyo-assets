最近，科技圈被36kr的一篇文章刷屏了——《AI 圈的新生意：不是卖课，是立门派》。这标题一出来，很多搞技术的朋友会心一笑。前两年，大模型刚火的时候，朋友圈里一半的人在卖“ChatGPT保姆级教程”，另一半人在搞“三天精通Prompt工程”。如今潮水退去，割韭菜的卖课生意越来越难做，真正懂行的玩家开始换赛道了：不卖课了，咱们立门派。今天RY哥就带大家剥开外壳，用工程师的视角看看这门“立门派”的生意到底在卖什么药。

## 从“知识付费”到“技术布道”：卖课为啥不香了？

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-09/9a39b1c7287ffcda.png)

卖课这门生意，核心逻辑是“利用信息差赚钱”。但在AI这个技术迭代按小时计算的领域，信息差的红利期短得令人发指。你今天录好的“高级API调用教程”，可能明天官方更新了一个原生的Function Calling功能，你的课就直接变成了废纸。

卖课模式退潮，主要源于以下几个技术的现实：

1. **官方文档的降维打击**：以前大家不会用AI，是因为文档晦涩。现在无论是OpenAI还是Hugging Face，官方文档写得比大多数教程都好，甚至自带Playground和代码示例。信息差被直接抹平。
2. **开源工具的平权效应**：像 Ollama、LM Studio 这种一键部署大模型的工具出现，让本地跑大模型的门槛降到了几乎为零。你不需要懂 Python 环境，不需要懂 CUDA 编译，双击一下就能跑。当操作门槛消失，卖操作课就成了伪命题。
3. **模型同质化**：以前教大家怎么写复杂的Prompt来约束模型输出，现在模型自身能力上来了（比如GPT-4o、Claude 3.5 Sonnet），你只要把需求说清楚，模型就能给你满意的结果。Prompt工程正在退化为简单的“表达清晰”。

所以，聪明人发现，与其去赚那点几百块钱的课费，不如把精力投入到建立一个技术生态里。生态的力量是指数级的，而卖课的边际成本递减效应太弱。

## “立门派”的底层逻辑：拿开源当杠杆，撬动生态位

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-09/61077aba7e81c65a.png)

所谓“立门派”，在技术圈的语境里，就是搞开源社区、推自有标准、建技术生态。这并非互联网时代的首创，但在大模型时代被赋予了新的意义。

立门派的底层逻辑，是**“拿开源当杠杆，撬动生态位”**。历史上的成功案例比比皆是：

- **Linux 基金会模式**：通过开源内核，聚拢全球开发者，最终在服务器端一统天下。
- **Android 模式**：谷歌开源安卓系统，建立AOSP（Android Open Source Project），通过生态绑定GMS（Google Mobile Services）实现商业变现。

在AI圈，这套玩法演变成了“模型开源+平台收费”的模式。典型的玩家是 Meta 和 Hugging Face：

1. **权重免费，生态无价**：Meta 砸了上亿美元算力训练出 Llama 3，然后免费开放模型权重。表面上是做慈善，实则是为了打破 OpenAI 的闭源垄断。只要全世界的研究者都在 Llama 架构上做微调和研究，Llama 就会成为事实上的开源标准，Meta 就能在AI时代拥有话语权。
2. **平台即生态**：Hugging Face 早期只是一个类似 GitHub 的模型托管平台，但现在它演变成了“AI界的 npm”。你在这里可以找到预训练模型、数据集、甚至算力提供商。它通过提供 Transformers 库这样的标准工具，把开发者死死绑定在自己的平台上。

这种门派生意，赚的不是C端用户的学费，而是B端企业的算力费、部署费、以及未来技术标准的话语权。

## 经典门派图鉴：从底层框架到应用层的圈地运动

![img3](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-09/34bfc051c2f2bd5d.png)

目前的AI圈，门派林立，大致可以分为三个层级。每一层都有其“掌门人”和核心护城河。

### 1. 底层基建派：卖铲子的铁匠
这一派的核心是算力和框架。英伟达靠 CUDA 生态形成了绝对的硬件护城河，这属于“修真界的绝顶高手”。而在软件框架层，PyTorch 基本一统江湖，成为了大模型训练的事实标准。此外，像 vLLM、TensorRT-LLM 这样的推理加速框架，也在通过优化推理速度（如 PagedAttention 技术）抢占开发者心智。

### 2. 中间件/编排派：大模型时代的 Spring Boot
这一派目前最热闹，也最像传统互联网的“中间件”。代表门派是 LangChain 和 LlamaIndex。
- **LangChain**：试图封装所有与大模型交互的接口，提供 Agent、Memory、Chain 等抽象。虽然近期因为过度封装和运行效率问题受到一些争议，但它先发制人，建立了庞大的集成生态，几乎接入了所有能接入的工具。
- **LlamaIndex**：另辟蹊径，聚焦于 RAG（Retrieval-Augmented Generation）场景的数据摄取和索引结构。在数据连接和检索增强这块做深做透。

这一派的做法是，通过开源核心包获取海量Star，然后推出 LangSmith 这样的商业托管平台，提供Trace和Eval服务来赚钱。

### 3. 垂直应用派：用微调建立壁垒
这一派不搞大而全的框架，而是深耕垂直领域。比如做代码生成的 DeepSeek Coder，或者专门做中文闲聊的 Yi 系列模型。他们通过在特定数据集上的精调（Fine-tuning，如 LoRA 技术），在特定任务上超越通用大模型，然后在 Hugging Face 上开放权重，吸引垂直领域的开发者加入其生态。

## 算力与硬件的隐形门槛：没有金刚钻，别揽瓷器活

![img4](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-09/c5ed6b0e59caea6a.png)

虽然立门派听起来很美好——开放代码，坐等Star破万，但现实是骨感的。AI时代的开源，门槛比互联网时代高得多。以前搞个开源网站，租个云服务器就能跑；现在搞开源大模型，没有算力连微调都做不动。

这就是为什么“立门派”本质上还是大厂和资本密集型创业者的游戏：

1. **显存墙**：哪怕你是个人开发者，想跑起一个 70B 参数的模型做推理，至少需要多张 A100 80G 显卡。如果要做全量微调，算力需求更是呈指数级上升。这已经不是买几张消费级显卡（如 RTX 4090）能解决的问题了。
2. **分布式训练的工程壁垒**：大模型训练不是单机多卡那么简单，需要涉及张量并行、数据并行、流水线并行。像 DeepSpeed 这样的框架，虽然开源了 ZeRO 优化技术，但真正要在千卡集群上跑通且不挂掉，需要极强的工程能力。这背后是动辄数百万人民币的硬件投入和机房电费。
3. **数据壁垒**：高质量的数据集比模型本身更稀缺。很多门派表面开源了模型，但绝对不会开源他们清洗数据的高质量 Pipeline 和核心数据集。这才是真正的“内功心法”。

所以，如果你看到某个“门派”开源了极其强大的模型，别急着感动，那往往是他们展示肌肉、吸引融资、甚至推销自家云算力服务的手段。连算力都凑不齐的团队去搞开源大模型，那不叫立门派，那叫“赛博丐帮”。

## 冷思考与实用建议

看懂了AI圈立门派的套路，对于我们普通开发者和从业者来说，该怎么应对？RY哥给大家三条冷思考：

1. **拥抱开源，但别被框架绑架**：很多中间件框架（如 LangChain）更新极快，且常常有破坏性更新。对于生产环境，尽量使用轻量级的原生 API 调用，或者自己封装核心逻辑。别为了用而用，导致系统复杂度失控。
2. **看清开源协议再上车**：不是所有打着开源旗号的模型都能商用。很多模型采用的是定制协议（如 Llama 的协议对商用规模有严格限制），或者带有非商业用途条款。在企业级应用落地前，务必让法务仔细审查 License，避免侵权风险。
3. **回归业务价值，而非技术狂欢**：无论是卖课还是立门派，都是别人赚钱的道场。作为工程师，我们的核心价值在于解决实际业务问题。不要盲目追逐最新的开源模型或框架，而是要评估它在你的具体场景下，是否真的能降本增效。多把精力放在数据清洗、RAG链路优化和评估体系搭建上，这比天天混迹社区当“精神股东”实在得多。
