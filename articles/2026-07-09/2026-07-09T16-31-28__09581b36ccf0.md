最近，36kr 一篇《我见证了 MiniMax 的"至暗时刻"》在科技圈刷屏。作为国内大模型"新六虎"之一，MiniMax 曾是资本宠儿——估值数百亿、创始人履历光鲜、产品矩阵看似完整。但"至暗时刻"这个标签背后，折射的不仅是一家公司的困境，更是整个中国大模型创业赛道正在经历的结构性洗牌。今天 RY 哥就带各位扒一扒，这场"至暗"到底暗在哪里，又能给行业留下什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-09/43dccf5cb4f2fad4.png)

## 一、"至暗时刻"的表象与内核

从公开信息和行业观察来看，MiniMax 面临的压力是多维度的：

1. **模型竞争力承压**：在中文大模型竞技场（如 SuperCLUE、OpenCompass）中，MiniMax 的排名一度被后起之秀追平甚至反超。当技术叙事不再是"第一梯队独占"，资本的耐心就会迅速见底。
2. **产品线收缩信号**：Glow 等社交向 AI 产品曾带来用户增长高光，但留存和商业化始终是硬伤。当 DAU 增长曲线趋平，"AI 社交"的故事就讲不下去了。
3. **人才流失与组织震荡**：大模型赛道的人才争夺从未停歇。核心算法和工程人员的流失，对技术驱动型公司来说比融不到钱更致命——因为模型迭代速度直接取决于团队稳定性。
4. **融资环境骤变**：2024 年下半年起，一级市场对大模型投资明显趋于理性。"烧钱换模型能力"的逻辑被重新审视，估值锚点从"对标 OpenAI"回归到"看收入、看留存、看毛利"。

> 本质上，"至暗时刻"不是一个时间点，而是一个"讲故事的人被故事反噬"的过程。

## 二、大模型创业的"不可能三角"

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-09/ecf8e681fc57ce1c.png)

把 MiniMax 的困境抽象一下，中国大模型创业公司其实面临一个"不可能三角"：

- **技术先进性**：模型能力要跟得上 GPT-4o / Claude 3.5 的迭代节奏
- **商业闭环**：要有能赚钱的产品，不能永远靠融资续命
- **组织稳定性**：核心团队不散，迭代节奏不断

这三者同时满足，在当前环境下几乎不可能。原因很直接：

**技术先进性要求持续高额投入。** 训练一个千亿参数模型的算力成本以千万计，还不算数据清洗、RLHF 的人力成本。国内 GPU 供给受限，进一步推高了边际成本。

**商业闭环要求产品快速迭代和用户增长。** 但 B 端客户付费意愿有限（很多还在用 API 套壳方案），C 端用户付费转化率低（国内用户对 AI 产品的付费习惯远未养成）。

**组织稳定性要求足够的现金和激励空间。** 当融资收紧 + 商业化未达预期时，期权想象空间缩水，核心人才被大厂挖走的概率直线上升。

MiniMax 的处境，本质上是被迫在三角中做取舍：保技术领先 → 持续烧钱 → 商业化压力增大 → 组织动荡 → 技术迭代放缓。这是一个负反馈循环，一旦进入，刹车距离很长。

## 三、技术路线选择的"路径依赖"

复盘 MiniMax 的技术路线，有几个值得行业反复咀嚼的点：

1. **模型架构的选择时机**：MiniMax 早期选择 MoE（Mixture of Experts）架构，在当时是前瞻性判断。但 MoE 的工程复杂度远超 Dense 模型——路由策略、负载均衡、通信开销，每个都是工程深水区。当开源模型（如 DeepSeek-V2/V3）用更高效的架构实现相近甚至更优性能时，先发优势就变成了沉没成本。
2. **多模态的节奏判断**：MiniMax 在语音和视频生成上有一定积累，但在 2024 年多模态爆发潮中（Sora 引发的视频生成竞赛），并没有形成足够强的差异化壁垒。多模态是烧钱更凶的赛道——算力、数据、工程三重门槛，创业公司资源很难面面俱到。
3. **API vs 自有产品的摇摆**：到底做基础设施（卖 API）还是做应用（做产品），这个战略摇摆消耗了大量组织能量。两条路都走，意味着两边都做不到极致。

> 技术路线的选择，本质上是在信息不充分的情况下做不可逆承诺。选错了不是换个方向那么简单——已投入的算力、数据 pipeline、工程团队的经验都是沉没成本。

## 四、行业洗牌的逻辑底层

把视角从 MiniMax 拉到整个赛道，2024–2025 年中国大模型创业的洗牌逻辑其实很清晰：

- **第一梯队固化**：智谱、月之暗面、MiniMax、百川、零一——"新六虎"的位次已基本确定。但"确定"不等于"安全"，而是意味着格局清晰后，资本向头部集中，后排选手加速出清。
- **大厂挤压加剧**：字节（豆包）、阿里（通义）、百度（文心）、腾讯（混元）凭借算力、数据、流量优势，在 C 端和 B 端同时施压。创业公司的生存空间被压缩到"大厂不愿意做的垂直场景"。
- **开源模型冲击**：DeepSeek、Qwen 等开源模型快速进步，让"自研闭源模型"的性价比叙事受到挑战。当开源免费就能拿到 80 分的效果，客户为什么要为你的 API 付费？
- **商业化时钟**：投资人耐心通常以 18–24 个月为周期。如果在这个窗口内无法证明商业可行性，下一轮融资会变得极其困难。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-09/fc4770bb6d25141d.png)

最后，RY 哥给各位端上三盘"冷菜"：

**1. 不要迷信"技术领先 = 商业成功"的线性叙事。**
技术领先是必要条件，不是充分条件。商业成功需要的是"在正确的场景中，用可接受的成本，提供足够好的体验"。80 分的模型 + 90 分的场景匹配，远胜于 95 分的模型 + 60 分的场景匹配。这个道理在云计算时代被验证过一次（AWS 不是技术最强的，但是最赚钱的），在 AI 时代会再验证一次。

**2. 创业公司的核心竞争力不是模型，是"对特定场景的理解深度"。**
模型能力会趋同（开源 + 大厂 API 的存在保证了这一点），但场景理解、数据飞轮、用户关系网络是难以复制的。与其追模型榜单排名，不如追"你的用户为什么离不开你"。MiniMax 的至暗提醒我们：当你的护城河只有"模型分数高 2 分"时，这个护城河的宽度大概只有一次量化的距离。

**3. 至暗时刻不是终点，而是价值回归的起点。**
当泡沫退去、叙事降温，真正能存活下来的不是故事讲得最好的，而是"单位经济模型"（unit economics）最先跑通的。对从业者来说，与其焦虑行业洗牌，不如把精力放在理解"什么样的 AI 产品能赚钱"这个最朴素的问题上。

> 龙虾在蜕壳时最脆弱，但蜕完壳才能长大。大模型行业正在集体蜕壳——活下来的，才会拥有真正的甲壳。
