港交所迎来了一家号称"视觉具身智能第一股"的公司。36kr报道里有个关键词值得反复琢磨——"场景先行"。这四个字背后，藏着一条和"先烧钱做大模型再找场景"截然相反的商业化路径。今天就来拆解一下，这条路径到底走得通不通，以及它对整个具身智能赛道意味着什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-09/dbb1ca78322ce5a5.png)

## 一、先把概念收紧：视觉具身智能到底在说什么

"具身智能"这个词最近两年被用得有点泛滥，从扫地机器人到人形机器人，什么都说自己是具身智能。先把概念收紧：

- **Embodied AI**：智能体拥有物理身体，能通过传感器感知环境、通过执行器改变环境，形成"感知-决策-行动"的完整闭环
- **视觉具身**：核心感知通道是视觉（RGB-D相机、多目视觉、事件相机等），区别于以力觉/触觉为主的技术路线
- **与纯CV的区别**：传统计算机视觉是"看图说话"，视觉具身智能是"看图干活"——输出不是标签，而是动作序列

更精确的定义：**视觉具身智能 = 视觉感知 + 世界模型 + 运动规划 + 物理执行**，四者构成闭环。

为什么是视觉？因为视觉信息密度最高、硬件成本下降最快。Intel RealSense D455深度相机现在几百块就能拿到，5年前这个价格想都别想。视觉路线的性价比优势在商业化场景里是决定性的。力觉传感器精度高但贵且易碎，激光雷达可靠但信息维度单一——视觉是唯一一个在"信息丰富度"和"硬件成本"之间取得平衡的通道。

## 二、"场景先行"是什么意思，和"技术先行"差在哪

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-09/ed86f9d26f06c4d1.png)

这是本文最核心的部分。两条路径的根本差异如下：

**技术先行路径（大多数AI公司的选择）：**

1. 先建大模型，追求泛化能力
2. 再找场景去适配
3. 商业化滞后，靠融资续命
4. 典型问题：模型在实验室跑分很高，到了真实场景不好用

**场景先行路径（这家公司的选择）：**

1. 先锁定一个具体场景（比如餐饮配送、酒店服务、仓储物流）
2. 针对这个场景的感知-决策-执行链路做垂直优化
3. 在真实环境中部署、积累数据，反哺模型迭代
4. 逐步扩展到相邻场景

打个比方：技术先行像是先造一台"万能发动机"，再想装到什么车上；场景先行像是先造一台"送餐车专用发动机"，跑通了再造下一台。

关键差异在于**数据飞轮的启动方式**：

- 技术先行：需要海量通用数据 → 数据成本高 → 依赖融资 → 商业化压力后置 → 上市时可能还没有稳定收入
- 场景先行：用少量场景数据快速冷启动 → 早期就有收入 → 数据在真实场景中自然积累 → 模型迭代有明确的优化目标 → 上市时已有可验证的商业模式

这不是什么新发明。Tesla的FSD本质上也是场景先行——先在高速公路场景跑通，再扩展到城市道路。区别在于，这家公司选择的是一个更垂直、更快能验证PMF（Product-Market Fit）的场景。

## 三、这条路径的技术底座：不是"少做"，而是"做窄做深"

别误会，场景先行不等于技术简单。恰恰相反，它对技术栈的要求非常specific，只是范围窄了：

**感知层：**

- 需要处理真实场景的遮挡、光照突变、动态障碍物
- 不能依赖理想化的实验室数据集
- 多模态融合：RGB + Depth + IMU + 语义分割，至少四路信号同步
- 实时性要求：感知端到端延迟 < 50ms，否则闭环控制会发散

**决策层：**

- 不需要AGI级别的通用推理能力
- 但需要场景内的因果理解：比如"人在走廊里走过来，我应该靠右停还是绕行"
- 用大模型做太重（延迟高、成本高），用规则引擎太脆（覆盖不全）
- 通常解法是**"小模型 + 结构化先验"**：用VLM做场景理解，用传统规划算法做路径生成，通过中间表征层对接

**执行层：**

- 底盘控制、机械臂操作、安全制动——这部分往往被低估
- 它是"场景先行"路径里最吃工程能力的环节
- 硬件的可靠性、可维护性、成本控制，直接决定能不能在真实场景部署
- 一个常被忽视的数据：服务机器人的MTBF（平均无故障时间）如果低于500小时，运维成本就会吃掉所有利润

**数据闭环：**

- 这才是真正的护城河
- 每台在场景中跑的设备都是数据采集终端
- 数据 → 自动标注 → 模型训练 → OTA下发 → 现场验证 → 新数据
- 飞轮一旦转起来，后来者在同一个场景里很难追上——因为你的数据是"真实分布"，对手的数据是"仿真近似"

## 四、商业化层面：为什么港交所愿意买单

资本市场对AI概念已经审美疲劳了。讲"AGI改变世界"的故事，投资人听够了。这家公司能上市，核心逻辑有几条：

1. **有真实收入**：不是PPT营收，是设备销售/租赁 + 运营服务费的双轮模式
2. **场景可验证**：投资者可以去实地看设备运行，不需要靠论文benchmark来想象未来
3. **单位经济模型成立**：单台设备的回本周期、运维成本、利用率都能算清楚账
4. **扩展路径清晰**：从一个场景到相邻场景的迁移逻辑是可论证的，不是"先做餐饮机器人再做人形机器人"这种跨度过大的跳跃

但"第一股"的光环背后也有隐含风险，不能只看亮点：

- **场景天花板**：垂直场景的市场容量有限，扩展速度取决于技术迁移的边际成本
- **竞争压力**：场景验证可行后，大厂和创业公司都会涌入，先发优势能维持多久是个问号
- **数据合规**：在真实场景中采集的视觉数据涉及隐私问题，合规框架需要提前搭建，尤其是如果未来要出海
- **硬件迭代风险**：传感器/芯片供应链变化可能导致BOM成本波动，毛利不稳定

## 五、对从业者的三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-09/479d527426550a54.png)

**1. 如果你在做具身智能创业：别急着做大，先找到你的"最小可行场景"**

最小可行场景（Minimum Viable Scenario）的判定标准：

- 场景足够窄，3-6个月内能部署出可运行的原型
- 任务足够重复，能产生结构化数据用于模型迭代
- 客户愿意付费，不是"试点项目"结束就没了下文
- 有明确的扩展邻接图：场景A → 场景B → 场景C，迁移路径不是跳跃式的

**2. 如果你在投资这个赛道：重点看数据飞轮的转速，不是看模型参数量**

关键指标体系：

- 在线设备数 × 日均运行时长 = 数据采集总量
- 数据标注成本 / 设备收入比 = 数据效率
- 从新场景部署到模型适配的周期 = 迁移能力
- 三个指标的复合趋势比任何benchmark分数都重要

一个简单判断：如果一家公司模型很大但在线设备很少，它的数据飞轮根本没转起来；如果模型不大但设备密度高、迭代快，它的护城河反而更深。

**3. 如果你做技术选型：视觉路线优先，但别忽视多模态冗余**

视觉是当前性价比最高的感知通道，但单一模态在特定场景会失效（强光直射、极暗环境、透明物体）。工程建议：

- 视觉为主通道（约70%信息来源）
- 超声波/ToF/IMU作为冗余通道
- 关键安全场景加力觉/碰撞检测
- 不要等到出了事故才加冗余设计——那时候成本是10倍

场景先行这条路，说到底就是一句工程界的老话：**先解决一个问题，再解决一类问题，最后才谈得上解决所有问题**。具身智能的终局也许是通用机器人，但通往终局的路是铺在具体场景上的。
