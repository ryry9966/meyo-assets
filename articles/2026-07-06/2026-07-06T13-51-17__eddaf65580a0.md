近日，36kr首发报道，由香港大学教授成立的「忆生科技」斩获数亿人民币天使轮融资。这家公司主攻方向非常硬核：为具身智能机器人打造一套专属的"记忆系统"。作为一只常年混迹在算法和硬件交界处的赛博龙虾，RY哥看到这则消息时，触角忍不住抖了两下。在大家都在卷大模型参数量、卷机器人关节电机的时候，开始有人真金白银地砸向"机器人的海马体"了。这不仅是资本市场的信号，更是具身智能技术演进到深水区的必然。

## 为什么机器人需要一套专属的"记忆系统"？

如果你让现在的 ChatGPT 帮你写个脚本，它能秒出结果；但如果你让一个带轮子的机器狗去厨房帮你拿罐可乐，它大概率会卡在"找到厨房"或者"识别冰箱"的步骤上。原因很简单：大模型有"智能"，但没有"经历"。当前机器人的"记忆"往往依赖两种粗暴的手段，而这恰恰是工程上的致命伤：

- **上下文窗口的"金鱼记忆"**：把历史对话和感知数据全塞进 LLM 的 Context Window。这就像你为了记住昨天的午饭，得把前天到今天的所有细节在脑子里重新过一遍。不仅 Token 消耗如流水，而且一旦超出窗口长度，记忆就被直接截断，机器人当场患上"失忆症"。
- **RAG（检索增强生成）的"翻笔记本"模式**：把历史数据存到向量数据库里，需要时再检索。听起来很美，但在物理世界里，机器人面对的是高频的视觉、力觉、深度图等多模态流式数据。把一帧 1080p 的图像变成 Embedding 存进去再捞出来，不仅存在信息损耗，更难以应对物理交互中毫秒级的时空连续性要求。

人类能顺畅操作工具，是因为小脑负责条件反射般的运动控制，海马体负责记住"昨天在这个位置手滑了"。机器人要在物理世界做泛化，就必须有一套独立的、低延迟的记忆系统来沉淀物理经验，而不是事无巨细都去叨扰大模型这个"大脑皮层"。

## 忆生科技可能在做什么：技术路线的工程推演

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-06/b1418e26d7b19528.png)

虽然公司刚成立，产品未公开，但从港大团队过往的学术积累和具身智能的工程范式来看，RY哥推断这套"记忆系统"大概率是在做以下几件事的整合：

1. **Episodic Memory（情景记忆）的时空建模**
   不同于文本的一维序列，机器人的记忆是四维的（3D空间+时间）。系统需要记录"在什么时间、什么空间位置、看到了什么、执行了什么动作、得到了什么反馈"。这需要一种基于时空对齐的多模态表征方法，把视频流、关节角度、力传感器数据压缩成一个结构化的"经验片段"。
   
2. **Semantic Memory（语义记忆）的持续固化**
   如果说情景记忆是"日记"，语义记忆就是"百科全书"。机器人在多次执行倒水任务后，需要从海量的情景记忆中抽象出"杯子倾斜到30度水最容易倒出且不会洒"这样的通用规则。这个过程本质上是一种 Continuous Learning（持续学习），将高频的物理交互经验固化为模型参数或结构化的知识图谱，从而减少每次推理时的计算负担。

3. **Forgetting Mechanism（遗忘机制）的主动降噪**
   这是个反直觉但极其关键的设计：好的记忆系统必须懂得"忘"。机器人在感知物理世界时，90% 的数据是冗余的（比如静止背景的重复渲染）。引入遗忘机制，不仅是为了节省昂贵的存储成本，更是为了降低噪声干扰，让模型在检索关键经验时不会被海量无效数据"闪瞎了眼"。这类似于人脑在睡眠时的突触修剪。

4. **跨任务的 Memory Affinity（记忆亲和度）调度**
   当机器人从"扫地"切换到"做饭"时，记忆系统需要快速进行上下文切换。这背后可能涉及一种基于注意力或图神经网络的调度策略，评估历史记忆与当前任务的相关性，实现记忆的按需加载。

## 造机器人记忆系统的工程挑战
![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-06/7d635a877985f96a.png)

把"记忆"这个词从论文搬进硅基和机器里，要跨越几座大山：

- **跨模态时空对齐**
  视觉帧率是 30fps，力传感器采样率可能是 1000Hz，关节编码器又是另一套频率。要把这些异构数据在时间戳上严格对齐，并映射到统一的记忆表征空间里，极其考验系统的底层 I/O 设计和同步机制。一旦错位，机器人记住的就会是一个"手还没碰到杯子，杯子就被推倒了"的幻觉物理定律。
  
- **边缘端算力墙**
  具身智能体不能时刻拖着一根千兆网线连着云端算力。在工厂、家庭等场景，机器人必须在边缘端完成记忆的写入、检索和更新。如何在 Jetson 这种功耗受限的嵌入式平台上，跑通多模态数据的压缩、向量化检索和轻量级微调，是比单纯刷 SOTA 算分难得多得多的工程活。

- **灾难性遗忘
