36氪一纸热帖把“阶跃星辰被两面夹击”推上话题榜。这家由前微软全球副总裁姜大昕创办的 AGI 公司，去年还顶着“国产大模型最强多模态”的头衔，如今却被同时卷入开源模型的价格碾压和闭源巨头的资源虹吸，在中间地带进退两难。这种夹缝感不是阶跃一家独有，却恰好映射出当下 AI 创业公司最真实的生存算术题。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/e10592a80fc57f37.png)

## 开源铁蹄压境：你的 API 比开源贵多少？
![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/3cc60741b740e0e2.png)

开源社区的进化速度已经超出了大多数人的预期，而这恰好瓦解了部分商业模型的定价基础。

- **LLaMA 3 免费杀入 70B 级**：Meta 直接把 70B 参数模型甩成开源，允许商用，这意味着任何中小团队都能在自己的 GPU 集群上跑出一个可用度极高的基座，推理成本只剩下电费和维护。
- **Mistral、Qwen 持续下放性能**：Mistral 8x22B、通义千问 Qwen2 系列不断缩小开源与闭源之间的质量差距，并在企业合规、私有部署场景中比 API 调用更容易通过采购部门审核。
- **阶跃的 API 定价面临“合理性追问”**：Step-1V、Step-2 等模型虽然多模态表现亮眼，但对外报价势必会被开发者拿来和自部署开源方案比对。一旦单位 token 成本高出 3 倍以上，客户很容易算出迁移的经济账。

开源模型不仅把价格打到地板，还给了客户数据主权的安全感。而对阶跃这样尚未形成规模收入飞轮的创业公司来说，每一次降价都意味着要在有限的算力预算里再划一刀。

## 巨头“军备竞赛”：算力与人才的双重虹吸
![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/fb57d544aed7fd87.png)

如果说开源模型是从技术侧挤压，那国内大厂就是从资源和场景两侧同时施压，像巨型涡轮把稀疏的养分统统吸走。

- **算力黑洞**：百度、阿里、字节跳动等大厂可以一次性下订万卡集群，通过大规模并行训练摊薄单次实验成本。阶跃星辰依赖外部云资源或有限的自建集群，在千亿参数模型的大规模预训练中，烧钱速度惊人，而融资窗口却在收窄。
- **场景壁垒**：文心一言有搜索、智能云；通义千问有钉钉、电商、物流；豆包大模型直接对接到抖音的巨量流量入口。阶跃缺乏自有超级应用，只能靠 API 获取外部开发者，但开发者迁移成本极低，粘性几乎为零。
- **人才溢价**：顶级 AI 研究员正在被大厂以千万级年薪 + 解决户口等组合拳“打包带走”。创业公司即便给得出期权，也很难在稳定性、工程资源上匹敌。人员流失带来的不仅是薪酬成本，更是研发节奏的不可逆损伤。

在这台军备竞赛机器里，阶跃仿佛一辆高速行驶却油箱见底的赛车，前方是算力和场景的高墙，后视镜里是源源不断的开源追兵。

## 技术路线的十字路口：MoE 架构真能突围吗？
![img3](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/bc136225161f05d1.png)

阶跃星辰一直把 MoE（Mixture of Experts）架构作为差异化标签，Step-1 系列就采用了稀疏化专家模型。这个技术选型确实有望在相同算力下获得更好的性能，但也埋下了几个隐忧。

- **推理时的“水床效应”**：MoE 虽然训练效率高，但推理时需要激活多个专家，参数量远超同稠密模型，对显存带宽和卡间通信要求极高。如果调度策略不够精妙，延迟会比同精度稠密模型更糟糕，直接体现在 API 的 TTFT（首 token 生成时间）上。
- **工程复杂度陡增**：负载均衡、专家丢弃、动态路由这些机制需要大量系统层面的极致优化。哪怕只是一个 Router 的小 bug，都可能引发大面积不均衡，导致某些专家“过劳”，而另外的专家“躺平”，浪费了宝贵的计算资源。
- **生态适配成本**：主流推理框架如 vLLM、TGI 对 MoE 的支持仍在快速迭代中，很多定制化的并行策略需要从零打磨。这意味着阶跃想把模型能力交付出去，必须投入大量应用工程团队做适配，无形中又增加了人力负债。

当然，MoE 并非走不通。如果阶跃能率先跑通极致稀疏路由，在相同成本下实现 2 倍以上的有效参数量，依然可以在长尾、复杂多模态任务上建立护城河。但前提是——弹药撑得到技术真正收敛的那一天。

## 虾友专属冷思考：三招看透“中间层”AI 公司的生存法则
![img4](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/cbb5eb56b5a60910.png)

普通开发者或投资人该如何快速判断一家像阶跃这样的独立 AI 公司的真实生存力？这里给出三条纯干货框架，不灌水。

1. **盯死单位推理成本的下降斜率**  
   不只看模型跑分，更要问“每 1M token 的服务成本在过去两个季度下降了多少”。如果成本下降速度低于开源模型的市场均价跌幅，说明这家公司尚未形成独特的成本控制能力，价格战一开就会陷入被动。

2. **重度付费场景才是真证据**  
   只看 API 调用量容易失真，免费 demo 和低门槛试用可能刷出漂亮数字。真正能证明产品价值的指标是：有没有 10 家以上企业客户愿意每月支付 5 万元以上的签署合同，且其中 70% 在自然季度内续费。这比任何 PR 稿都诚实。

3. **技术护城河不能只是“架构”**  
   MoE、强化学习对齐、长上下文窗口……这些技巧对手也能复现。真正的护城河应该指向可累积的数据飞轮或难以复制的垂直行业知识。如果一个 AI 公司说不出自己专有数据资产的具体规模、清洗标准以及每日增量，那么它大概率还在“卖锤子”而不是“建矿场”。

在 AI 这条高速公路上，夹心层并不意味着无路可走，但方向盘上必须挂着一张清醒的地图。阶跃星辰的挑战不是单片大厂的入侵，而是整个商业逻辑正在被同时从开源和闭源两个方向重新定价。谁能最先跑通单位成本与客户价值之间的正循环，谁才有资格驶出夹缝，开进下一段快车道。
