2025年的中国科技圈，一条热搜悄然点燃了“知识虾”们的神经——“中国最低调的3个男人，正在同一条赛道上赌命”。这三位极少公开露面、几乎不接受采访的技术领袖，分别执掌着三家估值超百亿美元的AI大模型公司。他们押注的赛道是通用人工智能（AGI）的前哨战，而赌桌上的筹码，是每年数十亿的算力投入与不可复现的窗口期。这背后不仅是商业叙事，更是一场关乎技术路径、组织效率与成本极限的深层博弈。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/0d36b7a1eb60a6c8.png)

## 同一条赛道：大模型的“算力-数据-算法”军备竞赛

三位创始人聚焦的，是大语言模型（LLM）从研发走向规模化落地的临界点。这条赛道上的竞争已经简化为三个硬指标的比拼：

- **预训练算力规模**：从千卡集群到万卡集群，头部玩家单次训练消耗的浮点运算次数（FLOPs）已跨入 10^24 量级。例如某个开源模型的一次完整训练，所需电能足以让一辆电动车绕赤道行驶 400 圈。
- **高质量数据储备**：互联网公开语料已被挖掘殆尽，高质量教科书、科学论文、多语言对齐数据的单位成本飙升。部分团队开始引入合成数据，但合成数据的“毒性”循环至今没有完美解法。
- **推理效率与成本**：模型参数并非越大越好。如何在下游任务中通过混合专家（MoE）、模型量化、投机采样等技术，把单次推理成本压缩到一分钱以下，直接决定商业模式能否成立。

这三个维度构成一个“不可能三角”：极致的模型性能往往意味着天价训练成本与缓慢的推理速度。三位技术领袖虽然风格迥异，但无一例外都在这个三角上用自己的方式下注。

## 技术底牌：从 Scaling Law 到推理即搜索

这轮大模型热潮的源动力，是 2020 年 OpenAI 发现的 Scaling Law（规模定律）——模型性能随参数、数据、算力增加而幂律提升。然而，纯粹的“大力出奇迹”在 2024 年底出现了边际递减，新共识正在形成。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/f32f9a73560c8b03.png)

- **Post-Training 崛起**：预训练不再是唯一的决胜点。强化学习从人类反馈（RLHF）、基于可验证奖励的强化学习（RLVR）等方法，让模型在数学推导、代码生成等领域产生“顿悟时刻”。某团队的模型在未专门训练的情况下，自发学会了用草稿纸推演数学题，这被内部工程师形容为“看到了火种”。
- **推理时间扩展（Inference-Time Scaling）**：OpenAI o1 系列证明，在推理阶段分配更多计算资源（让模型“多想几步”），效果比单纯增大模型更显著。这催生了一个新范式——把推理看作蒙特卡洛树搜索，语言模型成了“解题的搜索引擎”。
- **长上下文与记忆机制**：100 万 token 的上下文窗口已经落地，相当于一次性喂给模型一套《三体》全集。但上下文越长，注意力矩阵的平方级算力消耗越可怕。为此，环形注意力、长文本压缩、外部记忆库等方案相继登场。

三位技术背景迥异的创始人——一位是数学竞赛保送生、一位是自然语言处理领域青年学者、一位是搜索引擎老将——恰好在这三条技术路线上各有侧重。数学背景的那位坚持用纯粹强化学习对齐模型，执着于“慢思考”架构；学者出身的那位深耕长上下文与 agent 工具链，试图让模型变成能操作浏览器的工作伙伴；搜索老兵则把推理效率做到极致，用低价和精调模型切入企业服务。

## 商业模式赌局：开源、闭源与“模型即商品”

大模型不仅是技术竞赛，更是商业模式的巨大赌局。三位低调男人在开源与闭源的分岔路口上做出了截然不同的选择。

1. **激进开源派**：将最新模型权重完全开放，甚至采用 MIT/ Apache 2.0 许可，允许商用。目标是用社区生态碾压对手，通过云服务、企业级工具和咨询盈利。Red Hat 式的故事在 AI 时代重新上演。
2. **API 闭源派**：坚持模型权重是核心资产，只通过 API 输出能力。模式接近今天的 OpenAI，追求高毛利的即用即付模型，试图用更优的服务质量和安全合规建立护城河。
3. **混合生态派**：开源轻量版本，闭源最强的旗舰模型。开发者可以在本地免费获得不错的基础能力，但顶级推理、复杂 Agent 调度需调用云端 API。这种“放水养鱼”的策略既赚了口碑，也为云服务引流。

不管走哪条路，一个残酷事实已经浮现：模型能力正在迅速向头部收敛，推理 API 价格月月腰斩。有投资人戏称“今天囤积的算力，明天就是一堆昂贵的电费单”。三位决策者都清楚，单靠卖 API  token 永远无法支撑高昂研发成本，最终的出路必然是掌控应用入口，或者成为新时代的基础设施——就像当年移动互联网时代的微信与高通。

## 冷思考与三条建议

镁光灯聚焦“三个男人”的同时，我们不能忽视这场赌局背后的冰冷逻辑。算力硬件的迭代周期（约 18-24 个月）与模型翻新速度正在彼此绞杀；顶尖 AI 研究员的跳槽成本以亿为单位计算；地缘政治扰动让 GPU 供应链始终悬着达摩克利斯之剑。

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/6fa9cb5a710ef035.png)

无论你是技术从业者、投资者，还是单纯对 AI 未来感兴趣的思考者，以下三条建议值得刻在脑子里：

- **拒绝 FOMO，紧盯推理成本曲线**  
  不要被“万亿参数”“全人类知识”等口号迷惑。观察一个模型是否具备商业生命力，只有一个黄金标尺：单位智能的推理成本是否持续下降。如果推理成本不能在一个硬件迭代周期内降低一个数量级，再惊艳的 Demo 也只是实验室玩具。
- **关注 Agent 执行链而非单次问答**  
  下一代赢家不会是在聊天界面里做脑筋急转弯的公司。能自主规划、调用 API、甚至操作物理设备的 Agent 系统，才是模型释放价值的正确姿势。谁能先让模型“订一杯咖啡”而不仅是“描述如何订咖啡”，谁就拿到了下一站的船票。
- **押注工具链，而非单一模型**  
  大模型正在成为像电力一样的基础设施，但围绕它的观测、精调、安全、编排工具才是真正的“接头插座”。这些中间件层的创业机会，远比再训练一个基础模型安全得多，也更能抵御上游变局。

三位技术领袖的赌局，注定会分出阶段性胜负。但对于整个行业，这场赌命竞赛的唯一确定性赢家，将是那些把 AI 真正融入工作流、用工程思维做深度整合的组织与个人。聚光灯外，才是更大的战场。
