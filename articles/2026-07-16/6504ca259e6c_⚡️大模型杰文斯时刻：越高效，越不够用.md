最近半年，大模型圈出现了一个怪现象：模型的推理成本一降再降，API 价格打到了地板，但云厂商的 GPU 排队时长却屡创新高，高性能芯片反而更抢手了。OpenAI、Google、Meta、国内大厂集体把战略重心从训练转向推理，一边疯狂压缩模型尺寸，一边加码囤卡。经济学家 160 年前提出的“杰文斯悖论”，正在 AI 基础设施领域悄然重现——当某种资源的利用效率突然提升，它的总消耗量不仅没下降，反而会被推到一个更恐怖的数量级。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/b01adffece4b2c39.png)

## 谁挖出了杰文斯悖论

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/ab417f0479c76d0c.png)

- **19 世纪的煤炭难题**：1865 年，英国经济学家威廉·斯坦利·杰文斯发现，瓦特改良蒸汽机后，煤炭消耗不但没减少，反而暴涨。原因是蒸汽机效率提升让用煤变得经济可行，工厂、轮船、铁路全面铺开，用煤场景爆炸式增多，总需求被“效率红利”彻底点燃。
- **核心公式**：效率提升 → 应用门槛降低 → 场景泛化 → 总用量飙升。杰文斯悖论的本质是，技术进步并不节约资源，而是重新定义该资源的成本结构，让过去“用不起”的场景变成“用得起”，最终拉动总需求。
- **数字时代的影子**：这个逻辑在后来的互联网带宽、存储芯片、乃至数据传输中没有消失。光纤扩容后流媒体普及，流量总量不降反增；NAND Flash 便宜后，全世界都开始拍 4K 视频。今天，大模型推理成本的下坠，正在重复同样的故事。

## 模型正在瘦身，但胃口更大了

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/cd513a7a67776f3a.png)

- **推理效率的飞跃**：过去两年，模型侧最显著的进步不是又大了几倍参数，而是等效智能的单位成本骤降。量化（INT8/INT4）、知识蒸馏、MoE（混合专家）架构、Speculative Decoding 等技术，让一个 70B 模型在消费显卡上也能跑出可用性能。DeepSeek-V3 以 671B 总参、仅激活 37B 的 MoE 设计，在数学和代码能力逼近 GPT-4o，推理成本却低一个数量级。
- **开源释放“便宜智能”**：Llama 3、Qwen、Mistral、Gemma 等一系列开源模型把“入门价格”打到了零。开发者不再需要申请昂贵的 API 额度，本地部署即能获得可观的生成能力。模型下载量、Hugging Face 的模型仓库数量爆发式增长，这些数字本身就在预告需求侧的巨变。
- **单位 token 成本暴跌**：API 市场的价格战从 2023 年底开始就没停过。每百万 token 的价格从几十美元跌到几美分，甚至出现大量免费额度。然而，行业总算力消耗曲线却以更陡峭的斜率向上冲——因为每个 token 便宜了，应用层开始毫无顾忌地喂给模型更多上下文、更长的思维链、更多的轮次。

## 推理洪峰：从“用不起”到“随便用”

![img3](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/987af7ce92297f76.png)

- **长上下文吞噬算力**：价格够低时，产品经理们出手非常豪迈。以前只给 4K 窗口，现在 128K、1M token 的上下文信手拈来；Code Agent 一次交互就可能吞吐数百 KB 的代码；AI 搜索要把整个网页塞进 prompt 做综合摘要。每一片成本下降，都被成倍的查询长度和轮次耗尽。
- **Agent 与自动化连锁**：AI Agent 工作流普遍采用“思考-行动-观察”循环，单次任务可能调用 LLM 十几次甚至几十次。CoT（思维链）、ReAct、多 Agent 协作等范式让单任务 token 消耗放大 5~50 倍。企业一旦把核心流程接上 Agent，24 小时不间断运行，造成的 GPU 时租比人工客服时代高得多。
- **推理收入反超训练**：CEO 们的财报电话会里，推理收入占比成了新的关键指标。NVIDIA 的 GPU 出货中，用于推理的份额快速上升；云厂商的 AI 服务营收结构正在从“训练一次性大单”转向“推理持续细水长流”。杰文斯悖论的财务版本来了：效率让推理市场急速膨胀，蛋糕大到足以盖过训练时代的辉煌。

## 大厂集体转向：囤卡与商业重心的位移

![img4](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-16/9002ff4b44357d1e.png)

- **Meta 的激进推理基建**：Zuckerberg 多次公开表态，数十万张 H100 集群的主要未来任务不是训练下一代 Llama，而是支撑全球数十亿用户的推理请求。社交、广告、虚拟助手的每个角落都等着被 LLM 渗透，算力需求看不到天花板。
- **Google 和微软的混合路线**：Google 把 Gemini 的推理优化做到了 TPU v5p 极致，同时用蒸馏小模型 Gemini Nano 覆盖端侧；微软将 GPT-4o 迷你版推入 Azure 各个服务，把推理成本压至“连接器”级别，引诱企业大量接入。两家公司都明白，锁定开发者的策略就是——让你先觉得推理几乎免费，等你的业务架构深度耦合后，用量自然指数级攀升。
- **国内大厂的算力焦虑**：海外芯片受限的背景下，推理优化成了必修课。华为昇腾、寒武纪的适配加速，模型推理框架从 vLLM 到 SGLang 的疯狂迭代，目的只有一个：榨干每一块卡的产出。但因为“便宜智能”带来了更多的 App、小程序、企业私有化部署，推理卡供不应求的状态将在相当长时间内维持。

## 冷下去想：3 条破局思路

**1. 对开发者：别被低价迷惑，量化真实 TCO**
一个 token 的价格只是冰山露头。要把上下文长度、并发量、延迟、重复调用次数、微调和运维的算力成本计入总体拥有成本。优惠期低价策略一旦结束，那些没有做过成本对冲的产品会被瞬间压垮。尽早压测、建立 token 预算模型、混杂使用本地小模型与云端大模型才是稳妥之道。

**2. 对创业公司：优先在推理耗费上建护城河**
如果你的产品逻辑是“无限调用 LLM 拼凑结果”，竞争对手可以用更低的推理成本瞬间复制。真正的壁垒应建立在细分的垂直数据、难以迁移的 Agent 工作流参数、或者独特的多模态交互设计上，而不是跟风烧 token。

**3. 对产业观察者：杰文斯时刻里没有“饱和”二字**
当前算力短缺的表象，本质是效率突破后的需求爆发。不要期待效率持续提升会让算力需求趋平；相反，只要模型能力还在爬坡，应用场景的边界还在外扩，算力消耗就会继续超线性增长。这是产业成熟的前兆，也是基础设施长期投资的依据。

历史不会简单重复，但它的韵脚总是相似。瓦特让蒸汽机热效率翻倍，煤老板们没有破产，反而迎来了维多利亚时代的滚滚黑烟。今天，大模型推理效率每提升一倍，token 消耗的海洋就再抬高一次潮位——理解这个悖论，才算真正读懂 AI 大厂的集体狂奔。
