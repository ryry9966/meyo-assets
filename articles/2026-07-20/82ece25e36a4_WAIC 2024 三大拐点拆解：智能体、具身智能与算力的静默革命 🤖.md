世界人工智能大会（WAIC）办了七届，今年的体感很不一样——全场几乎没人再聊「大模型会不会有意识」这种哲学问题，取而代之的是扎扎实实的交付、落地和成本控制。当黄仁勋、李开复、王坚这些名字出现在同一个会场时，最密集的关键词不再是参数规模，而是三个正在同时发生的拐点：智能体（Agent）从对话走向行动，具身智能带着真机爬出 PPT，算力从集中训练转向训推一体与能效革命。这三点，正在悄悄改写下半场的游戏规则。



## 智能体拐点：从「猜你想问」到「替你干活」

过去一年，大模型应用最广的形态是聊天界面。但 WAIC 2024 传递出一个清晰的信号：对话框正在变成基础设施，真正的主角是能调用工具、执行多步任务的智能体（Agent）。

- **工作流的代际升级**：早期的 GPT-4 虽然能写代码，但无法自主完成「查询 API → 解析 JSON → 写入数据库 → 发邮件通知」这一整套连续动作。本届大会展出的 Agent 方案，普遍引入了规划（Planning）、记忆（Memory）、工具使用（Tool Use）三大模块，比如通过 ReAct 或 Plan-and-Solve 范式，让模型拆解任务并自我纠错。
- **企业场景的硬需求**：现场一个典型案例是财务 Agent——接收一份 PDF 发票，自动提取金额、税率，比对采购订单，生成记账凭证，并在 OA 系统发起审批。这种端到端的执行能力，才是企业愿意从「试点预算」转向「核心系统预算」的理由。
- **基座模型的角色变化**：多家厂商在展区明确提到，基座模型正从「前台迎宾」变成「后台调度」。用户不再直接和千亿参数模型对话，而是由 Agent 框架决定何时调用大模型、何时用更轻量的专用模型甚至规则引擎，成本下降了一个数量级。



## 具身智能拐点：机器人终于开始「接地气」

去年的具身智能还停留在仿真视频里，今年 WAIC 直接把一整排双足、轮式、协作机械臂搬到了展馆。但更重要的变化不在硬件本身，而在软硬件融合和数据闭环。

- **本体与大脑的解耦**：过去做机器人，机械结构、运动控制、感知决策是铁板一块。现在通用大模型作为「大脑」，通过标准接口（如 ROS 2）下发高层指令，本体只负责低延迟的运动执行。这意味着同一套模型可以驱动不同形态的机器人，极大降低了开发门槛。
- **Sim-to-Real 的工程突破**：展商透露，基于大规模合成数据的仿真训练（如 NVIDIA Isaac Sim）已经能覆盖 90% 以上的长尾场景，域随机化（Domain Randomization）技术让模型在仿真中学到的抓取策略，迁移到真实机械臂时成功率从去年的 60% 提升到 85% 以上。
- **成本曲线的陡降**：一个值得注意的数据——某国产六轴协作机器人整机价格从三年前的 12 万元压到了 3.5 万元，核心原因不是材料便宜了，而是减少了大量手写规则代码，转而用端到端神经网络直接输出关节角度。当硬件 BOM 成本逼近消费电子，规模化的奇点就不远了。



## 算力拐点：从「暴力训大」到「精准用算」

算力是这场展会的隐形主角。你几乎在任何一个展台都能听到「kW」「petaFLOPS」「token 单价」这些指标。拐点在于，行业正从疯狂堆卡，转向精细化运营。

- **训推一体架构开始主导**：以前训练集群和推理集群泾渭分明，现在因为模型迭代极快（从 LLaMA 3 到 3.1 仅几个月），企业更倾向搭建统一资源池，白天跑推理服务，夜间做增量训练或对齐。现场的液冷整机柜方案，PUE 基本压到 1.1 以下，单柜功率却能支撑到 100kW 以上。
- **小模型逆袭**：微软 Phi-3、面壁 MiniCPM 等小参数模型在特定任务上追平甚至超越大自己数十倍的模型，背后是数据质量革命和知识蒸馏。这意味着很多场景不再需要 A100/H100，一块消费级显卡即可部署。算力焦虑正在转化为效率红利。
- **绿色算力的定量约束**：政策层面已经给出明确信号，新建数据中心 PUE 高于 1.25 直接不予批准。这倒逼芯片设计从单纯的算力竞赛，转向每瓦特 token 输出量。展会上有初创公司展示了一款存内计算芯片，在运行 BERT 推理时能效比是传统 GPU 的 15 倍。



## 三条冷思考

拐点往往意味着机会，但也容易让人高估短期效果、低估长期难度。这里给出三个务实的判断：

1. **Agent 的信任瓶颈比技术瓶颈更难攻克**。让模型执行读邮件操作和让它发起一笔银行转账，风险模型完全不同。可观测性、人工兜底、回滚机制，这些工程基建的成熟度，才是 Agent 落地的天花板。别只盯着任务完成率，先盯住误操作率和可解释性。
2. **具身智能的「iPhone 时刻」尚未到来**。硬件成本下降很快，但场景收敛不够快。家庭场景的泛化操作仍是长尾难题，未来 2~3 年，真正能出量的还是工业拣选、物流分拣这类半结构化环境。创业者应把90%精力放在定义边界清晰的工作流，而非追求通用人形。
3. **算力竞争的下半场是数据编排，不是芯片型号**。无论是 MoE 的专家路由，还是长上下文的 KV 缓存优化，本质都是在更精细地调度计算资源。团队里有一个懂高性能计算和 CUDA 调优的工程师，比多囤 100 张卡更有价值。投资算力前，先投资 profile 工具和性能建模。
