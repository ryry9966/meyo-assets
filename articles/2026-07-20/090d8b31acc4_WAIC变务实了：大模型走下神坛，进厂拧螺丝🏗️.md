往年的 WAIC，展台上最醒目的永远是“参数破千亿”“万亿 Token 训练”这类军备数字；今年再去逛一圈，你会发现 PPT 上的大字悄悄换成了“场景”“行业大模型”“端侧部署”“ROI”。前排不再是比谁更能烧卡，而是比谁更能帮工厂省下 30% 缺陷率，帮三甲医院把影像报告初筛速度提升 5 倍。

有人调侃：AI 终于从实验室的玻璃房里走了出来，两脚蹚泥，开始下地干活。这届 WAIC 释放的信号太明显了——参数竞赛告一段落，产业价值竞赛正式拉响。



## 从参数军备到场景特种兵


过去两年，“万模大战”让整个行业患上一种病：参数饥渴症。好像谁的模型少一位数，就不配上牌桌。但今年 WAIC 的展商结构发生微妙变化，通用大模型厂商依然在，但更多中小团队开始拿着行业精调模型展示，金融风控、法律文书、制药分子筛选……每个细分场景都像一个小型特种部队。

- **生态位分化加速**：底座模型（如 GLM、Qwen、Baichuan）继续往更大更强演进，而腰部玩家转向垂直纵深，做金融合规场景的团队不会去卷通用对话，而是死磕条款级语义理解；某家专攻反欺诈的参展商，模型参数量还不到 70 亿，但查准率把好几个千亿模型按在地上摩擦。
- **行业 Know-how 成为壁垒**：水利行业要用 AI 做汛情推演，你不能只扔一个通用大模型进去，必须灌入数十年水文数据和调度规则；一家钢铁厂要做热轧表检，光靠视觉基础模型不够，得配合材料学机理、产线节奏建模，这些“脏活累活”恰恰是纯算法团队干不了的。
- **“卖铲子”的生意转暖**：这一波务实潮也带火了一批 MLops、数据标注平台、模型压缩工具的展商。模型落地不是下载个权重就能跑，背后是一整套工程化流水线。

换句话说，参数不再是唯一硬通货，能解决行业最后一公里的“场景特种兵”才是稀缺资源。

## 大模型“瘦身”：端侧智能的逆袭


如果说前两年 AI 是在云上飘，那今年 WAIC 最大的技术风向就是“把 AI 塞进设备里”。高通、联发科、展锐等芯片厂商不再只讲算力峰值，而是大篇幅介绍端侧推理能力；手机厂商、汽车座舱、工业相机展区，到处可见“离线运行”的端侧大模型 demo。

- **量化与剪枝成为显学**：把 1750 亿参数压到 13 亿而不明显掉点，靠的是 INT4/INT8 量化、结构化剪枝、知识蒸馏。展会上有团队展示了 3.5B 模型的端侧部署，在 ARM 芯片上跑出 20 token/s 的推理速度，功耗不到 5W，可以直接嵌入无人机目标识别模块。
- **成本驱动链条清晰**：云端推理 API 虽好，但物联网终端数动辄百万，每毫秒都要回传云端的时延和带宽成本谁也扛不住。某家电品牌现场展示了空调离线语音控制：本地 60M 参数的小模型能理解复杂指令，不需要联网，反应延迟低于 300 毫秒。
- **混合架构崛起**：云端大模型思考，端侧小模型执行，中间靠路由模块调度。这种“云管端”协同正在落地，连智能眼镜、AR 头显也纷纷亮出端侧 NPU 加速方案。

端侧智能不再是鸡肋，它正把 AI 从大型数据中心的功耗黑洞，变成真正能跑进千万设备里的生产力单元。

## 数据飞轮：工业 Know-how 的炼金术


大模型技术本身并没有绝对护城河，GitHub 上开源的权重一堆，但真正卡脖子的往往是高质量行业数据。今年 WAIC 上，工业互联网平台、医院信息化厂商、气象服务机构扎堆出现，他们手里捏着别人拿不到的金矿。

- **标注数据决定天花板**：某家做骨科影像诊断的团队，从三甲医院拿到 20 万例带多位主任医师交叉标注的 MR 片子，模型体量只有常规 3D CNN 的 1/5，但敏感度达到 97%，比通用大模型高了近 15 个百分点。用他们的话说，“不是模型聪明，是主任的标注太贵”。
- **数据飞轮自动进化**：比较理想的状态是“业务产生数据 → 数据训练模型 → 模型辅助业务 → 业务产生更多高质量数据”的闭环。一家港机厂商已经做到：龙门吊每次抓箱的动作数据回流训练，模型越用越准，司机起吊时的微调量半年间减少了 40%。
- **合成数据补位，但有天花板**：展会上也有不少合成数据方案，用 AIGC 生成缺陷样本、复杂路况，但都承认对物理世界机理较敏感的场景（如化学反应预测）合成数据仍需谨慎，专家经验短期内不可替代。

说白了，谁掌握了行业数据闭环，谁就掌握了 AI 落地的炼金术。

## AI Agent：给大模型穿上工作服


今年的另一个爆炸词是“AI Agent”。会上多个厂商展示了不再是聊天界面的 AI，而是能自主拆解任务、调用工具、执行多步流程的智能体。银行柜台流程自动跑、电商售后自动处理、产线排程自动优化——大模型终于学会用扳手了。

- **工具调用（Function Call）让大模型长出手脚**：过去大模型只能输出文本，现在结合 API 可以直接操作 CRM 系统、查询数据库、发邮件、调工业摄像头。一个典型的订单变更场景，Agent 先解析客户邮件意图，再查库存、调 ERP 改单、通知物流，全链路无需人工干预。
- **多智能体协作框架**：蔚来、理想等新势力展示了车内多 Agent 协作：主 Agent 负责对话，安全 Agent 监控路况并随时切断非紧急功能，导航 Agent 规划充电路线，三者并行通信。这种异构 Agent 架构让复杂场景处理从容不迫。
- **记忆与反思机制**：部分 Agent 加入了向量数据库存储“经历”，能自我反思错误并调整策略。比如工业巡检 Agent 第一次漏检了某种特殊锈蚀，被人工纠正后，会将负样本存入长期记忆，下次不再犯错。

大模型从此不再是飘在云端的“百科全书”，而是穿上工作服、手握工具箱的“数字员工”。

## 冷思考：别被烟雾弹晃了眼

WAIC 的热闹背后，也要警惕几种“虚火”。

1. **别被大模型 PUA，模型大小要匹配业务复杂度**。如果你的场景只是文档比对、票据识别，一个 1.3B 的轻量模型加上 3 万条标注数据可能比千亿模型更实惠。参数大不等于业务价值大，适合自己的才是最好的。
2. **80% 的智能化项目卡在数据治理，而非算法**。展会上的成功案例几乎都先啃下了数据整合、清洗、标注的硬骨头。一味采购大模型而忽视数据标准化，大概率会得到一个昂贵的玩具。
3. **先找到可量化的 ROI 锚点**。不要一上来就提“用 AI 重构业务流程”，这种万金油目标大概率失败。从每年降本 50 万的质检点，或者提升 10% 客单转化的推荐模块切入，跑通一个支付闭环再逐步扩展，才是落地的不二法门。

WAIC 2024 或许没有前两年那么“科幻”，但这份沉下来蹚泥的劲头，才是 AI 真正成为基础设施的必经之路。
