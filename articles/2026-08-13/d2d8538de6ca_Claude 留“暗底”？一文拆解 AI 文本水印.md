“以后让 Claude 写的东西，可能要小心留暗底了。”这条热搜出来后，很多人第一反应是：是不是模型在输出里偷偷埋了追踪符，以后用了会被秋后算账？其实更接近的真相是另一个方向——不是给你埋雷，而是给机器生成的内容留一个可溯源的出生证明。因为当大模型写出的文本越来越像人，平台、学校、版权方和法院都面临同一个问题：怎么知道这段文字是 AI 生成的？于是“文本水印”“内容凭证”“来源元数据”这些技术被推到台前。只是多数人不看 API 字段，也不关心文件头，才会把这类机制叫作“暗底”。这篇把它拆成三层来讲。



## 一、“暗底”是什么：三种常见技术路径


这里说的“暗底”，泛指机器可读、人不易察觉的来源标记。按实现方式，主要有三类。

1. 统计水印。它不往文本里写任何奇怪的字符，而是在生成时控制词与词之间的概率。比如“提高”和“提升”都能用，模型因为水印密钥更偏向其中一个。人读不出区别，检测端却可以从大量选择中算出统计偏差。
2. 不可见字符。零宽空格 U+200B、零宽不连字、同形异义字都属于这一类。比如视觉上完全相同的“Claude”，里面某个字母可能被替换成另一个 Unicode 码位。复制粘贴会带走，肉眼却难以分辨。
3. 元数据凭证。这是最容易被忽略、也最正规的一种。C2PA 等内容凭证在文件、API 响应或导出层附加结构化字段，说明生成模型、时间、编辑历史。它更像照片的 EXIF，而不是藏在正文里的暗号。

三种路径的隐蔽性、鲁棒性和侵入性都不同。元数据最“干净”但最容易丢；不可见字符最直观但容易被清洗；统计水印最隐蔽，检测却并不稳定。所谓“暗底”，很多时候只是这些技术被混在一起谈论。

## 二、文本水印如何工作：从 red/green token 到 SynthID


文本水印最棘手的地方在于：自然语言是离散的，改动一个词就可能影响语义；它不像图像有大量冗余像素可以藏信息。

- Red/green token。生成时，系统用伪随机函数把候选 token 分成红组和绿组。模型有意提高绿色 token 的采样概率。检测方拿到同一密钥后，统计文本里绿色 token 占比。普通文字绿色占比大约 50%，水印文本会明显偏高。只要绿 token 连串出现，就能给出“疑似AI生成”的判断。
- Google DeepMind 的 SynthID 文本。它不简单分成红绿，而是对 logits 或嵌入做微小扰动，把签名写进生成分布。优点是更平滑，对短文本、截取、改写有一定抵抗力；缺点仍然是概率性，不是精确编码。
- OpenAI 此前的研究。OpenAI 很早就讨论过文本水印，但 ChatGPT 很长一段时间没有默认部署，原因之一就是低熵场景质量损失明显。代码、公式、固定表达几乎没有同义词空间，硬加水印会让输出变别扭。

这些方案追求的目标是一致的：让检测方可以验证“这段文本是否经过某个带水印模型”，同时不让普通读者察觉。它更像一层薄薄的统计倾向，而不是一个无法洗掉的条形码。

## 三、Claude 与内容凭证：公开标准里的“暗底”


Anthropic 并没有宣称要给每句 Claude 输出埋入秘密追踪符。从公开资料看，它更多是在推进内容来源标准。

- C2PA 联盟。Anthropic 与多家公司共同参与或支持内容来源与真实性联盟。目标不是偷偷标记，而是让 AI 内容带上一个可验证的出处信息。
- API 层。Claude 的 API 响应里本来就有模型 ID、完成时间、停止原因等结构化字段。如果接入方转发时把这些字段丢掉，终端读者就看不到任何信息。很多所谓“留暗底”，其实是业务链路没有透传元数据。
- 产品导出。部分导出或分享功能可能附带内容凭证，普通用户不感知，但支持 C2PA 的工具可以读取。在支持内容凭证的客户端里，用户看到的是一个来源面板，而不是网传那样被默默埋入一堆字符。
- 误区澄清。公开标准不等于秘密后门。C2PA 的设计希望让来源可感知、可验证，而不是制造不可告人的追踪系统。把它叫“暗底”，容易让人联想到恶意追踪，但技术路线更接近给内容附一张出生证明。

简单说，如果 Claude 真留了元数据，那通常不在你复制的正文里，而是在文件外壳或 API 字段中。复制成纯文本、截图、OCR 之后，通常只剩统计水印，或者什么也不剩。

## 四、检测、清洗与局限：别把水印当万能证据


既然标记能被剥离，就必须讨论检测与对抗。这里没有“神秘黑科技”，只有概率和工程取舍。

- 元数据最好检测，也最好丢。纯文本、截图、打印再扫描都会丢失 C2PA 与头部字段。检测工具只能识别仍携带凭证的文件。
- 不可见字符用专用工具或正则就能找出，但很多正常排版和过滤系统会误伤，甚至清掉它们。
- 统计水印需要密钥或检测模型，普通用户通常拿不到检测接口。即使用上同义改写、翻译再回译、截断重组、换语气，信号都会大幅衰减。短文本尤其不可靠，几百 token 以上检测效果才会好一些。
- 假阳性必须重视。如果过度依赖词频分布，正常人类文本也可能被误判成 AI。错误指控的代价远高于漏检，所以严肃平台不会仅凭水印就封号或判定学术不端。

因此，AI 文本水印更像是“概率性标记”，不是 DNA 比对。它在成千上万条内容里做初筛时有用，但在个案争议中很难单独成为铁证。

最后给出三条冷思考，偏实用。

1. 默认可能被溯源。凡是把大模型输出直接当终稿发出去，来源都可能从元数据、统计特征、编辑行为等维度暴露。不要赌平台不检测。
2. 保留自己的过程证据。提示词、草稿版本、修改记录、人工编辑时间线，往往比花力气去除水印更有价值。即使 AI 标记被洗掉，过程证据仍是更完整的证据链。
3. 关注公开标准，而非追求“绝对无痕”。真正的风险不是某个模型留了来源标记，而是有人用不透明方式偷偷标记内容。尽量选择明确告知来源策略的服务，对任何声称“100%检测”或“完全无痕”的工具保持怀疑。
