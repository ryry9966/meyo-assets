最近微博上有个话题又热了起来：iPhone 18 Pro 的灵动岛要变小了。供应链消息说，苹果正在推动 Face ID 模组小型化，2026 年那一代 Pro 机型的顶部开孔会明显收窄。评论区一半人喊“早该缩了”，另一半人问“这颗黑药丸到底能不能彻底消失”。这篇文章不聊爆料真假，只聊工程：灵动岛里装了什么，“小号”是怎么实现的，以及离真正的完整全面屏还有多远。

## 从刘海到灵动岛：开孔的七年瘦身史

- **2017 年，iPhone X**：砍掉 Home 键上全面屏，前置的一堆传感器没地方放，于是有了刘海。刘海横向宽度约占屏幕顶部的三分之一，视觉上相当霸道。
- **2020 年，iPhone 12**：边框收窄，刘海小了一号，但内部结构没变。
- **2022 年，iPhone 14 Pro**：苹果把硬件开孔改成药丸形，再在软件层用动画把它“包”起来，取名灵动岛（Dynamic Island）。同一块缺口，上一代叫刘海，这一代叫岛——这是典型的软硬协同设计：物理开孔没消失，但 UI 把它写成了交互组件的一部分。
- **2023–2025 年**：灵动岛尺寸基本原地踏步，苹果把精力花在交互生态上——Live Activities、实时活动、第三方 App 适配。
- **2026 年，iPhone 18 Pro**：按供应链爆料，重点是“缩孔”，而不是“去孔”。

一句话总结这条时间线：先收边框，再缩开孔，最后才轮到开孔消失。顺序错了就会翻车。



## 那颗药丸里到底塞了什么：为什么它没法直接消失

灵动岛不是“一个摄像头孔”，而是一整套 3D 传感系统（TrueDepth）的出光和收光窗口：

1. **点阵投影器（Dot Projector）**：向人脸投射三万多个红外点，构成结构光的“光尺”。
2. **红外镜头（Infrared Camera）**：接收反射回来的点阵，算出深度图。
3. **泛光感应元件（Flood Illuminator）**：暗光环境补红外光，保证黑夜也能解锁。
4. **距离传感器、环境光传感器**：负责熄屏检测与自动亮度，位置各代有过调整。
5. **前置摄像头**：自拍和视频通话，是唯一靠可见光工作的元件。
6. **听筒与麦克风**：藏在顶部边缘。

Face ID 用的是结构光（Structured Light）方案：先投射、再接收、后比对，比对在本地安全芯片完成。这套“主动发光 + 主动接收”的组合，决定了它不能像指纹识别那样整体挪进屏幕就完事——红外光必须射出屏幕外，再原路返回。只要这个物理过程还在，开孔就至少得留一条“光路窗口”。

## “小号”的三条技术路线：塞紧、藏屏下、光学补偿

供应链层面的“缩小灵动岛”，通常对应三条路线，难度递增：

1. **路线一：组件小型化 + 重新布局（大概率是 18 Pro 的方案）。** 把点阵投影器做小，把环境光等外围元件移到屏幕其他位置甚至屏下，开孔宽度自然收窄。技术风险低，Face ID 性能不打折，属于最稳的“挤牙膏式进步”。
2. **路线二：屏下 Face ID。** 把投影器和红外镜头藏进 OLED 下方。难点在于 OLED 像素会遮挡红外光，必须在传感器正上方做一块局部低像素密度区——拉开像素间距、给红外光让路。业内有过类似方案，但透光率和成像一致性一直是坎。
3. **路线三：屏下摄像头（UDC）。** 最难啃的一块。可见光比红外光对遮挡敏感得多，穿过像素缝隙会带来雾感、眩光和衍射条纹，需要 ISP 层面持续做算法补偿。市面上已有的 UDC 机型，自拍画质普遍不如常规前摄——而苹果对前摄画质的要求出了名地苛刻。

郭明錤、Ross Young 等分析师过去几年多次给出屏下 Face ID 的时间线，又多次推迟。这说明路线一成熟得快，路线二、三还在爬坡。“小号灵动岛”这个爆料，恰恰符合路线一的特征：不推翻，只收紧。

## 别急着欢呼：缩孔背后有几道坎

- **透光率是硬约束。** OLED 本身不透光，传感器区域必须专门“开窗”：降低局部像素密度，意味着该区域显示精度下降，窗口边缘的像素排列要专门设计，否则肉眼能看出色块。
- **衍射与鬼影。** 光穿过像素间隙会发生衍射，成像出现条纹和雾感，需要光学结构 + 算法双重修正。
- **面板设计与良率。** 屏幕走线要绕开传感区，驱动电路更复杂，直接冲击面板良率，最终反映在整机成本和维修价格上。
- **软件空间变小。** 灵动岛的动画系统是围绕现有开孔尺寸设计的，开孔一缩，Live Activities、正在播放这些 UI 的可用面积跟着缩水，开发者的适配规范又要改一轮。

换句话说，“把岛变小”不是设计师拖一下选区的事，而是光学、面板、半导体和软件规范的一次四方会审。

## 给等机党的三条冷思考

1. **爆料不等于发布。** 供应链消息处于“编译未通过”状态，多源交叉验证后再下判断；苹果的屏下方案已经跳票过不止一次，时间线看看就好。
2. **别为“无孔全面屏”无限期持币等待。** 在屏下摄像头画质达标之前，苹果大概率不会牺牲 Face ID 和自拍体验去追求视觉洁癖，真全面屏更可能是 2027 年以后的故事。
3. **判断这类升级值不值，问三个问题：** 功能有没有缩水（Face ID 解锁速度与识别率）、成本有没有转嫁（维修价格）、开发者适配有没有被合理消化（UI 规范变更频率）。开孔每小一毫米都值得尊重，但你的钱应该花在体验上，而不是像素级的审美洁癖上。
