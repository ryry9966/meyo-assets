36kr 那句「再这样下去，Agent 要被卖保健品了」，听着像段子，其实是相当精准的行业观察。过去一年，Agent（智能体）发布会的话术越来越眼熟：万能、速效、包打天下，专家站台、案例轮播，观众听完热血上头，产品买回来却发现「疗效因人而异」。这篇拆解三件事：Agent 为什么特别容易长出保健品话术，技术真相到底是什么，以及普通人怎么判断眼前的是药还是糖水。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/b7f0c59e2125ce0d.png)

## 一、话术对照表：Agent 营销和保健品柜台像在哪

把两边的话术并排放，相似度高得离谱：

- **模糊功效词**：保健品说「调节微循环、增强免疫」；Agent 发布会说「重塑工作流、全面赋能业务」。共同点：不可证伪，怎么解读都行。
- **超额承诺**：保健品暗示包治百病；Agent 宣传动辄「替代一个团队」「10 倍效率」「一个人跑成一家公司」。
- **焦虑营销**：「同龄人正在抛弃你」对上「不用 Agent 的公司明年就会被淘汰」。
- **因人而异兜底**：保健品归因于体质差异；厂商归因于「你们流程不成熟」「prompt 没写好」。
- **疗程式收费**：订阅制 + 增值模块 + 企业版定制，结构上就是一个「大套餐」。

这不是巧合。两者共享同一个市场结构：**疗效难以事前验证 + 买卖双方信息严重不对称 + 用户焦虑真实存在**。凡是具备这三要素的市场，营销话术就会向同一个方向进化，跟产品本身是不是高科技无关。

## 二、技术根源：为什么 Agent 特别容易被「包治百病」

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/8bc0f1d671dad269.png)

玩笑背后有三个硬核原因：

1. **Agent 是系统，不是模型，链条越长越脆。** LLM 只是大脑，完整 Agent 还要拼接规划、工具调用、记忆、编排。可靠性是连乘的：单步 95% 准确率听起来很好，但一个 20 步的任务，端到端成功率约 0.95²⁰ ≈ 36%。发布会给你看的，是那 36% 里最漂亮的一次。2023 年 AutoGPT 横空出世、GitHub 星标破十万，几个月内热度崩塌，正是行业第一次集体撞上「演示到生产」的鸿沟。
2. **评测天然困难，榜单会「说谎」。** 传统软件有单元测试，通过就是通过；Agent 的任务开放、路径不唯一，SWE-bench、WebArena 这类 benchmark 的分数与真实业务表现之间隔着显著 gap，再加上训练数据污染和针对性刷分，「榜单 70 分」不等于「你的业务 70 分」。
3. **卖的是能力，不是结果。** 最终效果强依赖客户的数据质量、流程成熟度和验证能力，厂商天然倾向把失败归因为「你不会用」——这与保健品「因人而异」的说辞完全同构。

## 三、技术现实：此刻的 Agent 到底能干什么

研究机构 METR 在 2025 年的测算给了一个有用的坐标系：AI 能以 50% 成功率完成的任务时长，大约每 7 个月翻一倍，但前沿模型这条「可靠半径」目前仍在小时级。据此可以把任务分成三档：

- **适合交给它**：容错高、结果可自动验证、有人把关的任务——代码生成与 review、客服回复草稿、信息抽取与清洗、内部知识问答、营销文案初稿。
- **勉强能用**：长链路网页操作、跨系统审批流转，成功率随步数骤降，必须配人工兜底。
- **不该交给它**：不可逆操作（转账、删除、对外发送）、长周期无监督自主任务、没有任何验证信号的开放决策。

还有一个常被略过的真相：**成本**。token 费用加上失败重试，一次复杂长任务的账单，常常超过一个初级员工干同样活的时薪。「省人力」这笔账，很多场景下目前算不平。

## 四、「验方」四步：判断眼前的是药还是糖水

保健品行业后来能祛魅，靠的是成分表、临床数据和注册标识；采购 Agent 同样可以建立自己的验证流程：

1. **看验证闭环**：任务结果能不能被机器自动校验——代码能不能跑通、抽取的字段对不对？有验证信号的领域，Agent 可靠性会高一个量级。
2. **要失败演示**：让厂商现场展示失败案例、重试与降级逻辑。「永不失败」的 demo 本身就是红旗。
3. **算真实 ROI**：按结果计费优于按坐席计费；用自己业务的 30 个真实案例测跑通率、做 A/B 对照，比看榜单和发布会有用得多。
4. **查回滚与审计**：误操作能否撤销、每一步有没有完整日志。不能回滚的自动化，等于没有刹车。

红旗话术三件套：**替代整个团队 / 100% 自动化 / 不用就落后**——听到任何一句，直接按保健品柜台处理。

## 五、三条冷思考

1. **把 Agent 当「能力出众但需要带教的实习生」，而不是即插即用的数字员工。** 能放心交给它的，只有可验证、可撤销的任务；剩下的先设计人机分工，再谈自动化。
2. **采购逻辑从「信 demo」迁移到「自建评测集」。** 用自己的业务数据出题，比任何榜单都诚实。谁的验证流程更硬，谁拿到的真实疗效就更好——这部分投入目前被严重低估。
3. **行业层面，「疗效可验证」会取代话术成为核心竞争力。** 就像保健品行业最终被成分标注与注册制度重塑，能提供评估工具、失败率数据和结果 SLA 的 Agent 产品，会把话术型选手挤出牌桌。到那时，「卖保健品」这句嘲讽，才算真正过时。
