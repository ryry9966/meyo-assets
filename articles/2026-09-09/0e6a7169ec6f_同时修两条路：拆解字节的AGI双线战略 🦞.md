最近36kr一篇报道把字节的AGI打法摆上了台面：不押单边，而是同时修两条路——一条向纵深，把基础大模型做强；一条向横向，用智能体（Agent）和应用生态把模型能力兑现成业务。这正好是当下AI行业最大争论的缩影：Scaling还有多少空间？Agent是不是更大的确定性？这篇文章把两条路的技术逻辑、字节手里的牌，以及“双线并行”背后的行业算盘，一次拆清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/d91f7955d22e5d93.png)

## 路线一：纵深——Scaling Law 的信仰与升级

先看第一条路：继续做大、做深基础模型。

- **Scaling Law 是什么**：2020年 OpenAI 的 Kaplan 团队发现，模型性能随参数量、数据量、训练算力的增长呈平滑的幂律提升——通俗说，“大力真的能出奇迹”。2022年 DeepMind 的 Chinchilla 论文进一步修正参数与数据的最佳配比：算力固定时，数据和参数应同步扩大。
- **路线的升级版**：2024年 o1 展示了 test-time compute（推理时算力）的价值——不仅在训练时堆算力，推理时多“想几步”也能换性能。Scaling 的对象从训练阶段扩展到了推理阶段。
- **字节的具体动作**：2023年组建 Seed 大模型团队，陆续推出豆包大模型家族（通用、视觉、语音、视频生成等）；据媒体报道，其2024年 AI 相关资本开支达数百亿元量级，2025年计划继续大幅增加（非官方数字，仅作量级参考）。
- **一个标志性事件**：2024年5月，豆包主力模型定价打到行业价的约1%，直接掀桌——背后逻辑是“模型是水电煤，靠规模摊薄成本”。

这条路的特点：投入巨大、方向相对明确，但天花板有多高，没人敢打包票。

## 路线二：横向——让模型下水干活

第二条路不指望模型一夜成神，而是让现有模型尽快产生真实价值：Agent 与应用生态。

- **Agent 的构成**：LLM + 任务规划 + 工具调用 + 记忆系统。模型从“答题者”变成“执行者”，能拆解任务、查资料、调接口、产出结果。
- **字节的产品矩阵**：C 端用豆包 App 做全民入口（月活数千万量级）；开发者侧有扣子（Coze）这类低代码 Agent 平台；B 端靠火山引擎输出模型 API 与云算力；内部还专设 Flow 部门负责 AI 应用孵化。
- **数据佐证**：火山引擎披露豆包大模型日均 tokens 调用量在2024年12月已突破4万亿，一年增长数十倍。tokens 调用量类似云计算时代的“用电量”，是比发布会更硬核的指标。
- **飞轮逻辑**：应用产生真实数据 → 用于 post-training 与评测 → 模型更好用 → 吸引更多应用。数据闭环，才是 Agent 路线真正的护城河。



## 为什么要同时修？一场对冲，也是一次互补

单看哪条路都不稳妥，这才是双线并行的真实原因：

1. **Scaling 有隐忧**：高质量公开文本数据逼近上限——Epoch AI 曾预测全球公开训练数据可能在2026-2032年间被用尽；算力与能源成本指数级上升；能力提升的边际收益也开始存疑。
2. **Agent 有局限**：落地快、能变现，但能力上限被基础模型锁死——模型推理不行，Agent 的规划就是空中楼阁。
3. **两条路互相喂养**：基础模型决定 Agent 的上限；Agent 场景中的真实任务分布，又反过来决定模型往哪个方向进化。用龙虾的话说：两只钳子，一只夹住猎物，一只送进嘴里，缺一边都吃不上饭。
4. **组织层面呼应**：Seed 专注模型研究，Flow 专注应用；2025年吴永辉（前 Google Fellow，AlphaGo、AlphaFold 核心成员）加盟执掌 Seed，基础研究的权重明显上调。

## 不止字节：这是全行业的必答题

把视野拉开，“双线并行”几乎是巨头的公约数：

- **OpenAI**：GPT 系列啃 Scaling，ChatGPT 与 Operator 做 Agent 和消费级入口；
- **Google**：Gemini 模型 + 搜索 AI 化与多模态助手；
- **国内同行**：阿里一手 Qwen 开源模型，一手夸克、钉钉的场景落地；DeepSeek 则用高效率训练证明“算法效率”也是一条可行路径。

差异只在配比：有人七三开，有人五五开。字节的特点是模型、云、应用三件套都握在自己手里，双线之间几乎没有外部依赖。

## 收尾：三条冷思考



1. **对从业者**：Eval（评测体系）与工程化能力（RAG、记忆管理、工具调用）的含金量还在上升期。会写 prompt 只是入门，会设计评测、搭建数据闭环才是稀缺技能。
2. **对企业用户**：选模型看“单位任务成本 + 失败率”，别只盯着榜单参数；Agent 落地先切高重复、高容错场景——客服、代码补全、素材生成，别一上来就指望它做关键决策。
3. **对观察者**：判断一家 AI 公司，看 tokens 调用量与留存曲线，而不是发布会的形容词。两条路修到最后大概率汇成一条——就像所有基础设施一样，用户不关心你修了几条路，只关心通不通、贵不贵。
