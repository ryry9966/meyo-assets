最近微博上「iPhone 18 Pro 小号灵动岛」冲上热搜：供应链消息称，下一代 Pro 机型（预计 2026 年秋发布）的传感器挖孔会明显变小——思路是把 Face ID 元件部分或全部移入屏幕下方，只给前置摄像头留一个更小的孔。消息真假待验证，但"把药丸做小"这件事本身是个绝佳的技术切口：它同时牵动显示面板、红外光学、软件交互三条线。这篇就拆一拆，一颗药丸的瘦身，到底难在哪。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/2014b6bcdcbf0096.png)

## 从刘海到药丸：挖孔里到底塞了什么

先补点历史背景：

- **2017 年 iPhone X**：取消 Home 键后首次留刘海，根源是 Face ID 需要"无遮挡光路"——3D 结构光系统看不清你的脸，就解锁不了。
- **2022 年 iPhone 14 Pro**：刘海改成药丸形挖孔，同时用一套软件动画把"洞"包装成"岛"。

药丸里的硬件清单相当拥挤：

1. **点阵投影器 (Dot Projector)**：向面部投出约三万个红外光点
2. **红外摄像头**：读回点阵的深度畸变，重建 3D 面型
3. **泛光感应元件**：暗光环境补红外光
4. **前置摄像头、距离传感器、麦克风**

关键结论：这个孔不是装饰，是一整套 3D 光学系统的"取景窗"。要缩小它，本质是在问：这套光学系统还能塞进哪里？

## 为什么缩小这么难：像素和红外光在抢地盘

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/ee5a256c222ca26d.png)

把传感器藏进屏幕下方听着顺理成章，但 OLED 面板天然是光学的对手：

- **衍射与散射**：OLED 像素之间有金属走线，红外点阵穿过像素间隙会被打乱。深度点阵一"糊"，面型重建精度就崩，Face ID 直接失效。
- **透过率不足**：普通 OLED 对红外光的透过率很低，需要专门设计"高透明区"——局部降低像素密度、改用透光更好的封装材料。
- **屏下摄像头更难**：可见光成像对画质要求苛刻，市面上已量产的屏下前摄普遍雾蒙蒙，要靠算法去雾、去衍射纹补偿。

参考业界先例：三星 Galaxy Z Fold 系列的屏下摄像头 (UPC) 采用"局部低像素密度区"方案，亮屏时能隐约看出像素排布差异，画质也有可见折损。这印证了一条规律：**"藏得进"和"藏得好"是两个工程问题。**

所以传闻中 iPhone 18 Pro 的方案是个折中：红外深度系统 (Face ID) 先屏下化——红外系统的容错空间比可见光成像大；前置摄像头保留一个更小的机械孔。想一步到位全隐形，光学上还做不到。

## 硬件缩小 ≠ 灵动岛消失：软件层才是精髓

很多人以为灵动岛就是那颗黑药丸，其实它是两层结构：

1. **物理层**：挖孔本体，尺寸由硬件决定；
2. **软件层**：一套"液态"交互系统，通过 Live Activities API 开放给第三方 App。

一个容易被忽略的机制：**软件可以渲染在挖孔之外**。苹果把挖孔当"锚点"，周围那圈黑色区域其实都是可编程像素——录音波形、比赛比分、外卖倒计时都能从锚点向两侧延展。

由此有两个推论：

- 就算药丸缩成一个点，"岛"的交互形态大概率保留，甚至因物理占用变小而更灵活；
- 苹果改尺寸如此谨慎，也因为整套 API 与动画逻辑都锚定在现有挖孔的位置和曲率上——硬件一动，开发者生态的视觉基准就得跟着迁移。

## 供应链视角：苹果为什么总在"挤牙膏"

屏下 Face ID 的传闻从 iPhone 15 Pro 那一代就开始流传，显示供应链分析师多次给出时间表又不断顺延。背后有两个硬约束：

1. **安全冗余**：Face ID 的误识率指标是百万分之一，光学系统任何劣化都可能触碰安全底线。这是刷脸支付级别的功能，苹果宁可慢。
2. **良率与成本**：屏下集成增加贴合、标定工序，良率损失直接转化为整机成本，而 Pro 机型对毛利率极其敏感。

所以"小号灵动岛"更合理的解读是：**屏下化路线上的过渡信号**——先验证传感器可以缩小，再逐步收敛挖孔，而不是一个独立卖点。渲染图里的"小一圈"，背后是滤光片、封装、标定几条供应链的多年预研。

## 冷思考：小一号到底值多少

客观盘点收益：

- **屏幕可用面积**：增加量在几个平方毫米量级，刷视频时几乎无感；
- **沉浸感**：游戏、观影的画面边缘更干净，属于"有更好"，不是"没有不行"；
- **信号价值**：最大意义在于宣告"全屏下、无孔化"路线图确实在推进。

相比挖孔小几毫米，更值得跟踪的是苹果在超构透镜 (meta-lens)、局部透明像素、波导这些方向上的专利和供应链动向——它们才决定"孔"最终会不会消失。

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/b8c38cdf43f31bed.png)

最后给三条建议：

1. **普通用户**：别为"小号灵动岛"专门换机，它是渐进式改良，预算留给续航、影像、存储这些真正影响日常体验的地方。
2. **开发者**：适配灵动岛按"区域"思维设计，别硬编码尺寸——Live Activities 的布局由系统 API 决定，挖孔变小后适配成本接近零，更新视觉基准和预览截图即可。
3. **看传闻的方法论**：判断这类消息的可信度，盯光学供应链（滤光片厂、传感器封测厂）的订单动向，比盯渲染图靠谱得多。渲染图会骗人，产能不会。
