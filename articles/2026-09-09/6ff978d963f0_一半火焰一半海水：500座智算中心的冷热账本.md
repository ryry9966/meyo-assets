这两年路过不少城市的产业新区，总能看到一模一样的招牌：智算中心。粗略统计，全国这类项目已数以百计，36kr 把行业现状概括成一句话，“一半是海水，一半是火焰”：一边是头部机房排队抢卡、供不应求；另一边是刚落成的机房里，服务器还在包装箱中睡大觉。同样叫算力，命运为什么差这么多？这篇文章把冷热两极拆开看看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/1bf499f516dc19e3.png)

## 火焰的一半：算力到底有多缺

- **训练是“吞金兽”。** 训练一个 GPT-4 量级的模型，通常需要上万张高端 GPU 连续跑几个月。Meta 训练 Llama 3 用了 16384 张 H100、跑了 54 天，期间记录了 400 多次硬件故障导致的意外中断——训练算力不仅要“多”，更要“稳”。
- **需求高度集中。** 玩得起万卡训练的公司，全国一只手数得过来。它们把最优质的算力池填得满满当当，运营商和头部第三方机房的高端卡长期满载，客户甚至要靠关系“插队”。
- **推理正在接棒。** 大模型 API 调用、Agent、多模态应用让 Token 消耗量指数级上涨。耐人寻味的是，推理成本下降并没有减少算力总需求，反而把蛋糕做大了，这就是杰文斯悖论：蒸汽机效率提高之后，煤烧得更多了。

所以火焰侧的真实图景是：不缺需求，缺的是“大规模、高稳定、组好网”的集群。这种稀缺供给，自然被疯抢。

## 海水的一半：闲置、降价与“晒卡”

另一批智算中心的冷清同样真实。有行业调研显示，部分新建项目上架率不足三成；个别项目刚办完“点亮”仪式，就传出卖卡回血的消息。

- **价格是最诚实的信号。** 主流训练卡的租价从 2023 年高峰期的十几元/卡时，一路跌到个位数；消费级 4090 的租价一度逼近电费成本线。算力市场悄然换成了买方坐庄。
- **海水侧的标准画像**大致是：地方平台公司出地出钱，集成商总包建设，几千张卡一次点亮，然后发现没客户、没运维、没生态，机房成了最贵的展厅。
- **更残酷的是技术折旧。** GPU 一年一代，躺在库房里的卡不是资产，是每天都在缩水的存货。

## 撕裂的根源：不是过剩，是错配

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/35231a5da510cfbb.png)

把火焰和海水放进同一坐标系，会发现这轮分化不是简单的“建多了”，而是结构性错配，至少错在四个维度：

1. **纸面算力 ≠ 有效算力。** 宣传页动辄 1000P，但客户真正关心的是上千张卡连续跑几个月不崩的能力：网络是否 IB/RoCE 无损组网、存储能否喂饱 GPU、故障后断点续训要多久。衡量它的指标叫 MFU（模型算力利用率），打个比方，纸面算力是发动机排量，MFU 才是实测百公里加速。同样的卡，调度差的集群 MFU 可能只有好集群的一半。客户买的从来不是卡，是“把训练跑完”的确定性。
2. **训练需求 ≠ 推理需求。** 训练是寡头游戏，推理才是长尾市场。不少中心按训练规格堆卡，本地却只有零散的推理需求，规格与客群完全错位。
3. **硬件参数 ≠ 软件生态。** CUDA 二十年的护城河不是参数能追平的：算子缺失、框架版本、调优人力，迁移到国产软件栈的隐性成本以“人月”计。硬件追参数快，生态追习惯慢。
4. **建设能力 ≠ 运营能力。** 智算中心本质是重资产 + 高技术服务业：资产靠投资就能堆出来，运营却需要懂 GPU 集群运维、懂大模型客户、懂调度的团队。这轮建设潮里，最稀缺的从来不是钱，是会运营的人。

再把“东数西算”的布局叠加进来：西部枢纽靠低电价、低 PUE（东部 1.25、西部 1.2 的能耗硬指标）承接训练类负载，东部承接低时延推理。区位与负载类型的匹配，也在默默筛选谁被火焰烤着、谁泡在海水里。

## 历史的镜子：算力也有周期律

- **矿场的转型。** 2022 年以太坊转向 PoS，成规模的 GPU 矿场一夜失去主业。活下来的转型案例，几乎都是早就有运维体系和客户渠道的——“有厂房”从来不是护城河。
- **云的历史。** 云计算自己就是从“建机房”进化到“卖服务”的：头部云厂商的壁垒从来不是机柜数量，而是弹性调度、计费体系和开发生态。
- **光伏与 LED 的招商周期。** 补贴驱动的重复建设，最后都回到同一个硬指标上：利用率。

共同规律一句话：基础设施泡沫期，过剩的是产能，稀缺的是把产能变成服务的能力。

## 三条冷思考：怎么读这张冷热地图

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/120d7a33f6f5a851.png)

1. **看利用率，别看规划值。** 判断一个智算中心的成色，规划里的 EFLOPS 没有意义，盯三件事：上架率（机器是否真在开机干活）、PUE（是否迈过能耗门槛）、续约率（客户跑完一轮训练还回不回来）。
2. **海水与火焰可以互相转化，转化器叫“推理化改造”。** 训练需求不会永远满仓，而 Token 消耗的长期曲线决定了推理才是增量市场。谁能从“卖卡时”升级为“卖 Token、卖服务”，谁就握着下一程船票。
3. **从业者与企业用户的操作建议。** 租算力先问网络规格和断点续训方案，别只比单价；架构上保留多云多卡策略，避免被单一集群锁死；做选型尽调时，优先看运维团队背景与头部客户结构，这两个指标，比任何招商 PPT 都诚实。

海水与火焰并不矛盾，它们是同一次技术浪潮的两面。潮水退去后留在沙滩上的不会是卡，而是把卡变成服务的能力，这也是每一座智算中心真正要回答的考题。
