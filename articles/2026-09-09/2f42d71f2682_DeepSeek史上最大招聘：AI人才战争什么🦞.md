提到 DeepSeek，很多人的印象还停留在 2025 年初的"DeepSeek moment"：R1 一发布，全球刷屏，App 冲上下载榜第一，硅谷连夜开会。而这家极少做 PR 的低调公司，近日被 36kr 等媒体报道，开启了其历史上规模最大的一次招聘，岗位横跨深度学习研究、数据、infra 工程、产品等多个方向。别把它当成一次例行扩编——AI 人才的稀缺度、定价方式和能力门槛，正在被重新定价。今天就来拆一拆：这次招聘释放了什么信号，机会属于谁，普通人该怎么定位自己。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/1ab155f793c8e3ff.png)

## 为什么此时疯狂招人：研究路线图背后的账本

1. **模型发出来不是终点，是发令枪。** Pre-training 之后还有一长串 post-training 工作：RLHF、RLVR、蒸馏、多模态、Agent 化和长上下文优化，每一步都需要全职研究人员。从 V3（总参数 671B、激活约 37B，宣称训练成本约 560 万美元）到 R1，DeepSeek 的迭代节奏没有慢下来，对人手的需求只增不减。
2. **算力不会自动变成模型。** DeepSeek 从量化基金自建算力集群起家，最懂这里面的细节：MoE 的专家并行与负载均衡、MLA 的 KV cache 优化、FP8 混合精度训练、DualPipe 这样的流水线调度，每一项都要专人死磕。GPU 是硬通货，但把硬通货变成能力的是铸币厂——人。
3. **开源不是做慈善，是生态攻势。** R1 权重以 MIT license 放出，换来的是生态影响力；接下来要接住的是 API 服务、私有化部署方案和应用工具链，这些都需要编制。研发和商业化两条线并行，人手就得同步扩。
4. **人才是短期不可再生资源。** R1 爆火之后，DeepSeek 员工成了猎头的心头好。此刻不扩张，人才池就被同行分走。这次招聘的本质是"防守 + 进攻"。

## "人才密度"：DeepSeek 的用人方法论

DeepSeek 的用人观，创始人梁文锋在早期访谈中系统性讲过，归结为四个关键词：

1. **Talent density 优先于人才数量。** 组织之间的差距，本质是人才密度的差距；宁可虚位以待，不凑数填坑。
2. **重用应届生和竞赛选手。** 顶级高校数学、物理、CS 专业毕业生，ACM、数学奥赛背景统统加分——DeepSeek 相当一部分论文的核心作者，入职时还是研究生或实习生。
3. **招通才，不招完美匹配。** 不设"3 年以上 LLM 经验"这类硬门槛，看重学习速度和对问题本质的把握能力。
4. **弱流程，强自驱。** 不写 OKR，小团队自组织，项目自下而上发起，给顶尖人的好奇心留白。

这套打法为什么成立？因为在 AI 前沿领域，"经验"的折旧速度异常快：一个学习速度快、动手能力强的新人，产出未必输给一个老兵小队。从 DeepSeekMath 到 R1 系列的轻量蒸馏模型，不少工作就是年轻研究者主导跑通的。在这里，"年轻人"不是成本项，而是生产资料。

## 稀缺不是炒作：顶级 AI 人才的护城河在哪

- **供给极度稀薄。** 全球范围内，真正主导过大模型 pre-training 的工程师，量级上大约只有几千人；能把 RL post-training 做好、能把推理性能榨干净的，更少。
- **经验半衰期很短。** 技术栈以半年为单位刷新：MoE 结构、MLA、长上下文、RL 训练范式、新推理框架……两年前的经验可能已经是"祖传代码"。所以大厂挖人时不看"你工作几年"，看"你最近在摸什么前沿问题"。
- **算力是入场券。** Scaling Law 的指数是拿卡烧出来的；一个研究者能不能做 Scaling 实验，基本决定了产出上限。这也是顶尖人才流向大算力平台的底层原因。
- **定价已经起飞。** 硅谷传出过天价 package 挖角顶级研究员的消息；国内头部大模型岗位的核心年薪，也与普通研发拉开了明显差距，百万级 head count 差距不算新闻。

历史上这不是第一次：2012 年 ImageNet 时刻之后，Hinton 的小团队被大厂"打包带走"；2023 年 ChatGPT 之后，全球 AI 人才战开打。**每一轮技术突变，都是一次人才市场的重新洗牌——这次筹码更大。**



## 你在池子里吗：三类人的视角

**学生和科研党**（拼可验证的产出）：
- 优先级参考：顶会一作论文 > 高质量开源贡献（给 vLLM、SGLang、transformers 等框架提 PR）> ACM/数学竞赛成绩 > 大厂 AI 实验室实习；
- 实习瞄准"能上真卡、进真训练管线"的组，别只看 logo。

**在职工程师**（按红利期选赛道）：
- 转型优先级建议：infra（CUDA 算子、分布式训练、推理优化）> 训练与 post-training 管线 > 算法应用层。算法风口迭代快，但系统和工程能力是通用的。
- 会调 API 不算大模型经验；能给一个 serving 框架做 profiling 和性能压榨，才算上桌。

**转行者**（先进场，再逼近核心）：
- 清醒一点："半年培训班上岸算法岗"基本不现实；现实入口是数据工程、eval 体系、AI 应用开发、RAG/上下文工程，先进入行业再图核心。
- 避坑：区分"研究岗"和"包装出来的业务岗"，评估团队看三件事——GPU 规模、论文开放程度、圈内口碑。

## 三条冷思考

1. **招聘公告 ≠ 行业春天。** 判断信号要看转化：未来两三个季度的实际到岗量、回流规模和团队口碑，比挂出的岗位数量更有说服力。
2. **平台是变量，能力是常量。** 数学基础、系统能力、工程实现，这三样底层技能可以穿越技术周期。今年流行什么框架不重要，快速学会下一个框架的能力才是护城河。
3. **行业正从"参数战争"迁往"落地战争"。** Pre-training 实验室需要的只是金字塔尖的一小撮人；真正的海量需求在应用层。机会更宽，但定价逻辑会变——能用模型解决业务问题的人，拿走的份额会越来越大。

最后说一句：一家公司史最大招聘的时候，个体最正确的姿势不是 FOMO，而是盘点自己的"人才密度"——毕竟，你才是自己的第一家公司。
