2025年初，多家科技媒体报道了一个耐人寻味的细节：李彦宏把精力重新收拢，直接抓文心大模型团队的技术与产品节奏。36kr 用一个词概括——“重回”。把时间轴拉长看：百度是国内最早成立 NLP 部门、最早把深度学习列为公司级战略的厂商之一；文心一言也是国内大厂里第一个对标 ChatGPT 的产品。起跑最早的公司，如今出现在追赶者名单里，这个反差本身就是一份值得拆解的商业案例。本文不聊花边，只回答三个问题：百度为什么起个大早、中间卡在哪、现在拿什么追。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/965f9939edfe0a0f.png)

## “重回一线”，到底回归了什么

- **决策链缩短**：媒体报道显示，模型训练节奏、发布时间、资源分配这类原本逐级汇报的事项，被压缩到能直接拍板的层级。
- **资源信号**：创始人下场本身就是组织内最高优先级的信号——预算、招聘、跨部门配合都会向这条线倾斜。
- **战略转向的执行力**：2025年3月，文心 4.5 与深度思考模型 X1 提前发布并宣布免费；6月底，4.5 系列以 Apache 2.0 协议全面开源。而一年多以前，李彦宏还公开表达过“开源没那么重要”的判断。立场一年内转向，侧面印证决策权确实收拢到了一线。

创始人回归这套操作并不新鲜：Meta 的扎克伯格亲自坐镇 Llama，2025年又把超级智能团队直接挂在自己名下。但要说清楚：回归解决的是**决策速度和资源集中**，它不是银弹——方向对了是加速器，方向错了是放大器。

## 起个大早，为什么没跑到最前面

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/bfab54eeaeba5b87.png)

复盘百度的位置，至少有三个结构性原因，像极了2010年就办了健身年卡、却迟迟没练出腹肌——入场券从来不是奖牌：

1. **现金流的诅咒**。搜索广告长期贡献百度核心收入的七成上下，而 AI 助手的产品逻辑天然分流搜索：搜索引擎希望你多点击多停留，AI 助手希望你一次就得到答案。让旧业务给新业务让路，等于亲手撕自己的利润表。于是2023~2024年百度选择了相对保守的路线——把 AI 塞进现有搜索 App，而不是重做一个产品。
2. **闭源的路径依赖**。文心 2019 年就迭代到 1.0，闭源 API 模式在 OpenAI 出现之前并不构成问题；但2024年底 DeepSeek 把“开源+极致低价”变成行业默认选项（其 V3 论文披露 GPU 训练成本约558万美元、用2048张 H800 完成），闭源 API 的议价权被瞬间瓦解。开源决定晚了一年多，代价是时间与开发者信任的双重损耗。
3. **评测体系与真实需求的裂缝**。大厂模型团队容易围绕 benchmark 做工程，用户要的却是“拿来就能用”。文心一言早期的生图翻车、预录演示开场，暴露的正是内部评分与用户体感之间的落差；同期大量早期 AI 人才流向创业公司，进一步稀释了人才密度。

一句话总结：不是没技术，是旧模式太能赚钱，新模式在组织里动作变形。

## 追赶三板斧：开源、全栈、第二曲线

- **第一板斧，开源换生态**。文心 4.5 系列（最大版本424B参数的 MoE 架构）开源后，与飞桨框架形成“框架+模型”组合拳，用开发者生态的筹码，补回闭源 API 时代损失的份额。
- **第二板斧，全栈压成本**。百度是国内少数走“芯片（昆仑芯 P800，已跑通三万卡自研集群）—框架（飞桨）—模型（文心）—应用”四层全栈的公司。全栈的价值不在讲故事，而在推理成本与供应链稳定性：上一层的利润可以补贴下一层的价格战。
- **第三板斧，第二曲线输血**。萝卜快跑累计订单已破千万，版图从武汉铺向迪拜、阿布扎比；智能云乘着企业 AI 化的东风，增速回到20%以上。这两条现金流，是模型追赶期最需要的弹药。

## 对手没有一个是软柿子

- **DeepSeek**：算法效率+开源社区双轮驱动，把行业训练成本打下来一个数量级；
- **字节豆包**：背靠抖音分发与 App 工厂方法论，用户规模率先过亿；
- **阿里通义**：云+电商+开源生态三线并进，Qwen 系衍生模型在全球开源社区长期位居下载量前列。

百度要追的不是单点跑分，而是“模型—入口—生态”的完整闭环。更麻烦的是时间窗：AI 助手对传统搜索的替代不会等人，百度必须在“自己革自己的命”与“被别人革命”之间抢跑。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/1e09d54b8b8c4c96.png)

给关注 AI 赛道的同学三条可操作的判断框架：

1. **看单位成本，别看发布会**。全栈自研是不是护城河，用“每百万 token 的推理成本”和“集群利用率”来验证——账本永远比叙事诚实。
2. **转型窗口以年为单位倒计时**。参考微软、Adobe 的历史，现金牛业务自我革命的窗口通常只有2~3年；关键动作是新业务给独立预算、独立 KPI，而不是往旧产品里塞新功能。
3. **创始人回归是加速器，不是方向盘**。决策链可以缩到最短，但技术路线的对错，最终要靠数据飞轮和开发者反馈来校准——多听外部用户，少听会议室。

大模型这场马拉松，起跑早从来不是奖牌，配速和补给策略才是。百度的故事讲了一半，接下来两年，看账本。
