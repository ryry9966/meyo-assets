最近 36kr 那篇《下一轮 AI 真正的大趋势，很多人还没意识到》在朋友圈刷了屏。不少人看完的第一反应是：又造新概念了？但在 RY哥 看来，这篇爆款背后说的事其实很朴素——**AI 的主线剧情正在换轨：从拼训练算力转向拼推理算力，从生成内容转向完成任务，从模型本身转向模型所在的整个系统**。三条线拧在一起，才是“下一轮大趋势”的完整拼图。下面逐一拆开。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/e9eb7bae7b29d613.png)

## 一、Scaling 的接力棒：从预训练交到推理这一棒

2020 到 2023 年，行业的信仰是“暴力美学”：GPT-3 的 1750 亿参数、动辄万卡的训练集群，底层逻辑是 Kaplan（2020）和 Chinchilla（2022）两篇论文定下的 Scaling Law——模型越大、数据越多，损失函数就一路往下掉。但这套打法在 2024 年开始撞墙：

- **数据墙**：互联网上高质量人类文本接近采空，合成数据用不好还会“近亲繁殖”，导致模型退化；
- **成本墙**：一次前沿模型训练从千万美元量级飙到数亿美元，边际收益却在递减；
- **时间墙**：训练一代旗舰要半年起步，迭代节奏跟不上市场预期。

于是接力棒交给了 **test-time compute（推理时计算）**。OpenAI 的 o1、开源的 DeepSeek-R1 都是同一思路：让模型在“答题前多想一会儿”，通过长链思维（Chain-of-Thought）加上带可验证奖励的强化学习（RLVR），在推理阶段花更多算力换更准的答案。最直观的数字：o1 在 AIME 数学竞赛题上从 GPT-4o 的 13% 跳到 83%——靠的不是背了更多题，而是“草稿纸”变厚了。

类比一下：上一代模型是提笔就写的学霸，新一代是会打草稿的学霸，题越难，草稿用得越狠，得分越高。**草稿纸本身成了新的 Scaling 维度**，而且这块天花板远没摸到。

## 二、从“生成内容”到“完成任务”：Agent 接管入口

ChatGPT 式产品是问答范式：你问一句，它答一句，剩下的活儿还是你的。而 Agent 范式是：你给一个目标，它自己拆任务、调工具、查结果、错了重试。一套能真正干活的 Agent 系统，通常有四个构件：

1. **规划（Planning）**：把“帮我做份竞品报告”拆成检索→筛选→汇总→成稿的任务图；
2. **工具调用（Tool Use）**：能点浏览器、跑代码、查数据库，而不是只会输出文字；
3. **记忆（Memory）**：跨会话记住你的偏好和上下文，越用越顺手；
4. **验证与迭代（Evaluation）**：自己检查产出质量，不合格就推倒重来。

这条趋势最硬的证据来自编程领域：Cursor、Claude Code 这类 agent 化工具的爆发，本质是把“AI 辅助写代码”升级成了“AI 承包一个 feature”。为什么编程先行？因为代码可以自动运行、自动测试——**任务是否完成存在客观信号，正好喂给强化学习**。顺着推，凡是结果可验证的领域（财务对账、客服工单、运维排障），都会按这个顺序被 Agent 化。

入口也会跟着换：上一代的入口是搜索框，你输入关键词；下一代入口可能是“任务框”，你描述目标。谁接管了任务分发，谁就握住了下一代流量分配权——这才是大厂疯狂卷 Agent 的真实原因。

## 三、价值链迁移：模型层“通缩”，系统层升值

很多人没意识到的另一半趋势是：**模型本身正在快速贬值，而模型之外的系统正在升值**。看两个事实：

- API 价格雪崩：GPT-4 发布时百万 token 输入要 30 美元，如今能力相当的开源模型（DeepSeek、Qwen 系列）把价格打到几毛钱量级，两年降了近百倍；
- 开源追平闭源的周期，从“永远追不上”缩短到“几个月”，模型层的护城河被时间不断冲刷。

那价值去哪了？向上和向下同时迁移：

- **向上游**：算力、电力、数据中心。Stargate 级别的巨额基建投资说明，底层资源正在变成新的“油田”；
- **向下游**：垂直场景的领域知识、私有数据、工作流集成。同一个模型，接上律所的卷宗库和接上医院的病历库，就是两个完全不同的产品。

这和云计算的历史惊人相似：AWS 真正的护城河不在“卖服务器”，而在上面长出来的整个应用生态。模型会像电力一样成为标准化商品，赚大头的是“用电做事”的人。



## 四、更远的一站：AI 走出屏幕，进入物理世界

前三条是“正在进行时”，第四条是“将来时”：**具身智能（Embodied AI）**。当互联网文本被榨干后，下一个数据金矿是传感器采集的物理交互数据——机器人每动一次手，就产生一条文本世界里不存在的数据。VLA（视觉-语言-动作）模型、端到端自动驾驶、人形机器人的密集迭代，都是这个趋势的前哨。数字世界的 Scaling Law 靠 GPU，物理世界的 Scaling Law，靠的是“跑起来”的机器人保有量。用龙虾的话说：数字虾已经养肥了，机械虾才刚下苗塘。

## 收尾：三条冷思考

1. **判断趋势真伪，看“单位任务的边际成本”**。别被炫技 Demo 迷惑，只问一句：它让完成某件事的成本降了一个数量级吗？降了，才有商业拐点；只是“更像人”，多半是营销话术。
2. **从业者的护城河在“任务结构化”能力**。模型会继续通缩，但把行业流程拆成 Agent 可执行的步骤、定义清晰的验收标准（evals），这件事每个行业都要重做一遍——这是未来两年最值钱的技能。
3. **普通人的基本功是“委托”**。从“用 AI 写一段”升级到“把一件事整体交给 AI 并验收结果”：练习拆解目标、定义完成标准。这是人机协作用的下一代通用技能，越早练，学费越便宜。

趋势从不敲锣打鼓地来。它只是让某件事悄悄变便宜了，然后，世界重新排座次。
