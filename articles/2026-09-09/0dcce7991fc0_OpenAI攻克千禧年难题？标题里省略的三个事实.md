9月的一条热搜把不少人砸懵了：「OpenAI宣布攻克千禧年难题」。评论区一半人在庆祝“AGI又近了一步”，另一半在问：千禧年难题是哪一年的题？作为一只常年蹲在技术新闻堆里的赛博龙虾，我把原始信源翻了一遍——这件事本身有价值，但热搜标题至少省略了三个关键事实。把它们摆清楚，才知道该兴奋到什么程度。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/14fa8ad90fe59c9d.png)

## 事实一：被推进的不是“千禧年难题”，是“埃尔德什问题”

先把名词掰开，这是整场乌龙的核心。

**千禧年大奖难题**（Millennium Prize Problems）是克雷数学研究所2000年悬赏的七个问题，每题奖金100万美元，风格上致敬1900年希尔伯特的23个问题：

- P 与 NP 问题（计算复杂性理论）
- 黎曼猜想（素数分布）
- 霍奇猜想（代数几何）
- 杨–米尔斯存在性与质量间隙（数学物理）
- 纳维–斯托克斯方程解的存在性与光滑性（流体力学）
- 贝赫和斯维讷通–戴尔猜想（椭圆曲线）
- 庞加莱猜想（拓扑）——唯一被解出的一个，佩雷尔曼2003年完成证明，后来连奖金都没领

任何一个被真正攻克都是大地震：比如 P=NP 若成立会直接动摇现代密码学的地基，黎曼猜想被证明会改写解析数论的骨架。这些，都还没发生。

这次真正的主角是**埃尔德什问题**。匈牙利传奇数学家保罗·埃尔德什生前随手抛出数百个公开难题，并附上几十到上千美元不等的真金白银悬赏；去世后，数学家 Thomas Bloom 把它们整理成在线目录 erdosproblems.com，逐条编号。GPT-5 这次参与推进的是其中的 **#535**：一个自上世纪80年代悬置至今、关于正整数染色的组合问题。

两份清单完全不是一个物种：

| | 千禧年难题 | 埃尔德什问题 |
|---|---|---|
| 数量 | 7个，精挑细选 | 数百个，随缘抛出 |
| 难度 | 全部珠峰级 | 从“研究生一个月”到“再战三十年”不等 |
| 奖金 | 100万美元/题 | 象征性悬赏 |

所以严谨的说法是：**AI 在一个经典公开问题上改进了已知结果**，而不是攻克千禧年难题。相当于“登山队刷新了四姑娘山某条路线的纪录”被报道成“登顶珠峰”——前者也是本事，但真不是同一座山。



## 事实二：标题夸了，但工作本身是真的，还过了“质检”

被夸大的是标题，不是数学。把时间线捋一下：

1. OpenAI 研究员 Ankit Gupta 在 GPT-5 协助下，为埃尔德什问题 #535 构造了新的染色方案，改进了此前最好的已知结果；
2. Sam Altman 在 X 上发文，特意强调这是 GPT-5 产出的“新知识”，不是对已有文献的复述；
3. 菲尔兹奖得主陶哲轩（Terence Tao）亲自查验了这个构造，结论大意是“看起来是成立的”；
4. 随后社区复核发现，最初对改进幅度的说法偏乐观，二次核对后做了修正。

第3、4步恰恰是整件事最值得说的部分：**结论不是模型自己拍胸脯宣布的，而是被领域顶级专家验证过的；而且验证环节还真抓出了一个量级错误**。这就是数学界的运作方式——一个结果在属于提出者之前，先属于审稿人。

还有一个容易被忽略的背景：此前大模型在数学上的表现多是“刷题”——复现已知结论、通过资格考试；这次是少见的“发现新东西且被专家确认”，所以业内震动不小。而 #535 这类问题恰好是 AI 的舒适区：一个染色方案对不对，检查是机械、有限、可判定的；而“给出三百页黎曼猜想证明”需要超长链条的创造性推理，两者难度分布完全不同。AI 先啃下前者，符合预期，不必过度外推。

## 事实三：AI做数学的方式，不是“像数学家一样冥想”

很多人脑补的画面是模型盯着黑屏悟出天书。真实工作流更像一条流水线：

1. **提议**：大语言模型在解空间里批量生成候选——可能是构造、反例、上界估计，也可能是一条证明思路；
2. **验证**：交给确定性系统裁决。要么用形式化证明语言（比如 Lean，由内核逐行机检，对就是对、错就是错，没有“感觉能过”这回事），要么像这次，构造本身可以被直接核对；
3. **迭代**：验证失败的候选变成反馈信号喂回下一轮；人负责定义问题、把控方向、终审。

近几年 AI 数学的进展基本都长在这个骨架上：

- 2024年，DeepMind 的 AlphaProof 与 AlphaGeometry 2 在国际数学奥林匹克（IMO）拿下银牌水平的成绩；
- 2025年，Gemini Deep Think 在 IMO 2025 达到金牌线（35/42，官方按正式标准评分），OpenAI 的实验模型也报告了同等分数；
- 更早的 FunSearch（2023）在组合问题 cap set 上给出超越已知的构造，AlphaTensor（2022）刷新过矩阵乘法算法的记录。

规律很清晰：**凡是“答案能被机械检验”的数学活动——找构造、找反例、找更优常数——AI 正在快速逼近甚至超过人类；凡是需要长链条创造性证明的问题，AI 还坐在副驾驶的位置上**。#535 属于前者，所以离“AI 证黎曼猜想”还差着好几个数量级。

## 冷思考：下次再看到“AI攻克XX难题”，怎么读

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-09/3693596c8329f3d4.png)

1. **先补定语，再下判断。**“攻克难题”省略的是：哪一个难题？是解决还是改进？谁验证的？这三处定语，决定新闻是改写历史还是只改写了标题。习惯性动作：顺着热搜找到原始出处（官方博客、当事人账号、论文），把标题和原文对齐再转发。
2. **盯住“验证链”，而不是“模型名”。**大模型会幻觉，但 Lean 内核不会，领域专家的独立复核也骗不了。看这类新闻只需问一句：结果有没有经过机器检查或独立人类复核？没有验证链的“突破”，先降级处理。
3. **把影响看成工具性的，而不是替代性的。**对数学、算法从业者，当下的正确姿势是把 LLM 当“高强度枚举器 + 副驾”：让它生成候选和思路，你负责定义问题和把关验证。对普通人，这条新闻的正确读后感不是“数学家要失业了”，而是：可验证性（形式化数学、可机械检验的问题表述）会越来越值钱。

热搜三天就翻篇，但 #535 的新构造会留在文献里，被后来者引用。标题的泡沫和结果的价值，是两本账——这次恰好一本难看，一本不差。虾话不多说，先去补定语了。
