最近司晓迪在社交平台说了一句"内娱没有她喜欢的小鲜肉了"，引发广泛共鸣。表面看是一条随感，背后其实是一个有意思的产业级问题：当造星越来越像流水线作业，为什么消费者的"心动率"反而直线下降？今天就从产品逻辑、神经科学、信息传播三个层面拆一拆。



## 一、"小鲜肉"本质上是一种工业产品

先纠正一个认知偏差：很多人觉得"小鲜肉"是形容词，形容年轻好看的男艺人。但在产业逻辑里，它更像一个产品规格——有标准化的筛选路径、培训流程和上线机制。

练习生制度的核心目标是什么？——降低不确定性。

- **选角阶段**：通过外貌、才艺、性格标签筛出"符合大众审美均值"的候选者
- **培训阶段**：歌舞、表情管理、话术训练，把个性化差异压平到"可控范围"
- **出道阶段**：通过选秀/综艺制造曝光，用人设标签快速建立受众认知
- **运营阶段**：数据监控 + 粉丝运营 + 商业变现，保证 ROI 可预测

这套体系从日韩引入，核心 KPI 是"可复制性"。你不需要特别有才华，你只需要"达到基准线 + 不出错"。

这在商业上完全合理——降低风险、提高良品率是任何工业体系的天然追求。但问题在于：工业化追求的是"均值回归"，而你心动的瞬间，恰恰来自"方差"。

一个让你记住的人，一定有某个"偏离均值"的特质：可能是声线特别、可能是眼神里有一种无法训练出来的东西、可能是他在某个角色里展现了训练不出来的脆弱感。这些东西，流水线设计不出来。

## 二、审美疲劳不是矫情，是你的大脑在"节能"



"没有喜欢的了"这句话，经常被解读为"太挑剔了"。但从神经科学角度，审美疲劳是一个可解释的生理现象，核心关键词：**多巴胺奖励预测误差（Reward Prediction Error, RPE）**。

简单说，多巴胺不是在你获得奖励时分泌最多，而是在"实际体验超出预期"时分泌最多。

- 第一次看到某种类型的偶像 → 你的预测模型里没有这个模板 → RPE 为正 → 多巴胺飙升 → "心动了"
- 第十次看到同类型 → 大脑已建立预测模型 → RPE 趋近于零 → 多巴胺不再激动 → "无感"
- 第一百次 → 大脑甚至开始预测性疲劳 → "又来了"

这不是你变挑剔了，是你的多巴胺系统在做"预期校准"。它在告诉你：这个刺激源的边际效用已经递减到不值得分配注意力了。

还有一个机制叫**习惯化**。诺贝尔奖得主 Eric Kandel 在海兔（Aplysia）身上做的经典实验证明：重复刺激会导致神经突触反应减弱。这是所有生物的节能策略——对重复信号降低响应，把认知资源留给新信息。

所以当有人说"现在的小鲜肉都长得一样"时，不一定是他们真的长得一样（虽然也确实有同质化），而是你的感知系统对这类特征已经"脱敏"了。

这也解释了为什么"第一波"总是印象最深：不是因为那时候的艺人更好，而是因为那时候你的预测模型还没有建立，每一个都是"超出预期"。

## 三、同质化的加速器：信息瀑布与算法推荐

产品端标准化 + 用户端脱敏，已经够让"心动率"下降了。但还有第三个变量在火上浇油：**信息瀑布效应**。

信息瀑布，简单说就是——当人们不确定该选择什么时，会倾向于参考别人的选择。一旦足够多的人涌向某个方向，后来者就会放弃自己的判断，跟随大流。

在造星领域，这个机制运转得特别顺畅：

1. 某种类型的艺人火了 → 数据好 → 平台/资本追加投入同类
2. 算法捕捉到"这个品类点击率高" → 推荐更多同类内容
3. 用户在算法投喂下不断看到同类型 → 形成"这就是当下流行的"认知
4. 更多仿制者涌入 → 品类进一步饱和 → 同质化加深
5. 用户开始审美疲劳 → 但供给端因为惯性还在持续产出 → 库存堆积

这是一个典型的**负反馈延迟**系统：需求端已经饱和了，供给端还在基于滞后的数据做决策。等供给端反应过来，往往已经过剩了。

短视频领域的"跟风拍同款"是同样的逻辑，只不过周期更短、更可见。造星周期长，等你看清问题的时候，下一批同质化产品已经走完练习生培训流程了——沉没成本让它很难被叫停。

## 四、需求端在升维，供给端还在原地踏步

到这里可以做一个结构性总结了。当前"没人喜欢"的困局，本质是供需错配：

| 维度 | 供给端（造星方） | 需求端（观众） |
|------|------------------|----------------|
| 核心逻辑 | 标准化、可复制、降风险 | 个性化、差异化、求新鲜 |
| 审美层级 | 颜值 + 人设标签 | 实力 + 作品 + 独特魅力 |
| 决策方式 | 数据驱动、跟风式 | 圈层化、口碑驱动 |
| 时间尺度 | 培养周期 2-5 年，滞后严重 | 审美迭代周期越来越短 |

观众的需求已经从"长得好看就行"升级到"你能不能给我一些意想不到的东西"。但工业体系擅长的是"确定性"而非"意外"。

这就像一个厨师只会做标准化快餐，而食客的味蕾已经进化到想吃 fusion 创意菜了。不是厨师不努力，是体系的结构性局限。

好消息是：**长尾市场正在崛起**。当主流渠道的造星效率下降时，独立内容、小众平台、跨界创作者正在通过另一种逻辑生长——他们不追求"覆盖最大公约数"，而是服务特定圈层的特定审美。这类内容可能流量不大，但"心动率"高得多。

## 五、3 条冷思考



**1. 不要用"有没有喜欢的"来衡量整个行业**

你的注意力被算法引导到主流流量池里，看到的是同质化最严重的那一层。行业不是没有好东西，是好东西不在算法主推的位置。学会主动搜索，而不是被动接受投喂——你的搜索行为本身就是在给算法做"反向训练"。

**2. 区分"流量型"和"作品型"**

如果你要找的是"喜欢的人"，关注作品而非人设。人设是流水线产品规格表，作品才是个人特质的容器。一个演员在一部好剧里的表现，比 100 条短视频更能告诉你他值不值得喜欢。看作品的时间投入比刷短视频高，但信噪比也高得多。

**3. 给自己的审美建立"信息多样性"**

你的多巴胺系统需要新颖性刺激，那就主动给它喂不同类型的输入。看不同年代的作品、不同国家的内容、不同风格的表达。审美品味不是天生的，是信息环境塑造的——你输入什么，就输出什么样的"喜欢"。如果觉得"什么都看不下去"，有时候不是内容的问题，是你的信息输入管道太单一了。

---

最后说一句：司晓迪说的那句话，与其说是对某个群体的评价，不如说是一个信号——当消费者的辨别力在提升，而供给端的迭代速度跟不上时，"没有喜欢的"就是最诚实的市场反馈。对消费者来说这不是坏事，它意味着你的审美系统在正常工作。

对产业来说，这也是一个该听的信号。流水线能保证良品率，但保证不了"让人心动"。后者需要的不是更多流程，而是更多允许意外的空间。
