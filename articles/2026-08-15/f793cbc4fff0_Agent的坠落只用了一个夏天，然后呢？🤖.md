“AI Agent 的坠落，只用了一个夏天。”最近这句判断在技术和投资圈子里反复出现。并不是说模型跑不动了，而是市场对“通用自主智能体”的耐心，在短短两三个月里被现实迅速磨掉。演示视频仍然很酷，但企业预算开始收缩，开发者在群里吐槽“demo 一次过，自己跑三次都崩”。这更像一次典型的预期去泡沫：Agent 并没有消失，只是从魔法回归为工程问题。



## 1. Agent 和 Chatbot 差在哪：从“回答”到“办事”



Chatbot 的核心是一次输入、一次输出，评价标准是文本质量；Agent 的核心是一条多步执行链，评价标准是任务完成率。两者的差距不在模型大小，而在系统设计。

- 典型 Agent 循环：理解目标 → 拆解子任务 → 调用外部工具 → 观察返回结果 → 判断是否完成 → 必要时重试或调整。
- 工程上通常包含四个模块：memory（记忆）、tool use（工具调用）、planning（规划）、reflection（反思）。
- 举一个常见例子：让 Agent“把上周销售数据整理成周报并发送到指定邮箱”。它需要先理解表结构，再生成 SQL 或调用数据接口，处理缺失字段，生成图表，检查发送权限，最后调用邮件 API。任何一环断开，任务都会失败。
- 因此，Agent 的难点从来不是“更会聊”，而是“如何在复杂环境里稳定地把一件件事做对”。

## 2. 夏天发生了什么：预期曲线从峰值滑向低谷



如果把时间轴拉长，会发现这轮降温早有征兆。2023 年 AutoGPT 等早期项目把“自主智能体”推向大众；2024 年各类“数字员工” demo 刷屏；到了最近一个夏天，资金和舆论开始同步收缩。

- 一级市场不再只为“通用 Agent”的故事买单，转而追问 DAU、次周留存、任务成功率和复购。
- 多家产品开放测试后，用户发现演示里“10 分钟完成竞品分析”，自己用却卡在账号登录、表格格式、工具版本、API 权限等细节上。
- 企业采购态度也明显转变：从“要一个全自动 AI 员工”，退回“先做一个环节的 Copilot”。预算不再大面积流向端到端自动化，而是流向能证明 ROI 的小工具。
- 有产业报道提到，不少 Agent 产品在真实企业场景中的长任务完成率远低于 demo，部分通用产品的次周留存甚至低于 SaaS 行业中位数。

这一轮冷却并不是需求消失，而是预期向工程现实收敛。甚至可以说，只有把“全自动通用智能体”的泡沫挤掉，能活下来的 Agent 才更接近真实价值。

## 3. 技术根源：多步任务不是线性叠加，而是错误概率相乘



为什么看似简单的“多步任务”这么难？核心原因在于概率。假设单步工具调用成功率是 95%，连续 10 步都成功的概率只有约 60%；若单步成功率降到 90%，10 步成功率不足 35%。这就是长任务 Agent 最直观的命门。

- 上下文窗口只是入门门槛，真正卡住的是长时间执行中的目标漂移：模型跑着跑着忘了最初目标，或被中间结果带偏。
- 工具调用本身也很脆弱。真实业务中的 API 会改版、权限会过期、返回格式不规范，Agent 需要处理大量“脏现实”。
- 记忆策略同样关键。什么该写入长期记忆、什么只保留在本次会话、如何防止过时信息污染决策，目前仍没有通用解法。
- 安全和权限问题更棘手。一旦 Agent 拥有发邮件、删文件、写数据库的权限，错误成本就从“文本写错”升级为“生产事故”。所以很多企业只敢让 Agent“建议”，不敢让它“执行”。
- 评测体系也不成熟。许多 benchmark 基于干净环境和理想工具，分数很高，一进真实业务就大幅缩水。

## 4. 泡沫退去后，哪些 Agent 反而在长



降温并不意味着 Agent 赛道终结。相反，一些更务实的方向正在重新获得资源。

- 垂直窄场景：代码生成与 review、客服工单分类、销售线索清洗、财务对账、物流异常处理。这些任务边界清晰，结果容易验证，更适合当前技术水平。
- 半自动工作流：不是让 Agent 一个人把整条流程跑完，而是让它完成 70%~80% 的机械步骤，在关键节点停下等人确认。这种“人在环上”的模式能显著降低失败成本。
- 与现有系统耦合：把 Agent 能力嵌入 RPA、API 网关、低代码平台或内部数据工具，比独立做一个“数字员工”更容易被接受。
- 从 Gartner 技术成熟度曲线看，这类技术往往在“期望膨胀期”之后进入“泡沫破裂低谷期”，但真正的基础设施和最佳实践，恰恰是在这个阶段沉淀下来的。

最后给三条冷思考：

1. 把 Agent 当实习生，而不是当魔法。它需要明确指令、清晰边界和人工复核点。上线初期，关键动作必须有人确认。
2. 从窄场景切入，别一上来追求端到端全自动。先让它在单一环节把成功率做到 95% 以上，再逐步扩展。
3. 关注可观测性与评估，而非只看演示。没有稳定、可度量的任务成功率，再酷的 demo 都无法转化为长期价值。
