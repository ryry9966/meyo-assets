泡泡玛特重新回到千亿市值附近，财报里的 Molly、SKULLPANDA 依旧能打。但 36 氪这篇热文把灯光打向了幕后：一批被中国玩家称为“老师”的日本潮玩设计师，正成为这轮增长里最闷声赚钱的群体之一。他们没有在泡泡玛特上班，却可能靠着一个 IP、几套盲盒，在中国市场拿到比许多上市公司高管还高的分成收入。“日本老师”到底是谁？这桩生意为什么能成立？



## 一、“老师”不是员工：日本设计师如何嵌入泡泡玛特体系

“老师”这个称呼，在潮玩圈不是客套，而更像职人文化里的尊称。玩家遇到某款透明件做得极干净的软胶玩具，会说“这是大久保老师的作品”；蒸汽朋克动物系列火了，弹幕里刷的是“镰田老师又出货了”。

这些日本设计师多数不是泡泡玛特员工，而是以“艺术家 IP 授权 + 销售分成”模式合作。比较典型的合作名单包括：

- **大久保博人 / INSTINCTOY**：擅长透明渐变、异材质拼接，被称为“软胶天花板”。
- **镰田光司**：蒸汽朋克动物题材，早期在日本展会小圈子发售，进入泡泡玛特后迅速大众化。
- **横山宏**：Ma.K 科幻机甲作者，硬核模型圈知名度极高，盲盒化后破圈。

泡泡玛特负责把设计师的原型、设定、涂装方案转化为可量产的盲盒：3D 拆件、模具、供应链、门店、线上抽盒机、营销投放全部由平台完成。设计师主要投入前期创作与监修，收入则来自保底授权金加销售分成。

根据泡泡玛特近年财报，自有 IP 与独家 IP 合计贡献了七至八成收入。日本设计师大多被归入独家 IP 或非独家 IP，虽然不直接披露单人收入，但头部系列的年销售额过亿并不罕见。一个在日本本土一年卖几百只的工作室产品，放到中国平台上可能半年卖出百万只。

## 二、赚翻的底层机制：盲盒、分成与数据飞轮



日本设计师在中国赚翻，不是单靠“日本设计”四个字，而是被一套商业机制放大了。

1. **盲盒降低消费门槛**  
   传统设计师玩具动辄一两千元一只。盲盒把价格打到 59–79 元，用户一次性消费压力骤降。隐藏款概率通常控制在 1/120 或 1/144，二手市场溢价又会刺激复购。设计师玩具从“收藏品”变成了“高频消费品”。

2. **全渠道铺开，一个 IP 同时触达千万人**  
   泡泡玛特在全国拥有数百家门店、上千台机器人商店，再加上微信抽盒机、天猫旗舰店、抖音直播间。一个日本设计师 IP 从首发到铺满所有触点，最快只需要几个月。同样一个 IP，在日本可能只出现在几家买手店和展会摊位，在中国却可以形成全国性的铺货密度。

3. **授权分成不等于卖版权，而是深度绑定**  
   设计师保留 IP 所有权，泡泡玛特获得中国及全球部分市场的独占运营权。销售越好，设计师拿到的分成就越高。行业内常见阶梯式分成，头部项目还会增加设计费、监修费。虽然没有公开确切比例，但“日本老师”年收入达到千万级人民币的说法，在投资圈和潮玩圈并不算离谱。

4. **数据反馈闭环，让爆款更快被加注**  
   泡泡玛特通过抽盒机用户行为、会员复购、社交平台声量、二手市场溢价等数据，快速判断哪个 IP 有潜力。表现好的 IP 会继续追加 MEGA 大娃、联名款、海外发售；表现一般的则减少产能。设计师本人也相当于拿到了一个实时市场测试系统，这是他们在日本很难接触到的效率。

## 三、为什么是日本设计师？审美、工艺与历史红利

日本潮玩设计师在中国的成功，背后有超过半个世纪的产业积累。

- **Sofubi 软胶文化**：1960 年代日本玩具公司开始生产怪兽软胶玩具，到 1990 年代 MEDICOM TOY 推出 BE@RBRICK，把“平台玩具”彻底商业化。日本设计师很早就习惯了在固定素体上做艺术表达。
- **工艺细节**：透明件、渐变涂装、异材质拼接、可动结构，这些需要长期与工厂磨合才能稳定量产。日本职人文化让不少设计师对品控有近乎偏执的要求。
- **世界观设定**：蒸汽朋克、复古未来、怪诞治愈、科幻机甲，这些风格在日本同人志、模型展会、独立游戏里早已形成完整语言。中国年轻消费者对这类审美有天然好奇，又不必承担日本原版的高价和渠道门槛。

泡泡玛特做的，本质上是把“日本设计力 + 中国供应链 + 连锁零售/线上分发”组合起来。日本设计师提供差异化的视觉与故事，中国工厂解决量产稳定性，平台解决规模化触达。这让一个小众工作室 IP 能在 6–12 个月内从东京中野的展会摊位走到上海、北京、成都的商场盲盒机。

## 四、高增长下的三朵乌云

任何一个高速增长的模式，都有另一面。

- **金融化炒作**  
  隐藏款被炒到上千元，吸引大量非玩家入场。一旦热度退潮，二手价格崩盘会反噬品牌信任。过去几年潮玩二级市场已经出现过几轮价格过山车，玩家对“理财盲盒”的警惕正在上升。

- **IP 生命周期缩短**  
  盲盒要求高频上新，设计师一年要出多个系列。产能跟不上，就会出现“换色重涂”“微调再版”，老玩家很快审美疲劳。日本设计师习惯的慢节奏，与中国市场的快节奏之间天然存在张力。

- **合规成本上升**  
  盲盒销售已被要求公示隐藏款概率，部分地区限制向低龄未成年人销售。监管趋严增加了平台和设计师的合规成本，也压缩了某些灰色营销空间。

## 五、冷思考：三个判断 IP 可持续性的指标



1. **看设计师是否有“工作室基因”**  
   有大工作室支撑的 IP，品控、产能、系列迭代更稳。个人设计师一旦爆红，产能和创作质量容易波动。大久保博人的 INSTINCTOY 能持续输出，靠的就不只是个人审美，而是一套小型工作室的流程。

2. **看 IP 是否有叙事内核**  
   好 IP 不只是可爱造型，而是有角色设定、情绪表达、世界观延展。SKULLPANDA 的“反叛与柔软”就是一个典型。只有造型没有故事的 IP，抗周期能力通常更弱。

3. **看平台是否克制**  
   健康平台会控制发售节奏、管理二级市场预期、给设计师创作周期。如果所有隐藏款都被当成理财产品操作，短期 GMV 好看，长期 IP 资产反而会被透支。

潮玩生意的本质不是卖塑料，而是把设计力、情绪价值和稀缺性打包成可复购的体验。日本老师在中国赚翻，是几十年职人文化、中国供应链效率与平台算法的一场合谋。下一次抽盒前，不妨想一想：你是在为设计买单，还是在为那套被精心设计的稀缺感买单。
