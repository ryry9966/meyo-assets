2025 年 1 月，DeepSeek-R1 发布后几天内登顶多国应用商店下载榜，英伟达单日市值蒸发约 5890 亿美元、创下当时美股历史纪录。从那天起，"DeepSeek 会不会 IPO"就成了资本市场每隔几个月就要复习一遍的保留节目，而 DeepSeek 的公开口径始终一致：没有时间表。36kr 那篇《DeepSeek 的 IPO，两个现实一个目标》给出了一个干净的分析框架——公司头顶压着两个现实，心里揣着一个目标。这篇文章就把这三样东西逐一拆开，看看它本质上是一道什么样的选择题。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-12/2ac52f90f3a51ed2.png)

## 现实一：算力账本，烧钱是确定的

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-12/82505c96e5b5bbf5.png)

- 大模型前沿训练是标准的重资产游戏。DeepSeek 自己披露过 V3 的训练成本：约 278.8 万 H800 GPU 小时，折合约 557 万美元。注意这只是"最后一跑"的租用算力价，不含前期架构探索、失败实验和集群基建，真实累计投入是数倍以上。
- 训练只是开头，**推理才是无底洞**。R1 这类推理模型会"先想很久再回答"，单次请求的 token 消耗是普通聊天的数倍；开源加低价 API 带来爆发式流量，等于把算力账单同步放大。
- 值得强调：DeepSeek 是工程效率的优等生——MLA 压缩 KV cache、MoE 稀疏激活、FP8 混合精度训练、多 token 预测，单位 token 成本比同代模型低一个量级。但效率改变的是成本曲线的斜率，改变不了"用户越多、账单越大"的方向。
- 供给端还有硬约束：先进 GPU 的跨境供应受管制是客观事实，无论走囤货路线还是国产替代路线，都要额外支付时间和集成成本。
- 结论：开支是确定的、随需求增长的；收入的确定性和增速都弱一档。这道**"剪刀差"就是 IPO 传闻的第一性来源**——资本市场天然要问：缺口谁来补？

## 现实二：账上未必缺钱，但行业的资本结构在变

- DeepSeek 的母体是幻方量化，一家靠自营量化交易盈利的头部私募，早在 2019 年就自建"萤火二号"超算集群（公开报道投入十亿元级、万卡 A100），叠加管制收紧前囤下的 H800，短期内确实饿不着。
- 但对手的弹药在换量级：OpenAI 拿到软银牵头的数百亿美元级融资，Anthropic 的融资同样以百亿美元计；国内 MiniMax 已递表港交所，智谱进入上市辅导流程。当同行用"巨额融资 + 上市"武装到牙齿，竞争就从纯技术赛，部分变成了资本耐力赛。
- 上市的隐性代价也不小：强制信息披露、业绩节奏、股东诉求，都会一层层传导进组织决策。DeepSeek 以极扁平、自下而上的研究文化著称，和上市公司"每个季度都要交代"的治理节奏天然存在张力。
- 所以真正的问题从来不是"缺不缺钱"，而是**"钱附带什么条件"**。IPO 是工具，不是勋章。

## 一个目标：把研究自由排在估值前面

- DeepSeek 对外的表述一直很稳定：优先做前沿架构创新和 AGI 探索，商业化是研究的副产品。V3 技术报告公开了 MLA、MoE、FP8 训练细节，R1 论文完整给出 GRPO 强化学习方法，模型采用 MIT 协议可自由商用——这种透明度在商业公司里极其罕见。
- 开源是一步大棋：技术影响力 → 开发者生态位 → 隐性定价权和人才吸引力。低价 API 与其说是补贴大战，不如说是生态卡位。
- 反过来推：任何会压缩研究自主权、打乱论文与模型发布节奏的资本安排，都会和这个目标直接冲突。"一个目标"压舱，正是 IPO 迟迟不落地的根本原因。

## 假如真上市：市场会发生什么

- 通道是现成的：科创板第五套标准本就允许未盈利硬科技公司挂牌，港股 18C 规则也为特专科技公司开了门，制度层面没有障碍。
- 估值才是难题：按传统市销率，DeepSeek 收入体量小、API 定价又激进，报表撑不起传闻里的天文数字。市场更可能按"算力资产 + 人才密度 + 开源生态位"给出一套科研资产型定价——这在 A 股没有先例，波动可以想见。
- 还有资金虹吸效应：真正的大模型底座标的在二级市场是稀缺物种，一旦挂牌，一级市场的小模型和应用公司会明显感到抽水。

## 冷思考：给三类人的三条建议

1. **开发者**：技术选型别押注资本动作。盯两件小事——API 价格是否稳定、开源许可证是否延续，它们比上市传闻更能预示服务的连续性。
2. **投资人**：分清两种叙事。"融资需求"看 capex 缺口和推理成本曲线，"退出需求"看早期股东结构；传闻热度不等于上市概率。
3. **围观者**：最值得跟踪的信号在技术节奏里——论文质量、开源仓库的 commit 频率、模型发布间隔。一家公司的未来写在它的 git log 里，不在敲钟现场。

IPO 与否，只是 DeepSeek 回应"两个现实"的一种可能方式；它真正在优化的目标函数，从来不写在招股书里。
