最近，保险行业的财报里出现了一个新科目：Token。有险企首次披露了全年消耗的大模型 token 量，用它证明 AI 真正“跑”进了业务流程。这件事的意义超出保险业本身，当 AI 从 PPT 走进损益表，一个所有行业都躲不开的问题浮出水面：投入看得见摸得着（算力、token、人力），回报到底怎么算？这篇拆一拆 Token 这个指标的信息量，顺便聊聊给 AI 算账的正确姿势。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-12/4ae22e1d1b95be44.png)

## 先补课：Token 凭什么能进财报

- **Token 是大模型处理文本的最小单位**。一段话会先被切分成 token 再喂给模型：英文约 1 个单词对应 1.3 个 token，中文约 1 个汉字对应 0.6~1 个 token，不同分词器有差异。
- **大模型按 token 计费**，逻辑和电表水表一样：打电话按分钟、云主机按小时、大模型按 token。主流模型定价从每百万 token 几毛钱到几十美元不等，价差可达百倍。
- **它天然可审计**。API 账单精确到每一个 token，有供应商发票和内部计量日志，财务和审计都能追溯。相比之下，“AI 能力提升 30%”这种话在财务上无法入账。

一句话总结：Token 之于 AI 时代，就像千瓦时之于电气时代——它是给“智能”装上的一块电表。电表能进财报，说明用电量已经大到值得单独披露了。

## 为什么是险企先跑出来

保险恰好是大模型落地条件最好的行业之一，原因有三：

1. **单证密集**。一张车险理赔案卷里有现场照片、维修清单、定损单；一笔健康险理赔关联病历、发票、检查报告。这些非结构化材料靠传统 OCR 加规则引擎，长尾场景永远处理不完，多模态大模型正好补上这块短板。
2. **流程高度标准化**。核保、理赔、客服都有明确的服务时效（SLA），AI 介入前后的指标变化容易被量化。
3. **人力成本占比高**。客服坐席、理赔审核、录单录入都是可被替代的重人力环节，替代收益算得清。

一条典型链路：客户上传理赔材料 → 多模态模型识别与信息抽取 → 规则引擎自动初筛 → 简单案件秒级通过，复杂案件转人工。Token 消耗在识别和初筛环节，一单审核消耗几十万 token 很正常；对照人工审核每单几十到几百元的成本，账是可以拉平着算的。Token 量由此成了 AI 渗透率的代理变量。



## 关键认知：Token 是投入指标，不是回报指标

这是全文最想强调的一点。

- **Token 增长只说明“用得多”，不说明“用得值”**。如果员工拿大模型写周报、生成没人看的 PPT，token 消耗一样暴涨，商业价值约等于零。这类数字叫 vanity metric（虚荣指标）——看着热闹，不产生现金流。
- **财务口径上，Token 属于成本端科目**，回报在收益端。把投入当成绩披露，好比餐厅汇报煤气用量翻倍，先别鼓掌，得看这些煤气换来了多少营业额。
- **还有一个反直觉的坑：杰文斯悖论**。经济学家十九世纪就观察到，蒸汽机效率提高后，煤的消耗不降反升，因为用煤的场景爆炸式扩张了。大模型同理：推理成本每降一个数量级，使用场景可能扩张两个数量级。所以未来几年 token 消耗大幅上涨几乎是确定的，它本身不构成利好或利空。

因此，看到“token 消耗同比增长 500%”这类表述，第一反应不该是“AI 战略成功”，而应该追问一句：这些 token 换来了什么？

## 给 AI 算回报，要建三本账

**第一本：成本替换账。** AI 承接的工作量 × 单位人工成本。例如智能客服承接 70% 的会话量，人工单次会话成本 8 元，年千万级会话量的公司，这本账能算出千万级的节省。但要打两个折扣：AI 接不住的复杂 case 会回流人工；质检、兜底人力和系统建设费也要摊进来。

**第二本：效率账。** 理赔时效从 3 天压到 4 小时，不直接省钱，但会传导到体验，NPS 提升、续保率提升，再按客户生命周期价值（LTV）折算成收入。这本账最容易被忽略，因为它隔了一层。

**第三本：收入与风险账。** 智能推荐带来的件均保费与加保率变化；反欺诈模型压降的赔付率。这是险企最硬的回报，大型险企赔付支出以百亿计，欺诈识别精度每提升一个百分点，可能就是数亿量级的真金白银。

可操作的合并口径是**算单均**：每张保单的 AI 使用成本 2 毛钱，替代加增效折算出 2 块钱收益，投入产出比 1:10，这才叫回报。只披露分子不披露分母，或者反过来，账都不完整。

## 看财报里的 AI，别只盯 Token 数

给普通读者的四个判断抓手：

1. **看口径完整性**：披露 token 量的公司，有没有同时披露对应业务指标，处理件数、时效变化、成本节约额？只有投入没有产出口径的，保持警惕。
2. **看单均成本趋势**：健康的曲线是业务量上升、单均 token 成本下降（模型优化加场景规模化摊薄）。量涨价跌，才是规模化落地的样子。
3. **看投入产出对不对得上**：AI 投入占营收的比例，要能和对应业务线的成本率、时效指标变化互相印证，对不上的多半是叙事先行。
4. **警惕两种话术**：把 token 增长直接当成绩的；把 AI 投入全部包装成“长期主义”、回避当期回报测算的。

## 三条冷思考

1. **电表装上了，不等于电都用在了刀刃上**。Token 进财报是透明化的第一步，下一步值得期待的是行业形成 AI 回报的通用披露口径，就像互联网公司披露 DAU：DAU 也不是收入，但它是收入的前置指标，且市场有共识。
2. **对企业：先定业务指标，再定 token 预算**。正确顺序是“理赔时效要压到多少 → 需要多少次模型调用 → 折算多少成本”，而不是拿着预算找场景。
3. **对个人：别把用量当能力**。调用大模型的次数不是生产力，用完之后单位时间产出提升了多少才是。Token 计量这门功课，同样适用于给自己记账。
