过去两年，调用大模型 API 的价格像坐上了滑梯。36kr 近期报道指出，智谱和 MiniMax 相继进入“低价增长”阶段：单位 token 价格持续下探，调用量与收入却同步上涨。这乍看违反常识——降价怎么还能增长？这篇就拆一拆“低价增长”背后的技术底座、商业账本，以及它没说出口的隐忧。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-12/f18639b30a554126.png)

## 一、“低价增长”到底是门什么生意

先给定义：**单价下降，用量暴涨，总收入反而上升**。这不是降价清仓，而是一套“以价换量”的规模生意。

几个标志性节点：

- 2024 年 5 月，字节豆包把主力模型价格打到每百万 tokens 0.8 元，宣称比行业均价低 99%；阿里通义千问随即宣布降价 97%，价格战正式开打。
- 智谱把轻量级 GLM 系列做成低价档甚至免费档，用入门场景给旗舰模型引流；MiniMax 则在长文本、高并发场景持续压低单价，走“薄利多销”路线。
- 更早的参照系是 AWS：云计算价格十年间下调上百次，收入却不降反升——单位算力便宜了，用的人多出一个数量级。

本质变化是：模型公司从“卖稀缺算力”转向“卖规模化 token 流量”。**价格是获客工具，用量才是收入引擎。**

## 二、价格为什么降得下来：推理成本的技术底座

降价不是慈善，是真降得起。支撑价格下探的，主要是四项技术：

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-12/d2b4dbb2b50599ee.png)

1. **MoE 架构（混合专家）**：模型总参数很大，但每个 token 只激活一小部分“专家”。DeepSeek-V3 总参数 671B，推理时仅激活约 37B，算力开销断崖式下降；智谱、MiniMax 的旗舰模型也普遍走 MoE 路线。
2. **注意力机制优化**：MiniMax-01 引入线性注意力（lightning attention），处理超长上下文时计算成本增长更平缓，长文本推理不再“烧钱如流水”。
3. **量化与蒸馏**：FP8 等低精度量化直接砍显存、砍算力；用大模型蒸馏出的小模型，以十分之一的价格覆盖八成的简单任务。
4. **推理工程与供应链**：continuous batching、KV Cache 复用、算子融合，把同一张 GPU“榨”出更多 token；再叠加算力租赁市场成熟，单位算力本身也在降价。

一句话总结：**每 token 的边际成本以季度为单位往下走**，厂商才敢把报价同步打下来。

## 三、以价换量的账：Jevons 悖论在 AI 圈重演

经济学里有个经典现象叫 **Jevons 悖论**：19 世纪蒸汽机效率提升后，煤的消耗不降反升——便宜的动力催生了无数新场景。大模型正在重演这一幕。

- **价格降一个数量级，原本“用不起”的场景被激活。** 算笔账：客服机器人每天处理 10 万轮对话、每轮 2000 tokens，单价 20 元/百万 tokens 时每天成本 4000 元；降到 2 元时每天只要 400 元。一年 146 万的预算变成 14.6 万，大量中小企业瞬间“用得起”。
- **Agent 是 token 消耗的放大器。** 一个智能体完成一次任务，可能循环调用模型几十上百次；单价降 90%，单任务 token 用量涨 10 倍以上，总账反而更肥。
- **毛利率在换空间。** 行业估算显示，头部模型 API 业务毛利率已从早期的 50% 以上回落到 20%~40% 区间，靠量补齐后，总收入曲线依然向上。

低价还有一层战略意义：**抢占开发者心智**。API 的迁移成本不高，但一旦 SDK、工具链、Prompt 资产都围绕某家模型搭建，绑定就悄悄完成了。免费和超低价，本质是生态入口的门票。

## 四、低价不是万能药：三条隐忧

账本好看，硬币也有反面：

1. **烧钱换增长的前提是弹药充足。** 训练一轮前沿模型动辄数亿美元起，低价拉来的收入若覆盖不了研发投入，增长曲线随时可能被融资节奏打断。
2. **降价人人会做，差异化难做。** 当各家报价趋同，竞争会重新回到效果、稳定性、上下文长度、工具链体验这些“慢变量”上——而这些恰恰急不来。
3. **护城河偏薄。** API 天然可替换，成熟开发者普遍采用多云、多模型策略，随时“货比三家”。云计算价格战打了十年，最后活下来的靠的是规模、生态和企业服务能力，而不只是低价。

## 五、给开发者的三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-12/b9acb918ad8ca82e.png)

1. **算总账，不算单价。** 选模型看“单价 × 调用次数 × 上下文长度”：相同前缀用缓存能省一大截，非实时任务走 Batch 接口通常再打对折；简单任务交给小模型分流，旗舰模型留给硬骨头。
2. **别把业务绑死在单一模型上。** 工程上抽象一层统一的模型适配层，保留随时切换的能力；同时关注各家更新节奏、限流策略与 SLA——把“可迁移性”当成架构原则，而不是事后补救。
3. **判断一家模型公司健不健康，盯三个数：** token 消耗增速、推理毛利率、付费企业客户数。低价只是手段，可持续的单位经济（unit economics）才是终局。

价格战不是终局，而是把 AI 从“奢侈品”打成“水电煤”的必经阶段。对开发者，这是好时代——token 便宜到可以随手试错；对模型公司，这是最卷的时代——便宜只是入场券，活下来靠的是把每一度“电”发得更便宜、卖得更多。滑梯还在往下滑，但真正的比赛，才刚刚开始。
