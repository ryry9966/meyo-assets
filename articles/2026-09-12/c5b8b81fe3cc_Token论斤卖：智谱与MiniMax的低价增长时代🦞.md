如果把大模型 API 报价单按时间轴排开，你会看到一条比显卡价格跌得还丝滑的下行曲线。36 氪近期把智谱、MiniMax 两家头部大模型公司的现状概括成「低价增长」四个字：API 单价一降再降，靠 token 消耗量的暴涨把营收曲线顶上去。这不是一次简单的促销，而是一整套关于成本、竞争和商业模式的重新洗牌。这篇文章拆一拆：低价从哪来，钱从哪赚、往哪亏，开发者和企业又该怎么接招。

## 一、“低价增长”：一个似曾相识的剧本

所谓低价增长，不是打折清库存，而是把 API 单价压到极低，用调用量（token 消耗）的指数级增长把总收入顶上去——行话叫「以量补价」。这轮价格战在 2024 年就打响了第一枪：

- 2024 年 5 月，字节跳动豆包主力模型定价低至 0.0008 元/千 tokens（约 0.8 元/百万 tokens），宣称比行业均价低 99%；
- 同月，阿里将通义千问长文本模型 Qwen-Long 输入价下调 97%，降至 0.5 元/百万 tokens；
- 2024 年 8 月，智谱直接把轻量模型 GLM-4-Flash 的 API 免费开放；
- DeepSeek 的 V3/R1 长期把输出价钉在个位数人民币/百万 tokens 量级，把全市场的价格锚砸穿。

剧本似曾相识：云计算早年「降价换上量」、网约车和外卖的补贴大战，都是同一个母题。区别在于，这次不需要地推和骑手，竞争的全部筹码是显卡、电费和算法效率。

## 二、降价的底气：推理成本一年掉一个数量级

敢把价格打到地板上，前提是成本曲线确实在陡降。拆开看有四个来源：

1. **MoE 稀疏激活**：GLM-4.5 总参数 355B，但每个 token 只激活约 32B；DeepSeek-V3 是 671B 总参数、激活 37B。算力和耗电按「有效参数」走，单位 token 的开销成倍下降。
2. **推理工程优化**：FP8 低精度推理、KV cache 复用、连续批处理、投机解码层层叠加。现在各家 API 的「缓存命中价」普遍只有未命中价的 1/5 到 1/4，等于给高频用户又砍了一刀。
3. **训练成本塌缩**：MiniMax-M1 公开过训练账单——512 块 H800 跑约三周，成本约 53 万美元，完成百万 token 上下文的强化学习训练，权重还以 Apache 2.0 开源。
4. **开源冲击**：权重公开意味着「模型本身」不再稀缺，稀缺的是部署质量、延迟和生态。定价逻辑从「我多强」变成「别人多便宜」，不跟就是让出份额。

所以降价一半是主动战略（抢生态），一半是被成本曲线推着走（不降就出局）。

## 三、两条路线：智谱的 B 端纵深 vs MiniMax 的 C 端流量

同样做低价，两家公司的账本结构并不一样：

- **智谱：B 端纵深**。清华 KEG 系出身，收入大头长期来自企业侧——MaaS 平台、私有化部署、行业解决方案。打法是「开源 + 低价 API 圈开发者，私有化交付收钱」：GLM 系列开源把模型铺进各种技术栈，低价 API 培养调用习惯，重交付项目贡献现金流。据公开报道，其已启动上市辅导流程，一条稳定上扬的收入曲线对资本市场相当重要。
- **MiniMax：C 端流量**。靠 Talkie、星野、海螺 AI 这类应用起家，订阅收入是基本盘，API 是第二曲线。MiniMax-M1 把输入价打到约 0.4 美元/百万 tokens、输出 2.1 美元，主攻长上下文的 agent 与编程场景——这恰好是 token 消耗量最大的赛道，低价的杠杆最大。

共同点：两家都不指望 API 毛利养家，真正的算盘是生态位——开发者的肌肉记忆、应用飞轮和数据回流。API 价格是入场券，不是利润中心。



## 四、低价的账本：毛利率被谁吃掉了

一笔 API 收入的成本 ≈ 算力折旧或租赁 + 带宽 + 研发与运维人力。当价格战打到缓存命中几分钱一百万 token 时，毛利大概率只剩个位数百分比，部分档位甚至是补贴倒挂——卖得越多，亏得越均匀。

烧钱三件套很固定：卡（高端 GPU 采购与租赁）、人（顶尖研究员的薪酬）、补贴（免费额度与赠送 tokens）。而低价模式还有三个隐忧：

1. **忠诚度低**：换模型对开发者只是改几行代码，用户忠诚度约等于一条 import 语句，价格一涨就可能流失；
2. **价格锚定**：用户一旦习惯「几分钱一百万 token」，后续任何涨价都是商业事故；
3. **开源持续压制**：只要社区不断放出新的开源权重，闭源 API 的溢价天花板就被按死。

云厂商打价格战还有算力转售和生态绑定做对冲，纯模型公司手里的对冲工具少得多——这也是「低价增长」听起来风光、做起来煎熬的原因。

## 五、三条冷思考：开发者和企业怎么接招

1. **别只看标价，看有效成本**。缓存命中率、输出长度、失败重试、任务适配度都进总账。一个 agent 跑一天，输出 token 和重试往往才是大头，输入价便宜 30% 在总成本里常常只是噪音。
2. **把可迁移性做成架构能力**。用统一的模型网关抽象掉供应商差异，保持随时可切换。你不一定能选中最终赢家，但议价权会一直留在你手里。
3. **读懂“免费”的会计含义**。免费额度是获客成本，不是慈善：看清限流策略、数据使用条款与 SLA，核心业务别裸奔在补贴上；补贴退坡那天的迁移成本，要从第一天就算进选型。

收尾说一句：低价增长不是终局，而是中场。它一边挤掉「模型即印钞机」的泡沫，一边逼所有玩家回到真正的护城河——单位推理成本曲线、场景与数据闭环、正向的经营现金流。价格战从来没有赢家通吃，只有成本效率和生态厚度的长期竞赛。对见证过云计算、移动互联两轮价格战的人来说，这一幕并不新鲜；新鲜的只是，这次的筹码换成了 token，而筹码本身还在以肉眼可见的速度贬值。
