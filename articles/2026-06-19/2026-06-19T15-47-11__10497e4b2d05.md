前阵子刷到一条热搜：「从不限量到自费上班，互联网公司们付不起 Token 账单了」。配图里一堆产品经理愁眉苦脸，评论区一片「早就该收费了」「白嫖结束」。

这事儿乍看是个商业新闻，但背后其实藏着一套很硬核的工程经济学：大模型推理到底贵在哪？为什么去年还能「无限对话」的产品，今年纷纷开始限次、限速、限模型？这篇咱们不喊口号，把账本摊开聊聊。

## 一、Token 到底是什么，为什么按它收费

先把最基础的概念捋清楚。很多人以为「Token 就是字」，其实并不准确。

- **Token 是子词单元（subword）**：大模型用 BPE / SentencePiece 这类分词算法，把文本切成介于「字符」和「单词」之间的片段。比如 `unbelievable` 可能被切成 `un` + `believ` + `able`。
- **中文一般 1 个汉字 ≈ 1.5~2 个 Token**：因为常见汉字会被合并，但生僻字、emoji、代码符号会被拆得更碎。
- **图片、音频也算 Token**：多模态模型把一张 1024×1024 的图，编码成几百到上千个视觉 Token，所以「发张图问问」其实比你想象的贵。

按 Token 计费的本质，是因为大模型的算力消耗几乎和 Token 数线性相关——你给它的上下文越长、它生成的回答越长，GPU 就要算更多次矩阵乘法。这跟传统 SaaS 按席位收费完全不是一个物种。

## 二、一笔 Token 账单到底是怎么算出来的

咱们做个粗略的拆解。假设一个产品给用户提供「免费聊天」，平均每次对话：

1. **输入上下文**：3000 Token（系统提示词 + 历史对话 + 用户问题）
2. **输出回答**：800 Token
3. **每天活跃用户**：50 万
4. **人均对话轮次**：6 轮

按当前主流闭源大模型的 API 报价（输入约 $2 / 百万 Token，输出约 $8 / 百万 Token）算：

- 单轮成本 ≈ 3000 × 2/1e6 + 800 × 8/1e6 ≈ **$0.0124**
- 日成本 ≈ 0.0124 × 6 × 500000 ≈ **$37,200**
- 月成本 ≈ **$110 万** ≈ 800 万人民币

这还只是「文字聊天」。一旦接入：

- **联网搜索**：每次塞进去 5~10 篇网页内容，输入 Token 直接翻 3~5 倍
- **长文档解析**：一份 PDF 论文塞进上下文就是几万 Token
- **Agent 多步推理**：一次任务调用 10 次模型很正常，成本再 ×10
- **推理模型 (o1/R1 类)**：思考链本身就要烧几千上万个 Token，单次调用比普通模型贵 5~20 倍

所以你能看到，去年还在喊「不限量」的产品，今年要么默默把默认模型换成更便宜的小尺寸版本，要么把「深度思考」「联网搜索」做成会员专属。不是产品经理变坏了，是真的扛不住。

## 三、为什么「降价」赶不上「用得多」

有读者会问：模型 API 不是一直在降价吗？过去一年头部模型的单价确实跌了 80% 以上。但**总账单反而涨了**，原因有三：

- **杰文斯悖论（Jevons Paradox）**：19 世纪英国发现煤炭利用率提高后，煤炭总消耗反而增加——因为便宜了，大家用得更狠。Token 也一样，每便宜一档，开发者就敢做更复杂的应用。
- **上下文窗口军备竞赛**：从 4K 到 8K 到 128K 再到 1M，窗口越大，单次请求塞的东西越多。一个用 200K 上下文的客服 bot，比 4K 时代贵了 50 倍不止。
- **Agent 化趋势**：单次问答变成多轮规划+工具调用+反思。一个「帮我订机票」的任务背后可能是 30 次模型调用。

更扎心的是，C 端用户的「价格感知」是反过来的：他们觉得 ChatGPT 月费 20 美元已经够贵，但这点钱对应的 Token 配额，重度用户三天就能烧完。OpenAI 自己 CEO 也公开说过 Pro 套餐在亏钱。

## 四、厂商正在用哪些「省钱大法」

面对账单压力，工程团队这一年探索出了一整套降本组合拳，简单盘一下：

1. **模型路由（Model Routing）**：简单问题派给小模型，复杂问题才上旗舰。一个分类器+几行代码，能省 40~60% 成本。
2. **提示词压缩**：用 LLMLingua 这类工具把冗长的 system prompt 压一压，输入 Token 直接砍半。
3. **KV Cache 复用**：相同前缀的请求共享缓存，多用户场景下吞吐能翻倍。各大推理框架（vLLM、SGLang）都在卷这个。
4. **投机解码（Speculative Decoding）**：用小模型先草拟，大模型只做校验，生成速度提升 2~3 倍。
5. **蒸馏 + 自研小模型**：把闭源大模型的能力蒸馏到 7B/14B 的开源底座上，在自己卡上跑，单 Token 成本能降一两个数量级。
6. **分级会员**：免费版给小模型限次数，付费版解锁大模型——这就是你看到的「自费上班」的产品形态。

## 五、对开发者和用户分别意味着什么

这场账单危机不只是大厂的事，对每个相关方都有影响：

- **对应用开发者**：以前可以「先免费冲用户再说」，现在每个 DAU 都对应真金白银的边际成本。商业模式必须从第一天就想清楚，不然规模越大死得越快。
- **对企业客户**：买 API 时别只看单价，要看「每完成一个业务任务的总成本」。一个便宜模型如果要调 10 次才完成任务，未必比贵的模型划算。
- **对普通用户**：「免费午餐」会越来越少，但这不一定是坏事——付费模式反而能让产品有动力做长期优化，而不是用劣质小模型糊弄人。

## 六、三条冷思考

最后留三条务实的观察，给在这个行业里摸爬滚打的朋友：

1. **算力是新石油，但石油也是要算桶卖的**。任何「不限量」的 AI 服务都不可持续，看到这种宣传，先想想它的退出机制是什么。
2. **判断一个 AI 产品是否健康，看它的 Token 经济模型，比看 DAU 更重要**。能算清楚单位经济（unit economics）的团队，才有可能活到下一轮。
3. **本地小模型 + 云端大模型的混合架构会成为主流**。不是因为开源比闭源好，而是因为「该省省该花花」永远是工程的第一性原理。

说到底，「Token 账单付不起」不是 AI 退潮的信号，恰恰是行业从「魔法演示」走向「正经生意」的必经之路。当所有人都开始算账，这门生意才真正开始。
