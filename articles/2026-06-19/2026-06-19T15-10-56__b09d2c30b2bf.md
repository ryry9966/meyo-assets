"title": "中国大模型的三条主线，到底在卷什么？🧠",
  "content": "最近微博上又把\"中国大模型技术三大主线\"这个话题顶了上来。一年前我们还在围观\"百模大战\"——发布会一场接一场，参数从千亿冲向万亿，榜单天天有人屠榜。但眨眼到了今天，行业的关键词悄悄变了：从\"卷参数\"变成\"卷效率\"，从\"通用对话\"变成\"多模态+Agent\"，从\"我也有大模型\"变成\"我能落到哪个具体场景\"。这篇就借着热搜，把当下国内大模型的三条主线 + 一条底层支撑线，掰开讲清楚，让你在看新闻、做选型、聊融资的时候不至于被术语带跑。\n\n\n\n## 一、基座模型：从\"卷参数\"到\"卷效率\"\n\n第一条主线，是最硬核也最烧钱的一条——通用基座大模型。这是过去两年中国玩家投入最多、变化也最大的赛道。\n\n- **2023 年的关键词是\"大\"**：参数从 7B、13B 一路堆到千亿、万亿，谁的模型更大、谁刷的 MMLU 分更高，就更容易拿到融资和注意力。\n- **2024 年的关键词变成了\"省\"**：DeepSeek V2/V3 用 MoE（Mixture of Experts，混合专家）+ MLA（Multi-head Latent Attention）这种架构创新，把每 token 激活参数压到几十亿，训练成本据其论文披露约 600 万美元量级，相比 GPT-4 这一代动辄几千万到上亿的训练账单，直接打开了\"小公司也能训前沿模型\"的想象空间。\n- **2025 年的关键词是\"会想\"**：受 OpenAI o1 的启发，国内 DeepSeek-R1、Qwen-QwQ、智谱 GLM-Zero 等纷纷走上了\"强化学习 + 长链思考（long CoT）\"路线，把模型从\"快答型\"训练成\"会停下来思考再答\"。这条路的好处是数学、代码、推理类任务（GPQA、AIME、SWE-Bench）成绩明显涨，坏处是推理成本翻几倍，token 消耗肉眼可见地烧钱。\n\n代表玩家这里就不一一列了：阿里 Qwen、深度求索 DeepSeek、字节豆包、智谱 GLM、月之暗面 Kimi、MiniMax、百川……差异化已经从\"谁更大\"变成\"谁的架构更聪明，谁的推理更便宜\"。\n\n\n\n## 二、多模态：让大模型长出眼睛和耳朵\n\n第二条主线，是从纯文本走向\"看得懂图、听得懂声、生成得了视频\"的多模态。这条线在 2024 下半年开始集体加速。\n\n- **视觉理解（VLM）**：Qwen-VL、InternVL、MiniCPM-V 这一批模型，已经能做到截图问答、文档理解、UI 识别，甚至读 PDF 里的表格。技术底子是 ViT 视觉编码器 + 跨模态对齐 + 大语言模型解码，听起来朴素，工程坑不少。\n- **视频生成**：可灵（Kling）、Vidu、混元视频、Wan 等模型把 DiT（Diffusion Transformer）架构 + Flow Matching 推到了商业化门槛，5~10 秒高清视频生成已经能用于广告、短视频、电商素材。对比 Sora 的封闭策略，国内这一波明显更快地推到了 C 端可用。\n- **端到端语音**：传统语音助手是 ASR → LLM → TTS 三段拼接，延迟高、情感丢失。新一代像豆包、MiniMax 的语音模型走端到端架构，让\"打断、笑声、叹气\"这种副语言信息也能保留，体验上更接近真人通话。\n- **统一多模态**：还有一条更激进的路，是把图像生成、视频生成、文本生成统一到同一个 transformer 里训，目标是让模型像人一样\"用同一个大脑处理所有感官\"。这条路目前还在早期，但趋势很清楚。\n\n一句话总结：文本只是入口，**多模态才是大模型真正的产品形态**。\n\n\n\n## 三、Agent 与垂直应用：模型不再是终点\n\n第三条主线，也是最贴近商业化的那条——Agent 与垂直行业落地。如果说前两条是在卷\"模型本身\"，这条就是在卷\"模型怎么被用起来\"。\n\nAgent 简单理解就是这个公式：\n\n> Agent = 大模型（脑子）+ 工具调用（手）+ 记忆（笔记本）+ 规划（计划表）\n\n关键能力包括：\n\n1. **function calling / tool use**：模型能主动选工具、传参数、读结果。\n2. **代码解释器**：把模糊指令翻译成可执行代码，做数据分析、文件处理。\n3. **浏览器/电脑操作**：像人一样点网页、填表单，国内有 Manus、智谱 AutoGLM 等代表。\n4. **长任务规划**：把\"帮我订一个三天两夜的周边游\"拆解成几十步串起来执行，中途还能自我纠错。\n\n垂直行业方向上，节奏也很清晰：\n\n- **金融**：研报摘要、合规审查、智能投研，对幻觉容忍度极低，普遍走 RAG（检索增强）+ 小模型微调 + 人工复核的稳健路线。\n- **医疗**：辅助问诊、影像识别、病历结构化，监管严格，更多是\"医生副驾\"而非替代。\n- **法律**：合同审查、案例检索，是 LLM 最快产生 ROI 的领域之一。\n- **教育/办公/电商**：受众最大，迭代最快，也是 C 端 Agent 最先跑通的几个场景。\n\n还有一条容易被忽视的支线——**端侧 Agent**：手机厂商（vivo 蓝心、OPPO、荣耀 MagicOS）和 PC 厂商都在把 3B~7B 级别的小模型塞进设备，让本地能跑\"读屏 + 操作\"的轻量 Agent。这条路的瓶颈不是模型，而是内存带宽和功耗。\n\n\n\n##
