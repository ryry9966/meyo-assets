这两年 AI 圈最没悬念的剧情，是 OpenAI 一家独大；最近最有意思的剧情，是这格局正在被悄悄改写。据 36kr 报道，一批美国科技公司——以中小企业和创业公司为主——正在把线上服务的模型 API 从 OpenAI 偷偷换成中国开源大模型，出现频率最高的两个名字是 DeepSeek 和阿里通义 Qwen。理由非常朴素：同样的任务，成本直接降了约 90%。



## 便宜90%，这笔账到底怎么算的

先从最直观的 API 定价看。按官方公开的 token 单价对比：

- OpenAI GPT-4o 级别模型：输入约 2.5 美元/百万 tokens，输出约 10 美元/百万 tokens
- DeepSeek-V3：输入约 0.27 美元/百万 tokens（缓存未命中），输出约 1.1 美元/百万 tokens
- 如果命中缓存，输入单价还能再降到 0.07 美元/百万 tokens

把输入输出混在一起算，单次调用成本大约是后者的 1/9 到 1/10，正好对得上"便宜90%"这个说法。

再算一笔具体账：假设一个客服机器人每月处理 10 亿 tokens，输入输出按 3:1 分配。

- 用 GPT-4o：750M × 2.5 美元 + 250M × 10 美元 = 4375 美元/月
- 用 DeepSeek API：750M × 0.27 美元 + 250M × 1.1 美元 = 477 美元/月

一个月省下近 3900 美元，一年就是 4.7 万美元，对创业公司来说够再养一个工程师了。

但 API 降价只是表面。更关键的是这批模型都开放了权重（open weights），美国公司不一定要走中国厂商的 API，而是把模型下载下来，部署在自己的 AWS 或 GCP 账号里：

- 自部署后成本主要变成 GPU 机时费，请求量越大，平摊成本越低
- 可以自己做 int8/int4 量化，显存占用再压一半以上
- 可以定制 prompt 缓存策略，减少重复计算

所以这里说的"90%"，不是一个营销数字，而是 API 价差 + 自部署 + 量化压缩三个因素叠出来的工程结果。这个现象也不是一夜发生的：2024 年底 DeepSeek-V3 发布、2025 年初 R1 开源，加上阿里 Qwen 系列持续迭代，让"接近一线闭源模型的能力 + 可自行部署的权重 + 白菜价 API"这个组合第一次同时成立。



## 技术底座：中国模型凭什么把成本打下来

开源只是结果，真正支撑低成本的是几个关键的架构和工程决策。以 DeepSeek-V3 为例：

- **MoE（混合专家架构）**：总参数量 671B，但处理每个 token 只激活约 37B 参数。可以理解成公司雇了 671 个专家，但每次只叫醒 37 个人干活，电费自然省下来
- **MLA（多头潜在注意力）**：大幅压缩 KV cache，推理时显存占用更低，单位时间内单张 GPU 能服务的请求数就更多
- **FP8 混合精度训练**：训练成本下降，摊销到 API 价格上的压力更小
- **开源即生态**：R1 的推理能力被蒸馏成 1.5B~70B 的一堆小模型，小模型能跑在单张显卡上，部署门槛再降一档

阿里 Qwen 走的是另一条路：模型尺寸从 0.5B 覆盖到 70B 以上，并和 vLLM、SGLang 等主流推理框架做了深度适配。开发者不需要改太多代码，就能把旧的私有模型替换成 Qwen——这正是"偷偷换上"能够发生的工程前提。

## 平替不是万能：性能、合规与工具链的边界

换模型不是无脑省钱，目前有几个现实约束：

- **性能差距真实存在**：在代码生成、数学推理这类"可客观评分"的任务上，头部开源模型已经和闭源旗舰打平；但在长尾的复杂 agent 任务和长对话指令跟随上，仍有肉眼可见的差距
- **数据出境问题绕不开**：如果直接调用中国厂商的 API，数据出境是个合规痛点；所以多数美国公司选择自部署 open weights，而不是直连 API
- **工具链成熟度不同**：OpenAI 的 Function Calling、Assistants API、调试和可观测性生态相对成熟；换成开源模型后，评测、监控、回退链路都要自己搭
- **供应商绑定是双向的**：今天 DeepSeek 便宜，明天可能调价；合理姿势是把模型层抽象成可替换层，而不是和某一家深度绑定

## 三条冷思考与实用建议



1. **先跑通评测集，再谈省钱**：拿线上 10% 的真实流量做分流 AB，跑一周，盯准确率、延迟、用户反馈这些核心指标，而不是只看 token 账单
2. **按任务拆路（task routing）**：简单任务如分类、摘要、代码补全走便宜模型，复杂推理走旗舰模型。多数团队这么做能省下 50%~80% 的成本，还不会牺牲关键体验
3. **把 fallback 和监控做在前面**：LLM 迭代极快，今天的低价模型三个月后可能就被新模型超越。设计好统一接口层，保留随时切换的能力，才是真正省钱的姿势

这场"偷偷换模型"的浪潮，本质上是一次成本结构的重新定价。技术平权的故事没有终点，但能吃到红利的人，往往是先把评测、路由和回退机制做扎实的那批。希望这份拆解能帮你少走几步弯路。
