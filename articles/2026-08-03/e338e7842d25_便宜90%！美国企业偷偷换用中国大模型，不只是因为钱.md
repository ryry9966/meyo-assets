最近 36kr 报道了一件事：一批美国企业，正在把 API 调用从 OpenAI 换到中国大模型上，理由是“便宜 90%”。这听起来像一条纯商业新闻，但背后其实是一个关于成本结构、技术代差和全球 AI 供应链重新洗牌的故事。为什么美国企业愿意换？换过去之后到底损失了什么、得到了什么？这篇文章我想从商业逻辑和技术细节两个层面把它拆开。



## 一、90% 的成本差距是怎么来的

首先要明确：美国企业换用的不是开源模型本地部署，而是通过 API 调用中国厂商的云端模型。比如 DeepSeek、通义千问、豆包等，它们在海外也有服务节点。同样一个任务，调用 GPT-4o 的价格和调用 DeepSeek-V3 的价格差了将近一个数量级。

这个价差来自三个层面：

- **推理成本优化**：中国团队在 MoE（Mixture of Experts）架构上做得更激进。MoE 意味着每次推理只激活模型的一部分参数，而不是全部。DeepSeek-V3 总参数 671B，但每个 token 只激活 37B，算力消耗大幅下降。
- **工程优化**：比如 FP8 混合精度训练、KV Cache 量化、动态批处理等技巧，中国厂商用得更熟练。同样跑在 H800 上，吞吐量可以比一些美国团队高出 30%–50%。
- **定价策略**：中国厂商正处于抢海外客户的阶段，愿意用低价换市场份额。OpenAI 要维持高利润率和算力投资，不可能把价格打到成本线附近。

这里有个反直觉的点：便宜并不等于弱。很多美国企业一开始以为换到中国模型会损失大量准确率，结果实际评测发现，在代码生成、结构化数据提取、文本分类这些常见场景里，差距远没有价格差距大。



## 二、美国企业在换什么：不是“最强模型”，而是“够用模型”

企业用大模型，目标不是跑分，而是降低成本、提高效率。一个 SaaS 公司可能每天要处理上百万次调用，哪怕单次便宜 0.001 美元，一年下来也是几十万美元的差距。

具体来说，换模型的主力是这几类公司：

- **做客服机器人的**：需要大量重复性对话，对延迟敏感，但不需要写诗或做复杂推理。
- **做数据处理/清洗的**：从非结构化文本里抽取字段，中国模型的中文和英文能力都够用。
- **做代码辅助的**：GitHub Copilot 太贵，一些中小团队开始用中国模型的 API 接进 IDE，完成重复性补全。
- **做 SEO 内容生成的**：对质量要求不高，核心是批量产出、低成本、能过基础检测。

这类场景有个共同特点：**任务边界清晰，不依赖“涌现能力”**。模型不需要突然想出什么新点子，只需要稳定、快速、便宜地完成已知任务。

OpenAI 的优势在于复杂推理、长上下文理解、多模态融合，但很多企业的实际工作根本用不到这些。就像买一辆跑车，结果每天都在市区堵车，最后发现一辆省油的混动车更合适。



## 三、换过去的风险：数据隐私、合规和供应链安全

当然，不是所有企业都能随便换。美国企业对数据安全非常敏感，尤其是涉及用户隐私、金融信息、医疗记录的场景。这里有几个关键风险：

- **数据出境**：调用中国云端的模型，意味着数据会发往中国境内的服务器或中国公司的海外节点，可能违反 GDPR、CCPA 等法规。
- **供应链安全**：中美关系一旦变化，中国厂商的 API 可能被制裁，或者特定企业的账号被限制，导致业务中断。
- **模型更新和稳定性**：一些中国模型的 API 还在快速迭代，接口不稳定，或者突然更新后行为变化，需要重新调 prompt。

但现实是，很多美国企业并没有把核心数据直接发送给模型。他们会：

- 在本地预处理，去掉敏感字段，只发送脱敏后的文本。
- 使用中国厂商在海外（如新加坡、美国）部署的节点，绕开部分合规问题。
- 用开源版本自部署，而不是走公用 API。这也是一条重要的变通路径。

所以严格来说，这批“偷偷换”的企业，换掉的不是全部技术栈，而只是某个不敏感的中间层。真正核心的 AI 能力，可能还是留在闭源或自建系统里。



## 四、这轮换用潮暴露了一个事实：大模型正在“商品化”

历史上，任何新技术成熟的过程，都是从“奢侈品”变成“日用品”。大模型也不例外。

- 2018 年 BERT 刚出来时，调用一次需要昂贵的 GPU 集群。
- 2022 年 ChatGPT 引爆市场，API 价格依然高企。
- 2024 年之后，开源模型和高效推理技术普及，单 token 成本断崖式下降。

现在，大模型的能力已经分化为两个方向：

1. **头部模型**：追求更强的智能，冲击 AGI，成本依然高，比如 OpenAI 的 o1 系列。
2. **量产模型**：追求“够用 + 便宜”，占领长尾场景，DeepSeek、Qwen、Llama 等是典型代表。

这次美国企业换用中国大模型，本质上就是在“量产层”重新选择了供应商。他们发现，对于一个批量调用场景，中国模型的性价比已经超过了美国闭源巨头。

这不代表中国 AI 已经全面超越美国，而是说明：**AI 竞争已经不再只看“最强模型”的跑分，还要看“单位性价比”和“工程落地能力”**。



## 五、三个冷思考：别被“便宜”冲昏头脑

### 1. 便宜是结果，不是原因

很多人看到“便宜 90%”，第一反应是中国技术碾压。但更准确的理解是：中国团队在降低推理成本上的工程投入，叠加了市场扩张期的折价战略。如果把模型能力看作一个多维度指标，中国模型在推理深度上还有差距，只是在多数商业场景中，这个差距不致命。

### 2. 数据安全永远不要外包

即使模型再便宜，也不要让它接触未脱敏的核心数据。聪明的企业会用“模型垫底 + 本地校验 + 敏感信息屏蔽”三层架构。便宜的是“模型”，不是“数据管理”。

### 3. 供应链多元化是长期策略

美国企业换中国模型，就像 1990 年代日本企业买美国芯片一样，核心逻辑不是“谁更爱国”，而是“谁更可靠”。建议国内开发者也不要把所有鸡蛋放在一个篮子里，同时准备好 OpenAI、国产开源、自部署的切换方案，保持迁移自由。

最后说一句：大模型的价格战还在继续，今天 90% 的价差，明年可能变成 50%，后年可能变成 10%。但“换模型”这个动作背后，反映的是企业在技术选型上变得更加务实。谁能在“能力-成本-合规-稳定性”的平衡木上走出最优解，谁才是真正的赢家。
