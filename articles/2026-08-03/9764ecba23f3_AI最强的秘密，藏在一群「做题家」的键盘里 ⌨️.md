当你在 GitHub 上看到有人上传了 300 道高中数学题，你可能觉得这只是某个老师的教学备份。但就是这个看似普通的行为，正在被多家顶级 AI 实验室视作珍宝——他们正大规模抓取这类由普通人自发整理的高质量问题集，用来训练下一代大模型。全球最强的 AI，确实在「抄」这群普通人的作业，只不过抄的不是答案，而是人类思维的结构化切片。



## 数据配方的「厨神」们：为什么是他们在定义智能边界

- **从 ImageNet 到 GSM8K，普通人一直是催化剂**
  - 2012 年引爆深度学习的 ImageNet 数据集，源自斯坦福教授李飞飞团队，但背后是数万名普通网友在 Amazon Mechanical Turk 上一张张标注图片。
  - 2021 年 OpenAI 发布 GSM8K，8,500 道小学数学应用题，作者是几十位按小时计费的合同工，他们不是数学家，只是按照模板写出「小明买苹果」的题干与分步解答。

- **高质量数据不再是副产品，而是核心生产力**
  - 大模型训练法则 Scaling Laws 表明，增加数据量带来的性能提升已超过单纯扩大参数。但互联网自然文本充满噪声、重复、偏见，清洗成本极高。
  - 相反，普通人刻意创作的内容——题库、代码注释、维修手册、乐评注解——天然具有「人话的精华」：逻辑链条清晰、领域边界明确、错误较少。这正是当前 Instruction Tuning 和 RLHF 阶段最渴求的「特供食材」。

- **一个例子看清价值差**
  - 根据 Epoch AI 估算，Common Crawl 原始网页数据的 token 成本可低至每 GB 几乎为零，但筛选出可用的 multistep reasoning 轨迹，成本飙升到每条数据 2 美元以上。
  - 而一个中学物理老师在论坛上写的 200 道自编题，等于直接赠送了 400 美元的数据价值，还附带天然的 reward signal（步骤对错明确）。



## 你以为抄的是答案，AI 拿走的却是「思考的草稿纸」

- **思维链（Chain-of-Thought）的本质是打工人的工作记录**
  - 2022 年谷歌论文证明，只要在提示里加上「Let’s think step by step」，模型推理能力立刻跃升。但这句话之所以有效，是因为模型已经在海量人类写下的分步推导文本上做了预训练。
  - 这些推导来自哪里？Stack Exchange 上的数学证明、知乎上的环环相扣的高赞回答、技术博客里带命令行的 debug 过程。写这些的人当时只是想把问题讲清楚，没想到成了训练 AI 思维链的黄金语料。

- **ReAct 与 Tool Use 的背后是技术客服的噩梦**
  - 让模型学会「先查文档、再调用 API、报错后重试」的循环决策，需要大量轨迹数据。这类数据最丰富的来源不是实验室，而是 GitHub Issues 里的讨论串、Stack Overflow 的提问-回复-补充-最终解决的长线程。
  - 每一个「楼主已解决，原来是要在配置文件里加这一行……」的帖子，都是一条完美的 agent 训练样本，标注了观察、行动、反馈的闭环。

- **人类偏好数据：你点下的每一个赞都在为 RLHF 投票**
  - RLHF (Reinforcement Learning from Human Feedback) 决定了大模型回答的「腔调」和安全性。训练这个奖励模型需要几十万条人类偏好对比——两个回答哪个更好。
  - 这些偏好标定员绝大多数是远程工作的普通人，时薪 15-30 美元，根据平台准则判断有用性、真实性、无害性。他们或许不懂 Transformer 架构，却直接塑造了 ChatGPT 的「情商」和「边界感」。



## 从「人工标注」到「合成数据」，普通人的阵地正在转移

- **人工数据产能瓶颈催生 AI 自我循环，但发现仍需人类点火**
  - 目前头部大模型如 Llama 3 的训练数据已超过 15T token，人工无法生产出同等规模的高质量文本。于是「合成数据」成为主流：用现有强模型生成训练语料，再用小模型或规则过滤。
  - 但合成数据的「种子」和「校验标准」仍高度依赖人类原创。例如，需要开发者先在 GitHub 开源一套新的单元测试框架，模型才能衍生出数千条变体；需要一位老电工在论坛发帖解释电路故障树，才能生成整套维修对话。

- **小众领域的「数字方志」：一人即护城河**
  - 威尔士语、皮埃蒙特语等低资源语言只有几千人使用，他们的日常论坛发言就是语言多样性的最后防线。
  - 特定工业领域（如船舶除锈工艺、古籍修复流程）根本没有教科书，唯一的知识载体是少数技术工人在私下维基或博客上留下的手记。这些文本若不被数字化和利用，将导致某个真实世界的知识断面彻底缺失，模型在对该领域推理时只能幻觉乱编。

- **普通人贡献的「数据开源运动」正在成形**
  - LAION 从网页抓取图片-文本对，构建了 Stable Diffusion 的训练基础，但后续的可用性筛选依赖全球志愿者的标签投票。
  - 开源数据集项目如 OpenAssistant、Dolly 直接邀请用户提交指令-回答对，明确将许可协议设为 CC-BY，试图建立不受单一公司控制的「数据公地」。这背后正是无数普通人的主动贡献：他们认知到自己的作业被「抄」不是损失，而是参与定义未来能力的一种方式。



## 一张试卷背后的商业暗战：为什么你的作业会被高价收购

- **从 Scale AI 到 Surge AI，数据经纪已成隐秘产业**
  - Scale AI 估值 138 亿美元，核心业务就是组织全球数万名「领域专家」——实际上多数是有本科学历的 freelancer——生产训练数据，覆盖数学、代码、化学、法律合同审查。
  - Surge AI 专门招募擅长创意写作的母语者，按小时支付高价，要求他们写出带有特定情感弧线的故事，用来训练模型的叙事连贯性。

- **数据价值排名正在重塑知识表达方式**
  - 知识不再只是「被记录」，而是被「可被训练」赋权。一段文本受 AI 青睐的程度，取决于它的结构化程度、因果密度、可验证性。这催生了奇怪的激励：在 Reddit 的 r/askmath 上，用 LaTeX 格式写出完整推导的人比单纯给答案的人更受关注，因为前者是更好的 training target。
  - 有些技术博主意识到自己的文章可能被用于微调模型，开始有意在文末加上 License 声明或技术性误导陷阱，试图掌握控制权。

- **法律灰色地带：你的贡献被拿走时，版权在谁手里？**
  - OpenAI 被《纽约时报》起诉的背后，是对类似 Reddit 帖子、知乎回答能否被用于训练的法律试探。目前多数互联网平台的 ToS 赋予自身宽泛的数据使用权限，但普通用户完全不知情。
  - 欧盟《人工智能法案》要求披露训练数据来源，可能迫使公司公开「抄的是谁的作业」，届时普通人将第一次看到自己的影子坐进全球最强 AI 的驾驶舱。

### 三条冷思考与实用建议

1. **对普通人：你发的每一条有结构的内容，都是一项未收费的数据资产**
   - 如果想保护自己的核心知识，可以在公开平台上采用「展示结果、隐藏思考过程」的策略，或将深度推导留在付费墙后。
   - 如果愿意贡献，尽量使用清晰的结构（标题、编号、代码块）、明确声明 CC 协议，这会提升数据被「正面利用」的概率，而不是被随意剪碎。

2. **对开发者/工程师：善用这波「数据杠杆」反哺自己的工作**
   - 在维护技术博客或 GitHub 项目时，刻意写下 troubleshooting 的完整步骤，不仅帮助人类读者，也有可能在未来某次模型升级后，让你自己的私有 AI 助手更懂你的代码库。
   - 对于内部流程文档，可以尝试将常见决策案例编成 Q&A 格式的对话，这是最直接的 fine-tuning 原料。

3. **对行业观察者：重新审视「数据飞轮」，它的圆心始终是人**
   - AI 军备竞赛的表象是算力和算法，底层却是持续获取新的人类原创思维样本。一旦源头停止流动——比如社交媒体封闭化、人类创作者全面转入私域——模型的认知进化将迅速停滞，剩下只是在旧世界模型里打转的「数据近亲繁殖」。
   - 关注那些正在建设数据开放协议、探索数据收益分配机制的小型项目，它们可能比模型本身更具长期影响力。
