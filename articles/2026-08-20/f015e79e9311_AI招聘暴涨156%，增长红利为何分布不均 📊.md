“AI岗位招聘暴涨156%”这数字最近频繁出现。它不是一个孤立的好消息，更像棱镜：一面是行业景气，另一面是结构性分化。年轻人、高学历、男性从业者拿走更多核心岗位溢价，而女性和低学历人群更多停留在外围环节。今天不喊口号，拆开数据看蛋糕怎么切，以及普通人如何找到自己那一块。



## 一、156% 增长里，岗位结构变了什么



- 增长主力不是只有“算法研究员”。应用层和工程化岗位增速更快：AI 应用开发、数据工程、模型部署、RAG 开发、Agent 编排、AI 产品经理、模型测试等。
- 一个直观变化：懂 Python + FastAPI + 向量数据库 + LLM API 的人，比只会写传统 CRUD 的工程师更容易拿到面试。某招聘平台数据显示，“大模型应用开发”类职位同比增长超过 200%。
- 技能溢价在拉大。一个能独立跑通 RAG 流程、会做 embedding 优化和 prompt 评估的工程师，薪资可能比同资历传统后端高 30%~50%。这不是头衔酷，而是市场供给还没跟上。
- 岗位要求更“复合”：既懂业务又懂模型能力边界的人，比纯算法背景更容易把项目落地。只会调 API 和只会推公式的人，都不如中间那批。

## 二、性别缺口：不是能力问题，是管道漏损



- 全球多个 AI 行业报告显示，核心 AI 岗位女性占比约 22%~26%。国内一些招聘平台的投递数据也显示，算法、大模型方向女性投递占比不足三成。
- 这条“漏损管道”从教育阶段就开始：中小学阶段女生在 STEM 科目上的兴趣并不差，但高等教育进入计算机、自动化等专业的比例下降；就业后，部分女性因职业中断、晋升通道、团队氛围等原因离开核心研发岗。
- 需要区分候选池差异和岗位技能要求。很多 AI 岗位并不需要超常体力，但招聘描述中“能加班”“高频出差”等隐性条件，会把有能力的候选人挡在门外。
- 反过来看，数据标注、模型评估、AI 训练师等外围岗位女性占比相对较高，但这些岗位薪资天花板明显、可替代性强，容易造成一种“AI 行业女性参与度并不低”的统计错觉。

## 三、学历门槛：核心岗在“筛学历”，外围岗在“吃时间”



- 大厂核心 AI 研发岗，硕士、博士是常见默认线。不是学历本身产生生产力，而是因为模型训练、分布式系统、优化算法等方向确实有较高理论门槛。企业用学历做初筛，有点像数据库建索引：不完美，但查询成本最低。
- 低学历求职者进入 AI 产业链的主要入口是数据标注、内容审核、数据清洗。这些岗位时薪不高、重复性强，而且面临被自动化替代的风险——你用大量时间训练模型，模型变强后反过来替代你的岗位。
- 一个值得注意的趋势：学历信号正在被部分技能信号替代。开源项目、Kaggle 或国内竞赛排名、可展示的微调案例、行业数据集建设经验，在中小公司和 AI 初创团队中的权重在上升。
- 但“证书通胀”也来了。短平快的 AI 培训班证书，含金量远不如一个能跑通业务的 GitHub 仓库。招聘方越来越会看实际产出，而不是课程完成截图。

## 四、年轻人“吃肉”，但肉可能是高代谢速食



- 从数据看，AI 岗位从业者确实偏年轻。原因不复杂：没有被旧技术栈绑定，学习成本低，愿意接受高强度试错。
- 但 AI 知识的半衰期比传统软件工程短得多。一个框架可能 18 个月就被新工具替代。今天会用 LangChain 做编排，明天可能被更底层的 Agent 框架分流注意力。
- 所谓“吃肉”，更多是吃窗口红利：早期入场者享受了供需失衡带来的溢价。随着高校扩招、培训班批量输出、跨行业转行者涌入，部分岗位薪资会回归理性。
- 年轻人需要警惕一种错觉：把平台和行业红利当成个人能力。退潮之后，能留下来的还是那些能解决实际业务问题的人。

## 收尾：三句冷思考

1. 不要只追岗位名称，要追“技能组合”。例如“领域知识 + 数据工程 + 模型调优”的组合，比单独学 Prompt 或某一个热门框架更抗周期。
2. 学历不占优的人，优先选择能积累“项目资产”的入口：开源贡献、垂直行业数据集构建、AI 应用落地案例，这些比纯标注更可能向上移动。
3. 女性或非技术背景的人，AI 时代的入口未必是写代码。模型评估、AI 产品运营、可信 AI、合规落地、AI 训练师等岗位正在增加，复合技能溢价可能比单点技术更高。
