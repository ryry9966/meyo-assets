“停产”这个词，在二手市场比在发布会现场更有杀伤力。最近科技圈有一条消息把 iPhone X 重新拉回讨论区：这款曾开启全面屏时代的十周年 iPhone，正式进入 Apple 全球停产产品名单。对多数人来说，这不是一个突然的决定——iPhone X 早在 2018 年就从官网下架，此后只有第三方渠道在消化库存。可真正值得聊的，并不是它的产线停了，而是它留下的一整套设计公约，至今还在被旗舰机默默使用。刘海、Face ID、手势条、千美元起售价、竖排双摄，这些元素没有随着 iPhone X 一起退场，反而成了行业的基础设施。



## 1. 停产到底意味着什么？

Apple 的“停产”有明确定义：产品停止销售 5 到 7 年为“老旧”产品，超过 7 年则列为“停产”产品。进入停产名单后，Apple Store 和授权服务商会停止提供硬件维修及原装配件订购；即使设备仍能开机，官方意义上的生命周期已经结束。iPhone X 发布于 2017 年 9 月，2018 年 9 月随 iPhone XS 系列发布而从官网消失，到如今被列入停产产品，前后约 7 年。这条时间线符合消费电子行业的更新节奏，也说明“彻底停产”不等于突然死亡，而是一次缓慢退出。
对普通用户而言，影响集中在维修端：
- 官方换电池、换屏服务停止，第三方维修件来源变得更重要；
- 二手 iPhone X 仍能交易，但价格会因官方支持消失而进一步下探；
- iOS 系统支持可能还会延续一两个大版本，因为 A11 Bionic 的性能余量仍然不低。
真正被停掉的，是它的硬件服务；没有停掉的，是它写入行业标准的交互逻辑。

## 2. 一块“刘海”如何重塑手机正面

iPhone X 是第一款取消实体 Home 键的 iPhone，也是第一款在正面挖出一个明显传感器区域的 iPhone。这块“刘海”里塞进了红外镜头、点阵投影器、泛光感应元件、前置摄像头、听筒等一整套 TrueDepth 相机系统。以当时的技术，无法把这些元器件全部藏到屏下，于是苹果选择保留一个 notch，来换取 Face ID 和全面屏。
这个决定在参数上并不保守：5.8 英寸 OLED 屏，分辨率 2436×1125，像素密度 458 ppi，对比度 1,000,000:1，支持 HDR 显示。虽然屏占比约为 82.9%，放到今天并不领先，但它改变了“全面屏”的实现路径。
此后行业出现了一个明显的分流：
- 安卓厂商先模仿刘海屏，再快速演化成水滴屏、挖孔屏、升降摄像头和屏下摄像头；
- iOS 阵营则把 notch 变成视觉识别符号，直至后续机型缩小成“灵动岛”；
- UI 设计层面，状态栏从完整一条变成左右两侧“耳朵”，开发者必须适配安全区。
换句话说，iPhone X 让“全面屏”从无边框概念，变成了围绕传感器做减法的工程竞赛。

## 3. Face ID 与生物识别路线之争

iPhone X 用 Face ID 替代了存在十年的 Touch ID，这是一次高风险切换。技术原理并不神秘：点阵投影器向人脸投射约 3 万个不可见红外光点，红外镜头读取反射信息，A11 Bionic 的神经网络引擎据此构建深度人脸模型，再与设备内 Secure Enclave 中的加密数据进行比对。整个过程在本地完成，人脸数据不会以明文形式上传 iCloud。
苹果给出的随机解锁概率是 1/1,000,000，远低于 Touch ID 的 1/50,000。代价是结构光模组体积大、成本高，还带来了刘海。Android 阵营大多选择指纹或 2D 人脸识别，只有少数旗舰跟进 3D 结构光方案。
这带来两条技术路线的长期对峙：
- iOS 路线：以 3D 结构光为核心，强调支付级安全、注视感知和动画拟真；
- Android 路线：以屏下光学/超声波指纹为主，强调屏占比和低成本；
- 疫情等场景暴露了 Face ID 的短板，但也推动了“口罩解锁”和 Apple Watch 联动等补偿方案。
回到源头，iPhone X 把“生物识别前置到显示层之上”的产品思路固定了下来，后续手机无论用哪种方案，都在回答它留下的问题：如何在不牺牲屏幕的前提下完成身份认证。

## 4. 竖排双摄、OLED 和千美元定价的连锁反应

iPhone X 的竖排双摄常被吐槽像“红绿灯”，但它的根源不是审美，而是空间：刘海区域占用了机身顶部大量横向宽度，横排双摄已经没有足够位置容纳，于是两颗摄像头只能竖排。这种设计后续被大量机型借鉴，说明旗舰机内部堆叠的约束往往先于视觉风格。
屏幕材质切换到 OLED，也带来供应链重塑：
- 早期 OLED 面板高度依赖三星，iPhone X 的大规模订单进一步拉动中小尺寸 OLED 产能；
- 3D 结构光模组带动 VCSEL 激光器、DOE 衍射光学元件、红外镜头等细分领域；
- 更集成的 SiP 封装与双层主板设计，逐步成为旗舰机标配。
价格上，iPhone X 以 999 美元起售，第一次把主流旗舰拉入千美元区间。后来安卓高端机型跟进涨价，消费者逐渐接受“手机可以比笔记本贵”的定价预期。这个看似商业化的变化，其实与屏幕、传感器、存储和封装成本上升直接相关。
冷思考收尾，至少有三点值得记住：
1. 停产不等于过时：iPhone X 定义的刘海、Face ID、手势导航，仍然活在现役旗舰机中；真正被淘汰的是具体型号，不是产品范式。
2. 设计约束才是技术分水岭：它用牺牲一小块屏幕来换取更安全的识别和全新交互，说明旗舰机的差异往往来自物理空间的取舍，而不是单纯堆料。
3. 对普通用户的实际建议：如果还在用 iPhone X，不必因为“停产”恐慌，优先做好数据备份、更换非官方电池时选择可靠渠道；如果购买二手，重点检查屏幕、Face ID 和电池健康，不要只看外观。
