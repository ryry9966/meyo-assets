WAIC 的圆桌上从来不缺神仙打架的名场面。今年的火药味集中在一个问题上：多模态到底是给大语言模型打了个“外挂”，还是它本就是下一代智能的“灵魂组件”？五位首席科学家各执一词，有人把多模态比作 LLM 的眼睛和耳朵，有人却直言不讳：别神化多模态，它只是感官，离灵魂还远。

这场争论之所以出圈，不在于谁对谁错，而在于它戳中了一个关键的技术路线分歧——我们是应该继续在纯文本的思辨宇宙里攀登 AGI，还是必须让 AI 走进物理世界，去“看”、去“听”、去建立具身经验？下面的拆解，或许能帮你看清这场大模型军备竞赛的底层逻辑。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-19/0ff433376b5484c9.png)

## 外挂派：多模态是“感知外包”，核心智能在文本

这一派的逻辑非常工程师：大脑（LLM）负责推理和知识，眼睛（视觉模型）和耳朵（音频模型）只是 IO 接口。它们不触碰智能的本质。

- **论据一：推理能力不依赖多模态。** 人类最抽象的智能活动，数学证明、法律推演、代码生成，几乎全在符号系统内完成。LLM 在纯文本预训练中已经涌现出了思维链，多模态的加入并没有显著提升 GSM8K 或 MATH 基准上的推理分数，它主要提升的是 OCR 精度和图表理解能力。
- **论据二：多模态是“记忆锚点”而非“逻辑引擎”。** 视觉信息对人类来说更多是记忆挂钩，你看到一只龙虾，就能联想到“甲壳纲”、“整肢”、“底栖生物”等一系列概念。但 AI 不需要视网膜，它直接从 token 向量里建立关联。视觉输入只是换了一种编码方式，底层还是 transformer 在做自注意力。
- **工程视角：Plugin 化最经济。** 现在主流的多模态模型，从 Flamingo 到 MiniGPT-4，本质上就是一个预训练好的 LLM 前面插了个视觉编码器和适配器（Q-Former 或线性投影层）。LLM 的参数经常是冻住的，这活脱脱就是个外挂。外部工具调用的思路也印证了这一点，LLM 调用 OCR API、目标检测器，按需使用，灵活又低成本。

支持这一派的首席科学家喜欢用一句话收尾：**不要因为一个人装了高精度的义肢，就说他的大脑被替换了。**

## 灵魂派：感知是概念形成的起点，不是附属品

对面阵营的反驳更叩击认知科学的底层。他们的核心观点是：没有多模态经验的 LLM，即使学富五车，也永远是个“缸中之脑”。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-19/26fa55988a934050.png)

- **概念接地（Symbol Grounding）问题。** 哲学家弗兰克·杰克逊的“黑白玛丽”思想实验，一个从小在黑白房间中研究颜色光谱的科学家玛丽，知道“红色”的所有物理参数，但她真正看到红玫瑰的那一刻，才获得了关于“红色”的完整知识。LLM 现在就是那个没出过房间的玛丽，它处理的“红色”只是词向量里的统计共现，没有波长、没有饱和度、没有感官经验。多模态正是打开那扇窗。
- **世界模型需要物理常识。** 为什么 GPT-4 有时会一本正经地说“用毛巾包裹鸡蛋放进微波炉”？因为它没有见过微波炉内部的电弧放电，没有摸过烫手的碗。物理常识的缺失，根源在于没有多模态的具身经验。视频、深度传感器、触觉数据，这些是构建世界模型的原材料。纯文本来自人类的过滤，而多模态数据保留了世界的噪声和物理约束，这才是智能的磨刀石。
- **涌现的临界点可能依赖于模态丰富度。** 人类大脑皮层的功能分化告诉我们，高级智能（如语言）是在初级感知皮层的基础上演化出来的。如果我们在预训练中剥离了视觉、听觉原始的时空结构，只留下分词后的符号，很可能永远无法催生出空间推理、因果推断等真正的智能，天花板就是文本复读机。
- **多模态 fusion 不是拼接，是化学反应。** 真正的多模态是从神经架构底层就进行交叉注意力，让视觉神经元和语言神经元同步放电。比如具身智能里的导航任务，语言指令“绕过桌椅”必须和实时点云做帧级对齐，这种实时、高频、物理的信息流，不是 API 调用的“软外挂”能模拟的。它塑造的是系统从反馈中学习的本能，而非仅仅回答问题。

## 交锋背后的三条技术暗线

抛开“外挂 vs 灵魂”的比喻，这场争论实际上在三个技术断层上拉锯：

1.  **计算成本的数学不等式。**  
    真正的端到端多模态训练，算力开销是纯文本的几十倍。以 Sora 为例，视频数据的 token 化与时空压缩的复杂度，让训一个多模态基础模型的成本直奔数亿美元。所以“外挂派”很大程度上是务实派，是在算力约束下的折衷路线。

2.  **评测体系的话语权争夺。**  
    如果你只看 MMLU、HumanEval，多模态确实像鸡肋；但如果你看 MMVP、WorldBench 这种衡量物理常识和视觉幻觉的基准，纯 LLM 几乎零分。首席科学家们争论的，其实是谁的“考卷”更能定义智能。目前业界明显缺乏公认的多模态 AGI 级评测基准。

3.  **数据分布的时代局限。**  
    互联网的文本数据接近枯竭，但视频、音频、传感器数据仍是富矿。从数据红利角度看，多模态是不得不走的下一步。只不过走法不同：是先“消化”成文本再喂给 LLM，还是原生地让模型自己去“看”世界？这决定了多模态是工具，还是大脑本身的组成部分。

## 作为开发者或从业者，现在该怎么看？

别被概念之争带偏，脚踏实地看三点：

- **注意成本结构，别盲目追端到端。**  
  如果你的任务明确——文档解析、证照识别、视频摘要——用 LLM 调用专用模型 API 的组合方案，性价比碾压从头训一个原生多模态模型。外挂不是贬义词，是工程上的明智分层架构。只有当你的业务涉及复杂物理交互、实时空间推理时，才值得尝试端到端方案。

- **用“黑白玛丽”测试来审视你的产品。**  
  你的 AI 产品是否只停留在文本知识层面，而完全不了解用户的物理场景？试着问你的模型：“这把椅子能塞进后备箱吗？”“这个角度拿杯子会不会洒？”如果它只能给出文字层面的推演，那就是时候引入视觉输入了。用户需要的不是百科全书，而是能理解他们眼中世界的助手。

- **把“世界模型”当成北极星，但把“token”当成干粮。**  
  长期看，具备多模态感知和推理的具身智能一定是方向，这是灵魂。但通往这个方向的路上，文本数据依然是最高密度的知识压缩形式。最务实的路线是：先用文本逻辑把业务闭环跑通，再逐步加入视觉、听觉进行微调和强化学习，让模型获得物理常识。不要为了多模态而多模态，要为解决物理世界的问题而多模态。

多模态不会让 LLM 一夜之间拥有灵魂，但缺乏多模态的 LLM，注定无法进化出理解真实世界的心智。这不是一个非此即彼的选择，而是一个架构演进的时间表——就像龙虾的壳，虽硬却要定期蜕换，才能长出更强壮的身躯。
