数学家陶哲轩在一次公开交流中把当前的大语言模型（LLM）称为“高级猜谜机”。这句话没有贬义，反而像一把极简的手术刀，剖开了 AI 热潮底下最根本的那层机制。如果把每一个 token 都看作一次谜底，那么模型每生成一个字，都是在已知上文的前提下猜下一个字——仅此而已，却已足够掀起产业变革。这条推文的评论区两极分化：有人觉得“猜谜”降低了智能的逼格，有人忽然明白了为什么模型会一本正经地胡说八道。与其站队，不如把原理拆开看。



## 一、猜谜机的数学底稿：从条件概率到自回归
现代语言模型的核心任务，用一句话概括就是：**给定前文，最大化下一个 token 的概率**。这个过程在学术界叫自回归（autoregressive）生成。

- **Token 不是字**：BPE（Byte Pair Encoding）等方法把文本切成子词单元，GPT-3 的词汇表有 50257 个 token。每步预测就是在这些 token 上输出一个概率分布。
- **公式骨架**：如果把句子看成序列 \( x = (x_1, x_2, ..., x_T) \)，模型学习的是联合概率 \( P(x) \) 的分解：\( P(x) = P(x_1) \cdot P(x_2|x_1) \cdot P(x_3|x_1, x_2) \cdots \)。训练目标就是最小化每个位置上真实 token 与预测分布间的交叉熵。
- **类比猜谜**：想象你拿到一段被消掉最后一个词的文本：“月球绕地球公转的周期大约是______”。一个训练充分的语言模型根据数百万篇天文学文档中的统计规律，会在“27.3天”这类 token 上给出极高概率。它没有“计算”轨道，只是复现了曾经见过的搭配。

这个框架从 Bengio 团队 2003 年的神经概率语言模型开始，经 Transformer 加持后尺度量变引发质变。2017 年 Vaswani 等人提出的自注意力机制，让模型能把整段历史的上下文一并纳入“猜词”的依据，而不再像 RNN 那样依赖压缩隐状态。猜谜的剧本没变，变的是模型获取线索的广度和对齐线索的效率。

## 二、为什么“只会猜”也能涌现推理和代码能力
许多人对“猜谜机”的质疑在于：如果只是统计式地补全文字，怎么可能解释复杂的数学推理、代码生成，甚至多步规划？这得从三个维度来理解。



### 2.1 规模就是武器
- **参数量**：GPT-3 的 1750 亿参数已经能在少样本提示下执行中等难度算术，PaLM 5400 亿参数量进一步提升了链式推理的稳定性。
- **数据量**：在数万亿 token 的语料里，模型实际上“见过”人类文明中的大量推理痕迹——维基百科的证明步骤、Stack Overflow 的调试记录、ArXiv 上的推导链条。只不过它没有把推理看成一个逻辑游戏，而是看成了文本模板。

### 2.2 上下文学习（In-Context Learning）
当你在 prompt 中给出几个“问→推理步骤→答”的示例，模型并不更新参数，而是利用注意力的 KV 缓存直接复刻这种输出模式。本质上，它把示例当成了更强的前缀约束，让概率分布的峰值落在“先写步骤再给答案”这种 token 模式上。**形式化的推理被伪装成了风格迁移**。

### 2.3 思维链（Chain-of-Thought）的魔法
2022 年的研究证明，只要在 prompt 中加上 “Let’s think step by step”，模型输出中间推导过程后再给最终答案的准确率能大幅提升。这是因为中间步骤的 token 序列为最终答案提供了更长的上下文依赖，分摊了单步预测的 ambiguity。换言之，把一道难题拆成若干道更简单的猜谜题，每一道题的正确答案概率就会提高。

从这个角度看，AI 像是用海量统计拼出了一面巨大的透镜，把人类知识库里的逻辑结构折射出来。它自己并没有逻辑官能，却成功复刻了逻辑的形态。

## 三、猜谜的边界：幻觉、死记硬背与因果盲区
正因为模型本质上是一个条件概率分布生成器，它天生存在几条跨不过去的沟壑。

- **幻觉（Hallucination）**：当模型被问到一个它没有可靠统计依据的问题，比如“2027 年诺贝尔物理学奖得主是谁”，它不会回答“我不知道”，而是会按照以往诺奖公布新闻的文本格式，“猜”出一个看似合理的名字和理由。因为训练语料里几乎没有“无法回答”这类句型被奖励，软标签会让模型倾向于给出置信度最高的错误答案。
- **逆向推理陷阱**：BERT 时代的完形填空还能窥见双向信息，但 GPT 等自回归模型只能从左到右。遇到需要从结论倒推条件的任务，比如“已知结果 X，可能的前提是什么”，模型往往退化到高频前提的表面关联，而不是进行反事实推断。陶哲轩曾举过一个数学例子：模型可以模仿ε-δ 语言，却不能检查一个证明的每个推导是否有效。
- **统计相关性 ≠ 因果性**：模型轻而易举就能学到“吃冰淇淋的人数多少与溺水事故相关”，但它没有物理世界的因果模型去区分这背后是气温这个混杂因子。这导致在需要物理常识、空间推理或严格逻辑约束的场合，猜谜策略会露出马脚。

OpenAI 的研究员在 2023 年的一篇技术报告中展示过一个典型 case：让 GPT-4 规划用积木搭桥，它会给出步骤但完全忽略重心稳定性。它能猜对每一步该提什么名词（“放上第三块积木”“调整角度”），却猜不出这样搭会不会倒。

## 四、陶哲轩的数学家视角：符号推理与统计推理的张力
陶哲轩之所以用“猜谜机”这个措辞，跟他作为数学家对确定性证明的本能追求有关。数学系统的核心是符号操作，集合论的公理能够在有限步内机械地验证一个命题真假。而 LLM 的预测本质是一种近似逼近，既不能保证一致性，也无法给出失败边界。

- **定理证明的对比**：Lean、Coq 等交互式证明助手中，一段证明要么通过类型检查，要么不通过，不存在“大概正确”。而让 ChatGPT 去证明一个群论定理，可能 90% 的推理顺畅，但在某一步偷偷用了结论本身，出现循环论证。
- **概率智慧 vs 算法硬核**：人类数学家当然也用直觉、比喻和试探性猜测来发现新定理，但他们最终会把论证写成无懈可击的逻辑链条。LLM 输出的所有内容都停留在第一阶段——有根据的猜测，却没有第二阶段的形式验证能力。
- **新突破的可能**：近期的工作如 AlphaGeometry 结合了神经语言模型和符号推理引擎，用前者生成辅助构造的猜测，用后者做严格几何推导。这种架构某种程度上承认了“猜谜”的局限，也找到了弥补路径。

或许陶哲轩想说的不是 AI 弱，而是提醒大家：**当你把统计猜测误当成严谨推理时，就会在关键任务上翻车**。



## 五、守好“人类最后一道工序”：三条冷思考
作为工程师或普通使用者，与其纠结哲学上“它算不算理解”，不如把几个务实的判断框架装进工具箱。

1. **像审核实习生一样审核 AI 输出**
   - 每条事实类陈述都要交叉验证至少一个独立来源。对于法规、医疗、财务建议，坚持 human-in-the-loop。
   - 把生成内容默认假设为“内部一致性可能不错，但事实性待检”的草案，而不是成品。

2. **用约束把猜谜关进笼子**
   - 结构化输出（JSON 模式）、grammar 约束采样、logit bias 等工程手段能大幅减少幻觉。例如要求模型输出 `{"result": "yes" | "no", "reason": string}` 并把 reasoning 与决策字段分开。
   - 引入检索增强生成（RAG）或工具使用，把纯粹依赖内部概率分布的单步决策，改成“查资料→摘要→判断”的流水线，让外部知识承担一部分确定性。

3. **理解“猜”的边界，再去信任**
   - 适合猜谜的任务：翻译、摘要、创意写作、低风险问答。
   - 需要警惕的任务：法律条文解读、医药剂量计算、高可靠性代码审计、科学最终结论推导。这些场景中，把 LLM 当作启发式搜索引擎或草稿生成器，而不是最终裁决者。
   - 对自己使用 AI 的方式做一次“沙盘推演”：如果模型在这条链路的一个环节出现错误，影响是伤筋动骨还是可控容错？根据回答决定授权程度。

AI 是猜谜机这句话，看似低看了智能，实则是给狂热者的一杯冰水，也是给务实派的一份说明书。当一个系统用概率和统计模拟出了几乎人类同事般的能力时，最好的相处方式不是崇拜也不是鄙视，而是清醒地把它的强项嵌进流水线，把它的弱项拦在决策链最外面。真正可靠的，仍然是那个在循环中不断验证、修正和负责的人。
