当 Jeff Dean 这个名字再次被热议，不是因为他那封标志性的谦逊邮件，也不是又一次系统级的性能优化传奇。这次，是一段据称是他离职前最后对话的内容流出：他直白地承认“我低估了AI”，同时一针见血地指出了创业者未来的唯一生路。作为谷歌大脑与 Google AI 的奠基人之一，他的反思不仅是一份技术圈的忏悔录，更是一份给下一个十年定调的路线图。



## 1. 为什么巨头也会“低估”AI？——从 Transformer 到涌现的认知滞后

2017 年，谷歌团队发表《Attention Is All You Need》，Transformer 架构横空出世。然而内部对待这项技术的方式，与 OpenAI 后来的豪赌形成了鲜明对比。Jeff Dean 的“低估”并非缺乏远见，而是成熟科技公司面对破坏性创新时常见的路径依赖。

- **安全的保守主义**：谷歌过去几年将大部分自然语言处理能力押注在 BERT 类编码器模型上，强调理解而非生成。一方面为了保证搜索质量的稳定性，另一方面对生成模型的幻觉与伦理风险极度谨慎。
- **Scaling Laws 被当作理论游戏**：2020 年 Kaplan 等人提出的 Scaling Laws 已经暗示，模型性能会随参数、数据和算力幂级提升。OpenAI 放手将 GPT-3 推至 1750 亿参数，而谷歌同期最大的模型（如 Meena、LaMDA）迟迟未公开上线，规模也相对保守。
- **涌现的意外性**：当 GPT-3 展现出上下文学习、零样本推理甚至简单的代码生成时，许多研究者才意识到，某些能力并非线性增长，而是在某个临界点突然“涌现”。Jeff Dean 在回顾中提到，他们曾以为需要发明全新架构才能实现推理，没想到现有架构只是被喂了足够多的数据。

其实，谷歌并非没有技术储备，Pathways、Chinchilla scaling 甚至后来的 Gemini 都能证明其底蕴。但保守的发布策略让外部开发者转向了 OpenAI 的生态，创业浪潮也围绕 ChatGPT 的 API 疯狂展开。创始人如果还在等“完美模型”，只会重蹈覆辙。



## 2. AI 的陡峭进化曲线：为何它让每个人都感到“后怕”

从实验室里的玩具到改变产业格局的工具，AI 最近五年的进化速度已经脱离了传统软件的摩尔定律。如果你觉得 ChatGPT 只是聊天机器人，那只是管中窥豹。

- **多模态的融合**：2024 年的 Gemini 与 GPT-4o 已经可以无缝处理文本、图像、音频甚至视频流。这意味着模型不再是一个“语言处理器”，而是接近人类感官的通用感知器。创业者如果只盯着纯文本客服场景，很快就会被跨模态竞品降维打击。
- **推理与工具使用**：从简单的函数调用到自动拆解任务、规划子目标的 Agent 架构，AI 开始真正拥有“执行力”。例如 Devin 这样的 AI 程序员可以独立完成一个 bug 的修复并提交 PR，中间涉及读代码、定位、搜索解决方案、执行 shell 命令等一系列操作。
- **成本曲线俯冲**：硬件效率的改进与模型蒸馏、量化的成熟，使得运行一次 GPT-4 级别推理的成本在一年内下降了 90% 以上。这彻底改变了单位经济模型，那些原本因为 API 太贵而被否定的商业场景，正在重新变成金矿。

Jeff Dean 所谓的“后怕”，或许正来自这种系统性的加速：技术、成本、人才、资本四轮驱动，形成了一个几乎不可能被单打独斗打破的正反馈飞轮。但硬币的另一面是，基础设施每进步一分，上层应用创新的舞台就扩大十分。



## 3. 创业者的唯一生路：别去造火箭发动机，去造登月舱

对话中最犀利的部分，是 Jeff Dean 直言“如果你还在试图从头训练一个比 GPT-5 更好的通用模型，那你大概率会消失”。这并不是危言耸听，而是对技术栈分层的清醒认知。创业者真正的蓝海在于：

- **专有数据的护城河**：通用大模型吃的是公开互联网数据，对垂直领域的暗知识、非结构化私域数据几乎无能为力。比如医疗影像报告中隐含的诊断逻辑、顶级律所从未公开的法律意见书语料、工业传感器在极端工况下的噪声模式。将这些数据与强大的基座模型结合，是建立壁垒的最短路径。
- **工作流与人机协作的精细设计**：AI 目前的推理仍然不稳定，在企业级场景里，“输出 90% 的正确率”和“造成 10% 的致命错误”是同一件事。创业者需要设计的不是 API 调用接口，而是结合审核、纠错、人工干预节点的完整工作流。典型如 AI 会计不是让模型直接生成财务报表，而是自动抓取发票、分类、生成待复核的草稿，再由会计师拍板。
- **利基市场的深度绑定**：法律领域的合同审核、建筑领域的 CAD 图纸合规检查、跨境电商的多语种合规标签生成……每一个细分赛道都足以诞生一家小而美的 SaaS 公司。这类场景不需要千亿参数，一个经过精调的 7B 模型加上规则引擎，就能实现比通用模型更高的准确率和更低的延迟。

Jeff Dean 点出的“唯一生路”，本质上是提醒创业者放弃做巨头能标准化收割的层，转而成为那些巨头无法深入、但 AI 又能发挥巨大威力的垂直“泥潭”之王。



## 4. 冷思考与三条生存法则

大模型之光令人目眩，但任何技术革命的早期都布满美丽的陷阱。从 Jeff Dean 的反思出发，提炼三条可实操的原则：

1. **警惕“大模型万能”的幻觉，坚持成本与效果平衡**。幻觉、推理延迟和高昂的 token 消耗，决定了在很多高频、低容错场景中，规则引擎 + 传统机器学习模型依然是最优解。先用最原始的基线解决问题，再考虑是否真的需要一支超大规模特遣队。
2. **把 AI 当副驾驶，而不是自动驾驶仪，建立人类审查闭环**。尤其涉及金融、法律、医疗决策时，模型输出必须经过结构化验证。一个简单的验证器小模型或规则检查器，往往能拦截 80% 的严重错误，避免灾难性后果。
3. **不要追逐技术流行词，找到隐藏在流程中的“痛苦 15 秒”**。与其琢磨怎么用 Agent 重新发明一切，不如去观察真实用户在工作中反复手动复制粘贴、格式转换、多系统比对的环节。把这些 15 秒的摩擦点消除，才是赚到真金白银的产品内核。

AI 发展的曲线依旧陡峭，Jeff Dean 的坦诚给了所有人一次集体校准认知的机会。唯一生路不在算力竞赛的终点，而在每一个被大厂遗忘的潮湿角落，用最扎实的工程师思维，把 AI 的长板镶嵌进真实世界的断层。
