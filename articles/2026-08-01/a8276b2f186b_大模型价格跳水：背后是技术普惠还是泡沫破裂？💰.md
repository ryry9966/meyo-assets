AI 大模型的价格战比想象中来得更快。5 月初，某头部厂商将主力模型 API 调用价格直降 97%，一夜之间行业哗然。曾被视为“暴利赛道”的大模型行业，正在经历一场拷问：当每百万 token 成本趋近于零，上一秒还被捧上神坛的商业模式，下一秒就可能跌入凡尘。这究竟是技术平权的高光时刻，还是资本催熟的泡沫正在出清？



## 大模型为什么曾经“暴利”？

所谓暴利，不是凭空吹出来的，而是由三层成本结构和技术壁垒共同支撑起来的。

- **训练成本高得离谱**：训练一个千亿参数模型，需要数千张 H100 GPU 连续跑上数周，仅电费和硬件折旧就达数百万美元。以 Meta 开源的 Llama 2 为例，推测训练成本在 2000 万美元级别，而 GPT-4 级别模型轻松突破一亿美元。这些成本自然要分摊到每一次 API 调用中。
- **推理硬件投入不菲**：服务端推理同样需要高性能 GPU 集群做后盾。为保障低延迟，厂商必须提前部署大量算力，即使很多算力处于空闲状态。这部分成本像一座看不见的冰山。
- **技术稀缺性定价**：一年前能稳定跑通 RLHF（人类反馈强化学习）的团队屈指可数，高质量模型供给严重不足。供需失衡给了先行者极高的溢价空间，Token 定价远高于边际成本。
- **打包解决方案的溢价**：早期客户为“AI 能力”整体付费，不区分底层模型、中间件和应用层价值，这种捆包销售模式进一步推高了利润。

当技术领先、算力稀缺和需求爆发三者叠加，暴利就理所当然地出现了。然而，这个窗口期正在加速关闭。



## 价格腰斩的推手：多条路线合力拆壁垒

暴利的消失不是单一因素造成，而是技术、开源和商业策略多股力量合围的结果。

- **模型压缩与推理优化**：量化（Quantization）、蒸馏（Distillation）、剪枝（Pruning）等技术的成熟，让体积缩小 75% 的模型仍能保持 95% 以上性能。英伟达 TensorRT-LLM、vLLM 等推理引擎大幅提升吞吐量，单卡每秒处理 token 数呈倍数增长，边际成本直线下滑。
- **开源社区的降维打击**：Llama 3、Mistral、DeepSeek 等开源模型性能迅速逼近闭源前沿，企业可以自行部署，完全绕开商业 API 的高定价。Meta 更是以近乎零成本方式分发 Llama 系列，直接压低整个市场的定价天花板。
- **硬件效率跃迁**：H100、B200 等新一代 GPU 的算力密度飞跃，搭配稀疏计算和 FlashAttention 等算法创新，使得完成同样推理任务所需的芯片数量和能耗持续下降。
- **云厂商的算力价格战**：AWS、阿里云、火山引擎等云平台将大模型视作算力消耗的“入口”，宁可模型服务本身零利润甚至亏损，也要拉动背后存储、网络、数据库等基础云资源消费。当模型被当成赠品，价格自然没有底线。
- **同质化竞争烈度**：国内百模大战仍未结束，众多模型底座趋同，唯一的差异化点只剩下价格。各厂商为了抢开发者生态和市场份额，主动发起一轮又一轮降价，把行业推入“谁不跟谁出局”的囚徒困境。

这些推力一旦形成，就不可逆转。大模型正在从奢侈资源变为水电一样的基础设施。



## 暴利终结后的产业图景：谁会裸泳？

价格归位之后，裸泳者将率先浮出水面。整个产业的盈利逻辑和生存法则需要在三点上重新校准。

- **纯模型层没有护城河**：如果一家公司的核心壁垒只是“拥有一个大模型”，那它的定价能力会迅速被开源和竞品蚕食。模型能力无限趋近，客户切换成本极低，利润将无限趋近于边际成本——而硬件降价与软件优化正在把这个边际成本推向零。
- **API 中间件厂商面临挤压**：那些靠封装第三方模型、加一层简单业务逻辑就高价出售的中间商，会在上游降价和下游议价能力提升的双向夹击中失去生存空间。
- **数据飞轮和生态粘性成为新壁垒**：真正能留存客户的，不是模型本身，而是围绕模型沉淀下来的用户数据、反馈闭环、工具链集成和场景适配。谁能建立起“用得越多→反馈越多→模型越准→用户越离不开”的良性循环，谁就能在价格战中保持溢价。
- **云厂商和硬件商成为隐形赢家**：无论模型服务赚不赚钱，庞大的推理算力需求最终都会流向 GPU 提供商和云基础设施。NVIDIA 的财报已经证明了这一点，而云平台也乐于看到模型价格越低、开发者越活跃、底层资源消耗越大的局面。

暴利的终结实际上在宣告：大模型不再是商业模式本身，而只是商业模式的一个组件。



## 下一步价值会在哪里溢出？

当基础模型越来越便宜，真正的价值就会沿着价值链向两端转移：一端深入垂直场景，另一端上升为业务编排。

- **垂直行业深度定制**：通用大模型降价之后，医疗、法律、金融、工业等领域的 Fine-tuning 和 RAG 方案反而价值凸显。企业愿意为“懂我业务、不出错、可审计”的垂直模型支付溢价，因为这种模型直接嵌入核心流程，替换成本极高。
- **Agent 和多智能体协作**：单次 token 价格趋零，使得多步推理、长程任务规划、大量 Agent 并行协作成为可能。编排成百上千个廉价模型调用去完成一个高价值任务，就像用低价零件组装精密仪器，组装过程就是利润来源。
- **企业数据资产的觉醒**：之前企业担心模型太贵，不敢把核心数据接入 AI。价格下降后，企业反而更舍得用 AI 去盘活私有数据，于是数据清洗、标注、向量化、权限管控等工具链成为刚需，整个数据管理赛道被激活。
- **端侧 AI 与实时推理爆发**：低成本模型使得手机、汽车、IoT 设备可以本地运行高质量 AI，不再依赖云端。这带来隐私保护和毫秒级响应，催生出全新的交互模式和产品形态，价值分配将从软件层渗透到硬件和传感器层。

暴利时代终结，并不意味着 AI 的财富故事结束，而是换了一张地图重新开局。



## 保持清醒：三个冷思考与务实建议

面对漫天降价消息，开发者和企业决策层需要比以往更冷静。

**冷思考一：零元背后可能更贵。** 免费或超低价 API 往往伴随着数据收集条款、服务限制或云平台绑定。中途如果更换模型，迁移数据和调整 Prompt 流水线的成本可能远超省下的 token 费用。

**冷思考二：别为了降价而放弃质量。** 在一些高精度场景如合同审查、医疗建议中，哪怕 0.1% 的错误率都会引发严重后果。选择模型时，可靠性、一致性和可解释性要排在价格之前。

**冷思考三：模型不会自动创造商业价值。** 便宜的模型只是给了你一把更锋利的刀，但做菜的水平取决于厨师。如果没有清晰的业务问题定义、高质量的数据和产品化能力，价格再低也只是烧钱。

基于这些思考，给出三条务实建议：

1. **建立多模型路由层**：不要绑定单一厂商。利用 LangChain、Llamaindex 等框架抽象出统一接口，根据任务难度和预算动态路由到不同模型，利用好降价红利同时避免被锁定。
2. **优先投资数据和反馈闭环**：把省下的模型预算投入到数据清洗、标注和用户反馈系统上。模型会过时，但专有数据与业务理解的壁垒只会越来越厚。
3. **重新设计 AI 产品的价值主张**：不要卖“调用了大模型”，而要卖“解决了什么问题”。将卖点从技术炫酷转移到成本节约、效率提升或新营收上，定价权源自客户感知的业务价值，而非 token 数。

大模型的暴利时代确实结束了，但这恰恰是 AI 从少数人的奢侈品变成所有人的工具箱的开始。接下来的竞争，拼的不再是谁的模型更贵，而是谁用更便宜的工具做出了更值钱的东西。
