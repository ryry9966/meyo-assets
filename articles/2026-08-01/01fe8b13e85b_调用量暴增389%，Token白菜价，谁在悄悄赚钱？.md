DeepSeek 一纸定价，把大模型 API 拉进“白菜时代”，每百万 Token 输出降到 1 元级别，开发者弹冠相庆，投资人却暗自捏汗——这么低的单价，利润从哪来？然而就在同一片热土上，却有一家公司的 Token 调用量逆势暴增 389%，而且是在仍然盈利的前提下。一边是价格屠刀，一边是闷声发财，这件事反常识的地方，恰好藏着推理工程里最值钱的秘密。



## 1. 模型价格，为什么能一降再降？

大模型 API 的单价看似是“模型成本”决定的，但实际上，**绝大多数成本发生在推理侧，而不是训练侧**。推理能不能便宜，取决于工程优化程度，这是一个纯粹的技术变量。

- **量化让模型变“轻”**：把 FP16 模型量化到 INT8 甚至 INT4，模型体积成倍缩小，单次推理所需显存和计算量大幅下降。DeepSeek V3/R1 发布时就重点展示了 INT8/FP8 量化后几乎无损的效果，这为低价推理铺了路。
- **投机解码（Speculative Decoding）是效果放大器**：用一个小草稿模型先快速生成几个候选 token，再用大模型一次性验证，正确则一并接受。写代码、翻译这类高度结构化的任务，投机解码能把吞吐量提升 2~4 倍，等于让同样一块 GPU 多卖几倍的 Token。
- **动态批处理（Continuous Batching）榨干 GPU 空闲**：单条请求内部有大量 KV Cache 复用空间，把多条请求的动态拼接在同一个 batch 里执行，GPU 的流处理器就不会因为等待 I/O 而空转。开源推理框架 vLLM、SGLang 在这方面的进化速度极快，新版本已经能做到 90% 以上的显存利用率。
- **开源模型免去“牌照税”**：DeepSeek 本身开源，服务商直接拿权重部署，不需要承担千亿参数的训练开支。它们只需要做推理工程，而这个环节的护城河是可以不断叠加的。



## 2. 卖 Token 的“中间商”，凭什么赚？

如果 DeepSeek 自己已经把 API 打到“地板价”，中间商应该没有空间才对。但现实是，**推理服务商的单位成本比训练模型的厂商更低**，因为它们只做推理这一个垂直环节，可以把工程压到极致。

- **硬件选型更灵活**：模型厂商往往要为兼容性而使用较新的同代 GPU，推理服务商则可以大量采购上一代计算卡，甚至定制推理芯片。显存带宽够大、算力够用即可，成本可能只有 A100/H800 的 1/3。
- **规模效应产生负成本错觉**：当并发请求量足够大时，动态批处理能产生超线性吞吐提升。单条请求成本趋近于电费，卖 1 元 / 百万 Token 仍然有百分之几十的毛利，而在调用量暴增 389% 的情况下，这种毛利被放大成了实实在在的利润。
- **Token 不是单纯卖算力，而是卖“不可替代的 pipeline”**：很多客户一旦接入某家推理 API，会在 Prompt 工程、缓存命中规则、输出格式定制上产生深度绑定。迁移成本不低，客户粘性就形成了护城河，即便市场上出现更低价的竞争者，客户也不会轻易切换。
- **模型厂商把流量拱手相让**：DeepSeek 的官方 API 经常因为并发爆炸而限流，反而让用户主动寻找第三方推理服务，客观上给这类公司输送了种子用户。

## 3. “薄利多销”这套叙事，能走多远？

从商业逻辑看，暴增 389% 更像一个阶段性信号，而不是稳态终点。推理的边际成本正在以每年超过 60% 的速度下降，价格战还远没到收手的时候。

- **当价格趋向边际成本，规模就是一切**：推理的边际成本无限逼近电费加折旧，价格继续下行不可避免。届时只有前几名的服务商能靠规模存活，今天暴增 389% 的幸运儿，明天很可能就是发起价格战的那一方。
- **硬件迭代正在改写游戏规则**：Groq、Cerebras 这类推理专用芯片，以及 AMD、Intel 的新计算卡，都在挑战 NVIDIA 的推理霸主地位。谁能更早绑定新一代硬件生态，谁的 Token 成本就能再砍一截。
- **不光是卖 Token，还要卖“确定性”**：未来差异化的关键不是单价，而是延迟、并发上限、私有化部署能力、数据安全合规。暴增的使用量背后，很多是企业级需求，它们的支付意愿并不完全跟着 Token 单价走。
- **开源模型生态的隐形推力**：DeepSeek、LLaMA、Qwen 等开源模型持续更新，新模型往往推理效率更高。推理服务商无需为每一代模型重新支付训练成本，只要跟进部署，就能自动享受效率提升的红利，这个逻辑比“训练-销售”模式更健康。



## 4. 给开发者的三条冷思考

面对愈演愈烈的 Token 价格战，开发者该跟风薅羊毛，还是小心选择长期伙伴？以下三条思考框架，或许比单纯比价更有用。

1. **别只看单价，先算“有效 Token 成本”**  
   同样 1 元 / 百万 Token，A 厂商的模型输出经常需要重试、截断或者格式错误，实际浪费的 Token 可能高出 30%。一个稳定的推理 schema，再加上可预测的低延迟，比单价便宜 10% 更重要。将 Token 成本分摊到“线上成功的业务调用次数”上，你得到的单位成本才是真实的。

2. **未来 6 个月，Token 价格还会再降一半，锁价合同要谨慎**  
   如果今天有人让你签一年预付费合同确保单价，你最好掂量一下。推理成本的年降幅在 50% 以上，锁价等于年底还在用两倍的价格买同样的服务。保留灵活切换的能力，比眼前省下的几个点珍贵得多。尽量选择按量付费且没有最低消费的服务。

3. **关注推理部署方案的可移植性，别被黑盒绑定**  
   如果某家提供商要求你使用独家 SDK、专用 Prompt 格式，或者把关键业务逻辑写进不透明的托管函数里，迁移成本会迅速膨胀。尽量采用标准 OpenAI 兼容接口、通用的 System Prompt 和 function calling 方式，让业务代码能随时切换到另一家推理服务，甚至是自己的私有化部署。可移植性本身就是议价筹码。

低价 Token 的狂欢不会永远持续，但这个窗口期足够让聪明的开发者和服务商各取所需。精明的取舍，从来不是寻找最低的价格，而是找到成本与确定性之间最窄的那个平衡点。
