“涨价是 DeepSeek 的原罪？”这个话题登上热搜时，评论区最常见的情绪是：当初靠低价抢用户，现在涨价就是背叛。但把涨价直接等同于原罪，可能让讨论停在情绪层。AI 服务的价格不是一串拍脑袋的数字，它背后是算力采购、显存调度、电力、带宽和持续研发的复合成本。这篇文章不站队，只拆账本。



## 一、涨价是怎么发生的：从“价格屠夫”到成本回归


很多人对 DeepSeek 的印象还停留在“价格屠夫”。确实，在 2025 年初，DeepSeek 部分模型 API 价格只有 OpenAI 同类模型的几十分之一，甚至低到让开发者怀疑“是不是少看了一个零”。

这次调价之所以引发热议，主要有三点：

- 调价幅度看起来不小：社区开发者对比账单发现，部分未命中缓存场景的输入价格和输出价格出现接近翻倍的变化。
- 但绝对价格仍然很低：以每百万 tokens 为单位，调价后的价格仍处于行业低位，远没有到“用不起”的程度。
- 缓存命中的价格依然便宜：如果你能复用上下文，成本仍然可以被压得很低。

换句话说，这次调价更像是早期极端低价向可持续运营的一次校正，而不是从便宜突然变成昂贵。它动的是“用户已经习惯的低价预期”，而不是真正意义上的高价。

## 二、大模型推理不是“水电”：算力成本到底贵在哪


要理解涨价，先要理解大模型 API 的成本结构。很多人把 API 当成水电，插上就能用；但大模型推理是典型的“重资产 + 持续消耗”业务。

拆开看，一次看似简单的 API 调用，至少要经过这些环节：

1. 请求到达网关，进行鉴权、限流、路由。
2. 输入 token 被切分、编码，进入模型计算。
3. 如果是长上下文，KV cache 需要占用大量显存，缓存命中和未命中的成本差异极大。
4. 模型以自回归方式逐 token 生成输出，输出往往比输入更贵。
5. 推理结果再经过安全过滤、监控和日志，返回客户端。

DeepSeek 的 MoE 架构虽然总参数很大，但每个 token 只激活一部分参数，训练和推理效率比同尺寸稠密模型高。官方曾披露 DeepSeek-V3 训练成本约 557.6 万美元，使用 2048 块 H800 GPU 训练约两个月。这是一个非常亮眼的数字，但它只是训练成本。服务上线后，推理成本是持续发生的：GPU 集群要折旧，机房要电，带宽要钱，工程师要维护，还有安全合规和故障恢复。

更关键的是，输出 token 的成本天然高于输入。输入可以批量预填充，输出却要一步步解码，且无法提前并行人。这也解释了为什么输出价格通常比输入贵很多：不是厂商随意加价，而是物理约束。

## 三、低价竞争的隐性代价：便宜背后谁在买单


低价当然让用户开心，但长期低价并不是没有代价。当价格低到无法覆盖成本时，代价往往会以另一种方式回到用户身上。

常见的隐性代价包括：

- 服务质量不稳定：排队、限流、首 token 延迟升高，高峰期模型响应变慢。
- 产出质量波动：为了压成本，部分服务可能减少采样步数或缩短上下文窗口，影响复杂任务的稳定性。
- 开发者毛利被击穿：很多创业产品基于低价 API 设计定价，一旦上游涨价，自己的商业模型就会承压。
- 研发不可持续：API 收入无法覆盖推理成本时，厂商只能降低迭代频率，或减少免费额度。

如果把 AI API 看成一个生态，长期低于成本价竞争，最终伤害的不只是厂商，还包括依赖它的开发者。适度涨价并不只对厂商有利，它也能让服务变得更可预期。

## 四、AI 商业化的必经之路：从补贴到可持续


过去几年，AI 行业确实经历了一轮“补贴换市场”。2023 年 OpenAI GPT-4 发布时，API 价格高得让不少个人开发者望而却步。随后国内外厂商用降价、开源、免费额度争夺开发者心智。DeepSeek 是其中的代表之一。

但互联网的补贴逻辑，不能完全套在 AI 上：

- 互联网产品的边际成本接近零，多一个用户几乎不增加成本。
- 大模型 API 的边际成本由算力决定，多一次调用就多一份电力和显存消耗。
- 规模越大，绝对成本越高，除非推理效率持续优化，否则不会出现“越卖越便宜”的自然趋势。

更健康的商业化方向，不是一刀切涨价，而是定价分层：

- 缓存命中、错峰调用可以更便宜。
- 高并发、低延迟的企业级需求可以适当溢价。
- 开源权重继续降低自部署门槛，API 服务则按照服务质量收费。

对用户来说，涨价的真正信号不是“厂商变黑了”，而是 AI 服务正在从补贴期走向可持续运营。长期看，单位智能成本仍然在下降，只是下降曲线不会一直像过去两年那么陡。

**最后，留三条冷思考：**

1. 看绝对价格，不看涨幅百分比。涨 100% 听起来吓人，但基数极低时，绝对成本才是关键。
2. 把涨价当作成本优化信号。缓存复用、缩短上下文、减少无效输出、模型路由，往往比骂厂商更能省钱。
3. 关注单位智能成本趋势。单一厂商调价会波动，但行业整体仍在通过芯片迭代、架构优化和推理加速降低成本。

AI 服务的定价没有原罪，只有成本、效率和选择。与其纠结“涨没涨价”，不如问一句：这个价格下，它还能不能稳定地帮你解决问题。
