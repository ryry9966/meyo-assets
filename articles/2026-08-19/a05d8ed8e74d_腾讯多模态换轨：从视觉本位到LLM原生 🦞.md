最近，36kr 报道了一条让大模型圈很关注的消息：姚顺雨在腾讯多模态路线重整中，方向明显向梁文锋代表的 LLM 原生路线靠拢，同时减少对李飞飞式视觉中心路线的依赖。这不是简单的人事变动，而是一次技术底座的重新选择。本文从技术分歧、成本账、组织变化与行业影响四个角度拆解。



## 1. 两条路线，到底在争什么？

李飞飞路线与梁文锋路线的核心分歧在于：多模态智能应该以视觉先验为中心，还是以语言模型为中心。

- 李飞飞路线：视觉先验优先
  - 从 2009 年 ImageNet 数据集掀起深度学习视觉革命，到后来的空间智能与 World Labs，这条路线始终坚持“让机器先看懂物理世界”。
  - 典型做法是强视觉编码器再加生成模块，强调 3D 一致性、空间关系与视频生成。
  - 数据上偏好图像、视频、深度、点云，采集和标注成本非常高。
  - 优势在于视觉细节、物理交互、机器人等场景的理论上限更高。

- 梁文锋路线：LLM 原生优先
  - DeepSeek 系列用 MoE 稀疏架构、GRPO 强化学习与低成本训练推理，证明了工程效率的重要性。
  - 多模态做法更偏向把图像、视频统一 token 化后接入 LLM，让语言模型主导跨模态推理。
  - 数据上以文本为主，视觉部分只做轻量对齐，模型主干可以直接复用现有 LLM。
  - 优势是训练和推理成本低、端到端推理强、开源生态活跃、产品落地周期短。

一句话总结：李飞飞路线更关心“物理世界如何被看见”，梁文锋路线更关心“如何用低成本把视觉变成语言模型可读的 token”。



## 2. 姚顺雨的选择：技术基因与成本账

姚顺雨长期在 LLM 训练、强化学习与推理优化方向积累。从这个背景看，路线靠拢梁文锋并不意外。

- 技术基因匹配
  - LLM 原生多模态更依赖 RL、数据工程、分布式训练，这些正是他的技术舒适区。
  - 传统视觉路线需要庞大的 CV 学术团队与 3D 视觉工程团队，组织更重，协同成本更高。

- 算力与数据账
  - 高质量视频-文本对、3D 标注数据稀缺，采集成本远高于文本语料。
  - 以 DeepSeek-V3 为例，671B 参数的 MoE 模型训练成本约 557 万美元；而很多视频生成或空间智能模型单次训练成本可能是这个数字的数倍甚至数十倍。
  - 复用 LLM 主干做多模态，可以把预算集中在强化学习和推理优化上，单位参数产出更高。

- 产品节奏
  - 腾讯内部需要把多模态能力快速接入元宝、混元、广告、游戏、文档等场景。
  - LLM 原生模型更容易先跑通“输入一张图或一段视频，输出结构化文本或决策”这类任务。
  - 空间智能、世界模型更偏长期愿景，短期难以形成可度量的产品指标。



## 3. 腾讯多模态正在发生什么？

路线调整不会停留在口号，它会落到组织、架构、训练和产品四个层面。

- 组织层面
  - 独立视觉大模型团队可能被拆分，一部分并入 LLM 团队，一部分转向视觉 tokenizer 和生成模块。
  - 考核指标从“视觉任务刷榜”转向“跨模态产品指标 + 推理成本”。

- 架构层面
  - 统一视觉-语言 tokenizer 的优先级上升，独立超大视觉编码器的地位下降。
  - MoE 多模态主干与视觉专家路由会更常见，减少对单一视觉编码器的依赖。

- 训练层面
  - 从监督微调为主，转向 RLHF 或 GRPO 的跨模态推理优化。
  - 课程学习可能被更多使用：先让模型学好文本推理，再逐步加入视觉 token。

- 产品层面
  - 优先落地多模态文档理解、UI 自动化、视频摘要、代码辅助等 LLM 相关场景。
  - 空间智能与 3D 世界模型可能降级为前沿探索，不再占用核心资源。



## 4. 行业影响：多模态进入“LLM原生”阶段

腾讯的转向不是孤立事件。Google Gemini、OpenAI GPT-4o、Qwen-VL 等头部模型都在做类似选择。

- 多模态重心从“生成像素”转向“生成决策”
  - 市场更愿意为“看图回答问题、看视频做总结、根据截图操作软件”付费。
  - 纯粹图片或视频生成竞争激烈，但商业闭环更依赖 LLM 推理能力。

- 成本敏感型厂商会加速跟进
  - DeepSeek 证明可以用较少的卡训练高性能 LLM，多模态路线同样会复制这套逻辑。
  - 开源社区会优先接受轻量、可微调、可本地部署的 LLM 原生多模态模型。

- 李飞飞路线不会消失，但位置在变化
  - 视觉编码器、视频生成、3D 理解会被吸收为 LLM 的外部模块或插件。
  - 空间智能和世界模型更可能是下一阶段主题，而不是当前产品竞争的主战场。



最后，三点冷思考：

1. 不要简单站队。技术路线没有绝对对错，只有阶段匹配。当前 LLM 原生多模态更契合成本与产品需求，但视觉先验仍是长期天花板。
2. 从业者可以重点补 RL、推理优化、MoE 训练，但不要丢掉视觉基础。未来竞争力在“跨模态对齐 + 低成本推理”的结合处。
3. 判断模型好不好，别只看多模态 benchmark 或论文标题，要看单位 token 成本、实际任务完成率与产品留存。这才是腾讯这次转向的底层逻辑。
