2025 年安全厂商 Imperva 发布的《Bad Bot Report》显示，2024 年自动程序流量占其监测样本总流量的 50.4%，人类流量为 49.6%。这是有统计以来机器流量首次越过半数红线。有人把这个现象称为“三体流量时代”——人类、善意机器、恶意机器共同构成互联网的流量生态。

先说明一点：这个“50%”不是对全球互联网的精确普查，而是基于大量客户流量样本的统计结果。不同行业、不同站点口径差异很大，电商大促期间机器流量可能更高，以用户登录为主的工具产品可能低一些。但它揭示的方向是确定的：自动化已经成为互联网请求的主要来源。



## 一、先分清：机器流量不是一种东西



很多人听到“机器流量超过人类”，会直接联想到“网上全是僵尸号”。实际上，机器流量（bot traffic）是一个大筐，里面至少装着三类完全不同的对象。

1. 善意 bot：搜索引擎爬虫、站点可用性监控、RSS 抓取、CDN 健康检查、授权 API 调用。它们通常不伪装人类，会遵守 robots.txt，并在 User-Agent 中表明身份。Googlebot 就是最典型的一类。
2. 中性/基础设施流量：云原生环境里的探针、日志回传、微服务之间的 health check、Webhook、CI/CD 自动部署产生的请求。它们不算攻击，但也不产生内容消费或交易。
3. 恶意 bot：撞库、暴力破解、无授权爬取、抢票刷单、点击欺诈、短信轰炸、DDoS 攻击，以及无视 robots.txt 的 AI 训练爬虫。它们往往伪装成浏览器，并使用住宅代理池绕过 IP 限制。

一个容易误判的点是：这三类流量在日志里可能长得很像。一个来自云厂商 IP 的请求，可能是搜索引擎爬虫，也可能是某个抢购脚本。没有标签体系和风控策略，管理员根本分不清对面到底是谁。

## 二、为什么偏偏是现在越过 50%？



机器流量不是刚刚出现。过去十年，它在总流量中的占比长期在四成上下徘徊。2024 年越过半数，不是某一天爆发，而是几股技术力量叠加后的统计确认。

1. AI Agent 与 LLM 爬虫大规模上线。OpenAI 的 GPTBot、Anthropic 的 ClaudeBot、PerplexityBot、CCBot 等为了训练模型和实时检索，持续抓取公开网页。这些程序访问频率高、遍历面广，而且通常不产生广告展示或购买转化。
2. API-first 改变了流量结构。用户打开一个短视频 App，只滑动一次，但客户端可能同时发出十几到几十个 API 请求：推荐、埋点、广告竞价、状态轮询、日志上传。人还是那个人，请求数却被放大了一个数量级。
3. 黑灰产工具链成本大幅下降。住宅代理、验证码打码平台、浏览器指纹伪造、无头浏览器集群都可以按小时租用。过去需要一个团队才能维护的恶意 bot，现在个人也能快速部署。
4. 物联网与智能设备静默上传。摄像头、车联网终端、智能电表、工厂传感器持续向云端上报心跳和状态数据。它们不是传统网页机器人，但确实贡献了大量机器流量。

所以“机器流量超过人类”，本质上不是人类变少了，而是自动化变得更便宜、更普及，也更难被忽略。

## 三、三体流量时代，真正改变的是什么？



“三体流量”这个比喻，指的是人类、良性 bot、恶意 bot 三方互相挤占、互相伪装、互相依赖。它带来的不只是安全告警，而是一整套旧指标开始失真。

1. UV、PV、DAU 的解释力下降。如果一个内容页面 60% 的 PV 来自爬虫，那么“阅读量 10 万”可能只有 4 万来自真人。广告计费、影响力评估、融资数据都需要重新校准，否则很容易把爬虫热度当成真实需求。
2. 安全策略不能一刀切。过去很多站点看到可疑流量就封 IP、拉黑 User-Agent。但今天如果把 GPTBot 和搜索引擎一起封禁，可能失去来自 AI 助手的推荐入口；如果放任不管，又可能被抓爆带宽、数据库和 API 配额。
3. 运营成本被不可见地推高。机器流量会消耗 CDN 带宽、云函数调用、数据库连接。一次大规模 AI 爬取甚至可能造成类似 DDoS 的压力。Cloudflare 等厂商已经在产品中加入 AI 爬虫分类和单独控制选项，说明这已经从边缘问题变成平台级问题。
4. 流量造假与内容生态形成反馈循环。恶意刷量会抬高热门榜，热门榜又引导真人点击，真人点击再吸引更多 bot，形成污染循环。平台如果不把三体流量拆开治理，推荐系统会慢慢被噪声淹没。

换句话说，三体流量时代最重要的变化是：流量不再等于人，真实用户行为变成了一种需要额外识别和保护的稀缺资源。

## 四、冷思考：普通人和开发者能做什么？



机器流量超过人类，不等于“互联网要完”，而是提醒我们要把自动化治理当作基础能力。以下是三条更务实的建议。

1. 数据使用者：默认任何公开统计都可能含机器水分。看趋势时优先看“去重后的真实用户行为”或“转化率”，而不是原始 PV。例如做投放复盘时，如果落地页 PV 很高但转化极低，先查机器流量占比，再决定是否调整素材。
2. 站点与 API 维护者：不要只靠 robots.txt。robots.txt 是约定，不是防火墙。敏感数据、登录接口、搜索 API 需要鉴权、限流、设备指纹和异常行为检测。对 AI 爬虫应明确策略：允许抓取哪些目录、限速多少、是否要求标注来源。
3. 普通用户：遇到验证码、滑块、设备验真时，抗拒心理可以小一点。它们通常会拦住撞库和抢单脚本。公共网络下不要随意暴露 API token、Cookie；账号一旦被 bot 接管，你也会成为机器流量的一部分。

最后一句冷思考：互联网从未真正“只属于人类”。过去是服务器、客户端、缓存节点在响应请求；现在是爬虫、Agent、自动化脚本在参与流量生产。三体流量时代真正稀缺的能力，不是把机器赶出去，而是学会给流量标注身份、设定边界并动态定价。
