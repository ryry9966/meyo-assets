今年逛完 WAIC，最大的感受不再是“这 demo 好炸”，而是“这玩意儿下个月真能部署到我产线里”。展馆里少了很多炫技，多了一堆穿着工服来聊部署、聊数据、聊 ROI 的工程师。36氪把全场逛透，总结出五个很多人还在争论、但前线工程师已经用脚投票的非共识走向。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-24/6ab11e6c1b0f4ef8.png)

## 1. 大模型收起“屠龙刀”，开始认真切菜
2025 年大家还在争论千亿参数是不是太少，2026 年展台上最热闹的已经是 7B-13B 的微调方案。厂商不再亮出参数量，而是在大屏上滚动着延迟、准确率和“可部署的最小 GPU 数”。

- **从写诗到写 SOP**：去年观众最爱问“你会不会写十四行诗”，今年问的是“能不能根据 GMP 规范自动生成清洁间操作规程”。某制药企业甚至带着自己的 SOP 文档现场要求直接 RAG，效果不达标就不入场。
- **垂域模型成了硬通货**：法律、医疗、金融监管类的小模型扎堆出现。它们的瓶颈不在算法，而在高质量合规数据的获取。一家银行科技子公司用 7B 模型微调后替代 GPT-4 级大模型，客服意图识别准确率只降了 0.3%，推理成本却降至 1/20，一年能省下几百万。
- **RAG + Fine-tuning 变成默认配装**：几乎没有团队只靠 prompt 打天下了。向量数据库、召回策略、重排序模型、幻觉检测模块，像乐高一样被拼成流水线。

## 2. 人形机器人集体“下凡”，但离客厅还很远
今年 WAIC 专门划了一块“具身智能实景挑战区”，十多家公司的人形机器人不再跳舞，而是闷头拧螺丝、贴标签、搬物料。观众看久了甚至会忘记它们是机器人，以为是哪个技校的实训现场。

- **方案逐渐收敛**：旋转关节 + 行星滚柱丝杠的线性执行器成为主流，力控和触觉传感器因为工艺突破，成本比去年又降了近 40%。但灵巧手依然是老大难，绝大多数还是三指气动夹爪，能够稳定抓取不规则物体的五指方案只出现在实验室里。
- **落地边界极度狭窄**：所有跑得顺的 demo 都在结构化环境——灯光恒定、地面平整、物料摆放位置误差小于 3 毫米。一到真实工厂那种灰尘、振动、光照突变的环境，失败率就陡升。厂商的口径也变得异常冷静：“三年内别指望进家庭，我们能先把汽车总装线里的线束插接做好就该烧高香了。”
- **数据采集靠人“影武”**：动作捕捉服 + VR 遥操作仍然是获取训练数据的主要手段，号称“一天五百条，条条都是泪”。你看到的每一个流畅操作，背后可能都是一位操作工在闷热车间里反复示范。

## 3. Agent 终于学会了用工具，而不仅仅是说话
如果说 2024-2025 年 AI 学会了聊天，那 2026 年的 WAIC 宣告它开始正经“干活”了。Agent 框架几乎出现在所有软件和云服务的展位上，大家终于意识到：这个世界不缺一个更好的 chatbot，缺的是一个能自己查数据库、调 API、发邮件的数字员工。

- **核心循环：Plan → Execute → Verify**。与单纯的函数调用不同，现在主流的 Agent 架构（ReAct 变种，Plan-and-Execute 模式）会在执行前先生成多步计划，每完成一步就观测环境反馈并自我修正。例如一个电商运营 Agent 接到“分析上月退货率上升的原因”后，会自己写 SQL 查订单库，连接数据仓库做维度归因，发现是某款包装在运输中破损率高，然后自动抓取客服投诉关键词，最终生成带图表的报告和改进建议。
- **工具链开始标准化**：OpenAPI 驱动的 function calling 普遍增加重试机制和异常处理，向量化的工具选择器能把数千个工具压缩到语义空间里快速匹配。今年一个有趣的现象是“工具编排员”成为新岗位，他们的工作不是写代码，而是给 Agent 画工具调用流程，然后不断修改 prompt 和审批节点。
- **信任鸿沟依旧巨大**：长任务链一旦超过 5 步，整体成功率仍会掉到 70% 以下。所以多数 Agent 产品只被用在“建议-辅助”模式，最终确认必须由人点击。展商自嘲：“这不是 AI，是 RPA 的二次投胎。”

## 4. 数据飞轮转起来了，但转速和动静都比想象中小
“数据飞轮”这个词在展馆里出现的频率高得离谱，可如果你拉住一线的工程师问真实情况，他们的表情会瞬间变得微妙。

- **企业数据是“矿石”不是“石油”**：多数企业 ERP 里的数据脏乱差，字段缺失、编码不一致、时间戳错误，清洗成本高得吓人。一家做工业缺陷检测的公司说，他们花 3 个月采集的产线图像，真正能用的不到 40%，其余全因光照变化或标注歧义被丢弃。
- **隐私顾虑掐住燃料管**：客户不愿把核心数据上传公有云，飞轮转不起来。于是联邦学习和边缘 AI Box 成了热词——让模型在各工厂本地用少量数据增量训练，只回传加密梯度，不碰原始数据。但带宽开销和异构算力又成了新坑。
- **合成数据救人，也添乱**：医疗影像公司用 200 例真实病灶加上 GAN 生成的 800 例合成数据，把敏感度从 86% 提到 93%，但标注医生硬是又逐张复核了一遍合成图，怕混入“不可能的病灶纹理”，结果工作量反而翻倍。工程师苦笑：“这哪是数据飞轮，分明是人工飞轮。”

## 5. 资本冷下来，工程化却焊上了翅膀
前两年展馆里挤满投资人，拿着计算器问“你们估值怎么算”。今年他们问的是“部署要几个人？模型一周崩几次？监控告警做了没？”这种问题听起来没那么性感，却代表着 AI 真正进入工业化的标志。

- **MLOps / LLMOps 供应商遍地开花**：模型版本管理、Prompt 版本回滚、推理管道监控、漂移检测、A/B 测试框架……这些过去只有大厂才玩得转的东西，如今被做成 SaaS 或私有化套件，小团队也能用。
- **运维成本被严重低估**：一个汽车零部件厂引入 AI 质检，算法公司拍胸脯保证 99% 准确率。一上线，车间早晨和傍晚的灯光变化导致误报率飙升到 15%，产线差点停摆。最后靠一个三人运维小组，每天调阈值、更新素材库、重训小模型，花了两个月才稳住。这笔“工程化负债”在签合同前几乎没人算进去。
- **真正的壁垒不在模型**：展会上一个做电网巡检的初创公司说得很直白：“大模型我们直接用开源的，调几天就能到 90% 准确率。但剩下的 9%，需要懂电力设备和导线舞动的复合团队蹲现场半年，这种 know-how 根本抄不走。”

## 🦞 RY 哥的冷思考：三条给一线决策者的工程化建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-24/e3028bf10f0a2d7e.png)

1. **把 80% 的预算留给集成、监控和运维**。模型本身越来越便宜，真正烧钱的是把它无缝植入老旧系统、打通数据孤岛，以及上线后无休止的版本迭代和异常处理。签合同前咬着 TCO（总拥有成本）不放，别让 demo 骗了你的 CFO。
2. **先建“AI 就绪”团队，再谈 AI 战略**。你需要的不是三个算法博士，而是一个懂业务痛点又说得清技术边界的 AI 产品经理，外加两三个能写 pipeline、搭监控、处理脏数据的 MLOps 工程师。组织能力不匹配，再强的模型也只是会议室桌上的花瓶。
3. **给所有自动决策系上缰绳**。不管 Agent 多聪明，金融交易、医疗诊断、法律文书等高风险领域必须保留 Human-in-the-loop 强制确认节点。设计时就默认 Agent 会在第 N 步跑偏，然后反推需要多少护栏。不要等事故上了新闻才想起加按钮。

逛完这一届 WAIC，最大的真理其实是：**AI 不再是一种魔法，而是一套新型生产资料的开箱工具**。能把它用到什么程度，不取决于模型多聪明，而取决于你的工程化肌肉有多结实，以及你愿不愿意去清理那坨积累了二十年的企业数据。
