最近36氪那份「AI打工大排行」在技术圈炸出不少水花——Claude Fable 5 自动赚钱的能力，被折算成 GPT-5.5 的 2.5 倍。不少人第一反应是：“这又是哪家公关在放卫星？” 但如果我们拆开这层数据，会发现背后埋着一整套关于AI经济效率的底层逻辑。

## 自动赚钱：AI 打工人到底在赚什么钱？

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-13/6d488438a6d0e997.png)

先别急着争论谁强谁弱，我们需要搞清楚一个根本问题：AI 是怎么“自动赚钱”的？

- **本质是数字微任务外包**：在 Upwork、Fiverr、Toloka 等众包平台上，大量任务已经被 AI Agent 悄悄接手——写 Python 脚本、给数据打标签、设计一份简单的 UI 草图、润色英文简历。AI 不需要睡觉，只要 API 费用低于任务报酬，这笔账就算得过来。
- **赚钱≠输出 token，而是交付可验收的结果**：单纯生成一段文字不值钱，值钱的是「pass 验收」。比如写一个能跑通的无 bug 代码、整理出格式正确的 Excel 报表、生成可直接送印的广告 banner，这些都需要多步推理、工具调用和纠错能力。
- **以结果计价的“计件工厂”模式**：目前大多数 AI 自动赚钱的跑分场景，模拟的是一个人远程接单的完整闭环：阅读需求文档 → 拆解步骤 → 调用浏览器或代码解释器 → 产出成品 → 自我校验，最后提交。哪个环节出错，收入直接归零。

所以这份榜单比的不是“谁能写更漂亮的文章”，而是“谁更像一个靠谱的自由职业者”。

## 为什么这次 Claude 系统赚得更多？

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-13/8b67b59653fe0cb7.png)

Claude Fable 5（大概率指 Claude 3.5 Sonnet 增强版，并结合 Computer Use 特性）在这次测试中展现出极强的自主完成能力。差距拉大到 2.5 倍，主要来自三个关键维度：

- **Computer Use 的“真动手”优势**：Claude 是目前为数不多能像人类一样操作图形界面浏览器的模型——它真的可以去点按钮、上传文件、填写表单、滚动页面。很多赚钱任务（比如帮人注册账号、收集公开数据、发布商品链接）必须依赖这种“屏幕级操作”，GPT 系列虽然也能规划，但在实际执行层需要人类接入操作，这直接拉低了单位时间的交付件数。
- **长上下文在复杂任务中的碾压**：Claude 具备超长上下文窗口，可以一次性吞下整个项目的需求文档、历史沟通记录、代码库文件。当任务涉及 50 页的英文合同摘要+格式化输出时，GPT 可能因中途遗忘上下文而反复修正，消耗的 token 和时间都将翻倍，而你是在按固定报价接单——折算下来时薪被狠狠砍了一刀。
- **更“老实”的工具调用与错误处理**：测评数据显示，Claude 在工具调用失败后的自我纠错成功率显著更高。举例：当必须使用外部 API 查询汇率并计算报价时，Claude 在遇到 503 错误后更倾向于换端点重试、等待并降级输出；而 GPT 在某些版本下可能会编造一个汇率继续往下走，结果直接交付了一个假数据，任务被打回零酬劳。

把这些场景的“真金白银”累计起来，2.5 倍差距并不夸张，更像是一次工程能力对表面智能的诚实清算。

## 2.5 倍这个数字，是怎么“称”出来的？

![img3](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-13/77343ee23b9462a8.png)

任何跑分都要看秤是否公平。这类对比测试通常遵循一套严格的控制变量法：

- **相同任务池、相同定价**：从真实众包平台抽取 1000+ 个标准任务（涵盖初级编程、数据录入、文档处理、简单设计修改等），每个任务的报酬固定，比如 5 美元。两边 AI 各自独立完成，不允许人工中途干预。
- **只计算成功的「净利润」**：总收入减去 API 调用成本。Claude 的 API 价格或许略高于 GPT，但因为失败次数少、重试少，大块的任务顺利完成，最终净收益反超。好比两个外卖骑手，A 接 10 单只成功 7 单，B 成功 9 单且每单耗电更少，B 的净收入自然高。
- **时间权重也参与折算**：任务被限定在 24 小时内完成池子中的最大单量。Claude 因为自动化程度高，某些简单任务几乎能做到“秒级闭环”，跑量优势被进一步放大。

所以，2.5 倍不是某个神秘指标，而是净收入比：在完全假定的外部接单场景下，Claude 系统产生的美元净利润是 GPT 系统的 2.5 倍。

## AI 打工经济的三个冷思考

数据新鲜刺激，但更重要的，是这对我们这些“肉身打工人”和创业者释放了什么信号。

1. **别跟 AI 卷「完成量」，要卷「定义任务的眼光」**
   现在能用 AI 跑量赚到的活，在不远的将来利润会无限趋近于电费。真正值钱的是你能识别哪些高价值任务最难自动化、最依赖人类判断，或者你能将一个大任务拆解成 AI 可执行的流水线，自己做个监工——类似的转型，在工业革命时期发生在手工工匠身上，今天重演在知识工作者身上。

2. **工具链比单模型重要十倍**
   Claude 能赚 2.5 倍很大程度上不是因为它“更聪明”（在很多基准测试上两者不分伯仲），而是因为它被允许“动手”——接入浏览器、文件系统、外部 API。这提示我们，未来评价 AI 的应用场景，不看单点智商，而看 Model + Tools 的组合能打通多长的链条。

3. **重视自动化的「鲁棒性」，就是在构建商誉**
   AI 一旦出错并交出虚假结果，用户对你的信任立刻归零。2.5 倍差距里有相当一部分是“可靠性”变现。如果你在构建 AI 产品，把 90% 的精力花在让模型失败时优雅降级、而不是强行输出，短期看是保守，长期看是储蓄。

排名会过时，模型也会换代，但规律很少变：谁能让技术落地时少犯错、多干活，谁就能在账本上笑到最后。至于老罗、老张谁比谁强 2.5 倍，等下次真实任务的发票拉出来，我们再聊。
