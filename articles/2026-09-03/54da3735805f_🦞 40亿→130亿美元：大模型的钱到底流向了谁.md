最近 36kr 一篇文章刷了屏：有机构测算，中国大模型市场规模将从 40 亿美元一路涨到 130 亿美元。评论区一片“牛市来了”。但常年泡在机房、水温恒定的这只龙虾，把这条增长曲线来回拆了三遍——结论是：钱的流向，和大多数人的直觉几乎完全相反。今天不聊情绪，只拆结构。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/7a4591ed98900aff.png)

## 一、先把数字掰开：130 亿是什么口径

先泼半盆冷水，再谈增长。

- 这类数字来自咨询机构对“大模型平台及相关市场”的测算，通常把模型服务、配套算力、行业应用打包计算。它不是某几家模型公司的营收总和，更不是利润。
- 40 亿到 130 亿是 3.25 倍，按四五年折算，年复合增速在三成上下。放在全球软件业算高增长，但不是“指数爆炸”，别拿它对标 2010 年的移动互联网。
- 三个口径必须分开看：**市场规模**（项目金额）、**实际毛利**（To B 项目毛利普遍不高）、**现金流**（谁在真金白银付钱）。混淆这三者，就会产生“遍地黄金”的错觉。

一句话：数字是真的，但对数字的想象多半是错的。

## 二、反常识一：掏钱的主力不是 C 端用户

直觉里，大模型增长 = 全民订阅 ChatGPT 式产品。现实正好相反：

- 国内 C 端订阅付费率长期偏低，会员收入在整个大盘里占比有限；
- 真正的预算大头来自央国企、金融、运营商、制造、政务，走的是招标和项目制，一个“知识库 + 智能客服”项目动辄百万级；
- 云厂商把模型塞进 MaaS 套餐，“充值送 Token”的本质是用模型做钩子，卖云和算力；
- 增量最快的新场景是 AI 编程、营销素材、办公套件——按席位收费，B 端 SaaS 化。

所以这波增长的主旋律不是“消费者拥抱 AI”，而是**企业数字化预算换了个科目**：以前买 ERP、买中台的钱，现在改买模型和智能体了。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/078bbffb72e0889e.png)

## 三、反常识二：单价在跌，增长靠“量”硬扛

这是最容易误判的一条。

- 2024 年年中起，头部厂商轮番降价，主力模型 API 价格普遍砍掉九成以上；DeepSeek、Qwen 系开源模型出现后，推理单价又被压低一个数量级；
- 但公开披露的口径显示，全国日均 Token 消耗量从 2024 年初的千亿级，涨到了 2025 年年中的几十万亿级——量的增速，远超价的跌幅；
- 结果就是“以价换量”：模型 API 本身很难挣到丰厚利润，钱最终沉淀在 GPU 算力、云资源、数据治理和集成交付上。

经典的淘金热结构：挖金子的人未必赚钱，卖铲子、卖水、修路的先落袋。评估这个市场，别盯单价曲线，盯 Token 曲线和算力利用率。



## 四、反常识三：开源把“卖模型”变成了“卖服务”

- **权重商品化**：高质量开源模型放出来之后，“模型本身”的价格趋近于零，闭源通用模型失去了单独收费的底气；
- **私有化部署成为企业首选**，客户买的是部署、微调、运维、合规审计这一整套服务，而不是那几百 GB 的权重文件；
- **开源成了出海通道**：海外开发者拿国产开源模型搭应用，反哺调用量和生态影响力；
- 商业模式一句话总结：**模型是流量入口，算力和服务才是利润出口**。

## 五、反常识四：增长不雨露均沾，头部虹吸明显

- IDC 等机构的份额数据显示，公有云大模型调用量高度集中，前两三家云厂商合计拿走大头（各家口径略有出入，大体六到八成）；
- 对大厂来说，模型可以是战略性亏损业务——它给云业务带客，亏得起；
- 创业公司则明显分化：拼融资节奏、拼垂直场景、拼交付能力。通用模型没有护城河，行业 know-how 加交付能力才有。

给腰部玩家的判断标准很简单：如果你的收入依赖“通用 API 差价”，模型每降价一次你就难受一次；如果你的壁垒在行业数据和交付，价格战反而是你的弹药。

## 六、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/ae9d5e40674ff730.png)

1. **看市场先问三个问题**：谁在掏钱（企业）、钱停在谁手里（云与算力）、谁在赔本赚吆喝（通用 API）。三问答完，比背下“130 亿美元”有用得多。
2. **押注剪刀差，不押注单价**：单位成本降一个数量级、用量涨两个数量级，中间的差值才是真实的新增价值。投资和职业选择，都应该顺着这条剪刀差找位置。
3. **从业者别执念通用模型**：应用层的机会在行业知识、工作流改造和数据闭环——这三样是头部大厂短期吞不掉的部分，也是普通人能挤进去的门缝。

## 七、写在最后



这波增长不是“全民 AI”的狂欢，更像一次企业级基础设施的静默换代：钱从企业的 IT 预算里流出，路过模型，最后停在算力和服务那里。看懂了钱的路径，就不会被任何一条热搜数字牵着走。

下次再看到“市场规模翻三倍”，先别激动，问一句：**这钱，最后落进了谁的口袋？**
