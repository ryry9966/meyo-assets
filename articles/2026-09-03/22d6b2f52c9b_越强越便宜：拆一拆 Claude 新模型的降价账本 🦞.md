科技圈有一条反常识的曲线：手机一年比一年贵，大模型却一年比一年便宜。最近 Claude 发布新模型，媒体关键词很直白——更强了，也更便宜了。但如果只看到“强”和“便宜”两个词，就错过了真正有意思的部分：这背后是一整套训练方法、推理工程和商业策略的合谋。这篇文章把账本摊开，一笔一笔算。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/054a8f4c505630b8.png)

## 先对齐事实：这次更新到底改了什么

- **能力层面**：新模型主要在代码、长时程任务和 agent（智能体）能力上拉了一波。以 SWE-bench Verified 这个真实软件工程基准为例，中端模型开启扩展思考（extended thinking）模式后，解决率能到 70% 上下甚至更高——这个水平一年前只有旗舰级模型勉强够到。
- **价格层面**：更有意思的是价格表。2024 年 3 月，Claude 当时的旗舰 Opus 定价是每百万 tokens 输入 15 美元、输出 75 美元；如今的中端 Sonnet 档定价 3/15 美元，能力已经反超当年旗舰。入门档 Haiku 降到 0.8/4 美元，官方口径是能力对标上一代旗舰、价格约为它的十八分之一。
- **翻译成人话**：同样的预算，两年前只够“尝一口”的智能，现在可以拿去批量跑生产任务。

## 为什么 AI 能“越强越便宜”

降价不是厂商发善心，而是三条技术主线同时把成本曲线往下压：

1. **训练效率提升**。高质量数据配比、课程化训练和蒸馏技术，让更小的模型继承大模型的核心能力。蒸馏本质上是“老师做题、学生抄思路”——用大模型生成的高质量输出训练小模型，这是这两年各家小模型能力飙升的最大功臣。
2. **推理工程优化**。模型训完只是第一步，线上服务还有一整套省钱手艺：KV cache 优化减少重复计算、高并发批处理提高 GPU 利用率、量化压缩权重、投机解码加速生成。单个 token 的边际成本，每年都在实打实地下降。
3. **规模效应**。调用量越大，固定成本摊得越薄，单次推理越便宜，于是有底气降价；降价又吸引更多调用量。这是个正循环。

所以降价更像是成本曲线自然下移的体现，让利只是结果。这大概是科技行业里唯一一条“明年一定更便宜”的可靠曲线。

## 降价不是慈善：算一笔商业账

- **竞争压力是第一推动力**。2025 年初 DeepSeek 以极低的 API 价格入场，把“性价比”变成全行业的必答题；Google 的 Gemini、OpenAI 的小模型系列也都在同一价格区间贴身竞争。成本没降下来的厂商，根本扛不住这种价格战。
- **分层定价是标准打法**。注意一个细节：降价的通常是中端和入门模型，旗舰档价格基本纹丝不动。前沿能力永远保留溢价，中端走量摊成本，入门款负责圈开发者。
- **低价本质是获客成本**。开发者一旦把工作流、工具链和提示词资产搭在某家 API 上，迁移就不只是改个接口的事。今天少收的 API 费，明天用生态黏性赚回来——云计算厂商十几年前就玩过这套：S3 存储价格降到最初的几十分之一，剧本惊人地相似。



## 红利怎么接：能力下放后的真实变化

- **门槛在消失**。过去“调用顶级模型”是大厂研发预算才能干的事，现在个人开发者按量付费就能用。以入门档模型为例，一个日均几千次调用的客服机器人，月成本大概率低于一杯精品咖啡。
- **但总账要重新算**。Agent 场景有个反直觉的地方：一次任务可能包含几十轮工具调用，再叠加扩展思考消耗的推理 token，单次任务的 token 用量可能是单轮对话的 10 到 100 倍。单价降了一个数量级，消耗涨了两个数量级，账单照样起飞——起飞速度可能比你的 prompt 写得还快。“模型更便宜”和“你花得更少”是两件事。
- **几个实打实的省钱开关**：
  - Prompt caching（提示词缓存）：重复的系统提示词命中缓存后，读取成本最高省约 90%；
  - Batch API：对时效不敏感的任务批量跑，通常直接半价；
  - 模型路由：简单任务走小模型，复杂任务升级大模型，混合调度一般能砍掉一半以上成本。

## 怎么选：一个三档判断框架

与其追榜单，不如按任务类型分层：

1. **入门档（Haiku 类）**：分类、信息抽取、格式转换、简单摘要。特点是量大、单价低、容错高，错了重来也不心疼。
2. **中端主力（Sonnet 类）**：日常编码、RAG 问答、内容生成。性价比最优解，九成生产任务应该停在这一档。
3. **旗舰档（Opus 类）**：复杂推理、长程 agent 任务、硬核 debug。按需调用，别让它常驻默认配置。

方法论只有一条：拿 50 到 100 条你的真实任务做个小评测集，跑一遍效果、算一遍成本。数据不会说谎，榜单会。

## 收尾：三条冷思考

1. **盯总账，别盯单价**。单价下降是行业的曲线，总成本上升可能是你自己的曲线，agent 时代这两条线经常朝反方向走，做预算时要一起看。
2. **低价是竞争的结果，不是承诺**。今天的定价随时可能调整，架构上留好抽象层，别把业务命脉绑在某一家的价格表上。
3. **稀缺资源正在换手**。当“智能本身”越来越便宜，真正值钱的变成两样：知道该问什么问题，以及能判断答案好坏。模型降价降得越狠，人的判断力溢价越高。

说到底，“更强更便宜”不是魔法，是工程和商业共同踩出来的节拍。接住红利的前提，是先看懂节拍。
