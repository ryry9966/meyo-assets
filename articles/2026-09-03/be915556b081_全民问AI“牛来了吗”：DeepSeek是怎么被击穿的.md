行情最热的那几天，股民打开手机只干两件事：看盘，和问 DeepSeek。“牛市来了吗？”“现在该加仓还是减仓？”“帮我分析下这只票。”当这类提问以百万级并发砸向同一个对话框，那个熟悉的提示出现了——“服务器繁忙，请稍后再试”。36kr 把这一幕概括为“‘牛来’击穿 DeepSeek”。这不是段子，而是一次教科书级的压力测试：全民级突发流量，撞上了一门天生怕尖峰的生意。这篇文章拆两件事：算力是怎么被击穿的，认知又是怎么跟着一起被击穿的。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/0fba620954e2e41c.png)

## 一、“击穿”现场：一种很新的大促流量

这次流量尖峰和电商大促、抢票都不一样，它有三个更“毒”的特征：

1. **和行情强共振**。开盘、午后跳水、收盘复盘，提问曲线几乎同步于大盘分时图；行情越猛，提问越猛，情绪本身就是流量引擎。
2. **提问高度同质化**。不是一百万个不同的问题，而是几万人在同一分钟问“牛来了吗”。
3. **单次请求异常昂贵**。DeepSeek-R1 是推理模型，回答之前要先“思考”。你看到的两百字结论，背后往往是两三千 token 的隐藏思维链，全是 GPU 时间。

类比一下，它比 12306 抢票更难：抢票高峰里多数是“查询”，而大模型每一个请求都要现场生成。排队论里这叫到达率超过服务率——队列只会无限增长，系统唯一的选择就是限流、排队、报“繁忙”。

## 二、算力侧：大模型为什么天生怕尖峰

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/5b4e5c10c126677a.png)

- **自回归生成没有捷径**。模型每吐一个 token，都要把激活参数完整过一遍（V3/R1 是总参 671B 的 MoE 架构，每 token 激活约 37B）。输出一千 token，就是一千次前向计算，不存在“算完一次随便看”的红利。
- **显存墙限制并发上限**。KV cache 随上下文长度增长，长对话动辄吃掉数 GB 显存；一张卡能同时伺候多少路对话是有硬上限的，满了就只能排队。
- **峰值/常态比太狠**。日常流量平稳，行情日可能是日常的数倍到十倍；为了持续几天的尖峰常年备货 GPU，等于平时让机房烧钱。
- **供给刚性**。尖端算力卡的扩容周期以月计，而尖峰以小时计，供需在时间尺度上完全错配。

做个毛估估：假设一次 R1 问答消耗约三千输出 token，单卡批处理后的有效吞吐按千 token/秒量级算，一次问答约等于 3 GPU·秒；每天一百万次同质提问，就相当于几十张卡全天满负荷——这还只是“牛市话题”一个切片。更麻烦的是经济账：App 免费问答没有直接收入，成本全是真金白银的电费和折旧。免费的全国级热情，是基建的天敌。

## 三、认知侧：所有人问同一个问题，就会得到同一个答案



比服务器更值得担心的是大脑。把大模型当股神，至少要撞上四堵墙：

1. **知识截止与时效**。模型权重里的世界停在训练截止日；没接实时行情时，它对“今天”一无所知，但语气依然笃定。
2. **幻觉**。让它“预测明天大盘”，它会努力生成一个“看起来像分析”的答案——因为训练目标是让回答像样，不是让它承认“我不知道”。
3. **有效市场**。公开信息早已被价格消化，短期涨跌接近随机变量；LLM 擅长把已知信息讲得头头是道，不擅长掷骰子。
4. **同质化导致策略拥挤**（最隐蔽的一堵墙）。几十万人拿同一个模型问同一个问题，得到高度相似的观点，再做出趋同的买卖动作。个体看是“参考 AI”，群体看是一次由算法协调的羊群行为。

历史注脚：2023 年曾有媒体实验让 ChatGPT 按知名分析师的逻辑选股，五周涨幅大幅跑赢基金平均，标题传遍全网——但样本小、时点特殊、逻辑是事后整理。真正把机器学习用于投资的量化机构，用的是自有数据管道、风险模型、执行系统，加上对回测过拟合的十年警惕；和对话框里聊两句，完全不是一个物种。

## 四、工程侧的应对：三板斧与一个死结

- **限流与降级**。“服务器繁忙”本质是 load shedding：主动挡住部分请求，保住核心链路。听起来不优雅，但它是最便宜、最有效的止血手段。
- **推理优化**。MoE 稀疏激活、MLA 压缩 KV cache、FP8 量化、continuous batching、prefill 与 decode 分离——每一项都在压低单 token 成本。官方后来几次大幅调低 API 价格，本质是把这些工程红利释放出来。
- **分流**。开源权重让第三方云厂商托管同款模型，把溢出流量引到外部生态；API 端限速、限购也是自然结果。
- **死结**。以上手段能降本增效，却治不了“非付费尖峰”：全民情绪驱动的流量来得快、去得快、不付钱，任何商业模式都只能“扛一部分 + 挡一部分”。这不是 DeepSeek 一家的问题，是所有 to C 大模型的共同宿命。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/1f3cf69985286982.png)

1. **把大模型当“知识压缩器”，别当“未来预测器”**。它对已发生的公开信息做归纳、解释、写代码复盘很强；对明天的随机变量无能为力。任何“AI 说会涨”，先自动降级为娱乐内容。
2. **让它交出可核验的东西**。要来源、要日期、要数据出处；涉及真金白银，回到公告、财报、行情终端。可以让它当学习助手和纪律教练——比如帮你把止损规则写成代码——但别让它替你按按钮。
3. **学会读“服务器繁忙”这个信号**。一件事热到能击穿全国级算力，说明注意力已经极度拥挤；无论在算力市场还是资产市场，拥挤本身往往就是风险指标。免费的流行有代价，只是账单常以延迟和排队的形式支付。

下次牛市来的时候，DeepSeek 大概还是会忙。繁忙是它被问出来的；而你的决策质量，不该由一个对话框单独决定。
