据 36 氪报道，智谱的单月收入做到了约 9 亿元人民币，折算年化已站上百亿量级。放在两年前，“大模型六小虎”里谁能先把商业化跑通还是一桩悬案；如今智谱把“月收入”做到了同行“年收入”都难望其项背的位置。这杯敬自己的酒值得拆开看：钱从哪来？含金量几成？还能不能续杯？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/65c2e2e3f24289ff.png)

## 9 亿从哪来：大模型生意的三条“水龙头”

大模型公司的收入口径看着复杂，剥开其实就是三个水龙头：

1. **API / MaaS，按 token 计费**。开发者调用模型，按输入输出的 token 数付费，逻辑类似水电表：读一份长文档、生成一段代码，都在“走字”。输出单价通常高于输入；命中 prompt cache（上下文缓存）还能打折，鼓励重复上下文复用。这是本轮增长最快的部分，尤其是智谱面向海外的 Z.ai 平台。
2. **订阅套餐，面向个人开发者**。代表是 GLM Coding Plan 这类包月产品——以“一杯奶茶钱”的月费，把 GLM 接进 Claude Code、Cline 等 coding agent 工具。单价低，但用户量大、黏性强，是最便宜的用户教育。
3. **ToB / ToG 项目，私有化部署与行业方案**。政企客户买的是“模型 + 工程 + 交付”的打包能力，客单价高、回款周期长，是国产大模型公司的传统基本盘。

一个体感数字：一次复杂的 agent 编程任务，往往要几十轮连续调用，动辄消耗上百万 token。对话时代一个月用不完的量，agent 一晚上就能烧完。调用频次变了，收入曲线的斜率自然就变了。

## 为什么是现在：Agent 把“聊天量”变成了“烧卡量”

- **场景切换**。2023~2024 年模型主要被“聊”，2025 年开始被“用”。编程是公认的杀手场景：模型要读代码库、写补丁、跑测试、自我纠错，每一步都在消费 token。海外 Anthropic 的收入爆发同样由 coding 驱动，这条逻辑不分国界。
- **性价比杠杆**。GLM-4.6 主打编程与 agent 能力，API 价格定位在海外旗舰模型的几分之一。对预算敏感的开发者，“能力够用 + 价格便宜”就是迁移理由；对智谱，这是用利基场景撬动大盘的经典打法。
- **开源当获客漏斗**。从 ChatGLM 到 GLM-4.5 / 4.6，智谱持续开源旗舰模型。开发者本地跑通之后，上云付费便顺理成章走自家 API。开源少赚了“卖权重”的钱，换来的是全球分发渠道和开发者心智——“开源引流、云上变现”这条路，Meta 和 DeepSeek 都验证过。
- **低价的底气在 infra**。敢打价格战，前提是推理成本工程过硬：量化、批处理、缓存、集群利用率，每一项都直接改写毛利公式。价格战的表面是模型能力，底牌是 infra 能力。

## 9 亿的含金量：几个需要按住的“但是”

- **单月 ≠ 年度**。“月收入 × 12” 得到的是 run rate（年化运转率），是势能指标，不是财务确认收入，会随降价、竞争、大客户波动而变化。
- **收入 ≠ 利润**。大模型公司最大的成本项是算力：训练一次旗舰模型是万卡级别的投入，推理要持续租用或自建集群。行业里“收入暴涨、亏损同步暴涨”并不罕见，判断健康度要看毛利与现金流，而不是只看流水。此前公开报道口径下，智谱 2024 年全年收入还在个位数亿元量级——一年内跃迁到单月 9 亿，增速惊人，也意味着成本曲线在同步陡峭。
- **结构 ≠ 质量**。同样 9 亿，to G 项目收入与 API / 订阅收入的成色完全不同：前者确认慢、复购弱，后者现金流好但价格战惨烈。
- **坐标系放对**。年化百亿人民币约合十几亿美元，对比 OpenAI（年化约百亿美元级）、Anthropic（数十亿美元级）仍有量级差距；但在国内创业公司梯队里，这基本是断层领先的成绩。不必神化，也无需唱衰。



## 竞争棋盘：前面有巨头，后面有追兵

- **国内**：字节豆包背靠火山引擎，量大管饱；DeepSeek 以开源加极致性价比搅动市场；Kimi、MiniMax 各守自己的场景。“六小虎”的考题已经从“谁能活下来”换成了“谁能规模化赚钱”。
- **海外**：OpenAI、Anthropic、Google 占据品牌与生态高地，且都在持续降价，低价生存空间被不断挤压。
- **智谱的牌**：全栈自研与技术品牌、开源与商业双轨、已进入上市辅导阶段的资本通道。牌不差，但每张牌都有对手在研究反制打法。
- **真正的护城河**：模型能力的代差正在被快速抹平，长期壁垒更可能长在三个地方——成本工程（同等能力下更便宜的推理）、数据与客户飞轮（用得越多越好用）、迁移成本（企业工作流一旦嵌入就很难拔出来）。

## 冷思考：续杯之前，先看这三条

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/7251a79910c188d4.png)

1. **看收入先看结构**。把一次性项目收入和可复购的订阅 / API 收入分开算，再盯净收入留存率（NDR，Net Dollar Retention）：老客户的花销会自己长大，才是好收入。
2. **看增长先看单位经济**。token 均价的下降速度，是否快于单位推理成本的下降速度？如果“是”，增长越快、失血越多；如果“否”，规模才会从负担变成武器。
3. **给使用者的建议**。agent 时代工具的迁移成本很低，别把工作流锁死在单一供应商；按场景选模型——长文本、编程、多模态各有所长；别只看 benchmark 分数，拿自己的真实任务做 A/B 实测，比任何跑分都诚实。

9 亿是一杯值得敬的好酒，但这局牌才打到中盘。酒可以敬，账要接着算。
