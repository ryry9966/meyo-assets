前几天 36kr 一篇报道冲上热议：中国大模型市场规模，预计将从约 40 亿美元一路涨到 130 亿美元，几年时间翻三倍多。评论区不少人的第一反应是"风口来了，冲"。但如果把这组数字拆开看，你会发现这波增长的构成，和很多人直觉里的"人人都买 AI 会员"完全是两回事。今天就把这份数据掰开揉碎，看看钱从哪来、流向哪去、哪些指标才值得盯。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/d77f5c0ca4011180.png)

## 先校准口径：40 亿和 130 亿量的是什么

- **市场规模 ≠ 融资总额。** 融资是资本市场的钱，市场规模是客户真实付出的收入。前者看预期，后者看交付。
- 这里的"大模型市场"一般包含三块：**模型能力授权与私有化部署**、**MaaS**（Model as a Service，按 token 计费的 API 调用）、以及强绑定的**算力与交付服务**。
- 40 亿美元（约 300 亿人民币）听起来很大，但摊到几百家大模型相关公司，属于"市场很大，我很小"的经典场景——别把行业规模误读成个体利润。
- 130 亿是预测值，隐含年复合增速在三四成量级。放在软件行业算高速，但离"躺着数钱"还差得远。

## 第一推动力：不是聊天，是 token

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/c3558b284e9a3a61.png)

很多人以为增长来自"多了一个聊天机器人"，主力其实在 B 端推理消耗：

1. 2024 年国内 API 价格战后，主流模型单价降了一个数量级，但平台 token 消耗量出现数十倍增长。单价 × 用量 = 收入：分子跌、分母暴涨，总收入照样上扬。
2. 头部云厂商公开披露的日均 token 调用量，一年内从千亿级涨到数万亿级。背后是 AI 编程助手、智能客服、营销生成、办公 Copilot 在 7×24 小时不停地跑。
3. 换句话说，AI 正在从"演示品"变成"耗材"。耗材模式的健康度远高于一次性卖 license：客户用得越多付得越多，续费是自然结果，而不是销售每月打电话求来的。
4. 这也解释了为什么各家拼命压推理成本——KV Cache 优化、量化、MoE 稀疏化、投机解码。推理侧每省一块卡，都是在给价格战储备弹药。

## 钱的三条流向：谁在真正付费

| 流向 | 典型买家 | 特点 |
| --- | --- | --- |
| 私有化部署 | 金融、大型企业、政务机构 | 数据不出域、合规优先，单笔大、周期长 |
| MaaS 按量付费 | 互联网公司、中小企业 | 起步快、随用随付，token 毛利靠规模摊薄 |
| 应用层订阅 | 终端用户 | AI 编程、客服 SaaS、数字人，竞争最激烈 |

一个反直觉的事实：**基座模型本身越来越不直接赚钱**。DeepSeek、Qwen 这些开源系列把基座价格打到了地板上，价值被推向推理、云资源和应用层——剧本类似当年开源 Linux 之后，钱流向了云计算。

## 为什么说"和你想得不一样"

- **美国叙事**是"超级应用 + API"：少数巨头吸走大部分价值，C 端订阅贡献显著。
- **中国叙事**是"行业纵深"：制造、金融、医疗各有数据壁垒和合规要求，通用模型打不进去，必须做行业模型加私有化交付，于是产生大量集成与实施收入。
- 一个副产品是**国产算力生态**的加速适配：推理侧对国产芯片的兼容投入远超海外同行。
- 所以，拿美国大模型公司的收入曲线直接套中国市场，会系统性高估 C 端、低估 B 端交付。这正是这波增长的核心差异：**发动机是行业渗透和 token 消耗，不是订阅人数。**

## 价格跌、盘子涨：一个老悖论在重演

经济学里有个杰文斯悖论（Jevons Paradox）：蒸汽机效率越高，煤反而烧得越多——效率提升刺激了总消耗。云计算早期和流量资费的走势都验证过这一点。今天 token 单价跳水、总盘子变大，是同一个剧本。所以判断市场冷热，别盯着报价单，盯这三个指标：

- 日均 token 消耗量（行业真实的"用电量"）
- 活跃企业客户数
- 客户续费率

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/9d22df2b6ebc6690.png)

1. **看指标别看口号。** 评估任何一家大模型公司，优先问日均 token 量、企业客户续费率、交付毛利率，而不是参数量和融资轮次。烧出来的 token 和用出来的 token，是两种生意。
2. **企业落地先算 TCO。** 私有化还是 API 调用没有标准答案，用"数据敏感度 × 调用量 × 自有运维能力"三要素做决策，先跑三个月 POC，再谈全面铺开。
3. **个人的机会在"卖水层"。** 基座日益开源化，稳定的机会在垂直行业知识库、数据治理、模型评测与部署运维。技术周期怎么变，这些活儿总得有人干。

130 亿美元不是终点，只是行业从"讲故事"切换到"跑报表"的信号。接下来的分水岭很清晰：谁的 token 是客户真用出来的，谁的就是好生意。趴在数据管道口看报表，比站在风口喊口号，看得清楚得多。
