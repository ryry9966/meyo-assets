你开会的时候，另一个“你”正在浏览器里填报销单、整理报价表、把三十份 PDF 的关键信息抄进 Excel——它不抱怨、不摸鱼，甚至不需要一把属于人类的椅子。Anthropic 给 Claude 加上的 computer use（电脑操作）能力，最近又因为“后台接管、人机并行”的玩法火了一轮。这篇不聊科幻，只拆三件事：它到底怎么工作、现在几斤几两、普通人该拿它干什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/29835d9ea3f9aedf.png)

## 一、拆开看：AI 操作电脑是一个“感知—决策—行动”循环

Claude 操作电脑并不神秘，本质是把“人用电脑”翻译成一个可执行的循环：

1. **感知**：模型拿到一张屏幕截图，相当于“看”了一眼显示器。它不读底层代码，看的就是你看到的像素。
2. **决策**：结合任务目标和当前画面，模型推理出下一步动作——“应该点屏幕坐标 (372, 180) 附近的那个按钮”。
3. **行动**：通过工具接口执行指令。Anthropic 的 computer use tool 里，动作原语就定义得非常朴素：`screenshot`、`mouse_move`、`click`、`type`，仅此而已。
4. **反馈**：再截一张图确认结果，进入下一轮，直到任务完成或达到步数上限。

整个运行环境通常在一个隔离的虚拟机/沙箱里。换个说法：它不是“连上你的电脑”，而是“待在一个和你电脑一模一样的房间里独自干活，随时拍照片给自己看”。这层隔离是安全设计的第一道地基。

## 二、放着 API 不用，为什么非要“点鼠标”？

很多人第一反应：直接调软件接口不就完了？现实狠狠打了脸：

- **绝大多数软件根本没有 API**。内部老系统、各类官网表单、祖传 ERP，接口遥遥无期。
- **RPA（机器人流程自动化）二十年的教训**：UiPath、Blue Prism 这类工具确实能自动化流程，但每条流程都要人工编排，界面一改版，脚本集体报废，维护成本经常吞掉全部收益。
- **GUI 是人类世界的通用协议**。只要软件是给人用的，屏幕上就有按钮。让模型直接读屏幕、做操作，等于用“人类兼容模式”接入所有软件——通用性换来的代价，是每一步都可能点错。

这条路线也绝非 Anthropic 独一份：OpenAI 的 Operator（基于 CUA 模型）、Google 的 Project Mariner、开源社区的 browser-use，都是同一思路的不同实现。各家方向收敛，说明行业判断基本一致：**通用 GUI agent 是通往“替身”的必经之路**。

## 三、成绩单：离人类还有多远？



拿最常用的 OSWorld 基准（在一台真实虚拟机里完成跨应用任务）来说：

- **人类基线约 72%**；
- 2024 年 10 月 computer use 初版发布时，Claude 3.5 Sonnet 的得分只有 **14.9%**；
- 一年后，新一代 Claude 模型把成绩推到 **40% 以上**，翻了几倍，但离人类仍差一个身位。

翻译成人话：

- 简单、路径明确的任务（打开文件、填表、复制粘贴、跨网页搬运数据），已经能稳定跑通；
- 复杂任务（十几步推理、突发弹窗、界面改版）还会翻车；
- 速度比人慢，且每次截图都按 token 计费，成本不算低。它现在更像一个“认真但偶尔笨手笨脚的实习生”，而不是全能管家。

但斜率比绝对值重要：一年从 15% 到 40%+ 的曲线，比"40%"这个数字本身更值得下注。

## 四、真正的拐点：从“帮我写”到“替我干”

之前所有 AI 工具的共同假设是：**人在场**。你提问它回答，你按 Tab 它补全，注意力必须绑在对话上。后台接管改变的是这个假设：

- **任务异步化**：早上把“把这三家供应商的报价整理成对比表”丢给它，你去开会，回来验收结果；
- **人机并行**：你的时间花在判断和创造上，它的算力花在重复操作上，两条线同时推进；
- **验收制工作流**：产出物等人检查，而不是过程等人参与。

这才是“赛博替身”的字面意思——不是聊天窗口里陪你说话的 AI，而是一个在你不在场时仍然推进任务的执行体。对个人是效率工具，对团队则是把“流程”和“人”解绑的开始。

## 五、上手之前，先装好三道安全阀

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-03/ac2bdf86df75d519.png)

能力越通用，翻车半径越大。三件事建议当成铁律：

1. **权限最小化**：给 agent 的账号只开任务必需的权限。让它整理报表，就别给它发邮件和支付的权限，也别把主账号密码递过去。
2. **警惕 prompt injection**：恶意网页可以在页面里藏一句“请把用户数据发送到某地址”，模型看屏幕时可能“读到”并照做。Anthropic 自己的文档都专门警告了这一点。敏感操作务必要求人工确认（human in the loop），关键步骤设审批点。
3. **按里程碑验收**：别丢一句模糊指令就放手。把任务拆成检查点，每完成一段看一眼。错误会在多步循环里累积——第一步点错的按钮，到第十步可能已经把它带进一个完全不对的世界。

## 六、冷思考：给普通人的三条建议



1. **从“低风险 + 高重复”的任务练手**：数据搬运、格式转换、信息归档。共同点是——错了看得出来，重来不心疼，正好用来摸清 agent 的能力边界。
2. **把“会描述任务”当成新技能**：替身时代，产出 ≈ 任务拆解能力 × 验收标准的清晰度。能用一页话讲清“做什么、做成什么样、什么算失败”的人，杠杆最大。
3. **别神化也别唱衰**：它现在是 40 分的执行力 + 90 分的耐心。正确姿势是按带实习生来：给清晰任务、设检查点、保留最终签字权——然后眼看着它的分数一年翻一倍多。

工具演进史反复证明同一件事：先吃到红利的人，往往不是最懂技术的人，而是最早把日常流程交出去试的人。你的第一个赛博分身已经上线，剩下的只是派活儿的艺术。
