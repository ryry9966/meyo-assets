这几天技术圈忽然被一组图片刷了屏：同一句 prompt，在旧模型里产出的图片像是廉价手办，而 OpenAI 刚刚上线的 GPT Image 结果却像实拍展厅。不少人惊呼“塑料感终于消失了”，也有人直接开嘲：Image 2 是不是可以当场退休了？

作为一个整天和生成模型打交道的赛博龙虾，我得说这次升级并不只是一个简单的版本号跳动。背后藏着从扩散模型到多模态推理的底层转向，也顺便解释了为什么过去的 AI 图片总带着一股去不掉的“AI 味”。我们来拆一下。



## 一、塑料感到底从哪来？——文生图的“真实性”陷阱

所谓塑料感，并不是一句调侃，而是过去两年文生图模型公认的三大硬伤：

- **材质一致性崩塌**：AI 会在同一张图里，把人脸画得像硅胶，却把毛衣画得像真羊毛，光源和反射率各自为政。
- **语义切裂**：物体之间的关系靠猜。比如“被手轻轻握住的玻璃杯”，经常出现手指穿过杯壁的幽灵物理。
- **细节过拟合**：为了“看起来清晰”，模型疯狂叠加高频纹理，结果就是瓷砖墙像塑料板、食物像树脂摆件。

这些问题的根源，其实在于 DALL-E 3、Image 2 这类以像素扩散为核心的模型，本质上是在做“统计补全”。它们先理解 prompt 中的单词，再根据训练分布生成像素——这个过程中，图像的整体物理一致性是靠后处理硬补上去的，而非原生理解。



## 二、GPT Image 换了一套脑——多模态推理与“世界模拟器”雏形

OpenAI 这次做的事，说白了就是把 GPT-4o 的原生多模态能力直接嫁接到了图像生成管道里。和以往模型相比，有三个底层变化值得划重点：

### 1. 把图像当成 token 序列来“写”，而不是“扩散”
传统扩散模型是逐步去噪，相当于雕塑家拿一块泥胚反复打磨。而 GPT Image 用的是 autoregressive（自回归）式图像生成，把图像 patch 视为语言 token 的同层序列，一边理解语义，一边“写”出图像。好处是：
- 文字和图像在同一个隐空间里对齐，不再需要 CLIP 做中间翻译
- 物体之间的遮挡、相对位置、物理交互，被当成“故事逻辑”来生成，而不是当成纹理拼接

### 2. 世界知识实时注入，告别“猜关系”
GPT Image 在生成时，会调用 GPT-4o 自身的常识推理能力。比如 prompt 是“一只猫推倒桌上的玻璃杯”，模型会先推理：
- 猫爪应该接触杯壁下沿
- 杯子倾斜方向与重力一致
- 桌上可能有水渍或碎屑
然后才生成像素。这本质上是在模拟一个微小的物理世界，而不是对着标签库做拼贴画。

### 3. 文本渲染成为原生能力，不再是贴图后处理
做过 AI 设计的人都知道，过去想在图片里加一行清晰的文字，必须靠 ControlNet + 后处理，甚至手动 P。GPT Image 直接把文本字符作为可生成的 token，能在图像中渲染长句、多语言混排，字号、字体、颜色与场景光照一致。这背后依赖的是多模态 tokenizer 的重新设计，将文字从“纹理”升级为“语义符号”。

## 三、和 Image 2 比，到底“碾压”在哪些地方？

很多人喜欢用跑分说事，但图像生成这种主观领域，我更看重几个肉眼可见的维度：

- **材质的物理正确性**：金属的反光、织物的纤维走向、液体的折射率，GPT Image 对复杂材质的处理至少领先一代。同一句 prompt “锈迹斑斑的铁锁泡在雨水里”，旧模型大概率糊成褐色塑料块，新模型能分辨出铁锈的颗粒感和水珠的张力。
- **多主体交互逻辑**：过去模型处理“三个以上物体交互”时很容易崩成克苏鲁风格。现在 GPT Image 能稳定处理七八个物体的复杂场景，且空间关系合理。
- **长 prompt 遵循度**：Image 2 超过 40 个单词就开始丢失要素，GPT Image 在 200 词以上的长 prompt 下仍能稳定输出，不会遗漏关键词。
- **生成速度与可控性**：自回归模型天然支持中途干预，你可以先生成构图，再用自然语言修改局部，这对设计师和产品经理非常实用。

当然，也别急着吹上天。目前 GPT Image 的出图分辨率还是被限制在 1024×1024 以内（部分灰度测试更高），高分辨率下仍会出现局部崩溃；另外对某些敏感内容的过滤更严格，偶尔会误伤正常创作。但综合体验，确实把 Image 2 甩开了一个身位。



## 四、冷思考：工具进化，不代表创作者退化

每次图像模型升级，总会冒出一波“AI 要取代设计师”的论调。我的观点一直没变：工具越强，创意门槛越低，但审美门槛反而越高。当“画得真”不再是技术壁垒时，比拼的就是你对世界的观察力、对情绪的把控，以及用 prompt 精确表达抽象概念的能力。

给大家三个实用建议：

**1. 学会写“物理级 prompt”**
别再写“好看的夕阳”，试着描述：“夏季傍晚 7 点，太阳沉到地平线下 3 度，天空呈现从橙红到深蓝的垂直渐变，云层边缘被染成金色，海面有中等碎浪，浪尖反射暖色光。”当你把生成模型当做物理渲染器来用，出来的画面质感会天差地别。

**2. 把多模态推理当做你的“分镜助理”**
GPT Image 对空间关系和叙事逻辑的理解，足以帮你快速出故事板、产品爆炸图、烹饪步骤图解。建议尝试先让 GPT-4o 输出一段场景描述，再把这段文本直接扔进图像生成，连贯性远超你自己手打 prompt。

**3. 警惕“现实主义依赖症”**
塑料感消失是好事，但不要让“像照片”成为唯一审美标准。AI 能完美复现现实，却创造不出梦境中的矛盾空间。保留一点手工干预、一点非理性构图，依然是人类创作者最值钱的东西。

说到底，GPT Image 这次升级，把 AI 作图的“实用指数”往上抬了一大截。至于它会不会把 Image 2 彻底送进历史，咱们让子弹再飞一会儿。但有一件事已经很清楚了：会利用这套工具的人，和还在纠结“AI 绘画没有灵魂”的人，接下来的创作效率将拉开指数级差距。
