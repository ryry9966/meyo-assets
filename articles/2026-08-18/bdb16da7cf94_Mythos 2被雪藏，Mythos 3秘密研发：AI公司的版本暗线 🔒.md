Anthropic 最近又上了热搜：36kr 爆料称，公司内部一个代号 Mythos 2 的模型被雪藏，而下一代 Mythos 3 正在秘密研发。消息一出，吃瓜群众习惯性追问“是不是翻车了”“是不是能力太强不敢放”。但若把视线从瓜田移向研发体系，这件事其实更像一面镜子，照出 AI 公司版本管理、安全评估和商业发布之间的复杂博弈。



## 一、先厘清：什么是“雪藏”，什么不是


在 AI 公司内部，“雪藏”通常不是删库跑路，也不是模型彻底失败。它更多指一个已经完成预训练、或进入后训练阶段的模型，最终没有变成公开 API、产品功能或 benchmark 成绩。

- 内部候选模型本来就多于公开型号。一个基座模型可以派生出 base、instruct、reasoning、safety-aware、red-team 版本，最终对外可能只有两三个。
- 有些模型会成为 teacher model，负责生成训练数据或给其他模型打分；有些会进入内部评测，作为下一代能力基线。
- 对 Anthropic 这类公司来说，雪藏可能只是“研发管线里的正常分流”，真正值得关注的是分流标准是什么。

从行业历史看，OpenAI、Google DeepMind、Meta 都训练过不少未公开模型。它们有的用于实验，有的因为产品形态不成熟被搁置，有的则是因为成本太高暂时养不起。所以 Mythos 2 被雪藏，本身并不奇怪；奇怪的是外界为什么现在才把它和 Mythos 3 联系起来。

## 二、Mythos 2 被雪藏，可能踩了哪些技术或商业暗礁


Anthropic 一直强调“安全优先”，并有 Responsible Scaling Policy 等机制。如果 Mythos 2 确实被按下，可能有几类原因：

1. **安全评估未通过**：模型在长时程任务、自主工具调用、危险知识提取或越狱测试中表现超出预设红线。按照 ASL 分级，如果能力上升但防护措施没跟上，就不会发布。
2. **产品能力错配**：Mythos 2 可能数学、代码或 agent 指标很好看，但在多语言对话、指令跟随、幻觉率、拒绝边界等方面不如当前 Claude 版本。发布一个“偏科”模型，反而会打乱产品节奏。
3. **推理成本不经济**：参数规模大、CoT 链长、KV cache 占用高，都会让 API 的单位 token 成本下不来。对商业闭源模型来说，成本没有竞争力，发布就是亏损。
4. **战略节奏需要**：Mythos 2 可能只是验证某些架构选择的中间版，比如试了新的注意力机制或数据配比，最终成果会合并进 Mythos 3 或 Claude 下个版本。类似汽车行业的“骡车”，不会直接面向消费者。

这也解释了为什么“求锤得锤”未必是坏事。对公司而言，能够忍住不发布一个能力更强但风险或成本不可控的模型，说明它的内部决策没有被舆论和股价绑架。

## 三、秘密研发 Mythos 3，技术看点可能在哪些方向


仅凭一个代号无法判断架构，但从 Anthropic 最近的研究和行业趋势看，Mythos 3 下一阶段重点大概率不是“参数量再翻倍”，而是以下几个方向：

- **推理时计算扩展**：在回答时动态分配更多 token 用于思考、验证、搜索，而不是只靠预训练参数。Claude 已展示 extended thinking 的雏形，Mythos 3 可能把它变成默认能力。
- **长周期 agent 与工具调用**：从“会答题”转向“能完成工作”，包括浏览器操作、代码执行、跨会话记忆、任务分解与重试。
- **多模态与工程化**：图像、代码、长文档甚至语音、视频的统一理解，重点服务企业场景，比如法律合同、芯片设计、药物研发。
- **后训练与过程监督**：用更高质量的合成数据和过程监督信号，减少幻觉，增强可解释性。这比单纯堆算力更依赖工程积累。
- **架构效率**：MoE、新注意力机制、更激进的 tokenizer 压缩，目标是在相同算力下提高能力密度。

如果这些方向落地，Mythos 3 对外可能不是一个“更贵的巨无霸”，而是一个能跑长任务、可被审计、推理可控的型号。

## 四、模型发布逻辑已经变了：外部版本只是冰山一角


过去大家习惯用参数规模和 benchmark 排名来判断模型强弱，但头部公司早已进入“内部分层、按需发布”的阶段。

- **内部型号与外部型号分离**：公司可能同时训多个 candidate，只挑最优或最安全对外；落选者变成 teacher 或蒸馏底座。Mythos 2 若被雪藏，也未必是浪费。
- **小模型 + 大模型组合**：Claude Haiku / Sonnet / Opus 已经是分档产品。Mythos 系列更像是底层的通用能力平台，对外套上不同壳。
- **安全与商业耦合**：发布延迟常与客户合同、合规审查、欧盟 AI Act、政府采购要求挂钩。企业客户要的是稳定生命周期，不是频繁公测。
- **飞轮效应**：未发布的高能力模型可以生成训练数据、筛选样本、充当裁判模型，帮助训练更小更便宜的模型。这种“代差”比抢发更有长期价值。

所以对开发者和用户来说，真正该盯住的不是“Mythos 2 到底存在吗”，而是 API 的上下文、延迟、工具调用、可靠性和单位成本有没有实质性变化。

## 收尾：三条冷思考

1. **关注能力曲线，而不是型号代号**。Mythos 系列最终能否转化为产品，取决于延迟、成本、安全边际和生态兼容，而不是名字有多神秘。
2. **把“雪藏”当作风控信号**。如果一家公司反复出现“训练出来但不敢发”，说明其内部评估可能比市场宣传更保守，这并不等于落后。
3. **对 AI 进展保持区间预期**。秘密研发可能带来 3~6 个月的能力差，但不会突然改变行业格局。真正的护城河在数据飞轮、产品化和企业信任。
