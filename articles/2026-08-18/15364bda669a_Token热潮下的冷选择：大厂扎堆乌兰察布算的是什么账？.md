最近，多家头部大厂不约而同地出现在内蒙古乌兰察布。他们不是去团建，而是在批量锁定数据中心园区、电力指标和未来三到五年的算力产能。消息传开后，社交媒体上最高频的词是“圈地”。但只看到圈地，容易忽略一个更本质的变化：大模型把 Token 变成了一种新的数字耗材，而 Token 的背后是电费、芯片折旧、散热和网络。谁能在单位 Token 成本上压低一毛钱，谁就可能在下半场 AI 服务竞争里多拿一点定价权。因此，真正值得讨论的不是乌兰察布有没有地，而是 Token 为什么把算力逼到了北纬 40 度以上。



## 一、Token 不只是文本碎片，它是最小的算力计费单位


Token 在 LLM 中，是模型读写和处理文本的语义最小单元。英文大约三到四个词，中文常常一个到两个汉字。用户调用 API 时，看到的是“每百万 Token”的计费单位，但这个单位的成本结构却非常“重”。

- 训练端：从零预训练一个千亿参数模型，需要处理数万亿 Token，总算力通常以 10^23 到 10^25 FLOPs 计算。训练集群一旦开机，几个月内不能停，选址必须提前锁定。
- 推理端：以 7B 密集模型为例，单个 token 的前向计算量约为 2 × 7 × 10^9 = 1.4 × 10^10 FLOPs。百万 token 输出就是约 1.4 × 10^16 FLOPs，这还没有算 KV cache、通信优化和批量调度带来的额外开销。
- 成本端：Token 的边际成本约等于电力、芯片折旧、制冷与网络费用的组合。对训练任务来说，时延不那么敏感，但对电价、设备故障和一次成功运行率极其敏感。一次大规模 checkpoint 失败，可能让万卡集群浪费数万元的电力与算时。
- 所以，Token 越成为商业入口，算力选址就越像能源选址。它不再只是软件问题，而是基础设施问题。

## 二、乌兰察布凭什么被选中：电、冷、地、网四件事


乌兰察布不是唯一，但它是少数能同时拿到四张牌的地方。这四张牌，基本决定了一座智算中心未来十年能否把单位算力成本压到最低。

- 冷：当地年平均气温相对低，自然冷源充足。大型数据中心可在较长时间内使用新风或自然冷却，PUE 可做到 1.25 甚至更低。PUE 每降低 0.1，对万机柜级别项目来说，每年可能是数百万元级的电费差异。
- 电：内蒙古风电、光伏资源富集，大数据园区可以通过绿电交易、直购电或增量配电网等方式获得相对低的综合电价。AI 集群 7×24 小时运行，电价几乎是最敏感的长期变量。
- 地：乌兰察布地处高原，土地开阔、地价低、地质条件稳定，适合建设大体量园区，也为二期、三期扩容留下余量。数据中心是重资产，土地和园区扩展性决定了长期边际成本。
- 网：这里距北京约 300 公里量级，光纤单向时延可控制在数毫秒级。对预训练、精调、批量推理、日志处理、数据清洗等离线或近线任务足够；需要毫秒级交互的在线推理，仍然会保留在东部边缘节点。
- 换句话说，“圈地”更准确说是圈“电、冷、地、网”的长期组合。早期互联网数据中心靠近用户，是为降低时延；AI 时代，重负载像制造业一样，开始向能源和土地成本洼地迁移。

## 三、大厂扎堆：从自用到云化，这是算力供给的工业化


头部大厂集中出现在乌兰察布，不只是因为政策号召，更因为 AI 算力的业态本身发生了变化。

- 自用重负载：大模型预训练、强化学习、数据清洗、批量评测等任务，通常要占用数千卡 GPU，连续运行数周甚至数月。把它们放到乌兰察布，能把电费和制冷成本降下来，而且这些任务基本不在意几毫秒的额外时延。
- 云化算力：一些厂商把乌兰察布园区做成“算力工厂”，向中小企业提供按卡时或按 Token 的弹性算力。客户在东部终端发起请求，重计算在西部完成，最后只把少量结果传回。
- 风险分散：多个园区、不同气候和电力条件并行，可以降低单座城市限电、高温或供应链故障带来的停机风险。大模型训练最怕突然中断，多区域部署相当于给算力上了一份冗余保险。
- 历史背景：2010 年代云计算数据中心多集中在北上广深周边，主要考虑时延与客户集中度。2022 年“东数西算”工程全面启动后，内蒙古、贵州、甘肃、宁夏成为重要算力枢纽，乌兰察布是其中受益最明显的节点之一。
- 本质上，大厂是在把 AI 算力变成可规划、可扩容、可计价的公共基础设施，类似发电厂和水厂：用户不关心电厂建在哪里，只关心电是不是稳定、价格是不是便宜。

## 四、冷思考：Token 不会自动变得便宜


对开发者和创业者来说，有三条算力账值得提前算清楚。大厂可以圈地，小团队更应该圈住成本边界。

1. 不要只看 PUE，要算总拥有成本。低温能省电，但风沙、干燥、滤网维护、设备寿命损耗也会产生运维成本。把 PUE、电价、设备折旧、带宽与灾备加总，才能知道“北迁”是否真的划算。
2. 分清负载类型。训练、批量推理、数据管线适合去低成本算力区；实时对话、推荐、搜索等在线推理应留在离用户更近的边缘节点。混合调度，才能同时拿到成本和体验。
3. 关注长期变量：绿电价格、能耗指标、电网接入、碳排放核算。如果未来碳成本进入 Token 定价，乌兰察布这类绿电富集区会更吃香，但前提是现在就把能耗与碳排纳入技术选型。

Token 是表，算力是里；圈地是表，电价与碳排是里。大厂去乌兰察布，不是去追逐一块地，而是去锁定 AI 基础设施的下一个成本周期。
