自进化是今年大模型圈出现频率很高的一个词。智谱在讲 Agent 自进化，DeepSeek 在讲推理模型通过强化学习自我改进。很多读者容易把两者当成同一条路，但如果把两家公司公开的技术树摊开看，会发现它们从根上就不是一棵树：一个更偏“系统外进化”，一个更偏“权重内进化”。



## 一、先把“自进化”拆开：这不是同一个物种

自进化在大模型语境里至少有两种形态：

- 权重级进化：通过训练、强化学习、蒸馏等方式改变模型参数，让模型在下次推理时直接拥有新能力。
- 系统级进化：模型参数基本不动，靠外部工具、记忆、工作流、反馈回路来提升任务完成率。
- 一个更直白的类比：智谱更像给大脑外接一套可替换的机械臂，DeepSeek 更像不断改写神经元之间的连接规则。

如果只看宣传稿，两家都说“模型越来越聪明”；但落到工程实现，“聪明”的位置完全不同。

## 二、智谱的进化树：从 GLM 到 Agent 生态

智谱的路线可以粗略概括为：

1. 语言底座：从早期的 ChatGLM 到 GLM-4 系列，先解决通用对话、长文本、基础推理。
2. 多模态补全：GLM-4V、CogView 等把视觉生成和图像理解接入同一生态。
3. Agent 工具层：AutoGLM 是标志性节点。它的关键不是模型参数变强，而是让模型生成动作序列，去操作真实界面，比如打开 App、点选菜单、填写表单。
4. 平台化交付：通过 MaaS、私有化部署、智能体平台，把模型包成企业可用的 API 或工作流。

在这个树里，自进化更多发生在“工具注册表—操作轨迹—用户反馈—Prompt/Workflow 更新”的循环中：

- 同一个任务失败后，系统可以调整工具调用顺序或补充示例。
- 新增一个内部 API，Agent 的能力范围立刻扩张。
- 用户操作日志可以回流成下一次任务的 few-shot 样本。

这类进化可审计、可回滚，适合需要稳定交付的行业场景；但它也依赖大量工程维护，不是模型“自己突然开窍”。

## 三、DeepSeek 的进化树：从 MoE 到强化学习驱动

DeepSeek 的技术树更贴近模型算法本身：

1. 架构层：DeepSeek-V2 开始使用 DeepSeekMoE 和 MLA，目的很明确——参数总量可以大，但推理时不能全激活。
2. 训练层：DeepSeek-V3 把 MoE 与 FP8 混合精度训练结合起来。公开论文给出的训练成本约 557 万美元，不含前序研究与消融。这个数字在当时直接拉低了行业对大规模模型训练成本的预期。
3. 推理层：DeepSeek-R1 用 GRPO 替代常见的 PPO。GRPO 不需要独立价值网络，而是对一组采样结果做组内相对比较，降低显存占用，同时让模型在数学、代码等可验证任务上学会更长的思维链。
4. 生态层：权重开源后，外部社区蒸馏、微调、部署，形成一种分布式演化。

这里的自进化更接近“模型通过奖励信号改变自身策略”：

- 给定一个数学题，模型先生成多步推理；
- 规则检查器判断最终答案；
- GRPO 根据同一题多组答案的相对优劣更新策略；
- 更新后的模型再生成更高质量的推理轨迹，下一步继续迭代。

这条路线在推理、代码、数学等有明确 reward 的任务上进步很快，但工具操作、企业流程、权限与审计不是它的核心战场。

## 四、两条进化树为何必然分叉？



如果只看技术标签，智谱和 DeepSeek 似乎都在做“自进化”，但它们的分叉不是偶然，而是由三个变量决定的：

- 商业交付方式：智谱面向行业客户，客户要的是可解释、可私有化、能接入现有系统；DeepSeek 面向开发者和研究者，影响力来自开源权重、算法创新和低价推理。
- 反馈信号来源：智谱的信号来自用户在 App、OA、浏览器里的操作与纠错；DeepSeek 的信号来自数学答案、代码是否通过测试、推理步骤是否一致。
- 护城河位置：智谱的护城河在工具生态和交付链路上；DeepSeek 的护城河在训练效率、模型能力与社区认知上。

因此，一条树把“进化”放在模型之外的系统闭环里，另一条树把“进化”放进模型内部的奖励闭环里。两者不是谁更高级，而是把资源投向了不同的瓶颈。

## 五、冷思考：如何不被“自进化”三个字带偏



判断一个产品的“自进化”是否适合你，可以先问三件事：

- 进化发生在权重层还是工作流层？
- 进化成本由谁承担？
- 失败时如何回滚？

基于这三问，有三条实用建议：

1. 做企业内部流程自动化，优先看 Agent 平台。需要操作真实系统、保留审计记录、能精确回滚时，系统级进化更实用。
2. 做代码、数学、知识推理类产品，优先看开源推理模型。重点比较推理成本、上下文长度、权重重训或微调难度。
3. 无论哪条路线，先建设反馈数据闭环。没有用户修改、点击、拒绝、人工接管这些数据，任何“自进化”都只是演示视频。

真正的分叉不是谁偏离了 AGI，而是大家终于开始解决不同的问题。
