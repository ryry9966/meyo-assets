最近社交网络流传“哈佛麻省理工造了83亿AI人”。很多人脑补成83亿个机器人活在服务器里，或者人类意识被复制。严格说，这个说法更像一次语义放大：它指的不是实体机器人，而是用大语言模型（LLM）驱动的虚拟智能体（AI agent）进行大规模社会模拟。83亿这个数字恰好约等于全球人口，传播上很炸，但技术现实要冷得多也硬核得多。



## 1. 先分清：AI人不是机器“人”，而是生成式智能体


- 一个生成式智能体通常由五个模块组成：LLM（大脑）、记忆流（过去经历）、反思机制（从经历里总结规律）、计划模块（安排下一步）、行动接口（对外输出）。
- 举例来说，虚拟角色“老王”可能有年龄、职业、性格设定、记忆里的家庭关系。他每天接收到信息，会写入记忆；遇到选择时，调用模型生成决策；再通过反思调整后续行为。
- 这跟传统游戏 NPC 不一样。传统 NPC 的台词和行为是事先写好的，而生成式智能体的行为是动态生成的，甚至可以做出脚本之外的事。
- 2023 年斯坦福的“Smallville”实验让 25 个生成式智能体在一个虚拟小镇生活。它们不仅会起床、吃饭、工作，还自发组织了一场情人节派对，并开始传播一个候选人的信息。这个实验让学界看到，LLM 驱动的 agent 不只是聊天机器人，而是可以构成微型社会。

## 2. 83亿为什么有冲击力：人口级模拟的极限推演


- 83亿约等于当前全球人口规模。听到这个数字，人们天然会联想到“一比一造一个地球社会”。
- 社会模拟有很长的技术脉络：1971 年 Thomas Schelling 用极简棋盘模型解释居住隔离如何从个体偏好中“涌现”；1990 年代 Sugarscape 用多主体模型模拟资源、迁徙和冲突。但这些早期 agent 基于规则，行为僵硬。
- LLM 改变了这一点。每个 agent 能理解自然语言、生成有语境的反应，这让社会模拟从“规则驱动”走向“语言生成驱动”。
- 不过要强调：目前公开研究里，1,000 人甚至 10,000 人规模已经算大型生成式智能体实验。83亿大概率是概念框架或极限推演，而不是所有 agent 都在持续完整运行。规模一旦过大，误差、偏见和数据分布问题会被成倍放大。

## 3. 算一笔账：83亿AI人一天要烧多少钱


- 粗算一下：假设每个 agent 每天只做 20 次行为决策，每次调用 LLM 消耗 800 token。83亿 agent 一天的 token 量约 1.33×10¹⁴。
- 如果按云服务每百万 token 2 美元计算，一天成本约 2.7 亿美元，一年接近千亿美元。这还不包括记忆存储、环境交互、日志分析和实验重跑。
- 现实优化手段包括：使用 7B/13B 小模型、量化到 4-bit、缓存相似角色的推理结果、只对关键节点做完整模拟、把大量同质个体做分桶聚合。即便如此，人口级完整模拟依然是国家级算力项目。
- 所以，热搜里的“造了83亿AI人”如果指 83亿个独立、持续、完整运行的 agent，成本账首先就过不去；更常见的是“统计意义上的 83亿人口规模”，而非 83亿个互相独立的完整模型实例。

## 4. 真正有价值的不是“造人”，是造一个社会风洞


- 城市与交通：模拟一条新地铁线开通后，数百万通勤者的路径选择变化。
- 公共卫生：在虚拟人口中注入一种传播参数，观察不同戴口罩、隔离、疫苗策略如何改变传播链。
- 信息传播：研究谣言、新闻、观点如何通过社交网络级联放大，哪些节点是传播关键。
- 经济与金融：让大量 agent 根据价格、收入、预期做消费和投资决策，观察宏观指标是否出现泡沫或踩踏。
- 合成数据：用虚拟社会的交互数据训练模型，补充隐私受限、边缘场景稀少的问题。
- 游戏与内容：未来开放世界游戏可能出现真正有记忆、有关系的海量 NPC 社会。

## 冷思考：三条实用建议

1. **看“AI人”先分三层**：演示（Demo）、论文（Paper）、产品（Product）。能被传播的往往是最刺激的演示，但真正要读的是论文里的规模、模型、交互步数和评估方式。
2. **追问成本与可复现性**：看到“83亿”这种数字，先问它是否持续运行、是否每个 agent 独立、使用多大的模型、总 token 成本是多少、代码和数据是否开源。不能被一个数字带着走。
3. **规模不等于真实，警惕模拟偏见**：如果 83亿个 agent 都基于英文互联网数据训练，它们对全球社会的理解天然偏斜。大规模模拟可以把少数群体的偏差放大成“多数共识”。用于政策推演时，需要校准、审计和伦理边界。
