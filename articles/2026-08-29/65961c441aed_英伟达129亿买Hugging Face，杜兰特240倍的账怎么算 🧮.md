最近，36kr 一则关于英伟达拟以 129 亿美元收购 Hugging Face 的报道引发热议，同时被推到台前的还有 NBA 球员凯文·杜兰特——据称其早期投资可能获得约 240 倍回报。交易尚未官宣，数字也充满假设，但这背后藏着 AI 基础设施、开源模型生态和风险投资回报三个值得拆解的维度。本文不做财富神话，只把账算清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-29/8acdf42b0c632d91.png)

## 一、Hugging Face 是什么：AI 世界的“模型仓库”

Hugging Face 创立于 2016 年，最初做青少年聊天机器人，后来转向开源 NLP 工具。真正让它出圈的是 Transformers 库——一个让开发者用几行代码调用 BERT、GPT、LLaMA 等模型的标准接口。此后它逐步扩展成机器学习领域的“GitHub”。

- **模型与数据集分发入口**：开发者可以在 Hub 上托管、下载、微调模型，企业也可以发布私有仓库。公开 Hub 上已经有数百万个模型仓库、数据集和 Space 演示应用。
- **事实标准**：几乎所有开源模型发布时，都会优先提供 Hugging Face 链接。它降低了模型使用门槛，也垄断了“下载量”这个注意力指标。
- **商业模式**：免费开源 + 企业订阅 + 推理端点 + GPU 实例 + AutoTrain 等。虽然 ARR 相比估值不算高，但生态卡位非常稀缺。

可以把 Hugging Face 理解成 AI 时代的“应用商店”或“模型物流中心”。它不是模型生产商，而是模型流通的基础设施。

## 二、英伟达为什么想买：从卖铲子到修高速公路

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-29/7000baf0b0195173.png)

英伟达过去十年靠 GPU 和 CUDA 软件生态吃下 AI 训练与推理市场，但它始终面临一个长期威胁：云厂商和芯片对手正在用自研芯片 + 自建软件栈削弱 CUDA 锁定。收购 Hugging Face，本质是向更下游的开发者入口延伸，把“硬件—软件—模型分发”串成一条更粗的护城河。

具体逻辑可以拆成四层：

1. **绑定开发者心智**：开发者未来找模型、调模型、部署模型都在 Hugging Face 上完成，英伟达可以在 Hub 内天然推荐 TensorRT、Triton、NeMo 等自家推理优化工具。
2. **对抗云厂商自研芯片**：AWS Trainium、Google TPU、微软 Maia 都在抢训练/推理负载。如果模型分发入口握在英伟达手里，企业客户更容易被引导回 GPU 方案。
3. **开源模型爆发带来的长尾需求**：越来越多中小企业不从头训练大模型，而是下载开源模型微调。这个趋势不会减少 GPU 需求，反而把需求从少数超大规模训练扩展到了海量推理节点。
4. **战略溢价**：按消息中的 129 亿美元计算，相比 Hugging Face 上一轮约 45 亿美元估值，溢价接近 3 倍。从纯财务看，这更像战略卡位，而不是按 ARR 估值。

风险同样存在：开源社区会担心中立性，云厂商可能减少与 Hugging Face 的深度合作，监管审批也可能成为变数。但英伟达历史上几次大收购都在做同一件事——把软件生态牢牢焊在自家硬件上。

## 三、杜兰特 240 倍：纸面回报的另一个算法

凯文·杜兰特是通过 Thirty Five Ventures 参与早期科技投资的。据公开报道，该机构在 2021 年前后进入 Hugging Face 投资者名单，具体金额和估值鲜少披露。网上流传的“240 倍”更多是一种简化估算。

举一个可能的估算路径：

- 假设早期投资 100 万美元，对应投后估值约 5400 万美元；
- 如果按 129 亿美元被收购，且没有后续稀释，那么股份价值约 2.39 亿美元；
- 100 万美元变成 2.39 亿美元，账面约 239 倍。

但这个“240 倍”至少有五个折扣项：

1. **后续融资稀释**：Hugging Face 之后又完成了多轮融资，早期股东持股比例会被 B/C/D 轮显著摊薄。
2. **清算优先权**：优先股通常有 1 倍甚至更高清算优先权。如果收购对价低于某个阈值，普通股股东可能分不到理论增值。
3. **期权池扩大**：为了吸引人才，期权池会扩大，进一步稀释早期股东。
4. **收购对价结构**：129 亿美元可能是现金加股票，还有或有对价、管理层留任、锁定期。纸面价值不等于马上可变现。
5. **税负成本**：长期资本利得税加州税，综合税率可能超过 30%—50%。

换句话说，杜兰特可能确实赚了很多，但“240 倍”更接近新闻标题里的账面倍数，而不是最终落袋的倍数。风险投资的幂律分布也提醒我们：少数项目贡献了绝大多数回报，看到单个成功案例就重仓早期投资，往往会被幸存者偏差误导。

## 四、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-29/bb17f07cf5e72718.png)

不管交易最终是否成真，这件事给开发者和科技观察者留下了三个判断框架。

1. **看回报，先看 IRR 和 DPI，再看倍数。** 10 年赚 100 倍，IRR 约 58%；20 年赚 100 倍，IRR 只有约 26%。DPI 反映实际分回现金的有多少。一个没有退出、没有现金回流的账面倍数，只是估值游戏。
2. **AI 基础设施的竞争正在从算力延伸到分发层。** Hugging Face 的价值不在模型本身，而在于模型、数据集和开发者社区的标准化入口。未来类似“编译器—框架—模型仓库—推理服务”的中间层，可能会出现更多整合。
3. **开源社区需要关注商业整合后的中立性。** 如果硬件巨头控制模型分发平台，开发者应该问一句：未来哪些优化会被优先支持？哪些硬件会被默认推荐？开源不等于免费，商业收购后的治理结构同样重要。

对于普通开发者，比起跟风讨论谁赚了多少倍，更实际的做法是：持续关注模型分发生态的演变，把 Hugging Face 这类平台当作观察 AI 商业化路线的窗口，而不是财富故事的背景板。
