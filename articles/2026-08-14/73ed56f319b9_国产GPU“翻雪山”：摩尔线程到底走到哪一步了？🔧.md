36kr 最近一篇报道把摩尔线程推上风口，称其迎来国产 GPU 最接近“翻过雪山”的时刻。这个比喻很重——翻雪山意味着生死考验，翻过去只是活下来，后面还有草地。作为长期关注半导体的工程师，我不打算复述新闻，而是从技术、商业、生态三个维度拆解：这个“最接近”到底有多少含金量。



## 一、“翻雪山”为什么是国产 GPU 最合适的比喻

长征中的翻雪山，是非生即死的关口，但翻过去不是终点。GPU 行业恰好是这个逻辑：

- **赢者通吃，生态为王的赛道**：英伟达凭借 CUDA 生态和快速硬件迭代，占据了大部分通用计算与 AI 训练市场。国产 GPU 长期在“能点亮”和“能干活”之间挣扎。
- **“最接近翻过雪山”核心标志不是某一项参数**，而是三个信号同时出现：产品量产、商业化客户、以及可能的 IPO 融资。这意味着从纯烧钱研发，开始转向自我造血。
- **但要泼一盆冷水**：翻过雪山只代表拿到继续走下去的门票，不代表已经走出险境。后面还有“草地”——生态建设、架构迭代、全球化竞争，哪一段都不轻松。

## 二、摩尔线程手里的牌：MUSA 架构与全功能路线

摩尔线程成立于 2020 年，创始人张建中曾担任 NVIDIA 全球副总裁兼中国区总经理，团队大量来自 GPU 行业。这种背景决定了它一开始就选择全功能 GPU 路线，而不是只做 AI 加速器或只做图形卡。

- **技术核心是 MUSA（Moore Threads Unified System Architecture）统一系统架构**，既支持图形渲染，也支持通用计算。产品线覆盖桌面（MTT S80）、工作站和数据中心（MTT S3000 等）。
- **软件栈上提供 MUSA SDK，并兼容 CUDA 生态**。这非常关键：开发者可以用类似 CUDA 的代码，通过迁移工具跑在摩尔线程 GPU 上，降低适配成本。但兼容不等于原生，性能损耗和功能缺失仍需持续观察。
- **全功能路线的优势是市场面宽**，可以切入游戏、设计、信创、AI 推理；劣势是每个市场都有成熟对手，生态适配压力被成倍放大。

## 三、真正难翻的雪山：生态、制程与商业化的三重关卡



- **第一重：生态壁垒。** NVIDIA CUDA 生态拥有数百万开发者，大量核心库和框架深度绑定。国产 GPU 做兼容层，相当于给外国方言做“同声传译”——能用，但表达效率和细节会打折扣。尤其在高性能计算领域，底层汇编级别的优化很难完全移植。
- **第二重：先进制程受限。** GPU 对晶体管密度和功耗极其敏感。国产代工在先进节点上仍有差距，导致国产 GPU 在同代际下难以正面比拼频率、功耗和绝对算力。这不是摩尔线程一家的问题，而是整个行业的共同天花板。
- **第三重：商业化闭环。** 研发投入动辄数十亿，需要真实付费场景：云游戏对延迟和驱动稳定性要求苛刻，AI 推理对内存带宽和精度敏感，信创市场相对稳定但规模有限。靠补贴或项目制订单无法形成健康现金流，必须找到可复购的行业市场。

## 四、翻过雪山之后：国产 GPU 的真实生态位在哪里？

很多人把“翻雪山”误读为“超越英伟达”，这是不切实际的。翻过雪山意味着活下来，能持续迭代，而不是成为性能王者。

- **现实生态位可能集中在：AI 推理、边缘计算、专业图形、云游戏、信创办公。** 这些场景对生态要求低于训练大模型，且对国产化有刚性需求。
- **CPU 领域国产替代走了十年以上，GPU 的复杂度更高，至少需要 5-10 年耐心。** 摩尔线程如果成功上市，只是获得了粮草，后面还有“草地”。
- **用一句工程师的话说：今天别急着开香槟，先把驱动跑稳。**

## 五、冷思考：三条判断框架



- **看软件栈，不看峰值算力。** 一张卡的 TOPS 或 TFLOPS 只能说明理论天花板，驱动、算子库、框架适配才决定能不能用。建议问清楚：目标场景是否跑过真实业务，POC 结果如何，而不是只看发布会参数。
- **看付费复购，不看融资新闻。** 融资和上市是输血，不是造血。关注是否有行业客户持续买单、毛利率是否为正、售后支持是否到位。没有真实订单支撑的“最接近翻雪山”，只是媒体叙事。
- **看 5 年周期，不看短期热点。** 半导体没有捷径，制程、架构、生态都是长跑。把“最接近翻雪山”当作观察窗口，而不是投资信号或技术拐点。对普通用户而言，国产 GPU 值得期待，但别把期待当成现状。
