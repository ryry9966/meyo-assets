这两天，AI 技术圈被一篇论文搅得有些激动——Google DeepMind 提出“视觉提示工程”（Visual Prompt Engineering），称其比文本指令更直接、更有效。一时间，“Prompt 工程已死”的说法甚嚣尘上。作为常年和语言模型打交道的虾友，你可能会心慌：花了半年打磨的提示词技巧，是不是一夜之间被扫进垃圾堆了？先别急着焦虑，这事儿没这么简单，但信号非常清晰：AI 的操控方式正在经历一次深层的范式转移。



## 一、视觉提示工程：不敲字，改“圈图”？

先弄清新范式到底长什么样。传统的 Prompt 工程，是用户用自然语言给模型下达指令。比如你要让模型识别图片里的故障零件，得精心设计一句：“请找出图片中所有表面有裂纹的金属部件，并以红色框标出。”这句话的长短、用词、语序，都影响模型输出质量。

视觉提示工程换了一条路：你不再费劲敲字，而是直接给出一张输入图像的变体。在目标物体周围画个圈、打个点，或者粘贴一个示范图块，模型就能理解你要什么。它的运作核心是“示范即指令”。

- **操作方式**：在图片上直接标注（点、框、涂鸦、掩膜），作为 query 的一部分馈入视觉语言模型（VLM）。
- **技术支撑**：Google 的最新论文《Visual Prompting for Multimodal LLMs》展示，只需在输入图像上放置一个红点，模型就能定位对应物体并完成分割、描述或计数任务。
- **应用案例**：给一张杂乱的货架照片，在某个商品上画个圈，模型就能告诉你它的品牌、数量、位置，甚至扫描出所有同类商品。整个过程不用写一句提示词。

也就是说，从“用语言描述意图”跃迁到了“用视觉示例传递意图”。这背后，是对人机交互逻辑的一次重构。



## 二、文本 Prompt 为何遭遇瓶颈？

不是文本 Prompt 做得不够好，而是它遇到了语言本身的“天花板”。

1. **语言的模糊性难以根治**。你写“把那个突出的部分切掉”，模型很难确切知道“那个”是哪个。尤其在多模态场景下，一张图胜过一千个形容词。我们为了消除歧义，不得不发明各种 Prompt 技巧——小样本提示、思维链、约束语法……这些臃肿的手段，本质上是在用更多语言去修补语言的缺陷。
2. **表达成本过高**。描述一个物体的精确空间位置（“在图像左上角第三排第二个蓝色按钮”）比直接在图上点一下低效得多。视觉提示把空间信息直接编码进图像，跳过了语言转译的损耗。
3. **跨模态对齐的误差**。语言模型虽然学会了对齐图片与文字，但将抽象文本精确映射到像素级别的视觉区域，仍是一项不稳定工程。视觉提示天然地在像素空间操作，绕开了这种“对齐鸿沟”。

此外，现实世界中很多知识本身就难以言传。例如你要让模型识别“焊接不良”的样板，给三张焊接良品图、三张次品图，比写三百字工艺说明更靠谱。这就是为什么工业缺陷检测、医学影像分析等领域，越来越倾向用参考图代替文字指令。



## 三、视觉提示为什么比语言更“直接”？——科学原理拆解

这种效率差异并不玄学，背后有认知科学和模型架构的双重根基。

- **认知层面**：人类视觉处理通路比语言通路快数倍。著名的“图优效应”表明，人脑对图片的记忆和识别远优于文字。当 AI 的交互界面从语言通道迁移到视觉通道，它实质上是在模拟人类更底层的认知偏好。视觉指令减少了“文字翻译成心理图像”的中间步骤，让指令传递近乎直觉。
- **模型架构层面**：现代视觉语言模型（如 PaLI、Gemini、GPT-4V）底层都是 Transformer 统一处理文本和图像 token。视觉提示直接在图像 token 序列中插入“扰动标记”——红点、外框、箭头——这些 token 在自注意力机制中会强烈吸引模型焦点，形成一种软性注意力引导。这相当于你在像素空间里对模型高喊：“看这里！就这个区域！”语言描述再怎么强调，也难达到这种强制注意力的效果。
- **信息密度**：一张 224×224 的标注图所承载的空间和语义信息，换算成文字可能需要上千字。视觉提示用高带宽的视觉信道传输指令，文本 Prompt 则受限于人类键盘的串行输出速度。在要求实时响应的场景（如自动驾驶、机器人操控），这种差距是决定性的。

简而言之，视觉提示不是“更聪明的提示词”，而是把指令媒介从符号系统换成了感知系统，本质上是让 AI 用更接近它的“母语”——视觉信号——来接收任务。



## 四、从“说”到“指”：工程实践的彻底转向

这波范式转移会如何重塑从业者的日常工作？不妨从几个层面透视。

1. **交互界面的变革**。未来的 AI 产品可能不再标配一个聊天输入框，而是一个画板或实时摄像头视图。用户用画笔圈选、用手势滑动，甚至用眼动追踪来下达指令。Prompt 工程师的战场会从 Notion 笔记转移到 Figma 画布上。
2. **评估指标的迁移**。文本 Prompt 的优化关注困惑度、指令遵循率；视觉提示的优化需要关注“注意力得分热力图”“区域定位准确率”“用户标注的稀疏度”等新指标。一套全新的打磨方法论正在成型。
3. **开发流程的重组**。一个视觉提示系统可能包含“示例生成器 + 提示合成网络 + 验证器”的闭环。工程师不再反复改写一句话，而是搭建数据飞轮：收集示教标注→训练提示编码器→部署推理。工作重心从纯文本技巧转向数据和流程设计。
4. **多模态融合成为默认项**。未来极少有纯文本文模型的应用，视觉提示和文本提示会混合使用。在对话中扔一张标注过的截图，后面跟一句简单的文本补充，将成为新的“黄金格式”。

这意味着，我们过去总结的“与 AI 对话的艺术”，有一部分会升级为“给 AI 指路的艺术”。



## 五、范式会杀死 Prompt 工程师，还是会催生新一代？

“Prompt 工程已死”是媒体化的夸张说法，更准确的描述应该是：原始的手工文本 Prompt 的稀缺性在下降，而复合型提示工程的门槛在上升。

- **文本 Prompt 不会消失**，它会沉到更底层，成为组装视觉提示的胶水语言。许多高层逻辑仍然适合用文字表达，比如“忽略背景，只统计前景物体”。
- **纯 Prompt 调参侠将面临冲击**。那些只会排列组合形容词、套用模板的初级技能，很容易被自动化视觉提示替代。Google 的论文已经展示了零样本下视觉提示就超越大量精心设计的文本 Prompt。
- **新职业：视觉提示设计师**。你需要懂一点视觉认知原理、会操作标注工具、能设计高效的信息图谱。这个岗位上，艺术背景和工程能力同样重要。

整个行业正走在从“语言操纵时代”迈向“多模态指意时代”的断点处。这个过渡期里，最大的机会留给那些能同时在文本和视觉两个通道里思考交互的人。

## 行走虾塘：几条冷思考与实用建议

别被标题党带节奏，踏实看清自己该做什么。三点实在的建议：

1. **立刻上手视觉提示工具**。找一台支持视觉标注的模型（Gemini 2.0、GPT-4V 的视觉问答模式），用最简单的红框、红点做 10 个测试案例。感受一下“指点”和“打字”的效率差。你会发现，某些过去需要 5 轮优化 Prompt 的任务，现在只需一个准确的圈。
2. **重新梳理你的任务，做媒介匹配**。把手上用 AI 解决的问题分成两类：强空间性任务（检测、定位、分割、导航）果断走向视觉提示；强逻辑推理任务（报告撰写、代码生成、法律分析）依然深耕语言 Prompt。不要为了追逐新范式而盲目替换。
3. **储备“视觉词汇量”**。正如写 Prompt 需要积累触发词，做视觉提示也需要积累有效的视觉标记——不同颜色、形状、粗细的画笔在模型眼中的“语义强度”完全不同。你可以开始建立自己的“视觉提示库”，比如红色圆圈代表“目标物体”，黄色箭头代表“运动方向”，绿色叉代表“剔除区域”。这将成为你的新护城河。

Prompt 工程没有死，只是脱下了文本斗篷，换上了一身像素铠甲。真正的龙虾，从来不会只守着一种捕食方式。
