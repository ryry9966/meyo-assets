去年还在疯狂比谁的参数量大、谁的长上下文吞得下整本《三体》，今年硅谷工程师饭桌上的高频词已经变成了“ROI”“去中层”和“Token成本屠夫”。36kr 那篇《中层消失，Token 狂热退潮，硅谷工程师眼里的「AI 创业下半场」》像捅了一层窗户纸——原来大家私底下都在悄悄转向，去赌一个更骨感但也更真实的 AI 下半场。

这一篇，咱们就把这层窗户纸撕大一点，看看组织结构和模型叙事都在发生什么深层位移，以及普通开发者和创业者该怎么站队。



## 中层消失了，但消失的不只是公司的“中间人”

### 1. 组织中层被吃掉：不是裁员，是根本不再需要
过去一家 AI 创业公司从 10 人到 50 人，通常会迅速长出：技术组长、产品负责人、项目经理、运营主管……这套层级在 AI 原生工作流里正在快速失效。

- **文档和沟通成本被 LLM 打骨折**：需求文档、技术方案、周报甚至跨部门撕逼邮件，都可以用 GPT-4o 级别的工具草拟、对齐、翻译成对方听得懂的版本。中层过去一大半时间是在做“信息路由”，现在一个 prompt 比 3 个会管用。
- **代码 review 和 debug 的中层把关人冗余**：GitHub Copilot Workspace、Cursor 的 agent 模式，让一个 senior dev 能直接带着 2-3 个 AI junior 干活，code review 从“check 逻辑”变成了“check 意图”。中间那层“把关型”的 tech lead 需求直接腰斩。
- **决策权上浮到下钻**：数据看板 + NL2SQL + AI 自动化归因，CEO 可以自己追问“为什么昨天留存掉了 2%”而不用等着运营总监去跑数、写分析报告。扁平化已不是管理哲学，是工具在物理上消灭了中间层的信息垄断。

### 2. 产业中层（中间件层）正在被模型与应用夹碎
这比砍几个人要命得多。以前 AI 栈是三层：基础设施（算力/模型）→ 中间件（向量数据库、LangChain 类编排框架、RAG 工具链）→ 应用。现在两头疯狂向内挤压。

- **基础模型自带 RAG、function calling、长上下文记忆**，把“外挂知识库”这种典型中间件价值空间吃掉大半。OpenAI 的 Assistants API 和 Google 的 Gemini 直接内置了多步推理、自主工具使用，你凭什么还得额外搭一套 LangChain？
- **应用层追求极致成本，正在绕过中间件**：优秀团队发现，把 prompt 优化到极致+cache 策略+自建简易索引，比接入一套通用中间件平台省钱一个数量级，而且延迟可控。YC 最新一批 AI 创业项目里，几乎没有在 pitch 里把“我们基于 LangChain”当作亮点的——说了反而像在承认自己不会做底层控制。

### 3. 工程师自己也在“去中层化”：全栈+AI = 一个人的团队
一个新梗在硅谷流传：“L7 以下都是 IC。” 一个会写 frontend、懂点 backend、会调模型 API 的全栈工程师，配上一个 Cursor 和 v0.dev，可以单枪匹马干出过去一个产品组一个月的工作量。连设计师的工作都被 Midjourney 和 Figma AI 顶了一部分。组织中层的消失，其实是超级个体崛起的 B 面。



## Token 狂热退潮：从“暴力美学”到“算力会计学”

上一波狂热是典型的供给端叙事：GPT-3 有 175B 参数，GPT-4 传说 1.8T，大家比着发论文，动辄 million-token 上下文。资本市场也买单——你能烧更多算力，就说明你有更“厚”的护城河。

### 1. 成本曲线的残酷真相
- **推理成本 10 倍速下降**：一年前 GPT-4 的 32k 上下文 API 价格是 $0.06/1K tokens，如今 GPT-4o 的价格是 $5/1M tokens 输出，便宜了近一个数量级。开源阵营更疯：Mixtral 8x22B 在 Groq 上跑出 500+ T/s，价格可以忽略不计。
- **Token 经济模型被打穿**：靠卖 Token 赚钱的初创公司，毛利正被基础模型提供方和云厂商两面夹击。Character.AI 被收购的桥段不是单一事故，是所有“大 Token 消耗型”应用的共同天花板——用户越多，亏损越猛。

### 2. “大好快”的叙事失效了，小模型 + 精巧工程开始统治
微软的 Phi-3、HuggingFace 的 SmolLM、苹果的 OpenELM 都在宣示：在垂直场景下，精心筛选数据、量化压缩后的 1B-3B 模型，能在手机端跑出 GPT-3.5 级别的效果。工程师们不再追逐“一口气吞掉 1M tokens”，而是琢磨怎么把 prompt 压缩到 200 个 tokens 依然保持准确率。这背后是一种集体反思：

- **上下文多 ≠ 可靠使用**：长上下文中信息检索的准确率（Needle in a Haystack test）虽然在进步，但对关键信息的遗漏率仍然让生产环境忌惮。与其把 50 页合同一股脑扔进去，不如先让传统检索找出相关条款，再用 LLM 精读。
- **精细流程才是护城河**：企业真正愿意付费的，不是“这个模型能写诗”，而是“它能严格按照我们的 SOP 处理 1000 个工单，错误率<0.5%”。这套流程里的 prompt chaining、guardrails、人机协同节点，没法用原始 Token 数来吹牛。



## AI 下半场的生存法则：三个务实转向

### 1. 从“模型崇拜”转向“工作流效率”
别再问“你们用的是 GPT-4o 还是 Claude 3.5 Sonnet”，该问的是“你们从 issue 到 PR 的自动化程度是多少”“客服单次解决成本降到了几分钱”。模型是建材，不是房子。赢家会是那些把 AI 当成编译器、把业务流拆解成有向无环图（DAG）的工程师，而不是天天刷榜谁是 MMLU 第一的人。

### 2. 把“去中层”当方法论，而不是裁员工具
组织上消灭中层不是目的，把省下来的沟通摩擦变成决策速度才是。可以用三步走：
- **诊断**：梳理出团队里哪些日常决策本质上只是“格式转换”或“信息搬砖”，这些是 AI 的优先吞噬目标。
- **重构**：以“人+AI助手”为最小执行单元，让一个资深 IC（个体贡献者）带着 AI 对接多个业务流，砍掉不必要的审批节点。
- **补偿机制**：省下来的人力和时间，不能简单变成额外工作量，要明确转化为创造性产出、反哺模型优化的数据飞轮，否则团队只会更卷更崩。

### 3. 在“Token 通缩”的时代做“价值通胀”的事
Token 便宜到几乎免费是大势所趋，别再想着靠卖 API 调用次数赚差价。两种方向是抗通缩的：
- **合规与信任**：金融、医疗、法律等场景里，客户愿意为“确定性”和“可审计性”支付溢价，这些无法用原始 Token 计量。
- **数据飞轮**：构建“人的反馈→模型微调→更准输出→更多用户→更多反馈”的正循环，这才是即便在 Token 免费时代也搬不走的护城河。

## 冷思考：别把上半场的水晶球扔太快
虽然中层在消失、Token 狂热在冷却，但有两件事容易被误判：
- **基础模型进步不会停，垂直工程可能一夜过时**：今天的精细 prompt pipeline，明天可能被新模型的 system 2 推理能力直接内化。时刻保持对模型代际差别的敏感度，不要把工程架构焊死在当前模型弱点上。
- **组织完全扁平化可能是另一种灾难**：当所有决策都靠 CEO + AI 从一线抓取，信息过载和决策疲劳会指数级上升。中层的本质从来不是“传话”，而是“过滤与守护”。AI 翻车的时候，总得有人类来背锅和修正。

说到底，AI 下半场不再是技术的狂欢，而是效率与信任的平衡术。把 Token 换成 Dollar，把中层换成决策速度，才是工程师最性感的 KPI。
