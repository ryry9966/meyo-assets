最近一条消息在 AI 圈子里炸出不少水花：智谱（Zhipu AI）启动科创板 IPO，拟募资 150 亿元人民币，外界开始喊它「大模型第一股」。150 亿是什么概念？2023 年整个科创板 IPO 平均募资额也就 12 亿出头，这个数字直接把它抬到了头部行列。但比起股价猜测，更值得聊的是：一家做基础大模型的公司，到底凭什么值这个钱，又会面临哪些结构性挑战？这篇咱们不喊口号，按工程师视角拆一拆。

## 一、智谱是谁：从 GLM 到完整模型矩阵

先把背景搭清楚，避免「听过名字但说不上做什么」的尴尬。

- **学术血统**：智谱孵化自清华大学知识工程实验室（KEG），早年做的就是知识图谱、预训练语言模型这条线，2020 年前后开始押注大模型。
- **代表作 GLM 系列**：GLM-130B 是国内较早开源的千亿级双语模型（2022 年），其特点是采用 General Language Model 框架，把自回归、自编码、Seq2Seq 三种范式融合在一起。后续演进到 ChatGLM、GLM-4、GLM-4.5 等版本。
- **产品矩阵**：除了基础语言模型，还有代码模型 CodeGeeX、多模态 CogVLM/CogVideoX、向量模型 Embedding 系列，以及 To B 的 MaaS 平台「智谱开放平台」。
- **客户类型**：金融、能源、政企、运营商，以及一部分互联网中长尾客户，做的是「私有化 + API」两条腿。

一句话总结：它是国内少数同时拥有「自研基础模型 + 多模态 + 商业化平台」三件套的公司。这个完整度，是它能讲出 IPO 故事的前提。

## 二、150 亿募资：一个直观的「烧钱地图」

很多人看到 150 亿的第一反应是「天价」，但放到大模型语境里，这其实只够「打一个回合」。我们粗算一下钱会花在哪。

1. **算力采购与租赁**：训练一次 GPT-4 级别的稠密模型，业内公开估算在 6000 万~1 亿美元区间；如果是 MoE 架构，单次训练成本能压到 1/3，但配套的实验、消融、对齐训练加起来也是数倍的开销。一年训 2~3 个主力版本 + 若干小模型，光训练就能消耗 30~50 亿。
2. **推理基础设施**：To B 私有化部署需要交付整套推理集群，To C/API 则要长期承担在线推理成本。推理成本随调用量线性增长，是个无底洞，必须靠规模摊薄。
3. **数据采购与清洗**：高质量中文数据、专业领域语料（法律、医疗、金融）、多模态数据，单项采购+人工标注一年 5~10 亿不夸张。
4. **人才**：核心算法科学家年薪百万美元级，团队若 500~1000 人规模，人力成本一年也是 10 亿量级。
5. **生态与应用**：投资 Agent 创业公司、做开发者社区、补贴 token 价格——这部分是「占地盘」的钱。

把账摊开看，150 亿不是「太多」，而是「刚够续两到三年的命」。这也是为什么国内外头部模型公司都在持续融资，OpenAI、Anthropic 单轮就是几十亿美金。

## 三、科创板上市：技术公司选择的现实路径

为什么是科创板，而不是港股或者美股？这里有几个工程之外的现实约束。

- **未盈利企业通道**：科创板第五套上市标准允许未盈利企业上市，对硬科技公司友好。大模型公司目前几乎不可能有规模化利润，这条路径几乎是唯一选项。
- **数据与合规**：基础大模型涉及大量训练数据、算法备案、内容安全等议题，在境内上市天然规避了跨境数据合规的不确定性。
- **战略叙事**：AI 被列为新质生产力的核心方向之一，科创板对这条赛道有明确支持态度。
- **客户结构匹配**：智谱的大客户里政企、金融、能源占比不小，境内上市能进一步降低这些客户的合规顾虑。

但也别只看好处。境内上市意味着：信息披露要求高、研发投入要被反复审视、估值锚定 A 股可比公司（而不是按美股 AI 倍数给）。简单说，故事得讲得「扎实」，不能纯靠想象力。

## 四、「大模型第一股」含金量怎么看

这个标签听着唬人，但要冷静拆三个维度。

**1. 技术维度——还在中间梯队的追赶位**

- 国内基础模型在中文场景已经能打，部分评测榜单接近 GPT-4 级别；但在长上下文稳定性、复杂 Agent 任务、代码生成的真实可用性上，与 GPT-5、Claude 3.5/4、Gemini 2 仍有差距。
- 国产模型之间也在贴身肉搏：DeepSeek 用 MoE + 极致工程把成本打了下来，通义、豆包、Kimi、MiniMax 各有侧重，智谱不是「一骑绝尘」，而是「头部之一」。

**2. 商业维度——收入结构是关键**

- API 调用收入：受价格战影响巨大，过去一年国内 token 价格降了 90% 以上。
- 私有化交付：单价高、毛利好，但交付重、复制性差，更像「项目制」而不是「产品制」。
- MaaS / 应用：还在早期，护城河不明显。
- 投资人真正想看的是：收入增速、毛利率走势、付费客户净留存（NDR）。这三个数字才是估值的锚。

**3. 生态维度——开源是把双刃剑**

- 智谱长期坚持把部分模型开源（GLM、ChatGLM 系列），这给它带来了庞大的开发者基础和声量；但开源也意味着部分商业空间被自己让渡。如何在「开源拉新」与「闭源收钱」之间切线，是长期命题。

## 五、对行业的连锁反应

如果智谱顺利登陆科创板，会触发几个可见的变化。

- **估值锚被重置**：A 股将出现一个「纯大模型」可比公司，后续月之暗面、百川、MiniMax、阶跃星辰等的融资估值都会以此为参考。
- **算力产业链受益**：服务器、液冷、光模块、国产 GPU 的订单可见度提升。
- **二级市场出现新的「AI 主题股」**：但要警惕主题炒作和基本面背离——大模型不是越炒越好，越炒反而越容易让公司动作变形。
- **人才流动加速**：上市公司股权激励的吸引力，会再一次重塑国内 AI 人才地图。

## 六、给不同身份的实用建议

说了这么多分析，落到行动层面，给三类人三条「冷思考」：

1. **如果你是开发者**：别只追「谁是第一股」，更值得关注的是模型 API 的稳定性、长期价格策略、私有化交付能力。技术选型上保留多模型抽象层（比如统一走 OpenAI 兼容接口），别把自己锁死在一家供应商上。
2. **如果你是企业决策者**：上市本身不等于交付能力提升。评估供应商的核心仍然是 POC 真实效果、私有化运维成本、合规与数据隔离方案。给「上市」溢价，不如给「SLA」溢价。
3. **如果你是普通围观群众**：把它当作观察 AI 产业进入「资本市场化」阶段的一个样本，而不是短线博弈的标的。大模型这条赛道，胜负要用 5 年甚至 10 年来评判，IPO 只是开场哨，不是终场。

大模型行业现在处在「技术曲线还没收敛、商业模型还没跑通、监管框架还在演进」的三重不确定中。150 亿听起来很多，但放进这三重不确定里，更像是一张「续命门票」而不是「胜利奖杯」。真正的好戏，在上市之后才开始。
