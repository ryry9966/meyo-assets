## 背景

E2E 测试是所有测试层级里最耗人工的一环：写 Playwright 脚本、维护 selector、跟进页面改版，大把精力花在机械操作上。Agent 出现后，很多团队的第一反应是“让 AI 全自动生成测试”。但直接扔需求给 Agent 写一整套 E2E，得到的往往是伪代码、脆弱断言和一路红灯的 CI。

问题不在模型能力，而在于 Agent 对被测系统没有可靠的观测通道。我在 OpenClaw 里跑通的协作模式是：通过 MCP 让 Agent “看得见” 页面，再把测试任务拆成探索、计划、生成、维护四个阶段。这个流程在真实项目里用了两个月，稳定性和可维护性都比裸写脚本好不少。

## 问题：直接生成的三个典型坑

1. **幻觉选择器**：AI 生成的 selector 和真实 DOM 偏差很大，测试一跑就红。
2. **断言空洞**：只检查 “页面没报错”，没有对关键业务状态做校验。
3. **上下文漂移**：在一个 session 里反复让 Agent 改代码，几轮之后它开始编造之前的页面信息。

根本原因就一句：Agent 没有真正接触页面，全靠训练记忆在猜。

## 做法：四步协作流程

### 步骤一：测试探索（Sanity Walk）

在 OpenClaw 的 agent 配置里注册 Playwright MCP 服务（`npx @playwright/mcp`）。先不写任何测试代码，让 Agent 实际走一遍目标页面，采集真实 DOM 结构、可交互元素、加载行为。这一步的核心目的是建立“共享事实”：Agent 对页面的认知来自真实观测，而不是模型记忆。

### 步骤二：输出测试计划（JSON Plan）

不让 Agent 直接写代码，而是先产出结构化测试计划，包含用户路径、关键交互节点、断言方向。计划用 JSON 落地，方便跟踪和 diff。举例：

```json
{
  "path": "登录-购物车结算",
  "steps": [...],
  "asserts": [
    {
      "target": "[data-testid=cart-total]",
      "condition": "text 为 ¥230"
    }
  ]
}
```

这一步是让 Agent 把思路显性化，你可以提前发现它理解错了需求，而不是等代码写完再返工。

### 步骤三：生成代码 + 执行验证

Agent 根据计划生成 Playwright 代码后，**立即在本地跑**。只有通过的执行结果才有资格进入 MR。这里必须给 Agent 一份测试规范文件（如 `e2e-agent.md`），里面写明：优先使用 `data-testid`、禁止固定时间等待、断言必须涉及业务语义。没有这个文件，Agent 会自由发挥出一堆脆弱脚本。

### 步骤四：回归维护闭环

页面改版导致测试失败时，把失败输出和 DOM 变化信息丢回 Agent，让它提修复方案，人工确认后执行。CI 里用 `openclaw run` 定期触发一批 E2E 任务，输出结构化报告，避免人工在日志里翻找失败原因。

## 踩坑点

- **selector 策略不前置，Agent 必用 CSS 继承链**。强制维护一份 `data-testid` 白名单，Agent 只能从列表里选。
- **Agent 会发明不存在的状态**。禁止它“凭经验”写断言，要求每个断言引用真实 DOM 属性或接口响应字段。
- **截图和 DOM 要配合使用**。截图能看到视觉布局异常，DOM 能拿到语义结构，只用其中一个会漏掉另一类问题。
- **一个 session 别干所有事**。探索、生成、修 bug 分开，中间状态存文件，避免上下文被撑爆后编造信息。
- **不要让 Agent 自动修复并自动通过**。修复建议必须人工 review，否则“修好的测试”会变成“为了让测试变绿而忽略断言的测试”。

## 可复用建议

1. 每个项目建一份 `e2e-agent.md`，写死 selector 规范、断言规范、文件组织方式，Agent 每次开工先读它。
2. 测试计划用 JSON 文件管理，扩散和回滚都方便。
3. 从一条核心业务路径开始试点，跑通全流程后再铺开。
4. 在 CI 阶段把历史失败用例喂给 Agent 做趋势分析，定位高频不稳定模块。
5. 配置一个 MCP 工具专门返回最近 N 次测试结果摘要，节省排查时间。

## 总结

Agent 协作写 E2E 的价值，不在 “全自动”，而在于把探索、计划、生成、维护拆开，让 Agent 每一步都有明确上下文和校验标准。能落地的核心是两件事：给 Agent 装上可靠的眼睛（Playwright MCP），以及用测试规范文件卡住它的自由发挥。这套流程不需要改现有基础设施，OpenClaw 接一个 MCP 就能跑起来，值得在真实项目里试一轮。
