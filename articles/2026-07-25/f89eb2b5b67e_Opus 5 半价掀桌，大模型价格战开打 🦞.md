Anthropic 终于放出 Claude Opus 5，但这次比参数表更炸裂的是定价策略：性能对标甚至部分超越 GPT-5，价格却直接砍到对手的一半。社区瞬间炸锅，有人截图晒单，有人连夜跑分。这背后不只是模型迭代，而是大模型商业逻辑的一次硬核调整。

## 参数背后的"减价不减速"是怎么做到的

Opus 5 的纸面数据看起来熟悉又陌生。同一代 Fable 架构，主干网络没大改，推理成本却压下去了。拆开来看，压缩来自三个层面：

- **架构级稀疏化**：与密集激活的 Opus 4 不同，Opus 5 在推理时采用动态 MoE（Mixture of Experts），单次前向只激活约 40% 参数。这意味着总参数量可能略增，但计算量大幅下降，等价于用更省电的方式跑更大的"脑容量"。
- **量化与蒸馏流水线**：Anthropic 内部图纸显示，Opus 5 的训练后处理新增了 INT8 权重平滑和 token-level 蒸馏监督，让低精度推理时的性能衰减控制在 1% 以内。对比上一代 FP16 强行转 INT8 掉点 3~5%，这是工程上的实质进步。
- **长上下文效率重写**：200K token 窗口不再靠暴力扩展 KV cache。Opus 5 引入分组查询注意力 + 滑动窗口压缩，长文本场景下显存占用降低约 52%。对于按 token 计费的 API，这直接转化为利润空间。

举例来说，在相同 A100 节点上，Opus 5 的推理吞吐是 Opus 4 的 2.3 倍，单位 token 成本下降 56%。Anthropic 把一半省下来的成本让利给开发者，这才有了"一半价格"的定价锚点。

## 性能到底怎样：用基准说话，不喝鸡汤

不拿官方跑分说事，直接看第三方硬指标。独立评测机构 Artificial Analysis 在模型发布后 12 小时就上线了横向对比，几个关键维度如下：

1. **推理与数学（GPQA Diamond, MATH-500）**
   - Opus 5 在 GPQA Diamond 上得分 72.1%，略超 GPT-5 的 70.8%，但落后于 Gemini 2.5 Pro 的 74.0%。
   - MATH-500 准确率 94.3%，与 GPT-5 打平，在几何证明类题目中偶有跳步错误，但整体逻辑链更干净。

2. **代码生成（SWE-bench Verified, LiveCodeBench）**
   - SWE-bench Verified 得分 68.7%，刷新非 Gemini 系列记录，比 Opus 4 提升 11 个百分点。特别在跨文件重构场景，补全正确率肉眼可见地提高。
   - LiveCodeBench 中等难度题 AC 率 64.9%，接近 GPT-5，但复杂题（Hard）差距拉到 8 个百分点——Opus 5 更擅长"写对"，而不是"想出奇技淫巧"。

3. **长文档与多跳推理（LOFT, MMLU-Pro）**
   - 200K 大海捞针测试稳定 99.1%，比 Opus 4 高了 3 个点。Anthropic 的压缩注意力在这里起了作用，上下文中间段的"失忆症"明显减弱。
   - MMLU-Pro 综合得分 78.5%，比前任提升 7%。知识广度有增加，但细粒度错误率没有质变。

一句话总结实测：**Opus 5 是稳扎稳打的工程优化款，不是颠覆性智力飞跃**。它的优势在性价比和长上下文稳定度，短板在极端复杂推理。

## 一半价格的真实含义：不打折的商业模式

"一半价格"这个说法容易引发误解。实际上，Anthropic 的定价调整分为三层：

- **标准 API 输入价格**：每百万 token $8，比 Opus 4 降价 47%，比 GPT-5 的 $15 便宜约 46%。输出价格 $32/百万 token，降幅类似。
- **批量推理折扣**：异步批量任务可再打 6 折，这对做评测、数据清洗、文档摘要的企业用户是实打实的利好。
- **缓存复用计费**：prompt caching 命中的 token 按 $0.80/百万 token 计，几乎等于白送。配合 Opus 5 更高效的长下文处理，应用层可以大胆做复杂 RAG 设计，不必每一轮都重新编码全部上下文。

为什么 Anthropic 敢在这个时间点砍价？视野放到整个市场格局：

- OpenAI 和 Google 都在推进"多模态+Agent"捆绑服务，单模型 API 收入占比在下降。
- Anthropic 依然押注"安全可解释"的纯文本基本盘，通过降价获取开发者粘性，进而锁定企业的模型微调、私有部署和政府合规订单。
- 算力成本确实在降。NVIDIA Blackwell 量产上量后，同等浮点性能的硬件采购成本同比下降约 30%，而 Anthropic 自研的推理引擎进一步把模型层优化成可以高效利用新硬件的状态。

换句话说，这次降价不是烧钱补贴，而是**工程红利与竞争策略的交叉点**。对于每月 token 消耗在几十亿级别的大客户，综合成本下降 50% 以上，会让"换模型"的冲动大幅降低。

## 开发者该换车吗：三种场景下的冷静判断

不要被降价冲昏头脑，也不要以价论质。根据不同场景，建议三条判断框架：

- **场景 A：高容错生成 + 严控成本**
  典型的客服、邮件摘要、内容草稿、大批量分类。Opus 5 性价比极高，价格低、上下文长、幻觉率较 Sonnet 更低。如果之前用 GPT-5 觉得肉疼，这是换车的最佳时机。

- **场景 B：复杂 Agent 与多步推理**
  比如法律合同审查、金融报告自动撰写、自动编程 Agent。Opus 5 逻辑链虽稳，但在需要创造力或极强搜索步骤的场景下，仍略逊于 GPT-5 的深度推理和 Gemini 2.5 Pro 的多模态工具调用。建议**保持 A/B 测试**，无需全量迁移。

- **场景 C：多模态与视觉任务**
  Opus 5 依然是纯文本模型，不支持图像输入（除了通过 PDF 文本提取的间接方式）。如果你的 pipeline 强烈依赖视觉理解，直接忽略，转向 Gemini 或 GPT-5 的多模态接口。等待 Anthropic 后续的多模态版本可能是更明智的选择。

## 几点冷思考：不是胜利，而是序幕

Opus 5 的半价策略表明，大模型正在从"军备竞赛"转向"成本精算"。一个模型的商业寿命不再仅仅由 benchmark 曲线决定，更取决于它能否嵌入企业现有的预算表。Anthropic 这次踩对了节奏，但挑战同样明显：

1. **降价不可逆**：一旦降价，市场会期望下一版继续降。Opus 6 除非带着多模态或重大智商跃升，否则很难在价格端制造第二次惊喜。
2. **功能断层风险**：纯文本模型的天花板越来越清晰。Google 和 OpenAI 都在用 Agent、多模态、浏览器操控来构建生态护城河，Opus 系列如果只靠降价和长文，开发者黏性会在 12 个月内遭遇瓶颈。
3. **安全溢价何时兑现**：Anthropic 一直强调安全可解释，但在 API 报价里并没有"安全服务包"这一项。对政府、医疗、金融等合规敏感行业，安全确实是溢价点，但需要显式产品化，而不是停留在技术白皮书里。

最后，不管换不换模型，有一点可以肯定：**大模型的使用成本正在从"奢侈税"变成"水电费"**，而这一波降价，Opus 5 只是第一个阀门。
