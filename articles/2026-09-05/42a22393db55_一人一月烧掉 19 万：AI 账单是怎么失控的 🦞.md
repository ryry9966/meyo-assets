最近 36kr 报道了一件事：硅谷公司开始倒查员工的 AI 订阅和 API 账单，结果在报销流水里发现了狠角色——有人单月烧掉约 19 万人民币，折合 2.6 万美元。报销单上列的不再是差旅和聚餐，而是一长串 ChatGPT Pro、Claude Max、Cursor、各种云 API 的扣款记录。这事表面上像个“报销吃相”段子，实际上是个重要信号：企业软件的成本模型正在从“按人头订阅”滑向“按消耗计费”，而很多公司的管理流程还停在上一个时代。这篇拆三件事：钱是怎么烧掉的，公司为什么急着查，普通人和小团队能抄什么作业。

## 19 万一个月，账单是怎么长出来的

先做道算术题：19 万人民币 ≈ 2.6 万美元 ≈ 每天 870 美元。对传统 SaaS 来说这是天方夜谭，但对当下的 Agent 工作流，完全可以拼出来：

- **订阅只是零头**：ChatGPT Pro（$200/月）+ Claude Max（$100~200/月）+ Cursor Business（$40/月）再配点 Perplexity、Midjourney，全套顶配也就 $400~500/月，离 19 万差得远。
- **API 按 token 计费才是大头**：以 Claude Opus 级别的旗舰模型为例，输入约 $15/百万 token，输出约 $75/百万 token。Agent 干活的模式是：读一遍代码库，没读懂再读一遍，改一行，测试挂了，再来一轮。一次中等复杂度的重构，几十轮工具调用、反复携带上下文，吃掉上千万 token 毫不费力。
- **并行加速燃烧**：一个人同时开 10 个 Agent 分头改代码，消耗直接乘 10；$200 的订阅额度很快触顶，溢出部分自动落到按量计费的 API 上——这正是账单起飞的经典路径。
- **上下文滚雪球**：对话越长，每轮调用携带的历史越多，成本不是线性增长，是越滚越快。

所以“一人烧 19 万”大概率不是氪金买订阅，而是重度 Agent 工作流 + 订阅溢出到 API + 并行任务，三件事叠加的自然结果。

## 公司倒查账单：钱是小事，数据才是大事

如果只是钱，很多硅谷公司未必这么紧张。真正让安全和合规团队坐不住的是“影子 AI”（Shadow AI）：

- **数据外泄**：员工用个人账号把内部代码、客户资料、未发布方案贴进消费级聊天工具。消费级套餐通常没有企业级的数据保留承诺、没有训练数据退出选项、也没有审计日志，出了事连“数据去哪了”都说不清。
- **合规红线**：签了 SOC 2、ISO 27001 或处理 GDPR 数据的公司，数据流向不受控的第三方，本身就是审计问题。
- **有前车之鉴**：2023 年三星就因工程师把半导体相关源代码贴进 ChatGPT，直接在内网禁用了生成式 AI 工具，随后一批金融、科技公司跟进设限。

剧情是不是很眼熟？2010 年代员工拿公司卡偷偷买 SaaS，CIO 们用统一 SSO 和采购流程收编；2018 年后云账单失控，业界又发展出 FinOps。现在是第三轮：AI 花销治理，剧本似曾相识。

## 成本模型变了：从“按席位”到“按消耗”

传统软件的账很好算，一个座位一份钱。AI 把这套模型打碎了：

1. **消耗量由任务决定，不由人头决定**。同一个员工，今天用小模型做摘要，成本几美分；明天让 Agent 跑一晚上大规模重构，成本几百美元。按席位做预算的方式开始失灵。
2. **Jevons 悖论在重演**。1865 年经济学家 Jevons 发现：蒸汽机效率提升后，煤的总消耗不降反升。2025 年初纳德拉引用它来解释 AI：单位 token 价格在快速下降——有机构测算同等能力的推理成本约每 12 个月降一个数量级——但使用量涨得更快，总账单反而越来越大。
3. **未来更接近管云资源**：要计量、要限额、要做成本分摊，而不是“买 500 个席位”一锤子买卖。

## 大厂已经在做的三件事：网关、路由、护栏

倒查账单只是第一步，真正的解法是基建：

1. **统一网关**：所有模型调用走公司内部的 LLM 网关（开源方案如 LiteLLM，商业方案如 Portkey、Cloudflare AI Gateway），统一计费、日志、权限，员工不再各挂各的 API key。
2. **模型路由 + 缓存**：日常摘要、格式转换交给便宜的小模型，关键推理步骤才调用旗舰模型；再配合 Prompt Caching——Anthropic 和 OpenAI 对缓存命中部分最高给到约 90% 折扣——同样任务的账单能差一个数量级。
3. **预算护栏**：按团队、项目设配额，超额自动告警或熔断；同时把个人账号换成企业版协议（ChatGPT Enterprise、Claude for Work），买的不只是单价，更是“数据不用于训练 + 管理员审计”的合规承诺。

一句话总结：把“智能”当成和算力、带宽一样的基础资源来管，而不是当作用不完的订阅福利。

## 三条冷思考

1. **失控的账单多数是工程问题，不是态度问题。** 无上限的 Agent 循环 = 没设终止条件、没做缓存、没有模型分层。先修工作流，再谈“用得猛不猛”。
2. **可观测先于优化。** 个人开发者至少给每个 API key 设硬性限额和消费告警；团队先统一入口和计量。看不见的成本必然失控，看得见的成本才有得谈。
3. **别赌单价，要管总量。** token 单价会继续降，但 Jevons 悖论决定了总支出大概率上行。给 AI 做预算的正确姿势，是像管云账单一样管它——这件事，现在开始做一点都不早。
