最近 36kr 一条消息在圈内刷屏：Anthropic 明确表态，不打算参与大模型的价格战，"只做值钱的生意"。放在一个 API 单价几乎按季度腰斩的行业里，这句话多少有点逆行的味道。但有意思的是，人家不是嘴硬——Claude Code 的收入爬坡和企业客户的续约数据都摆在那。本虾今天掰开揉碎讲三件事：价格战为什么打起来、Anthropic 凭什么不打、"贵"背后到底怎么算账。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-05/6e5a35853e77cc8a.png)

## 一、价格战为什么打得起来

价格战不是谁脾气差，是行业结构决定的。几个因素叠在一起：

- **推理成本持续下降**：MoE 架构、低精度量化、批量调度、KV cache 复用、专用推理芯片，单 token 成本几乎一年降一个数量级。成本降了，价格自然有得打。
- **开源模型追平"够用线"**：DeepSeek、Llama、Qwen 把"能用"的门槛拉到极低，闭源厂商被迫用价格回应。
- **切换成本几乎为零**：对开发者来说，换模型基本就是改个 endpoint、重跑一遍 prompt 的事。用户忠诚度比金鱼的记忆还短。
- **补贴换生态**：云厂商和后发者用低价圈开发者，和当年外卖、网约车的剧本一脉相承——先把人圈进来，再想怎么赚钱。
- **能力被跑分透明化**：benchmark 全公开，差异越来越难讲成故事，那就只好讲价格。

小结一句：当产品同质化、切换成本低、又有补贴方入场时，价格战几乎是必然结局。

## 二、Anthropic 的底牌：贵，但贵得有出处

敢不打价格战，靠的是几块实打实的牌：

- **代码场景的硬实力**：Claude 系列在 SWE-bench 这类真实软件工程基准上的表现，加上开发者社区的口碑，让它吃下了"agent 写代码"这个高价值场景。Claude Code 作为命令行/IDE 工具，直接把模型能力变成工程师的日常工作流。
- **企业市场的信任资产**：Constitutional AI、负责任扩展政策（RSP）、安全叙事，对金融、医疗等行业的采购决策者来说，这些是能签字的理由，不只是营销话术。
- **Agentic 场景的可靠性**：长任务、多步工具调用、复杂指令遵循——agent 干活时模型差一点，整条链路就崩。这种场景下，对"可靠性"的付费意愿远高于对"便宜"的敏感度。
- **定价动作本身就是信号**：Opus 系列的 API 定价长期处在行业天花板，Claude Max 订阅开到 $200/月。据公开报道，其企业收入占比和 ARR 增速在头部实验室里都属于最陡的一档。

用波特的竞争框架说，这是主动放弃"成本领先"，全力押注"差异化"。一句话概括：它卖的不是 token，是"这活儿能一次干成"。

## 三、算一笔账：贵模型的"总成本"可能反而低

这是全文最核心的机制，值得展开算。

**总成本 ≈ token 费用 + 返工成本 + 事故成本**

拿一个 agent 修 bug 的任务举例：

1. 任务大约消耗 800K token（agent 每一步都要重读上下文，消耗比想象中大得多）；
2. 用强模型（输入约 $15/M）：单次成本十几美元，一次跑通；
3. 用便宜模型（约 $0.5/M）：单次不到 1 美元，但成功率低，平均重试 3 次，还可能需要工程师人工兜底修一轮；
4. 算总账：便宜模型的 token 费 ×3，再加上 1 小时工程师时间（$50–$100）。强模型反而整体更便宜，当天就能交付。

更关键的结构性事实是：**agent 时代，token 消耗在整个任务成本里是零头，人类的时间和返工才是大头。** 一次重试循环烧掉的钱，可能还不如工程师喝杯咖啡的时间值钱。只要场景是"人类时间为主要成本"，价格战就打不进来——这正是 Anthropic 押注的结构性位置。

当然，反过来也成立：如果你的场景高频、简单、容错高（分类、抽取、格式转换），便宜模型就是理性选择。这也是 Anthropic 自己保留 Haiku 这类小快灵产品线的原因——高端定位不等于全线高价。

## 四、高端策略的边界：这不是稳赢的牌

把话说全，高端定位也有它的命门：

- **能力差距收窄的风险**：DeepSeek-R1 已经证明，可以用低成本逼近前沿推理能力。一旦开源模型在 coding agent 上把差距抹平，溢价逻辑的地基就松了。
- **企业客户比想象中精明**：大公司都有自己的 evals 流程，benchmark 是公开的，谁家平替够用，采购委员会看得一清二楚，合同说换就换。
- **高端是一场不能停的军备竞赛**：每次 frontier 级训练 run 的成本以亿美元计，溢价收入必须持续覆盖下一次豪赌。停更一版，差距就缩一截。
- **差异化不自动等于护城河**：它只是护城河的原材料，能不能挖成河，取决于每一代模型能否持续领先。

所以这句话更准确的读法不是"我们不降价"，而是：**在能力差距还能撑住溢价的窗口期，把钱投在拉开差距上，而不是投在降价上。** 这是一场和时间赛跑的定价策略。

## 五、给开发者和团队的三条冷思考

不管你是做选型的工程师，还是做 AI 产品的创业者，这件事都有可操作的部分：

1. **用自己的任务做 evals，别只看跑分买模型**。跑分是别人出的题，你的任务是你的题。搭一个 20–50 条真实 case 的回归测试集，每次换模型跑一遍，比任何 benchmark 都管用。
2. **算总成本，不算单价**。一张表就够：token 费用 + 重试次数 × 单次成本 + 人工审查时间 × 时薪 + 延迟与事故损失。很多"便宜"的模型，算完总账并不便宜。
3. **架构上保持可切换**。把 LLM 调用层抽象出来（用 LiteLLM、OpenRouter 这类网关，或者自建适配层），把模型当可替换零件。这样不管市场上打不打价格战，主动权都在你手里。

最后收个尾：价格战是同质化的终点，却是差异化的考题。Anthropic 那句"只做值钱的生意"，翻译成工程师语言就是——先把别人替代不了你的那部分拉开差距，再谈定价。
