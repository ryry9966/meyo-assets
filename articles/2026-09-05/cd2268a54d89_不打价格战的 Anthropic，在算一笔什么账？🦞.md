最近，Anthropic 公开表态：不打价格战，只做值钱的生意。这话放在当下听颇有点“头铁”——过去两年，大模型 API 的 token 价格一路跳水，部分模型便宜到几乎论“斤”卖。但把商业逻辑拆开看，这不是嘴硬，而是一整套关于“卖什么、卖给谁、怎么定价”的策略选择。这篇就拆三件事：价格战是怎么烧起来的，Anthropic 不参战的底气在哪，以及“按价值定价”这门生意的底层经济学。

## 价格战是怎么烧起来的

大模型 API 的降价速度，比当年的云计算还凶猛：

- 2023 年起，多家厂商掀起降价潮，部分入门级模型的调用成本在一年内降了一个数量级；
- DeepSeek 把性价比推到极致：开源权重 + 极低 API 定价，旗舰模型百万 token 的价格只有头部闭源模型的零头，直接改写了全行业的心理价位；
- Meta 持续开源 Llama 系列，等于给闭源模型的价格封了顶——你收的每一分钱，都在和“免费”竞争；
- 成本端也有支撑：MoE 架构、KV cache 优化、量化、批处理等工程手段，让单次推理成本持续下探。

经济学上这很好解释：当产品在用户眼里差异很小、可替代性强时，价格就成了唯一竞争维度，价格战是自然结局。真正的问题是：大模型市场，真的“无差异”吗？

## Anthropic 敢不打价格战的三个支点

Anthropic 的判断是：至少在高端市场，差异真实存在，而且客户愿意为差异付钱。

1. **场景溢价：代码与 Agent。** Claude 系列靠编程能力建立口碑，Claude Code 这类工具直接长在开发者工作流里。编程是典型的高价值场景：一名工程师时薪几十美元，模型若每天帮他省下几个小时，API 花费在总成本里几乎可以忽略。
2. **企业客户买的是确定性。** 大机构采购模型时，排序通常是稳定性、安全记录、合规、数据隔离、SLA，最后才轮到单价。B2B 决策的本质是风险最小化，而非成本最小化——一次事故造成的损失，远超省下的那点 token 钱。
3. **安全叙事的心智占位。** 从 Constitutional AI 到可解释性研究，Anthropic 在“对 AI 使用持谨慎态度的大型机构”里建立了品牌。这类客户恰恰最不敏感于价格、最敏感于风险。

一句话概括：Anthropic 卖的不是 token，而是“把事情做成”的结果。

## 值钱生意的经济学：按价值定价

定价策略教科书上基本就三种：成本加成定价、跟随竞争定价、按价值定价。

- **按成本定价**：算清 GPU 折旧、电力、带宽，加上毛利。适合同质化商品——就像买大蒜，谁便宜买谁，没人在意品牌；
- **按价值定价**：算清客户用它赚了多少、省了多少，从中分一杯羹。

关键在于：当模型产出能直接变现——写代码、跑客服、生成营销内容——买方算的是 ROI：花 100 美元省下 1000 美元人力，这笔账成立，单价就不再是首要变量。NVIDIA 是最好的参照：H100 毛利率高到离谱，客户照样排队抢购，因为大家算的是回本速度，不是单价。

这背后是需求价格弹性：如果客户“贵一点也照买”，定价权就在你手里；如果“一涨价就流失”，你就被锁死在成本线上打转。Anthropic 赌的是：高价值场景的头部客户，价格弹性很低。

## 历史参照：不打价格战的赢家与输家

- **Apple**：从不参与 Android 阵营的价格混战，靠生态与体验维持溢价，长期拿走手机行业的大部分利润；
- **Intel 与 AMD 的前半场**：性能领先时 Intel 毛利高企；一旦被追平、进入同质化，立刻滑入价格缠斗；
- **反例**：共享单车、外卖补贴大战，烧钱换来的份额，在补贴退坡后大量蒸发。

规律很清晰：价格战适用于“规模经济显著 + 产品无差异”的行业；而当能力差异显著、且客户能感知到差异时，溢价策略反而成立。大模型恰好属于后者——顶级与二线模型的差距，开发者是能实实在在感受到的。



## 但溢价能守多久

这条路线并非没有隐忧：

- **能力差距的可持续性存疑。** 开源模型迭代速度惊人，DeepSeek 靠工程创新把训练与推理成本打了下来，头部与追赶者的差距在肉眼可见地缩小；
- **商品化风险。** 如果模型层最终像云计算一样趋同，溢价会被逐步抹平，“不打价格战”就可能变成“没资格打价格战”；
- **嘴上不动，身体很诚实。** Anthropic 自己也在调整订阅与 API 结构、做产品分层，说明“不打价格战”不等于“价格永远不动”，更像是不做无底线的单价竞赛。

## 三条冷思考

1. **看 AI 公司的健康度，别只盯用户量和降价幅度。** 更该看它在高价值场景的渗透率：编程、企业服务、Agent 工作流贡献的收入占比，才是可持续性的硬指标。
2. **对使用者：token 单价不等于总成本。** 把“完成任务的总账”算全——重试次数、返工率、人工校验时间。便宜的模型若要反复重来，综合算下来可能更贵。
3. **对从业者：往“能定价价值”的环节走。** 越靠近应用、Agent、垂直场景，越能按结果收费；越靠近纯模型调用，越容易陷入单价竞赛。价格战打不死的，永远是那些卖结果、而不是卖 token 的生意。
