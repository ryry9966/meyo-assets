36kr 这条消息在群里刷屏时，不少人的第一反应是“蒸馏还能被禁？”。Fable 5.1 改写自家 API，矛头直指行业里心照不宣的老路子——用大模型 API 的输出去喂自己的小模型。厂商这次没停留在条款里那句“敬请勿用”，而是从接口层动了刀。这事值得认真聊：它大概率是大模型行业“低成本搭车时代”的收尾信号。这篇把三件事讲透：蒸馏为什么便宜，“切断后路”在技术上怎么实现，以及普通团队该怎么应对。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-05/f833ab6059d53e95.png)

## 蒸馏是什么：一门“老师教学生”的老手艺

- 学术起点是 2015 年 Hinton 那篇经典论文 Knowledge Distillation：学生模型不学硬标签，而是去拟合教师模型的软标签（概率分布），因为分布里藏着“类与类之间有多像”的暗信息。
- 到了大模型时代，玩法变了：API 不吐 logits，于是最主流的做法变成拿输出文本当训练数据——教师生成大量高质量问答和推理链（CoT），学生直接做 SFT。抄的不是答案，是“答题方式”。
- 为什么有效：教师输出里编码了它的格式感、语气、逐步推理习惯、拒答策略和对齐结果，这些恰恰是最烧钱、最难自己从零造的部分。
- 几个经典案例：
  - 2023 年斯坦福 Alpaca：175 条种子指令让 text-davinci-003 自举出 52k 条数据，几百美元微调出一个能打的 7B；
  - 微软 Orca 用 GPT-4 的“解释式”输出做 explanation tuning，把推理过程也抄了过来；
  - phi 系列大量依赖 GPT-4 合成数据，把“教科书式数据”路线走到了极致。

## 蒸馏为什么曾是性价比之王：算一笔账

- 成本差距是数量级的：公开估算里 GPT-4 量级的训练成本超过 1 亿美元，Meta 论文披露仅 Llama 3 405B 预训练就用了三千多万 GPU 小时。而走 API 蒸馏一个 7B 模型：几万条样本，几千到几万美元封顶。
- 更妙的是，API 输出是“自带 RLHF 的成品”：对齐、安全、格式、语气全打包，等于把最贵的“人肉标注 + reward model”环节外包给了别人。
- 法律上是灰色地带：头部厂商条款早写明“不得用输出训练竞争模型”，但“竞争”边界模糊、举证困难，长期处于违规成本≈0 的状态。
- 开源是唯一的例外：从 Llama、Qwen 这类开放权重模型蒸馏，协议明确允许甚至鼓励，完全合法。
- 于是过去两年的默认剧本：闭源 API 冷启动 → 蒸馏微调 → 小模型降本 → 对外讲“自研”故事。

## “切断后路”的三板斧：指纹、水印、接口改写

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-05/357e769154024310.png)

报道说 Fable 5.1 是“改写 API”，拆开看其实是三层组合拳：

**1. 风格指纹检测**
- 每个模型都有统计指纹：高频词（前两年学术界集体吐槽 GPT 满嘴 "delve"）、标点习惯、排版偏好、emoji 使用模式。
- 训一个轻量分类器就能判断“这段文本出自谁手”，相关研究里准确率普遍能到九成以上。
- 厂商还能反向扫描自家流量：谁在批量拉取“训练集形态”的数据——覆盖面广、重复率低、指令分布异常均匀——基本一目了然。

**2. 输出水印与蜜罐**
- Kirchenbauer 等人 2023 年提出 soft watermark：把词表切成绿/红两份，生成时轻微偏置采样、偏向绿词。单句看不出来，几万条做统计检验立刻现形，相当于给每句话盖了隐形章。
- 更刁钻的是蜜罐：往输出里埋极罕见的 token 组合甚至虚构事实（类似老地图上的“陷阱街道”），对方一蒸馏，学生模型里一查一个准。

**3. 接口层改写**
- 这就是“改写 API”最字面的部分：服务端对输出做规范化与随机化改写，打散稳定的风格信号；抹掉原始 CoT 痕迹；按客户注入个性化水印。
- 再叠加请求模式分析，识别批量抽取行为，按条款处置。
- 得说句实话：没有银弹。文本一旦交付就在用户手里，攻防注定是长期猫鼠游戏。但把“零成本违规”抬高到“有检测、有证据、有处置”，商业威慑已经足够成立。

## 洗牌之后：谁难受，谁舒服

- 难受的：
  - 把“蒸馏 + 微调”当核心路线的创业公司，自研故事讲到一半，被迫回头补数据、补算力、补评测；
  - 靠近道超车的二线实验室，成本结构一夜向一线看齐。
- 舒服的：
  - 开放权重生态：Llama、Qwen 成了合法蒸馏的几乎唯一源头，引力明显上升；
  - 数据与评测服务商：合规的合成数据管线、领域评测集变成硬通货；
  - 一线厂商自己：护城河加固，API 定价逻辑更硬。
- 一个值得琢磨的信号：“模仿前沿”和“自己成为前沿”之间的成本差被重新拉大，能力扩散速度会放缓。这不是技术退步，是定价体系回归正常。

## 给从业者的三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-05/058b5b1522763fb8.png)

1. **条款先于技术。** 动手前先读 ToS，把数据来源分成三类：明令禁止（多数闭源 API）、明确允许（开放权重模型）、灰色地带（个别企业条款）。记住灰色地带不是护身符，只是延期偿付。
2. **蒸馏当起点，别当终点。** 蒸馏最适合冷启动，真正的壁垒是你自己的领域数据、反馈回路和评测集。学生模型经典的坑是“榜单追平、鲁棒性欠费”——教师没见过的长尾场景一冲就垮。所以一定要建自己的 eval，别只盯通用 benchmark。
3. **把“管道随时会关”当默认假设。** 如果产品规划依赖“持续从某个 API 抽数据”，就按这条管道明天就断来设计架构：用开放模型当教师、用自己的线上推理做数据飞轮，把外部依赖压到最低。

蒸馏这门手艺不会消失，它只是从“默认免费”变回“明码标价”。Fable 5.1 这一刀切掉的不是技术，而是搭车的默认选项。对认真做事的团队，墙的存在反而让路变清晰：要么付钱，要么开源，要么自己变强。省下来的那点算力，本来就该花在自己真正的数据上。
