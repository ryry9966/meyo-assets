## 研学怎么长成一门千亿生意

研学不是新事物，但它长成“产业”其实很晚，需要三个条件凑齐：

- **政策起点**：2016年底，教育部等11部门联合发文，将研学旅行纳入中小学教育教学计划。研学从“学校组织的春游”升级为“有政策背书的教育产品”，门槛和溢价空间同时被打开。
- **需求转移**：双减之后，学科培训退场，家长的教育预算需要新的出口。素质教育、科技启蒙接棒成为新叙事，焦虑没有消失，只是换了载体。
- **AI 点火**：2023年 ChatGPT 出圈后，"AI"成为教育市场最强的溢价词。有第三方机构测算，2023年国内研学游市场规模约1469亿元，预计2026年将突破2400亿元，科技类主题是其中增速最快的细分之一。
- 与此同时，近年多地市场监管和消保部门密集发布研学消费提示，集中指向几个老问题：资质不全、行程与宣传不符、“游多学少”、退费困难。

一句话总结这个市场的结构：**需求端是真焦虑，供给端是真溢价，中间隔着一层“科技感”的包装。**



## 钱从家长口袋流向哪里：拆一条成本链路

一张万元营费大致会这样分账（按行业普遍结构估算）：

1. **获客与渠道，约25%~35%**：信息流投放、代理商返佣、KOL 探营视频。家长刷到的那条“孩子眼里有光”的短视频，本身可能就吃掉营费的三分之一。
2. **交通、食宿、场地，约40%~50%**：大巴、酒店、景区门票、大厂园区参访的对接费用。这部分决定体验下限，但不决定教育上限。
3. **真正的教学，约10%~20%**：讲师费、教具、云服务。这里有个反直觉的事实，大模型 API 的调用成本极低，一个营期让每个孩子调用几百次 GPT 级别的接口，算力开销可能不到每人几十元。最贵的是“会教的人”，而不少营恰好在这里最省。
4. **剩余部分**：利润与分账。

所以这类产品的定价锚点不是教学成本，而是家长的支付意愿。同样7天，带“进大厂”名头的版本可以比本地科技馆版本贵两三倍，哪怕后者的课程密度更高。

## 把“科幻”和“科学”分开：AI 到底能教孩子什么

先给结论：AI 素养值得学，但要按年龄段和认知规律来，不存在“7天速成”。

- **8~12岁**：适合“可触摸的 AI”。比如用 Teachable Machine 训练一个图像分类器，用 Scratch 搭积木式编程。这个阶段的目标是建立直觉：AI 能做什么、不能做什么、为什么会认错。
- **12~15岁**：Python 基础 + 调 API 做小项目，比如一个自动整理文件的脚本、一个简单的对话机器人。核心收获是“我能用工具解决问题”的掌控感，而不是“我会AI了”的幻觉。
- **15岁以上**：才谈得上真正的机器学习——从线性回归到 gradient descent，需要函数和一点线性代数做地基。这不是能力歧视，是数学准备度问题，跳过这一步的都是空中楼阁。
- 顺便泼一盆冷水：**“会写 prompt”不构成核心竞争力**，就像会打字不等于会写作。真正稀缺的是问题拆解能力和数据直觉，这些没法靠话术速成。

很多万元营宣传的“孩子亲手训练大模型”，落地往往是调一个现成 API 或在拖拽平台点几下，技术上约等于用微波炉热了一顿饭，回来宣传孩子掌握了分子料理。

## 四步验货法：分清教育产品和风景团

判断一个营的含金量，不需要专业知识，四个问题就够：

1. **查师资署名**：讲师敢不敢写真名、真履历？一线工程师和兼职大学生助教的成本差一个量级。敢把讲师履历写进合同的机构，整体上更经得起推敲。
2. **要产出物**：直接问“营期结束，孩子会留下什么”。一个能运行的图像分类器？一个自己写的小工具？还是一沓合影和结营证书？好产品敢承诺具体的、可展示的产出。
3. **算动手时间占比**：要一份详细日程表，数一数“参观、观看、拍照”与“动手、调试、修改”的时间比例。动手时间低于一半的，本质是旅游团穿了件科技马甲。
4. **看持续路径**：结营后有没有进阶课程、社群答疑、作品集指导？教育是长跑，只做一锤子买卖的机构，从一开始就没打算对你的孩子长期负责。

这四问成本为零，但能过滤掉市面上绝大多数溢价产品。

## 三条冷思考与实用建议



1. **免费资源已经足够入门。** 吴恩达的公开课、fast.ai、Hugging Face 教程、B站和大学慕课上的入门内容，质量普遍高于多数研学营的内部讲义。家长真正缺的不是资源，而是帮孩子搭一套“每周固定两小时动手”的执行系统，这套系统不花钱，花的是家长的坚持。
2. **换一种一万块的用法。** 一本 Python 入门书（几十元）+ 一年在线课程（几百元）+ 几次科技馆和开发者活动的深度参观（几百元）+ 一小笔“孩子自己的项目基金”。同样的预算，有效学习时长是7天营的几十倍，而且节奏由孩子自己掌握。
3. **警惕以焦虑为定价依据的产品。** 教育消费有一条规律：越难评估质量的商品，越依赖情绪定价。当销售话术反复强调“再不学就晚了”，而不是“孩子具体会获得什么”，这本身就是最强的信号。

AI 值得学，孩子也学得会。但真正值得学的东西，从来不需要靠万元价签和7天速成来证明。这门生意里最贵的从来不是课程，而是家长在焦虑中暂时下线的判断力。
