两年前大模型刚上车时，办公赛道的玩法高度统一：给自家软件加一个 AI 按钮。两年过去，按钮时代的红利基本见底，腾讯、字节、阿里在 AI 办公上真金白银地"会战"了一轮，战场关键词已经从"生成"悄悄换成了"Agent"——从让 AI 写点东西，变成让 AI 把活干完。这篇就来复盘：这一仗怎么打的，格局到底变了什么，以及普通团队该怎么上车。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-05/8b263b0cb8ae42ff.png)

## 一、复盘：第一回合，大家都在造"AI 按钮"

- 2023 年，微软发布 Microsoft 365 Copilot，定价每用户每月 30 美元，给全行业立了商业锚点；
- 国内迅速跟进：钉钉在 2023 年 4 月把通义千问接进 IM，现场演示 AI 生成 PPT；飞书发布智能伙伴；腾讯 9 月发布混元大模型，接入会议、文档、企业微信"三件套"；
- 这一阶段的共同动作，是把大模型切成一个个功能点：纪要 30 秒出稿、文档一键摘要、周报自动润色。

问题也恰好出在这。功能点解决的是"写得快"，不解决"干完活"：纪要再快，会后跟进还是你自己；PPT 再快，需求还是你来提。大量 AI 功能用两周就吃灰，付费意愿撑不起第二个 Copilot。用工程师的话讲：给自行车装涡轮增压，听着唬人，蹬起来还是那两条腿。

## 二、变局引擎：Agent 能"干活"，靠三个技术变量

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-05/e4e47265cda875b4.png)

从"按钮"到"Agent"不是营销话术升级，而是三块拼图先后到位：

1. **推理模型**：o1、DeepSeek-R1 这类模型让"先拆解、再执行、能反思"成为可能。以前的模型一步错步步错，现在的模型能把"整理上周销售数据并出周报"拆成取数、清洗、作图、成文四步依次跑完；
2. **工具协议**：Function Calling 让模型能调用外部工具；2024 年 11 月 Anthropic 提出 MCP（Model Context Protocol），一年内被 OpenAI、Google 及国内主流云厂商跟进。Agent 由此从"会说"升级为"会做"，能连上日历、文档、CRM 乃至祖传 ERP；
3. **组织知识**：长上下文 + RAG 让 Agent 读得进企业内部文档和历史沉淀，能回答"我们公司的报销流程是什么"，而不是搜索引擎式的泛泛而谈。

拼图齐了，办公场景——高频、数据结构化、企业愿为提效付费——自然成了 Agent 落地的第一主战场。

## 三、牌桌重排：三家牌路，和一张被挤压的桌子



会战打完，三家的打法已经清晰可见：

- **阿里（钉钉 + 通义）**：押注组织入口。钉钉上线 AI 助理并开放市场，让企业和 ISV 自己搭 Agent，走"平台 + 生态"路线，覆盖自研盖不住的长尾需求；
- **字节（豆包 + Coze + 飞书）**：豆包抢 C 端心智，Coze 用低代码把搭 Agent 的门槛压到"会写需求就行"，飞书承接工作流，流量与工具双轮驱动；
- **腾讯（企业微信 + 混元 + ima）**：从连接与知识切入——企业微信握着企业与客户的连接场景，ima 主攻个人与团队知识库，Agent 先在客服和知识管理里跑通闭环。

被挤压的牌友也得点名：单点 AI 工具（AI PPT、AI 纪要这类）的护城河正被大厂功能覆盖，越来越薄；通用 Agent 创业公司证明了"任务执行"的想象空间，却要直面大厂入口压制。活路集中在两处：垂直行业的 know-how，以及大厂伸不进去的私有化部署。

## 四、竞争焦点迁移：从模型跑分到工作流占有

格局之变的核心，是竞争的计量单位换了：

1. **模型不再是唯一壁垒**：开源与 API 把模型能力快速拉平，跑分差距用户基本无感；
2. **入口即分发**：Agent 依赖上下文，而上下文长在 IM、文档、日历里——谁坐在用户每天打开的工作流里，谁的 Agent 就自带场景和权限；
3. **数据与流程成为新护城河**：Agent 好不好用，取决于它对企业数据、权限、SOP 的理解深度，而这恰是办公平台的存量资产。

一句话总结：牌桌上比的不是谁的模型大，而是谁的任务闭环更短。

## 五、冷思考：给团队的三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-05/030cb86e4abc7405.png)

1. **先小后大，流程先行**：别一上来就幻想"数字员工"，先挑高频、低风险、可校验的任务（周报汇总、会议跟进、数据日报）跑通闭环。给 Agent 喂 SOP 比喂咒语有用——先有清晰流程，才有可靠自动化；
2. **权限与审计先行**：Agent 能读你的文档、替你发消息，接入前先划清数据边界——哪些库能碰、哪些操作要人工确认、日志能否回溯。幻觉没法归零，关键产出必须留人审；
3. **选型看契合度，不看 demo 帅不帅**：优先评估团队已经住进去的那个入口，让厂商拿你的真实任务跑 POC。模型跑分是纸面实力，接得上你的业务系统才是真实战力。

Agent 时代的办公竞争才刚过中场。牌桌重新洗完之后，真正的变量不是谁又发了新模型，而是第一批把"派活给 AI"变成日常习惯的团队——效率红利，会先进他们的口袋。
