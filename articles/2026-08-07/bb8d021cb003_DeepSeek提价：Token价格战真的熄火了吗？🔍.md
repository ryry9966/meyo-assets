一条消息在开发者群里炸了锅：DeepSeek 大幅上调 API 价格，曾经“白菜价”的百万 tokens，一夜之间贵了不少。有人拍手叫好，说无底线的价格战早就该结束了；也有人愁眉苦脸，觉得刚调好的预算又要翻盘。这不是 DeepSeek 一家的动作，而是整个大模型行业在烧了整整一年钱之后，第一次集体开始摸钱包。今天我们不站队，就聊聊价格战是怎么起来的、为什么有人敢涨价、以及接下来我们这些写代码的人该怎么选。



## 一、Token 价格战：从“烧钱换量”到“赔本赚吆喝”



说价格战，得先知道“Token”这门生意怎么就成了白菜。

- **风起云涌的 2023**：ChatGPT 引爆市场以后，国产大模型如雨后春笋。智谱 AI 的 GLM、阿里的通义千问、字节的豆包、百度的文心一言……家家都想先圈住开发者。圈人最快的办法就是降价。
- **近乎荒谬的低价**：2024 年上半年，某头部模型的输入价格跌到 0.0005 元/千 tokens，输出也不到 0.002 元。这相当于处理一部《三体》全集（约 90 万字）的 token 费，可能还买不了一根冰淇淋。甚至有的厂商直接宣布“免费”，走“羊毛出在猪身上”的路子。
- **价格战的经济学基础**：为什么敢这么便宜？推理成本确实可以通过规模效应摊薄。一张 H100 如果满负荷跑，单位 token 成本能做到极低。而且大量调用能带来宝贵的用户反馈数据，帮助打磨模型。这跟当年云计算抢市场、网约车补贴大战如出一辙。
- **副作用已经开始显现**：赔本赚吆喝的结局是利润被榨干。中小厂商根本撑不住，只能削减研发；开发者习惯了免费，忠诚度几乎为零，今天用 A 家，明天就能切到 B 家。更麻烦的是，极低的价格让“服务质量”变得不可保障——SLA 形同虚设，超时、限流时有发生。

其实说白了，价格战的本质是把模型当成了标准化的“大宗商品”，但大模型远没到同质化的程度。于是有人开始反思：我明明卖的是澳龙，凭什么跟小龙虾一块儿论斤称？

## 二、DeepSeek 的底气：用技术溢价代替流量收割



DeepSeek 这次涨价具体幅度不低。以 V3 API 为例，输入价格从每百万 tokens 1 元涨到 2 元，输出价格从 2 元涨到 8 元。这在“白送”成风的环境里，几乎像个叛逆者。但它敢逆势涨价，靠的不是胆子，是身上有肉。

- **技术上的“长板”足够长**：DeepSeek 在长上下文处理、代码生成、复杂逻辑推理方面有真实口碑。1024K 的超长窗口，直接让很多长文档处理场景只能选它。换句话说，它在开发者心里的“可替代性”比一般模型低得多。
- **架构带来的成本结构**：DeepSeek V2/V3 使用 MoE（混合专家）架构，训练和推理效率都有优势，但维持高并发、低延迟的 API 服务所需要的算力储备依然昂贵。它没法像那些内置在自家云生态里的模型那样，用集团的引流补贴推理成本。
- **商业逻辑的主动切换**：从追求调用量，转向服务高价值客户。涨出来的利润空间，可以用来升级专线网络、提供更稳定的低延迟保障、甚至给企业客户做轻量私有化部署方案。这是一种“用价格筛选客户”的策略，跟 SaaS 软件从免费版到企业版的路数一模一样。
- **开源托底，API 做增值**：别忘了 DeepSeek 系列模型权重多数是开源的。有技术实力的团队完全可以自己部署，并不非要走付费 API。主动涨价，相当于官方说：“如果你想省钱，可以白嫖开源权重，自己折腾；如果想省心、要服务，就付这个价。”这种底气，不是哪家都有的。

用一个不恰当的比喻：普通对虾论斤卖，蓝龙虾按只卖。DeepSeek 想当 API 市场里的“蓝龙虾”，这需要技能够硬，还要承受得住短期内调用量的下滑。

## 三、退潮时刻：不是价格战结束，而是分层定价来了



如果把视角拉高，DeepSeek 涨价不是孤例。整个行业正经历一次“退潮”。

- **资本耐心见底**：2024 年不少大模型创业公司融资已经困难，投资人的问题从“你参数多大”变成了“你什么时候盈利”。单月推理成本数千万，收入却刚过百万的账本，实在拿不出手。继续烧钱换规模，已经没人买单。
- **免费派也在悄悄转身**：曾经免费最凶的几家，现在开始推“专业版”“企业版”，把高并发、长上下文、低延迟打包成付费功能。纯免费接口被限速、限频，逐渐变成“试用装”。整个市场一起往回收折扣。
- **分层定价成为新共识**：基础模型继续维持低价或开源，作为生态入口；高阶能力（长上下文、工具调用、多模态理解、微调服务）单独收费。分层之后，价格战其实还在，只不过从“全场一折”变成了“奢侈品涨价，快消品平价”。
- **开源生态的“零价格”竞争**：另一边，Llama 3、Qwen 2、Yi 系列等开源模型的性能快速追赶，企业自己部署的成本越来越低。API 如果太贵，一定会把一部分需求推向私有化部署。所以 API 涨价，有一个隐形的天花板——不能超过自运维的总成本太多，否则就是给开源送客户。

换句话说，Token 价格战不会彻底消失，只会从无差别的“烧钱大战”，演化成多层次的博弈。低价基础模型之间的价格战恐怕还会继续，但高阶服务会像 DeepSeek 这样，逐步恢复理性。

## 四、开发者该如何“接招”？

闹归闹，最后还得回到最实际的问题：涨价了，我们怎么把成本控住，又不让产品掉链子？这里给几条可以直接上手的思路。

1. **把“总拥有成本”当成唯一标尺**
   别只看每百万 tokens 单价。同样的任务，便宜模型可能需要反复重试七八次才能拿到正确结果，总 token 消耗反而翻倍。算账时要加上：任务成功率 × 平均 token 消耗 + 重试耗时带来的用户体验折损。有时候单价贵一倍的模型，总成本反而更低。

2. **建立“混合路由”的弹性架构**
   不要让产品绑死在任何一家 API 上。简单、容错高的任务（比如文本分类、摘要）用便宜模型甚至本地开源模型；复杂推理、编程生成等高价值任务，再走高质量付费 API。可以抽象一个统一的模型适配层，方便随时切换各家服务。灵活的架构，是最好的砍价筹码。

3. **重新审视私有化部署的性价比**
   如果月调用量大到一定程度，直接买几块 H20 或者消费级 4090 跑开源模型，可能比持续付 API 费更划算。特别是 DeepSeek、Qwen 这类有成熟开源版本的模型，部署门槛已经被社区降得很低。唯一要额外投入的是运维人力，这笔账也值得认真算一算。

4. **冷思考：价格战结束≠创新停滞**
   很多人担心价格涨上去，创新会变慢。实际上，只有当价格回归到能覆盖研发成本的健康水位，厂商才敢继续投入做长上下文、多模态、Agent 等更烧钱的方向。对开发者来说，珍惜那些敢“涨价”的厂商——至少说明他们还想好好活，而不是跑路前最后捞一把。

大模型 API 的价格，就像海鲜市场的时价，从来不会只跌不涨。潮水退去，才知道谁在裸泳，谁真的穿着泳裤、带着氧气瓶。欢迎来“知识虾”聊聊你的方案，一起把这笔账算得更明白。
