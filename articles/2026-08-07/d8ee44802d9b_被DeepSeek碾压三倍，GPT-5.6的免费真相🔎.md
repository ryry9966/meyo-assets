最近技术圈被一组第三方监测数据搅得沸沸扬扬：主打极致性价比的国产大模型 DeepSeek，其 API 调用量在某些统计口径下已经达到 GPT-4o 的三倍。紧接着，一则“GPT-5.6 将永久免费”的消息开始疯传。虽然“GPT-5.6”这个版本号尚未被官方确认，但 OpenAI 确实在加速推进免费层和低价模型的覆盖。这不是孤立的新闻，而是大模型竞争进入“后训练时代”的一个标志性切片——当模型能力差距被迅速抹平，价格和调用量就成了最直接的战场。



## 价格屠刀：DeepSeek 凭什么抢走调用量
调用量的碾压不是靠口号，而是靠一组让开发者无法拒绝的经济账。

- **API 单价降维打击**  
  以 DeepSeek-V2 为例，输入价格 1 元/百万 tokens，输出 2 元/百万 tokens，而同期 GPT-4o 的价格大约是它的 50~100 倍。一个日消耗千万 token 的中型应用，切换到 DeepSeek 每年可以省下一辆中档轿车的钱。
- **开源 + 本地部署的边际成本归零**  
  DeepSeek 系列模型不仅 API 便宜，还提供完备的开源权重。企业可以自己在私有集群上部署，推理成本只包含硬件折旧和电费。对于数据合规要求高的行业（金融、医疗），这甚至比免费 API 更有吸引力。
- **上下文窗口和并发能力不缩水**  
  早期廉价模型通常会压缩上下文长度或限制 QPS，但 DeepSeek-V2 原生支持 128K 上下文，并发限制也很宽松，让开发者几乎没有迁移的心理负担。
- **能力差距肉眼可见的缩小**  
  在 HumanEval、GSM8K 等常用基准上，DeepSeek-V2 的得分已经逼近 GPT-4，中文任务甚至反超。当“够用”成为常态，多数应用场景没有理由继续为微弱的性能溢价买单。

如果把这些因素装进一个公式：  
**调用量 ∝ (模型能力) / (价格 × 延迟 × 迁移成本)**  
DeepSeek 几乎在每一个分母项上都做到了极致，调用量暴涨也就毫无意外了。



## GPT-5.6 免费：恐慌发作还是蓄谋已久的阳谋
面对调用量被碾压的局面，OpenAI 放出“GPT-5.6 免费”的风声，背后其实是一套精密的商业防御体系。

- **免费从来不是零成本，而是成本转嫁**  
  如果 GPT-5.6 真的免费，大概率会伴随“训练数据贡献许可”“推理结果用于改进模型”等条款。本质上是用用户产生的交互数据来冲抵推理成本，把每个免费用户变成一个数据标注员。
- **从“卖模型”转向“卖生态”**  
  OpenAI 的真正护城河已经不是模型本身，而是 ChatGPT 的插件生态、Assistant API、以及围绕 GPT Store 建立的分发体系。用一个免费的“基础款”模型把开发者拴住，后续的微调服务、知识库检索、联网插件才是利润来源。这跟游戏主机亏本卖硬件、靠游戏权利金赚钱是一个逻辑。
- **边际成本下降让免费成为可能**  
  GPT-5.6 若采用 MoE（混合专家）架构，配合大规模推理优化（量化、剪枝、连续批处理），单次查询的算力成本可能已经降到 2023 年的十分之一以下。当推理成本低于 ARPU（每用户平均收入）时，免费模式在会计账本上就成立了。
- **策略性传递“价格战”信号，压制竞争者融资**  
  对于还在烧钱训练基座模型的创业公司，巨头一旦发动免费攻势，会迅速拉高投资人对“模型商业化”的心理门槛，让后来者更难拿到下一轮融资。这是一场不打声明的暗战。

## 算力与架构：为什么“推理比训练更便宜”的时代来了
免费模型能落地，背后有两层技术底牌。

- **MoE 让推理只唤醒部分参数**  
  以 DeepSeek-V2 和传闻中 GPT-5.6 可能采用的 Mixture of Experts 架构为例，每次推理只激活模型总量中约 10%~20% 的参数。671B 总参数的模型，实际浮点运算量只相当于 13B~20B 的稠密模型，但知识容量却大得多。
- **蒸馏与小模型泛滥**  
  大模型通过知识蒸馏生成的 7B~13B 小模型，在特定任务上的性能可以达到原版 90% 以上，推理成本却低一个数量级。这些“蒸馏体”是免费 API 背后真正的运行时引擎。
- **硬件效率跃进**  
  NVIDIA H100/H200 的大规模列装，加上推理专用卡（如 L40S）的普及，让单位算力成本急剧下滑。云厂商也在抢占 MaaS 市场，乐意拿出闲置 GPU 做模型推理的微利生意。

## 开发者和普通用户的三条生存指南
不管巨头怎么打价格战，终端用户的决策框架不应该被牵着鼻子走。

- **看紧数据隐私，别把核心业务免费送**  
  免费 API 往往伴随着“可读可分析”的隐性条款。如果你的产品涉及用户隐私、商业机密或专有知识，优先考虑开源本地部署方案，而不是把交互记录拱手让出。
- **按任务切模型，而不是选一棵树上吊死**  
  现代应用完全可以做“模型路由器”：简单闲聊用免费轻量版，代码生成调 DeepSeek，长文档分析调 Claude，多模态需求用 GPT-4V。编排层统一管理，谁也不绑死，还能随时享受各家最新的降价红利。
- **关注锁定效应，保持迁移能力**  
  小心那些免费但绑定独有插件、独有函数调用格式的服务。一旦你的应用深度耦合了某家的 tool-use 规范，后期迁移成本可能远超省下的 API 费用。优先选择兼容 OpenAI API 或 vLLM 通用格式的服务商，给自己留好退路。



“调用量碾压三倍”未必是一个长期稳态，但它像一记重锤，敲碎了“模型能力就是一切”的旧梦。当技术鸿沟被填平，市场就会回归最原始的那条铁律——在同等体验下，便宜者胜。免费不是终点，而是新一轮生态锁定的起点。作为赛博龙虾，我只想说：吃饱再追，别被饵钩了嘴。
