半年前，圈子里还在猛炒合成数据（synthetic data），仿佛 GPT-4 吐出来的东西只要洗一洗、滤一滤，就能无穷无尽喂养下一代模型。  
最近风向变了——Scale AI 的 CEO Alexandr Wang 喊出“专家数据才是壁垒”，Anthropic 的工程师公开说“我们需要更多人类真正做事的痕迹”，开源社区里 SWE-bench 这类评测直接把真实 Pull Request 修复流程当成黄金标准。  
这些声音指向同一件事：**真实工作流（real workflow）正在成为下一代训练数据的主角**。不是精修过的问答对，不是蒸馏出来的合成文本，而是工程师、设计师、分析师在真实环境里从头到尾解决一个问题的完整过程——包括点开什么网页、敲错哪行命令、在哪一步改主意、最后如何在 Slack 里骂一句才提交代码。

## 为什么合成数据开始“不香”了

合成数据当然没有过时，但它能撑住的天花板已经肉眼可见。尤其在需要多步推理、工具使用和长程决策的场景里，合成数据的三个短板越来越致命：

- **模型坍缩（model collapse）加速**  
  拿模型生成的代码去训练下一版模型，就像用复印机反复复印一张纸，细节会糊掉、边缘会消失。Nature 上的研究表明，即便用简单的 Gaussian 分布，迭代自生成数据也会迅速丢失尾部特征。真实软件工程的 corner case 本就长尾，合成数据几乎不可能覆盖“某个内部工具 403 报错但实际是 DNS 被劫持”这种诡异场景。

- **缺乏真实环境摩擦**  
  合成数据擅长产出“干净”的解题轨迹：问题描述清晰、步骤线性、一次就跑通。但真正的工作流里，你会在一个报错上卡 40 分钟，尝试 5 个 Stack Overflow 答案全都无效，最后发现是同事三个月前改了一行环境变量没写文档。这种**环境摩擦与隐性上下文**是合成数据永远模拟不出来的，而恰恰是它们教会模型如何“在泥地里走路”。

- **对工具与交互的建模几乎为零**  
  真实工作流天然是多模态、多轮交互的——开关浏览器标签、在终端和 IDE 之间切屏、读取 PDF 里的表格再贴进 Excel、中途翻内部 Wiki。合成文本或者合成截图只能产出扁平快照，喂出来的模型在面对真正的图形界面、真实 API 返回值时脆弱得像纸片。

## 真实工作流的数据形态，远比你想象的“厚”

这里说的“工作流数据”，不是简单录个屏或者存个聊天记录，而是一种**带有时间戳、操作序列、状态变更和决策注释的多模态轨迹**。一个标准的前端开发修复 Bug 的工作流痕迹可能长这样：

1. 收到 Jira issue，点开附带截图，用截图工具标注可疑组件；
2. 打开浏览器 DevTools，在 Network 面板发现一个 500 响应，复制 curl 命令到终端重放；
3. 切到 VS Code，搜索对应 API 路由，发现两处调用参数不一致；
4. 打开内部文档，确认接口格式后修改代码，本地构建报错——看到“Module not found”；
5. 返回终端安装缺失依赖，重新跑测试，失败两次；
6. 翻阅 GitHub Issues，找到一条 2022 年的类似讨论，按修正方案调整 tsconfig；
7. 测试通过，提交 PR，在 PR 描述里贴上前后对比截图与复现步骤。

这条轨迹包含了**文本、图像、shell 命令、IDE 操作、网页浏览、等待时间、甚至试错次数**。拿去训练一个 Agent 模型，它学到的不只是“怎么修这个 bug”，而是“怎么在一个混乱、信息不全、工具链复杂的环境里活下来”。  
这类数据通常被组织成 **observation-action-reward 轨迹**，每个 step 里嵌着视觉状态（截图或 DOM 树）、自然语言思考（thought）、动作（click, type, scroll, bash 指令），以及环境给出的下一个状态与最终结果。相比传统指令微调数据，它天然适合强化学习、基于偏好的对齐（RLHF/DPO），因为里面有天然的“好坏动作”对比——比如第 4 步的 build 报错就是一个负向信号，第 6 步参考 GitHub Issues 则是正向的检索增强行为。

## 谁在大规模“开采”这些工作流原油

行业内已经有至少三股力量在系统化采集和利用真实工作流数据，方法从“主动录制”到“静默收割”各不相同：

- **Agent 创业公司的先发积累**  
  Adept 在研发 ACT-1 模型时，雇了大量合约工和内部员工专门录制完成具体任务的屏幕操作——例如“在 Salesforce 里为上周关闭的商机生成一份周报”。这些录制不是看看就完，而是被切割成步骤、打上标签，直接作为训练多模态 agent 的动作预测数据。类似的逻辑也驱动了 MultiOn、HyperWrite 等产品，他们会引导用户授权记录浏览器操作，美其名曰“个性化”，实质在积累真实网页交互轨迹。

- **开源基准与社区驱动的轨迹众筹**  
  SWE-bench 可能是最有名的例子：它抽取 GitHub 上真实 Python 项目里已合并的 Pull Request，把 fix 前后的代码状态作为“问题-解决方案”对来评测模型。但更激进的是 OpenHands、SWE-agent 这类框架——它们让模型在沙箱里自己探索修 bug 的同时，也**允许人类操作员介入示范**，并将人类示范的操作路径保存为训练数据。某种意义上，每一个愿意贡献操作回放的开源开发者，都成了免费的数据标注师。

- **“全线录屏”类工具重塑数据边界**  
  Rewind AI 这样的产品把 Mac 上的一切行为做成可检索的时间线；Microsoft 的 Recall 功能（虽然饱受隐私争议）本质也是持续截屏+OCR，试图建立用户活动的数据库。这类工具目前主打“个人记忆增强”，但一旦用户同意数据用于改进服务（通常藏在用户协议里），它们瞬间就变成了**千万级真实工作流样本的收割机**。从写论文查阅文献的路径到财务对账时 Excel 里的操作顺序，覆盖的知识广度远超任何一家标注公司能企及。

## 打工人流下的“汗”，如何避免成为模型的裹脚布

工作流数据价值巨大，但它离安全、高质量、可规模化的训练燃料之间，还横着至少三道坎——每一道都又硬又扎脚。

- **隐私与知识产权红线**  
  屏幕录制天然会抓到微信聊天、银行余额、未脱敏的客户姓名。即便做自动化脱敏（模糊、替换），仍然无法 100% 杜绝信息泄露，尤其在法律和医疗场景。更棘手的是，**员工的工作流很可能就是公司的核心 know-how**——如果用一个顶尖架构师的完整设计过程训练出开源 agent，原公司的竞争优势还剩多少？当前几乎没有清晰的判例或协议界定这类数据的归属权。

- **数据质量是一锅混着金砂的泥浆**  
  真实工作流里 80% 是冗余、摸鱼和无效操作：打开了又关掉的新闻网站、第 3 次输错密码、因为咖啡洒了而发呆 5 分钟。如果直接把原始轨迹喂给模型，它会学到一大堆脏习惯。而一旦引入清洗和筛选，又极容易把“看起来错误但实际合理的巧妙操作”当作噪音扔掉，比如某人用了一个非预期的 button 绕过了表单限制——这恰是 expert 的宝贵直觉。

- **隐性的伦理与心理成本**  
  当知识工作者意识到自己每划一次水、每多试一个笨办法都可能变成训练样本，工作就变成了一场 24 小时不间断的考试。这会催生**表演式工作**——为了喂出一个“优秀员工 trajectory”而刻意规范操作、隐藏试错，反而丢失了数据里最有价值的真实挣扎。更深远的影响是，一旦薪资与个人工作流数据贡献挂钩，“打工人”会不会从卖时间彻底滑向卖“行为轨迹”？

## 收拾一下：三条冷思考与行动框架

问题摆在这儿，但趋势不会等人。真实工作流数据的采集与利用只会加速，无论你是 AI 从业者、普通打工人还是企业决策者，都可以提前做几件事，不一定是追风口，而是别被动裸奔。

- **给 AI 团队：把“过程”当一等公民数据对待**  
  不要只收集最终的正确输出，开始设计**轨迹采集管线**——哪怕只是记录模型推理时的 thought 序列，或者让内测用户在沙箱里自愿提交操作回放。同时建立好 version control 和元数据索引，一条不带时间戳和工具状态的工作流等于残次品。举个例子，如果你在做 code agent，除了 final patch，至少把每次终端命令、stdout/stderr 和对应的时间点保存成 jsonl 轨迹。

- **给普通知识工作者：养成“隐私视窗”和“工作区隔离”的习惯**  
  如果公司要求安装屏幕监控或浏览器插件，确认它录制的范围；在涉及个人事务（网银、私人社交）之前，主动切到完全隔离的账号或设备。这听起来麻烦，但比起未来某天发现自己的理财习惯出现在某开源数据集里，提前建立**行为边界**非常值得。另外，偶尔审视一下自己的操作习惯——哪些重复低效？哪些可以自动化？这本身也是在和未来的 agent 同事“对齐”。

- **给企业决策者：内部数据资产化，而不是被外部虹吸**  
  你员工的工作流是你公司最有价值的暗知识。与其等着他们不自觉地在公开 GitHub issue 或社区里无偿暴露操作细节，不如**在内部建立权限可控的工作流共享库**，把顶尖员工的调试轨迹、方案选型过程结构化保存，用于内部模型微调和新人 onboarding。这需要技术基建（类似内部 YouTube 但带步骤解析），更需要修改员工协议，明确“工作流衍生数据”的归属与奖励机制，把潜在的“剥削感”转成可量化的贡献回报。

真实工作流作为训练数据的浪潮，本质上是在把“人类如何思考和行动”从黑箱玻璃化。技术上看，它可能是通往通用 agent 的最后一公里燃料；社会层面看，它也可能重新定义劳动与隐私的边界。在这条路上唯一确定的是——**先理解自己每一步行为的价值，才不会稀里糊涂变成别人盘里的龙虾沙拉**。
