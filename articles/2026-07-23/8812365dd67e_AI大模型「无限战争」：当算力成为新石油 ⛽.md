2024 年的 AI 圈，最贵的不是顶尖科学家，而是一块显卡。一块 H100 在黑市的价格能炒到 4 万美元，交货周期排到半年后——这不是科幻小说的桥段，而是正在上演的“算力饥荒”。头部玩家们像军备竞赛一样堆参数、抢数据、烧美元，普通开发者一边看热闹一边焦虑：这场无限战争，到底要打到什么时候？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-23/7aebc137de3be3c3.png)

## 烧钱三件套：算力、数据与参数

任何一个大模型项目，都绕不开这三个核心要素，它们彼此绑定，互相刺激，把竞争推成了一场没有尽头的螺旋。

- **算力：新时代的石油**
  - 训练 GPT-4 级别的模型，一次实验就要烧掉几千万美元的电费和 GPU 折旧。Meta 的 Llama 3.1 405B 用了 1.6 万块 H100，如果按公开云租用价格，仅训练成本就超过 5 亿美元。
  - NVIDIA 凭借 CUDA 生态牢牢掌控 90% 以上的训练卡市场，尽管 AMD 的 MI300X、Intel 的 Gaudi 3 都在追赶，但软件兼容性和集群稳定性还有很长的路。
  - 更残酷的现实是：不是有卡就行。千卡集群只是入场券，万卡集群才是决赛圈。集群规模的线性扩展会面临通信瓶颈、散热、掉卡率上升等工程噩梦，能把万卡跑稳的团队全球两只手数得过来。

- **数据：隐形的天花板**
  - 大模型是“输入垃圾，输出垃圾”的极端放大镜。高质量、多样化的文本数据远比算法结构更值钱。
  - 互联网上的公开文本正在被“涸泽而渔”。研究预计，到 2026 年，高质量自然语言数据将接近耗尽。版权官司已经打到《纽约时报》起诉 OpenAI，Reddit 开始向大模型公司收费，数据获取成本急剧上升。
  - 合成数据成了救命稻草——用模型自己生成数据训练下一代模型。但这像是在回声室里提高音量，容易放大偏见并丧失多样性。微软的 Phi 系列小模型证明精炼的合成数据可以很高效，但想靠它突破 GPT-4 的上限，路还远。

- **参数：越大越好的幻觉？**
  - Scaling Law（规模定律）告诉我们：在给定计算预算下，参数和数据的增加能稳定降低loss。这直接掀起了“更大即更强”的浪潮。
  - 但其边际收益正在递减。从 70B 到 405B，性能提升不再像从 7B 到 70B 那样惊艳，而成本翻了数倍。
  - DeepMind 的 Chinchilla 定律指出，很多模型都被“过度参数化”了——算力花在参数上，数据喂得不够，反而浪费。于是 MoE（混合专家）架构兴起，用稀疏激活控制计算量，在同等算力下实现更大参数规模，但这又增加了系统工程复杂度。

## 变现迷局：从 API 价格战到落地困局

烧了这么多钱，总得有人买单。但现实是，大部分大模型公司还没找到可持续的商业模式。

- **API 价格战打到地板价**
  - 国内厂商尤其激进。2024 年 5 月开始，DeepSeek、智谱、阿里云等纷纷大幅降价，Qwen-Long 的 API 价格降到 GPT-4 的 1/400，甚至直接免费。
  - 背后的逻辑和早年网约车、团购一样：用低价抢用量，用量喂数据，数据迭代模型。但大模型不像出行，边际成本并非无限趋零——每次推理都要消耗算力，免费越久亏损越大。
  - 这种打法会迅速洗牌，腰部玩家要么被收购，要么退出，最终只剩少数几家有云业务或硬件业务支撑的巨头能扛。

- **订阅与企服：两条腿走路**
  - OpenAI 的 ChatGPT Plus 订阅是标杆，月费 20 美元，用户超百万，年收入可观。但订阅模式的天花板明显，普通用户愿意为“更聪明的问答”付出的金额有上限。
  - 真正的金矿在企业服务：金融、法律、医疗等垂直场景。但企业要的不是一个能聊天的玩具，而是结合私有数据、保证安全、低幻觉的定制方案。这让交付成本极高，难以规模化。
  - 更尴尬的是，很多场景用 API 调用轻量级开源模型（如 Llama3 70B）就够用了，没必要接千亿参数闭源大模型。开源社区的迅速跟进，正在吞噬闭源模型的低端市场。

- **算力套利与自研芯片：降本的生命线**
  - 既然算力是最贵的投入，控制算力成本就成了生死线。英伟达的垄断让所有玩家都感到肉痛，于是自研芯片成了共识：Google 的 TPU 已经迭代到 v5，Amazon 有 Trainium，微软也在搞 Athena。
  - 另一个玩法是“算力套利”：利用英伟达消费卡 4090 进行中小规模训练和推理，规避数据中心卡禁令。虽然不稳定，但成本只有几分之一，这在中型团队中非常流行。

## 开发者与普通人的真实处境

在这场巨头打架的硝烟里，大多数人其实是旁观者。但这场战争正在重塑整个技术行业的生态。

- **技术栈的快速腐烂**
  - 去年你花三个月调优的 prompt 工程，今年可能被一次模型升级直接干废。Agent、RAG、function calling 这些概念半年前还是前沿，现在已成标配。
  - 开发者陷入“版本焦虑”：永远在追最新的模型，永远在适配最新的 API，却很难沉淀出长期价值。

- **岗位市场冰火两重天**
  - 懂大模型训练、推理优化的 infra 工程师身价暴涨，年薪轻松过百万；而只会调 API 做简单套壳产品的所谓“AI工程师”，可替代性极高。
  - “AI 会取代程序员”的叙事被反复炒作，但真实情况是：AI 把初级编码效率提升了 30-50%，使得资深工程师能同时掌控更多项目，反而挤压了初级岗位。

- **信息过载与营销泡沫**
  - “通用人工智能还有三年”“大模型重塑所有行业”——这类标题每天刷屏。但实际落地案例远少于媒体报道，很多演示视频是精心编排的 demo。
  - 对普通人来说，最有用的可能就是 ChatGPT 帮你写周报、Midjourney 出几张图。减少焦虑的最好方法，是亲自去用，而不是只看新闻。

## 冷思考：三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-07-23/a68310f6fceeacec.png)

1. **对企业决策者而言：不要为参数买单，要为 ROI 测试**
   - 先问自己：这个场景里，用开源 70B 模型是否够用？是否真的需要千亿参数？不要被厂商的 benchmark 数字忽悠，一定要用自己的业务数据做盲测。很多时候，微调一个 7B 模型就能达到 90% 的效果，成本却只有百分之一。
   - 算力投资上，短期租赁云 GPU 做实验，长线自建小规模集群优化推理成本，不要一上来就采购千万级别设备。

2. **对开发者/创业者：抓住应用层“最后一公里”**
   - 模型能力正在快速同质化，真正的壁垒不在模型本身，而在与行业流程的深度耦合。去深耕一个你比别人更懂的垂类（比如法律文书合规、建筑图纸审查），把领域知识封装成 prompt 链、RAG 知识库和微调数据集。
   - 不要追着 SOTA 模型跑，锁定一个稳定版本做透，远比不停迁移更有收益。稳定性才是企业客户最看重的。

3. **对普通学习者：建立“AI 不可替代性”**
   - 用 AI 把自己从重复劳动中解放出来，把精力花在需要跨领域判断、创造性设计和人际沟通的事情上。AI 是放大器，不是替代品——它能让你更快到达边界，但在边界处突破的依然是人的直觉和审美。
   - 保持一周花 2-3 小时上手新工具的习惯，但不要陷入“工具收集癖”。学会用后立刻思考：这能解决我眼下的哪个具体问题？如果暂时没有，就先放下，等需要时再捡起来。

无限战争不会很快结束，甚至可能演变成年化百亿美元量级的持续消耗。但正如每次技术周期一样，泡沫沉下去，价值浮上来——能活下来的不是跑得最快的，而是最懂得把算力转化为真实生产力的那批人。
