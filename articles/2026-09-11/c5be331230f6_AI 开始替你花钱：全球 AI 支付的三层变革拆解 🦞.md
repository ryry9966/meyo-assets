最近 36kr 报道的全球 AI 支付研究报告在从业者圈子里刷了屏。这份报告的核心判断其实不复杂：支付行业正在和 AI 发生"两次握手"——第一次握手是 AI 成为支付公司的内部工具（风控、反欺诈、客服），这件事已经跑了十年，属于成熟存量；第二次握手是 AI 自己成为独立的"付款人"，也就是 2025 年集中爆发的 Agentic Commerce（智能体商务），这才是报告真正想讨论的新变量。这篇文章把报告里的关键结论拆开讲清楚：AI 支付到底变了什么、钱从哪来、卡在哪里，以及普通人和开发者该怎么看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-11/2d1d388a73b609fb.png)

## 一、先看大盘：AI 支付不是概念，是三笔真金白银

报告把市场热度落到了三个具体的资金流向，理解这三笔钱，就理解了整个叙事的骨架：

- **第一笔：风控投入。** Visa、Mastercard 的实时交易评分体系早已全面机器学习化，主流卡组织几乎所有交易都会经过 AI 模型毫秒级打分，这是 AI 支付的"地基"；
- **第二笔：效率改造。** 麦肯锡曾测算，生成式 AI 每年可为全球银行业增加 2000 亿～3400 亿美元价值，其中支付是最先落地的场景之一：争议处理、KYC 审核、商家入驻尽调；
- **第三笔：增量交易额。** AI Agent 直接下单带来的新 GMV。各家机构对 2030 年智能体驱动/辅助的电商交易规模口径不一，但方向一致：万亿美元量级。

一句话总结：前两笔钱是"AI 改造支付行业"，第三笔钱是"AI 成为支付行业的新客户"。后者才是真正的范式转移。

## 二、老本行：风控反欺诈，AI 支付的第一层

这是 AI 在支付领域最成熟的应用，报告用大量篇幅回顾了它的技术栈：

- **实时评分**：每笔交易在授权瞬间完成判断，特征包括设备指纹、地理轨迹、商户类别码（MCC）、历史行为序列；
- **图计算抓团伙**：欺诈很少是单点行为。GNN（图神经网络）可以把"同一批卡 + 同一批设备 + 同一批收款账户"的隐性关联挖出来，一锅端掉整个欺诈网络；
- **误杀才是隐形成本**：行业长期存在 false decline（误拒）问题——模型太保守，把正常用户挡在门外，历史上每年给全球商户造成数百亿美元的收入损失。所以 AI 风控的目标从来不只是"抓坏人"，更是"少冤枉好人"；
- **LLM 的新用途**：拒付（chargeback）申诉材料自动生成、争议工单分类、商家合同审核，把原来几天的人工流程压到几分钟。

这一层的结论很清晰：技术上已经卷完，护城河在于数据积累和场景覆盖，新玩家很难再切进去。

## 三、新变量：Agent 拿到钱包，信任链怎么建

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-11/5d3e3db6ca4d0cd9.png)

这是报告篇幅最大、也是产业动作最密集的部分。2025 年集中发生了一串标志性事件：

1. **Visa** 发布 Intelligent Commerce，把 token 化的虚拟凭证交给 Agent 使用；
2. **Mastercard** 推出 Agent Pay，强调"授权委托"（delegated）模式；
3. **Google** 牵头 AP2（Agent Payments Protocol），联合 60 多家支付机构制定开放标准；
4. **Stripe 与 OpenAI** 把 Instant Checkout 接入 ChatGPT，用户在对话里直接完成购买；
5. **Coinbase** 推出 x402 协议，复活了 HTTP 402 "Payment Required" 状态码——这个 1992 年就预留的状态码等了三十年终于上岗，堪称互联网史上最强延迟转正——让机器与机器之间可以直接完成小额付款。

技术上的核心难题只有一个：**怎么让机器花钱，但责任仍然是人的。** 各家方案基本沿着同一条信任链走：

- 用户对 Agent 下达意图并签名（intent mandate，意图凭据）；
- Agent 生成购物车，由用户确认或预设规则自动确认（cart mandate，购物车凭据）；
- 支付环节使用一次性 token 化凭证，真实卡号全程不暴露；
- 出问题时凭据链可回溯，明确这笔钱是"用户授权的"还是"Agent 自作主张"。

说白了，Agent 支付不是发明新钱包，而是把现实里"给孩子办一张限额副卡"这件事，做成可编程、可审计的协议。信任的本质没变，只是签名方式从手写变成了密码学。

## 四、新轨道：稳定币为什么被反复点名

报告另一个高频词是 stablecoin，原因很直接：

- **Agent 是 7×24 干活的**，而传统清结算有营业时间、有批次、有节假日；
- **跨境微支付**：为一篇论文的 API 调用付 0.01 美元，在卡网络里手续费都覆盖不了成本，稳定币可以；
- **可编程**：付款可以绑定条件——验收通过才放款、订阅到期自动续扣。

数据也在支撑这个方向：链上稳定币年交易规模已达数万亿美元量级；Stripe 以约 11 亿美元收购稳定币平台 Bridge；Visa 和 Mastercard 都在试点稳定币清结算。报告的隐含判断是："机器的钱包"大概率先由稳定币跑通，而不是信用卡网络，因为前者天然是为机器设计的接口。

## 五、冷思考：三个判断与三条建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-11/b3e892a287d2c7b1.png)

先给两个判断：

- **曲线划分**：AI 支付第一曲线（风控）已经成熟，增量在第二曲线（Agent 商务）和第三曲线（新清算轨道）；
- **短期瓶颈不是技术，是责任划分与监管口径**：KYC、AML、拒付责任归属，协议层面可以设计，法规层面需要时间。

再给三条实用建议：

1. **开发者/商户**：尽早让商品信息"机器可读"——结构化数据、开放 API、明确的履约与售后接口。未来 Agent 抓取与比价带来的流量，可能超过相当一部分人工浏览流量，现在的接口设计就是明天的入口位；
2. **普通用户**：给 Agent 设支出上限、白名单商户和单笔限额，把"授权范围"当成密码一样管理。AI 替你花钱的前提，是花多少钱、在哪花、什么时候花，由你说了算；
3. **行业观察者**：区分"发布会叙事"和"结算数据"。判断一个 AI 支付项目是否真落地，只看一个指标——它有没有真实跑在清结算链路里，而不是停在 demo 和概念视频里。

最后收个尾：支付的本质，是信任的标准化。AI 没有改变这个本质，只是把"信任谁"的问题，从人与人之间扩展到了人与机器之间。这一步跨过去，商业的流量入口和交易方式都会重新洗牌——而洗牌期，恰恰是从业者最该下场看牌桌的时候。
