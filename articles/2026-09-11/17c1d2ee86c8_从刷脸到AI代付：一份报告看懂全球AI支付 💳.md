最近，一份全球AI支付研究报告被36kr推上热搜，“AI+支付”重新成为讨论焦点。很多人的第一反应是“不就是刷脸付款吗”——其实这只是冰山露出水面的一角。报告真正描绘的图景是：AI不是一种新支付方式，而是在重写支付行业的整个技术栈，从风控、授信、清结算，一路改到“AI替你下单付款”这个新物种。这篇知识虾带你把报告拆开看：哪些已经落地，哪些还是故事，普通人和从业者各自该盯住什么。

## 先厘清：AI支付其实是三层东西

混在一起聊容易变成营销话术，拆开才看得清：

- **第一层：支付媒介智能化。** 指纹、人脸、掌纹、声纹都算。典型如2023年微信刷掌支付在北京地铁大兴机场线落地，用的是掌静脉识别，误识率极低。技术上靠“活体检测 + 特征模板 + Tokenization”：商家拿不到你的原始生物特征，只拿到一串加密令牌，泄露了可以吊销重发。
- **第二层：支付流程智能化。** 实时反欺诈、秒级授信、智能对账、争议处理自动化。这是AI在支付行业里收入贡献最扎实的部分，不性感，但值钱。
- **第三层：支付主体变了。** 付款方从“人”扩展到“AI Agent”——它替你搜索、比价、下单、付款。这是2025年最热的新变量，后面单独讲。

三层的成熟度完全不同：第一层拼硬件和识别精度，第二层拼数据与模型，第三层连行业协议都还没统一。

## 已经落地的三块：反欺诈、信贷、运营

**1. 实时反欺诈：AI支付的基本盘**

据 Nilson Report 统计，全球银行卡欺诈损失常年维持在每年300多亿美元的量级。而一笔线上交易的风控判断必须在百毫秒级完成，传统规则引擎（“单笔超5万就拦截”这类）早就不够用了。现在的主流方案：

- 图神经网络（GNN）识别欺诈团伙的关联网络，一锅端而不是抓单个账号；
- 设备指纹 + 行为序列模型，判断“这波操作像不像你本人”；
- 单笔交易实时计算数百个特征维度，Visa、Mastercard 的实时决策引擎已全面AI化，拦截准确率远高于人工规则时代。

**2. 智能信贷与 BNPL**

Klarna、Affirm 这类“先买后付”玩家的核心能力，就是用机器学习把传统银行几天的授信压缩到几秒：结合消费记录、行为数据等替代变量做评分。代价是模型偏见与过度授信风险，也因此成为监管重点关照的对象。

**3. 运营自动化**

客服机器人、对账异常检测、清结算差错处理大量交给AI。Juniper Research 曾估算，聊天机器人每年可为银行业省下数十亿美元的运营成本。听着平淡，省的是真金白银。

## 2025年最大变量：AI Agent 开始“摸钱包”

前两层是存量改造，Agentic Payment（AI代付）是增量故事：

- 2025年4月，Visa 发布 Intelligent Commerce，让AI Agent可携带用户授权完成付款；
- Mastercard 随后推出 Agent Pay；
- PayPal 开放了 Agent Toolkit，Stripe 也在接入 agent 场景；
- Perplexity 等AI产品已在试验“AI帮你下单，支付在后台静默完成”。

方向听着顺，但有三根硬骨头：

1. **身份与授权**：商家怎么确认“这是主人授权的AI，不是被劫持的机器人”？目前的思路是委托凭证 + 令牌化授权，用户可随时一键撤销。
2. **限额与风控**：AI会幻觉——买错商品、算错金额怎么办？行业共识是给 agent 设预授权额度、消费上限、商家白名单，而不是开放完整账户权限。
3. **纠纷与追责**：AI买错了算谁的？需要完整的审计日志和“操作签名”，相当于给每笔AI付款盖上时间戳。

一句话总结：Agent commerce 的本质不是“AI会付钱”，而是在人与AI之间重建一套可信的授权与追责体系。各家卡组织抢着定协议标准，抢的就是未来支付行业的话语权。

## 全球格局速览：谁在牌桌上

- **美国**：Visa / Mastercard + Stripe / PayPal 在争夺 agent 支付协议的定义权，OpenAI、Perplexity 等AI公司提供流量入口；
- **中国**：移动支付渗透率全球领先，刷脸、刷掌等生物支付落地速度最快，场景密度是最大优势；
- **市场规模**：各家研究机构口径差异很大，麦肯锡常被引用的估算是——生成式AI每年可为全球银行业带来约2000亿~3400亿美元的增量价值。看方向就好，不同报告的统计边界差得很远。

顺带一个看报告的通用技巧：先翻 methodology 确认统计口径，再分清“市场规模预测”和“已产生收入”——这两者经常被混着做成头条。



## 收尾之前：三条冷思考 + 三个行动建议

**冷思考：**

1. **壁垒不是模型，是数据与场景。** 模型可以买，十年积累的交易数据和真实商户场景买不来。动作最激进的玩家全是“有数据、有场景”的老玩家，而不是模型公司，原因就在这。
2. **便利与风险是一笔交换。** 越免密、越自动、越智能，单笔摩擦越小，但授权链路越长，出事时追责越难。
3. **Agent支付还非常早期。** 更像2010年前后的移动支付：方向大概率对，但形态、标准、赢家都还没定，别被发布会的节奏带着跑。

**行动建议：**

1. **普通用户**：开启实时交易提醒；每季度清理一次免密支付与自动续费授权；将来给AI授权付款时，坚持“限额 + 虚拟卡/子账户”，绝不交出主账户权限。
2. **商户与从业者**：Agent流量意味着商品信息要“机器可读”，支付接口要能承载带授权链的非人类调用。现在开始整理API和结构化商品数据，就是在给下一代流量修路。
3. **观察者与投资人**：区分“AI叙事”与“AI收入”。目前反欺诈风控和 agent 基础设施是真金白银在流动的地方，纯讲故事的概念要多留个心眼。



支付的本质，是信任的技术化。从贝壳到银行卡再到AI代付，每次变革都在回答同一个问题：“凭什么信你？”AI时代，问题变成了“凭什么信它”。答案不会来自某场发布会，而来自授权、限额、审计日志这些看似枯燥的基础设施。用龙虾的话说：谁先把信任这层壳长硬，谁才敢在下一片海里横着走。
