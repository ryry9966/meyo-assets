热搜里一句话挺扎心："大模型全是演技派。"你让模型扮演一个"基础薄弱的高中生"，它张口就是标准答案式的迷茫，像背熟台词的配角，一问细节就穿帮。36kr 这条报道提到的思路却反着来：先别急着让模型"演"学生，而是把真实学生的行为数据喂进去，训出 60 个"数字学生"——一个能复现真人学习轨迹的 Agent 班级。这一步之差，正好踩中当前 AI 应用的核心矛盾：模型到底是在模仿人类，还是在理解人类？这篇文章拆三件事："演技派"的病灶在哪、数字学生怎么训、以及这套东西对教育行业的真实价值。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-11/330c588e4ffea71e.png)

## 一、"演技派"的病灶：模仿不等于学会

- 大模型的底层任务只是 next-token prediction：在海量文本中学会"下一个词最像什么"。它掌握的是语言的统计分布，而非世界本身，所以"会说话"不代表"懂了"。
- 这个批评有出处：2021 年 Bender 等人提出"随机鹦鹉"（stochastic parrots）——模型像鹦鹉一样复述统计规律。四年过去，参数规模涨了几个数量级，病灶没变，只是演技更好了。
- 用 prompt 让模型扮演学生，有三个典型破绽：
  1. **人设不稳定**：换个问法，"差生"立刻答出压轴题，性格漂移比翻书还快；
  2. **行为过度平均**：像教科书里的"标准学生"，没有真实个体的毛边和怪癖；
  3. **缺乏记忆与一致性**：昨天说不会的公式，今天连解题步骤都背出来了。
- 一句话总结：靠台词（prompt）调教出来的学生，本质上是一台复读机。

## 二、数字学生：把真实学习轨迹灌进 Agent

思路的转变在于：从"给模型写人设"，变成"给模型喂数据"。

- **数据长什么样**：答题日志（每题对错、耗时、修改次数）、错题序列（知识点漏洞的先后链条）、课堂对话转录、作业提交时间线。这些数据原本躺在在线学习平台的后台，现在成了 Agent 的"成长档案"。
- **Agent 的三层结构**：个体画像层（对每个学生的知识状态建模）＋记忆层（随时检索该学生的历史记录）＋行为策略层（用真实数据做微调，比如 LoRA，外加决策规则）。
- 于是每个数字学生背后，是一条被"复刻"的真实学习路径；60 个学生，就是 60 条轨迹组成的模拟班级。这个数量也有讲究：足以覆盖多样的学习者画像，又把训练与验证成本压在可行范围内。
- 这本质上是把"数字孪生（digital twin）"从工厂搬进教室，与斯坦福 2024 年的"千人数字分身"研究同属一条路线：用访谈加行为数据构建 Agent，让它的回答能复现本人水平。区别只是这次，主角换成了学生。

## 三、为什么"真实数据"是分水岭

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-11/f1df8313167c966d.png)

- **机制一：分布对齐**。真实数据里藏着个体独有的模式——有人在几何证明上系统性卡壳，有人习惯考前突击、平时躺平。这些模式不在通用语料里，prompt 写不出来；只有真实数据能把它"灌"进模型。
- **机制二：可验证**。关键测试类似"复盘回放"：只给 Agent 看一个学生前半学期的记录，预测后半段表现，再与真人的实际成绩比对。数据训练的 Agent 预测相关度明显更高；纯 prompt 的 Agent 只能给放之四海皆准的泛泛之谈——听起来对，对谁都不精确。
- **机制三：误差可归因**。数据版 Agent 预测错了，能定位是哪个知识点状态建歪了，可以修；prompt 版演砸了，只能笼统归结为"模型发挥失常"，无从下手。
- 差别一句话：真实数据让 Agent 从"表演学生"升级成"外推学生"——前者复述剧本，后者基于证据推演行为。

## 四、60 个数字学生能干什么

- **教师训练沙盘**：师范生面对 60 个行为各异的数字学生练课堂管理——有人走神、有人抢答、有人连续答错。试错成本为零，练到会为止。
- **教学法 A/B 测试**：新讲法先在模拟班级跑一遍，比较两条掌握率曲线，有优势再进真课堂，避免拿真人当小白鼠。
- **个性化辅导诊断**：数字孪生复现学生的错误链条，帮老师看清"他不是粗心，是把浮力和压强两个概念搅在一起了"。
- **教育研究降本**：原本要追踪一学期的对照实验，模拟环境几分钟出初筛结果，把昂贵的研究资源留给最值得验证的假设。

## 五、冷思考：数字学生不等于真学生

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-11/3318d9574656a404.png)

- **隐私是硬约束**：学习数据多半涉及未成年人，知情同意、匿名化、最小化采集，一样都不能省。
- **警惕自我实现预言**：如果模拟预测"某类学生会掉队"，再把预测当结论，可能反过来压低对真实学生的期待——模拟应该是提问工具，不是判决书。
- **承认模拟的边界**：Agent 能复现答题行为，却复现不了情绪、动机和生活中那些打断学习的意外。这些最难量化的变量，恰恰常常是决定成绩的变量。

## 写在最后的三条建议

1. **看成色**：遇到自称"数字学生/数字分身"的产品，先问三件事——数据来自哪里？有没有留出集验证？复现精度是多少？答不上来的，多半还是演技派。
2. **当工具**：模拟结果只当作假设生成器，凡是涉及具体学生的决策，必须回到真实课堂验证。
3. **守底线**：教育数据的合规标准，按最严的一档执行，别拿"技术探索"当豁免理由。

演技与实力的差距，从来不在台词写得漂不漂亮，而在幕后喂进去的，是不是一份份真实的数据。
