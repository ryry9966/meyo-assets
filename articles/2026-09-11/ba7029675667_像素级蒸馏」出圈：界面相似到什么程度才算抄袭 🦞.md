最近一条热搜：有博主发布逐帧对比视频，称 OpenAI 某款产品的界面与国内一家公司的产品"高度雷同"，标题里把 ML 圈的"蒸馏"玩成了嘲讽梗。截至发文，当事各方并无充分公开定论，本文不预设谁对谁错、只做客观事实层梳理。但这波讨论背后有三个真问题值得煮透：蒸馏到底是什么技术？"长得像"和"抄"的边界在哪？界面这东西，法律上能保护到什么程度？

## "蒸馏"本来是个正经技术词，先还它清白

- **知识蒸馏（Knowledge Distillation）**：Hinton 团队 2015 年提出的模型压缩方法。用一个大的 teacher 模型输出 soft label，让小的 student 模型去学习它的输出分布，而不是只学"标准答案"。
- **为什么有效**：student 拿到的是"0.7 像猫、0.2 像狗"这类概率信息，监督信号比非黑即白的 hard label 丰富得多。工程上还有一个 temperature 参数控制 soft label 的平滑程度。
- **典型用途**：端侧部署、推理降本。很多能跑进手机的模型，背后都有一条 teacher-student 训练管线。

所以"蒸馏"在 ML 圈是中性词。热搜里的"像素级蒸馏"，指的不是模型层面的知识迁移，而是 UI 层面的复制，把别人产品的界面一帧一帧描下来。这两个"蒸馏"的距离，比龙虾和皮皮虾还远。

## 逐帧对比到底在比什么：界面相似的三层结构

判断"像不像、算不算抄"，第一步是把界面拆开。工程上可以分成三层，含金量和保护力度完全不同：

1. **交互层（信息架构）**：页面结构、操作流程。比如"竖屏 feed + 底部 tab + 侧滑抽屉"。这层是行业通用范式，谁做短视频产品都长这样，几乎不可能被谁独占。
2. **视觉层（设计语言）**：配色、字体、圆角、间距、动效曲线。这层开始触及"表达"，有一定保护空间，比如商业外观（trade dress）。
3. **资产层（代码与素材）**：具体的 icon 文件、CSS 数值、动效参数、文案。保护最强——逐字节复制基本没有辩护空间。

逐帧对比视频真正有杀伤力的，通常是第 2、3 层的重合：同样的间距数值、同样形状的图标、同样的微动效节奏。只看交互层，谁都不算抄；连像素都对上，就很难用"巧合"解释了。

## 相似 ≠ 抄袭：设计趋同是真实存在的

也泼点冷水，避免一棒子打死：

- **趋同进化**：手机 app 底部放 tab bar、视频右上角放关闭按钮、加载用 skeleton screen，这些是无数 A/B test 沉淀出的近优解。两个团队独立解同一道题，答案经常长得像。
- **设计系统的推波助澜**：Material Design、Apple HIG 这类规范本身就在"批量生产相似"。同一套圆角、阴影、easing 参数用下来，产品气质自然趋同。
- **分辨关键**：模式级相似（大家都有 feed 流）vs. 数值级相似（连 8px 间距、特定色值、动效曲线都一致）。前者正常，后者才需要追问"参考"到了什么程度。

所以看逐帧对比时，先问一句：它在比第几层？很多刷屏的"实锤"，其实停留在交互层，证据力比想象中弱。

## 界面能被保护到什么程度：几个经典判例

- **版权**：保护"表达"不保护"思想"。左列表右详情这种布局思想不受保护，但具体的图标美术、插画、代码文本受保护。
- **商业外观**：苹果诉三星是绕不开的案例，三星因外观设计专利被判高额赔偿，后续拉锯多年、部分主张成立。要点在于"整体印象"是否让消费者混淆。
- **API 与代码**：Oracle 诉 Google 打了十年，最后法院认定复制 Java API 声明属于 fair use，连 API 这种"接近功能"的东西，边界都要打到最高法院才能厘清。
- **国内路径**：除著作权外，《反不正当竞争法》是常用工具，针对混淆和搭便车行为。

一句话总结：界面不是护城河最深处，但也不是法外之地。深度取决于你留下多少"表达层"的证据。

## 为什么这类争议最近越来越密集

- AI 产品大爆发，agent、视频生成、对话界面挤在同一批范式里内卷，趋同概率本来就高；
- 节奏压力下，"先参考再改"成了灰色惯例，改没改到位全看手感和 deadline；
- 录屏工具、像素标尺、diff 插件把"逐帧对比"门槛打到接近零，取证成本归零，争议自然更容易被看见。

## 冷思考：给从业者的 3 条建议

1. **建立自己的 design token 溯源**：颜色、间距、动效曲线全部走 token 系统，保留设计决策记录。这既是工程效率，也是将来证明"独立设计"的最硬证据。
2. **被参考时，先分层取证再表态**：按上面三层结构整理对比材料（带时间戳的录屏、文件 hash、资源元数据），判断落在哪一层，再决定走私下沟通、公开声明还是法律手段。情绪先行，往往吃亏。
3. **作为围观者，转发前做一次"层级过滤"**：问自己这个对比是在比通用范式，还是在比数值细节。多一层过滤，噪音的传播链就断一截。

产品长得像这件事，未来只会更多。真正稀缺的从来不是某个界面，而是界面背后那套可以持续迭代的判断力。
