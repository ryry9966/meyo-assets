最近一周，AI圈有两个信号被反复放在一起看：软件侧的 Codex 商业化斜率明显变陡，甚至在一些增长指标上压过 Anthropic；硬件侧的具身智能开始被频繁类比为“GPT-2时刻”。单独看一个只是产品新闻，放在一起才更像趋势：AI 正在从“Demo 很强”进入“可部署、可计费、可留存”的工程化阶段。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-25/f036a7589a610176.png)

## 一、Codex 商业增速逆袭：不是模型跑分赢了，是商业曲线变了

- 36kr 这周观察里，Codex 被重点讨论的并不是某个 benchmark 刷新，而是商业增速。常见口径包括：企业席位导入周期、API 消耗量增速、团队版周活跃、ARR 斜率。
- Anthropic 过去一年在开发者圈口碑很好，尤其是 Claude Code 在 agentic coding 场景里渗透极快。这次所谓“逆袭”，更准确说是 OpenAI 在渠道、打包、计费和工作流集成上补课完成。
- 一个典型信号：不少小团队从 Claude Code 切向 Codex，不是因为模型多写对 2 分测试，而是因为 Codex 和 GitHub、IDE、CI、权限审批、用量账单这条链路更顺。对工程团队来说，“能用”和“敢在生产环境用”是两件事。
- 再举一个采购场景：一家 50 人团队要上 coding agent。如果 Claude Code 需要平台团队自己拼 MCP server、写权限脚本、维护审计日志，Codex Cloud 却原生提供审批流、变更摘要、自动 reviewer，采购决策会偏向后者。即使 Claude 在部分任务上更聪明，综合部署成本也更高。
- 换句话说，模型能力差距缩小后，系统集成权重上升。Codex 的商业增速逆袭，本质是“工程师工具链”对“单点模型口碑”的逆袭。

## 二、机制拆解：Codex 为什么能在商业上压过 Anthropic

- 第一，工作流闭环更深。Codex 不只是一个 chat 窗口，它把代码生成、测试、PR、review、回滚、安全审计串了起来。企业采购不是问“它会不会写函数”，而是问“它能不能管住代码变更流程”。这一点 Codex 的云版和团队版做得更完整。
- 第二，分发和计费颗粒度更细。开发工具的商业化需要贴近 DevOps 账单。Codex 在 CLI、Cloud、团队 seat、用量阶梯上都提供了中小企业容易启动的入口；Claude Code 早期偏 CLI 和 API，虽然极客喜欢，但企业采购决策链更长。
- 第三，边际模型能力不再稀缺。当 GPT、Claude、Gemini 在 SWE-bench 上的差距进入个位数百分点后，客户更倾向选择已经嵌入现有工作区的工具。这个阶段，生态和切换成本比单点分数更重要。
- 可以类比数据库行业：Oracle 长期赢的不只是单表查询，而是备份、权限、审计、生态。Codex 这轮也在复制同样的逻辑。

## 三、具身智能的“GPT-2时刻”，这个比喻到底准不准

- 2019 年 GPT-2 出现时，没有立刻改变世界。它真正的贡献，是让业界第一次看到：无监督预训练加大参数量，能带来零样本多任务能力，scaling law 从一个 idea 变成可验证路径。
- 具身智能今天类似：单一任务的成功率已经不算新闻，但泛化到未见物体、开放指令、非结构化环境还很吃力。最近的变化，是 VLA（Vision-Language-Action）基础模型开始出现“一个模型做多种操作”的早期迹象。
- 典型代表包括 Physical Intelligence 的 π0、Google DeepMind 的 RT-2、Figure 的 VLA，以及开源 OpenVLA。它们的共同思路是：把图像、语言、动作放进同一个 Transformer，让模型从多任务轨迹中学习“拿起杯子”“打开抽屉”这类动作的通用表征。
- 另一个相似点在于规模门槛。语言模型从 GPT-1 到 GPT-2，参数量从亿级跨到十亿级，数据从 BooksCorpus 换成 WebText，零样本能力才逐步显现。当前 VLA 模型也正在从千万级动作轨迹向更大规模混合数据迁移，参数规模、任务多样性、控制频率都在同步提升。
- 所以“GPT-2时刻”并不是说机器人已经像 GPT-4 一样能干活，而是说人们第一次看到同一种 scaling 思路在物理世界也成立。这会影响资本、人才和工程资源的重新配置。

## 四、为什么现在才摸到拐点：数据、模型、算力的三角

- 数据侧：真机数据很贵，但远程操作、仿真数据增强、人类视频可以交叉利用。仿真里能低成本生成“拧瓶盖失败”的百万条轨迹，让模型学会物理常识，再配合少量真机数据做 Fine-tune，缩小 Sim-to-Real gap。
- 模型侧：VLA 把视觉、语言、动作统一成 token 序列，避免了过去“感知-规划-控制”三个模块的误差累积。Transformer 的长程建模让多步操作更稳定，Diffusion Policy 等方法也改善了连续动作生成。
- 算力侧：机器人本体的实时推理比云端更难，但边缘芯片和低延迟推理在降本。NVIDIA 的 Isaac/GR00T 以及各家端侧芯片，让模型能在 10Hz~50Hz 控制频率下运行。
- 一个关键变化：过去是机器人公司做模型，现在是模型公司进入机器人。工程化能力和资本密度完全不同，这也是“GPT-2时刻”被频繁引用的原因。

## 五、别把拐点当终点：三条冷思考

1. 对开发者：Codex 的逆袭说明护城河不只是模型。CI、权限、回滚、审计、成本控制这些“无聊”的事，才是团队真正切换的动力。工具链闭环比追最新模型更重要。
2. 对具身智能从业者：GPT-2 时刻之后还有 GPT-3、GPT-4，以及漫长的工程化。物理世界的数据采集、安全、维修、部署成本远高于软件。先选容错率高的场景（工厂分拣、物流搬运、实验室操作）更容易活下来。
3. 对观察者：警惕“商业增速逆袭”被放大为“模型已胜出”的叙事。Codex 与 Anthropic 的竞争还在早期，具身智能也远没到 iPhone 时刻。看一家公司，至少看连续两个季度的净收入留存和部署留存，而不是单次 demo。
