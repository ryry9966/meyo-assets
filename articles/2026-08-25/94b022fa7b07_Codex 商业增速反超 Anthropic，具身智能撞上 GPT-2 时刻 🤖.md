过去一周，AI 圈有两个信号被放在一起反复讨论：一是 Codex 的商业增速出现陡峭爬升，开始反超 Anthropic 的 Claude 系列；二是具身智能被不少从业者称为进入“GPT-2 时刻”。这两个说法都很容易让人兴奋，但真正值得拆解的，不是谁又赢了嘴仗，而是软件 agent 与物理世界机器人是否同时摸到了同一条增长曲线。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-25/b30398ceeb29b24f.png)

## 一、Codex 商业增速：从“写函数”到“接管任务”

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-25/4aa42dc68f103602.png)

先说 Codex。它的商业增速被关注，不是因为模型跑分突然登顶，而是企业侧的 API 消耗、席位增长和 agent 任务完成率出现了连续数周的明显抬升。

- 口径问题：这类“增速逆袭”通常来自第三方监测的 API 消耗、企业许可证激活、CI/CD 环境里的 agent 调用次数。它不是总收入规模，却更能反映新增需求。
- 产品形态：Codex 已经不再只是编辑器里的补全工具，更像一个云端软件工程代理。给它一个 issue，它能拉分支、改代码、运行测试、提交 PR，甚至根据失败日志再修一轮。
- 与 Claude Code 的区别：Claude Code 强在长上下文和复杂代码理解，很多团队用它做大型重构；Codex 的优势是把执行环境、沙箱、Git 操作和浏览器工具打包得更像一个“能自己干活”的 worker。
- 支撑增速的三个原因：一是推理成本下降，长任务 agent 调用不再贵到不可接受；二是 GitHub 与 Azure 的分发渠道降低了企业试用门槛；三是模型在真实 repo 上的首次通过率提升，减少了“看着聪明但跑不通”的挫败感。

换句话说，Codex 这轮增长更像是从“代码生成工具”转向“任务完成工具”的迁移红利。

## 二、为什么“增速”比“榜一”更值得关注

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-25/071952534e26c458.png)

如果只看 SWE-bench 这类公开榜单，Anthropic 的 Claude 依然不弱。但企业买单的逻辑和模型跑分从来不是一回事。

1. 增速反映的是边际变化。Anthropic 的基数已经不小，而 Codex 从较低基数往上冲，斜率自然更陡。这不代表它马上能在收入体量上超过对方，但说明增量客户开始用脚投票。
2. 开发者要的是确定性。一个 agent 能写出 90 分代码但偶尔删错依赖，比一个稳定写出 75 分代码的 agent 更危险。Codex 近期口碑回升，很大程度是因为它在沙箱权限、审计日志、可回滚操作上补了课。
3. 工作流正在被外包。过去一年，开发者从“让模型补一个函数”，变成“让 agent 修一个 bug、写一组合测试、跑通 CI”。这个转变一旦发生，商业增速会先于收入体量变化。
4. 生态绑定在加深。工具调用、MCP 连接器、云主机权限、组织级密钥管理，这些看似无聊的集成，才是企业续费的关键。

可以半开玩笑地说：代码 agent 们卷得越凶，算力账单就越好卖。这场“逆袭”里，笑得最稳的可能是卖 GPU 和云主机的一方。

## 三、具身智能的“GPT-2 时刻”：泛化开始，落地还早

![img3](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-25/8c1f9ef08f6893e5.png)

具身智能被称作“GPT-2 时刻”，得先回到历史背景。

2019 年 GPT-2 发布时，最让人震撼的不是它回答多准确，而是大家第一次看到：模型规模变大后，语言能力出现了一些“没专门训练但也会做”的泛化。它既不是 AGI，也不是可交付产品，但证明了一条技术路线可能走得通。

现在的具身智能正处在类似的节点。

- VLA 模型：Vision-Language-Action 模型把摄像头画面、自然语言指令和机器人动作映射到同一个策略网络里。它的意义是，机器人不再只能复现固定轨迹，而开始理解“把红色方块放到左边盒子”这类组合指令。
- 数据从哪来：遥操作采集、仿真环境、人类视频，是目前的三种主要数据来源。与文本数据相比，机器人数据的采集成本高一个数量级，所以 scaling 才刚刚起步。
- 为什么偏叫 GPT-2 时刻：因为大家观察到三个苗头——多任务泛化开始出现、模型规模与成功率的相关性变强、失败仍然常见但失败方式变得可解释。
- 还不能乐观：机器人领域的硬件差异、传感器噪声、安全边界，都让“实验室能跑”与“工厂能上岗”之间还有明显 gap。GPT-2 发布后，语言模型也花了几年才走向产品化，具身智能不会更快。

一个更直观的类比：GPT-2 能写通顺段落，但你不能让它写法律合同；现在的具身智能机器人能听懂“把杯子推过去”，但你还不敢让它给你倒开水。

## 四、冷思考与实用建议

![img4](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-08-25/74f0a7f05a577842.png)

不管是 Codex 增长还是具身智能升温，都还处在“从 demo 到发票”的早期阶段。三条建议：

1. 用 coding agent，先当实习生用。给它一个隔离沙箱，禁止直接访问生产数据库；所有 PR 必须过 CI 和人类 review。不要因为增速快就默认它可以独立负责核心模块。
2. 看商业竞争，别只看增速榜。优先关注净收入留存、任务真实完成率、失败后的恢复能力。一个客户用了三个月还在续费，比十个 demo 账号更有信息量。
3. 具身智能落地，先找容错高的场景。仓库盘点、生产线上下料、夜间巡检这类结构化、低速、可重复的任务，比家庭服务或医疗护理更接近商业闭环。等技术真正越过“GPT-3 时刻”，再谈通用机器人也不迟。

结论一句话：软件 agent 开始抢工作流，具身智能开始抢泛化能力，但两者的共同点是——拐点刚刚出现，别把拐点当终点。
