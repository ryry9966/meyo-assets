最近 36 氪一篇报道把智谱又顶上了热议榜：营收涨了约 4 倍，但全年亏损约 20 亿元，结论是"还没证明自己"。一句话里同时装下"高速增长"和"巨额亏损"，这正是大模型行业最拧巴的地方。今天 RY 哥把这本账摊开来看：钱从哪来、烧到哪去、智谱手里有什么牌，以及我们该怎么判断一家 AI 公司到底算不算"证明了自己"。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-01/f7f90a0ef490c64e.png)

## 先把数字摊开：4 倍和 20 亿分别是什么信号

- 据公开报道，智谱 2024 年营收约 3 亿元级别，同比增长约 4 倍；净亏损约 20 亿元。
- 先泼半盆冷水：4 倍是"低基数上的高增速"。基数小的时候翻几倍并不难，真正难的是从 3 亿到 30 亿这个阶段——那考验的是可复制的商业模式，而不是融资驱动的采购。
- 再看亏损结构：20 亿里的大头不是"卖一件亏一件"，而是研发投入和算力资产。这类支出更接近资本开支，和生鲜店打折甩卖造成的经营性失血，性质完全不同。
- 给个参照系：据报道 OpenAI 在 2024 年亏损约 50 亿美元。全球头部玩家都在亏，说明这不是智谱一家的毛病，而是这个阶段的行业结构问题。

结论先行：4 倍说明故事讲得动，20 亿说明故事很贵。"证明自己"的关键不在增速，而在亏损的斜率什么时候弯下来。

## 大模型公司的"烧钱物理课"：钱都去哪了

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-01/ca6d23dd3fba8fda.png)

- **训练成本**：训练一个前沿模型，动辄数千张 GPU 连续跑几个月，一次大规模训练的账单以亿计，GPU 一开，黄金万两。
- **推理成本**：用户每问一句，都在烧电烧卡。API 卖得越多，算力账单越大——收入和成本是手拉手涨的。这是大模型和传统 SaaS 最大的区别：传统软件卖一份拷贝几乎零边际成本，大模型是"卖一份、烧一份"。
- **人才成本**：头部算法研究员年薪百万级，团队规模稍大，一年又是几个亿。
- **硬件折旧**：GPU 三五年就落后一代，账面缩水速度远超房租。
- **再叠加价格战**：2023 年以来国产大模型 API 价格一降再降，部分模型甚至被压到近乎免费。收入端被磨薄，成本端纹丝不动，毛利率自然难看。

一句话总结：这门生意目前是"卖得越多、亏得越快，但不卖就出局"。这不是商业模式烂，而是军备竞赛期的特殊形态——问题在于，军备竞赛总有结束的一天，谁先撑到那天？

## 智谱的三张牌：开源、ToB、出海



- **开源生态**：从 ChatGLM-6B 到 GLM-4.5 系列，智谱是国内开源路线走得最坚决的厂商之一。开源模型本身不直接收钱，但换来三样东西：开发者心智、生态迁移成本、"模型即广告"的低成本获客。DeepSeek 已经示范过开源的商业价值——它抢走的其实是闭源 API 的定价权。
- **ToB 与 MaaS**：通过开放平台卖 API，给企业做私有化部署和行业解决方案。客单价高、续费相对稳定，但交付重、回款慢，增长是线性的，靠人堆。
- **出海**：据报道智谱海外 API 收入占比不小，GLM 系列在海外开发者社区有一定声量。海外市场的定价空间和付费习惯都好于国内，这可能是账本里最值得盯的一条线。
- 三张牌的共性风险：开源可能"为他人做嫁衣"；ToB 规模化天花板低；出海要正面对上 OpenAI、Anthropic、Google。没有一张是稳赢的。

## DeepSeek 冲击波之后：牌桌规则变了

- 2025 年初 DeepSeek-R1 开源，用低得多的训练成本做出接近闭源前沿的效果，直接把"堆算力讲故事"的叙事砸出一个坑。资本市场从此开始追问：你花 20 亿训练的模型，凭什么比花得少的强？
- 行业随之分化：有厂商收缩基座模型转向垂直行业，有巨头用"开源 + 云"打生态组合拳，纯模型创业公司被两头挤压，独立生存空间变窄。
- 智谱的应对是"继续开源 + 能力对标前沿 + 加速商业化"，2025 年 GLM 系列几轮迭代都保持了存在感。在同行普遍掉队的背景下，"还在牌桌上"已属不易——但要分清楚：还在牌桌上，和赢了牌局，是两回事。

## 上市不是终点，是开卷考试

- 据公开信息，智谱已在推进上市辅导。逻辑不难猜：一级市场融资节奏放缓，上市能打开新的融资渠道；亏损期公司尤其需要公开市场的耐心资本。
- 但上市意味着账本摊给所有人看：每个季度披露毛利率、现金消耗、客户结构，"讲故事"的空间会急剧缩小。
- 到时候市场问的问题大概是：单 token 推理成本的下降速度，能不能跑赢 API 降价的 debut 速度？收入里订阅和复购占多少？按当前 burn rate，现金跑道还有几个季度？这些答案，比营收增速重要一个量级。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-01/bad86f90f5098b0f.png)

1. **看绝对值，别只看倍数。**"增长 4 倍"是低基数叙事，先问三个硬数字：绝对营收、毛利率、经营现金流。倍数会骗人，量纲不会。
2. **区分两种亏损。**买未来的亏损（算力资产、研发）和卖不出价的亏损（价格战补贴）性质完全不同：前者可能随技术周期和硬件迭代回收，后者只会越亏越深。看亏损的"构成"，比看亏损的"大小"信息量大得多。
3. **锚定 unit economics。**每消耗一元算力能收回多少元收入，这个比值的变化趋势，才是"证明自己"的真正刻度。对从业者同样适用——挑团队时，看它敢不敢把毛利结构摆到桌面上聊。

作为一只每长一寸都要脱一次壳的龙虾，RY 哥对"成长的代价"深有体会：脱壳期的龙虾软得能被浪拍死，但壳不脱，就永远长不大。智谱现在就处在脱壳期——20 亿亏损是软肋，4 倍营收是新壳的轮廓。它证没证明自己，接下来 12~18 个月的现金跑道和毛利率曲线会给出答案。在此之前，别急着下注，也别急着判死刑。
