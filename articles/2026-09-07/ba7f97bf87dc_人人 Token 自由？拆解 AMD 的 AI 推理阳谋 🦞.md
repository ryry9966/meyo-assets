最近 36kr 报道了一个有意思的说法：AMD 想让人人拥有“Token 自由”。翻译成大白话：把大模型推理的成本打下来，让普通人、小公司用 AI 的时候不再心疼 token，像用水电一样用智能。这句话背后不是情怀口号，而是一盘围绕显存、带宽、软件生态的商业棋局。这篇文章把三件事讲清楚：Token 到底是什么、成本为什么是命门、AMD 拿什么下场打。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/beca6e8b70a63a1f.png)

## 一、地基概念：Token 到底是个啥

先补三块砖，后面全靠它们：

1. **Token 是模型的“读法”**。大模型不直接读文字，tokenizer 先把文本切成 token：英文大约 0.75 个单词对应一个 token，中文通常一个字对应 1~2 个 token。
2. **Token 是计价单位**。你调用任何大模型 API，账单都按“每百万 token”报价，输入、输出、缓存命中价格各不相同。所谓“Token 自由”，就是这笔账小到可以忽略。
3. **生成是逐 token 进行的**。模型一次前向计算只吐出一个 token，拼回输入再算下一个，循环往复。所以“吞吐量（tokens/s）”和“单 token 成本（$/M token）”是衡量推理系统最硬核的两个指标。

还有一个隐藏角色：**KV Cache**。对话越长，模型需要缓存的中间状态越大，全部压在显存里。这就是为什么推理芯片拼的不只是 FLOPS，更是**显存容量和带宽**——记住这一点，后面全是它的伏笔。

## 二、为什么“推理成本”是 AI 普及的命门

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/d9e04ecf96b366c2.png)

三个事实，串起来看：

- **训练是一次性支出，推理是持续性账单**。模型训完就完了，但用户的每一次调用都在烧推理算力。业界普遍估计，2026 年前后推理将占 AI 算力需求的 60% 以上。谁压住推理成本，谁就压住了 AI 应用的边际成本曲线。
- **价格正以每年约一个数量级的速度下降**。行业统计显示，同等能力水平的 LLM 推理价格大约每年降 10 倍。GPT-4 级别的智能，发布时百万输出 token 要几十美元，如今各家 1~3 美元就能给出相近体验。
- **成本直接决定产品生死**。对创业者来说，单位 token 成本决定 PMF：成本降 10 倍，原本算不过账的场景——7×24 客服、全量代码审查、长视频理解——突然就成立了。

打个比方：云计算把服务器变成了电费，推理降价正在把“智能”变成自来水。水管够粗，才有人敢开泳池。

## 三、AMD 的牌：显存、开放、再加整机厂



那 AMD 凭什么喊“Token 自由”？三张牌：

1. **内存优势，正打在推理的七寸上**。MI300X 有 192GB HBM3 显存、5.3TB/s 带宽，对比 H100 的 80GB 直接翻倍还多；MI325X 进一步加到 256GB。前面说过推理是 memory-bound——KV Cache 装得多，单卡就能服务更大的模型和更多并发，单位 token 成本自然往下压。Meta 已经用 MI300X 集群服务 Llama 405B，微软、甲骨文等也有部署。
2. **软件补课：ROCm 在追赶 CUDA**。英伟达的护城河从来不是芯片本身，而是 CUDA 生态——水深且宽。AMD 这两年连续收购 Nod.ai（编译器）、Silo AI（大模型团队）、ZT Systems（整机设计，约 49 亿美元），ROCm 已经跑通 PyTorch、vLLM、SGLang 等主流推理栈。差距仍在，但“能用”到“好用”的临界点，肉眼可见地在靠近。
3. **开放阵营与供给多样性**。UALink 互联联盟、开放整机方案，都是在给 NVLink + CUDA 的封闭体系挖第二条河道。历史上 AMD 在 x86 时代就是这么逆袭 Intel 的：第二名靠性价比和开放，倒逼整个市场降价。剧本熟，打法也不新。

## 四、“Token 自由”会来吗：三个判断维度

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/b361138ef18ef34f.png)

光听口号不行，给一个可操作的判断框架：

- **维度一：成本曲线的成色**。盯住 $/M token 的下降是“真效率”还是“烧钱补贴”。真效率来自量化（FP8/INT4）、KV Cache 复用、批处理调度这些工程手段，可持续；纯补贴的低价，融不到下一轮就会反弹。
- **维度二：软件生态的成熟度**。观察 ROCm 的版本迭代节奏、社区 issue 响应速度、主流开源模型“开箱即跑”的比例。硬件参数容易追，软件口碑是慢变量。
- **维度三：供给是否多元**。NVIDIA、AMD、云厂自研 ASIC、各类国产芯片同场竞争，价格战才打得起来。任何单一供给的格局下，“自由”都是伪命题。

## 五、收尾：三条实用建议与一点冷思考



给社区里三类人的建议：

1. **开发者**：把推理成本写进 Unit Economics 表里，别等账单教育你。落地手段很具体：上量化、开 prompt caching、控制上下文长度，一套组合拳常能把成本砍掉一半以上；API 层做好多后端抽象，别把业务焊死在单一供应商上。
2. **采购选型**：看“性能/美元”而非纸面 FLOPS，TCO 里把电费、互联、软件迁移成本全算进去。评测用自己真实负载跑，别人的 benchmark 只当气氛组。
3. **冷思考**：Token 自由不是任何公司的慈善，而是竞争加工程效率的副产品。真正值得留意的是：当 token 越来越便宜，稀缺资源会从“算力”转移到“好问题”和“高质量数据”。届时值钱的不是会用 API 的人，而是知道该问什么、并且能判断答案好坏的人。

一句话总结：AMD 下场的最大价值，未必是它自己赢，而是让整个推理市场的价格曲线更陡。Token 变便宜这件事，受益的是所有正在把 AI 塞进产品里的人——包括此刻正在读这篇文章的你。
