最近 36kr 报道了一个值得琢磨的动向：一批创业公司正在做「给 AI 用的搜索引擎」。代表玩家如 Exa、Perplexity、Tavily，定位不再是给人看的十个蓝色链接，而是给 Agent 调用的检索接口（Retrieval API）。搜索这门二十多年形态几乎没变过的生意，为什么在 Agent 时代突然要被重造一遍？下面从技术、产品、商业三个层面拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/09d8a2588c8df3fc.png)

## 一、传统搜索是为「人」设计的，Agent 不是人

- **排序靠行为信号**。Google 的核心排序长期依赖点击率、停留时长、用户是否"点回去重新搜"这类行为数据——人点不点、看多久，决定网页排名。Agent 不点击、不停留，只抓取结果，这套信号体系直接失效。
- **商业模式天然冲突**。搜索结果页本质是广告载体，而 Agent 调 API 把答案直接拿走，广告没有展示机会。"把答案白送给用户"和"靠答案卖广告"互斥，这是最根本的矛盾。
- **内容质量在崩坏**。二十年 SEO 把网页优化成"给爬虫看、给算法猜"的样子，大模型又让低质批量文本泛滥。人还能靠经验过滤，Agent 照单全收——垃圾进，垃圾出，还是熟悉的配方。
- **交互形态不匹配**。人可以容忍翻页和弹窗，Agent 需要一次调用就返回干净、可解析、带来源的结果，而这恰恰是传统搜索最不擅长输出的东西。

## 二、Agent 要的搜索：语义召回、可引用、能多跳

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/be3547f770b26364.png)

- **语义层**：关键词倒排索引（BM25 那一套）擅长字面匹配，但 Agent 的问题常是意图型查询，比如"找一篇讲某机制原理的论文"。新一代检索用 embedding 向量召回，甚至像 Exa 那样用「用户下一个会点哪个链接」的 next-link prediction 模型训练，直接按含义匹配。
- **输出层**：返回的不是网页，而是清洗过的正文、结构化字段、可验证的引用来源，正好能接进 RAG 管线，让模型"有据可查"。
- **流程层**：Agent 搜索不是一次查询，而是循环：拆解问题 → 搜索 → 读结果 → 追问 → 再搜索（多跳，multi-hop）。所以检索接口要便宜、快、可高频调用，一个为"人慢慢浏览"设计的页面反而是负担。
- **算一笔账**：一个写行业周报的 Agent，单次任务可能连续调用几十次搜索，每次只需要几百 token 的事实与来源链接；若每次调用都拖着广告和冗余页面，成本和上下文窗口都撑不住。

## 三、商业逻辑变了：从「流量入口」到「工具调用」

- **回顾入口变迁**：门户 → 搜索 → 推荐流，每一代入口都重新分配了广告预算。Google 搜索广告收入常年占 Alphabet 总营收一半以上，就是这个位置的价值。
- **Agent 时代，入口变成对话本身**，搜索降级为 Agent 手里的一个 tool。但"工具层"也分层：通用检索、垂直数据（论文、代码、公司工商信息、社媒舆情）、实时资讯 API——每一层都可能长出新公司。
- **巨头没有缺席**：OpenAI 给 ChatGPT 接入实时搜索，并与新闻集团等内容方签下数据授权；Google 把 Gemini 接进自家索引。创业公司的生存空间在于更中立、更垂直、更便宜，以及巨头顾不过来的缝隙市场。
- **另一条暗线在内容方**：当流量从"人点链接"变成"AI 直接取用"，媒体开始收授权费——Reddit 与 Google 的数据合作据报道每年约 6000 万美元。检索层公司能不能拿到干净、可持续的数据供给，成了新护城河。



## 四、难的不是再造一个搜索框，而是内容与信任

- **索引成本高**：全网抓取、清洗、去重、向量化是重资产工程，创业公司通常从垂直领域切入，先做透论文、代码或企业数据一个方向。
- **冷启动难题**：没有海量用户点击数据，相关性只能靠模型预测，这正是 Exa 选择 next-link prediction 的原因，也是它的天花板。
- **信任是底线**：Agent 引用错误来源，错误会被放大到成千上万次自动调用中。可验证的引用（citation）不是加分项，是及格线。
- **生态博弈**：如果 Agent 吃掉全部流量、内容方拿不到回报，优质内容会收缩，检索层最终无米下锅。授权分成、按调用微付费这类新分配机制，可能决定这条赛道的上限。

## 五、三条冷思考，给开发者和建设者

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/123e5fa9167be86b.png)

1. **如果你有产品，尽早考虑"机器可读性"**：结构化数据、清晰的 API、明确的 AI 爬取策略（如 llms.txt 这类行业约定）。未来你的用户可能一半是人、一半是 Agent，而后者根本不看你的落地页设计。
2. **如果你在做 Agent，别把搜索当随手接的组件**：按任务评测召回质量、时效性、引用准确率和单次成本；关键词检索与向量检索混合使用，通常比单押一种稳。
3. **判断一家"新搜索"公司值不值得用，看三点**：数据来源是否干净且可授权、引用是否可验证、是否在垂直领域建立了难以复制的内容关系。至于界面像不像 Google，是最不重要的指标。

搜索的形态会变，但"在信息洪流里找到可信答案"这件事不会消失。重造 Google 的意义不在复刻那个搜索框，而在把检索重新接进 Agent 时代的供需关系——谁先跑通这条链路，谁就拿到下一张入口门票。
