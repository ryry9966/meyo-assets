过去一年，Perplexity、Exa、Tavily 这些名字反复出现在融资新闻里，它们做的事听起来有点“复古”：重做一遍搜索引擎。Google 明明在那儿，索引了几乎整个互联网，为什么还有人前赴后继地“重新造 Google”？这个话题戳中了正在发生的结构性变化——搜索引擎的“用户”变了：以前是人，现在多了一类没有眼睛、不点广告、一天能查几百次的机器。要理解这波创业潮，得先回到 Google 的底层设定。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/83a3071361c03813.png)

## 一、Google 的底层设定：为“人眼”设计的机器

- **技术栈**：爬虫抓取 + 倒排索引（inverted index）+ PageRank 这类链接分析 + 排序，最终交付一个页面——十条蓝链。
- **商业闭环**：人看结果 → 人点广告 → 广告主付钱。Alphabet 2024 财年广告收入约 2646 亿美元，占总收入约 75%。
- **产品逻辑**：排序、摘要、广告位，全都围绕两个问题优化——人能不能快速找到？人愿不愿意点？

这套设定运转了二十多年，前提只有一个：用户有眼睛、会点击、会被说服。搜索引擎本质上是一台“注意力分发器”。

## 二、Agent 的用法：没有眼球，也不看广告

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/56c192d12979e722.png)

Agent 把上述前提全部推翻了：

1. **不浏览，只调用**。Agent 不“看”网页，它发 API 请求，拿到结构化结果直接喂给模型。给 Agent 推广告，就像给光标递传单——它看不见，也不会心动。
2. **频率量级不同**。人一天搜几次；一个 Agent 完成“订机票 + 比价 + 写摘要”的任务，可能并发几十上百次查询。
3. **要的东西不同**。Agent 需要的是可直接消费的结构化答案、可验证的引用来源（citation）、足够新鲜的实时数据、稳定可组合的接口。

一次任务几十次调用，“按千次展示收费”瞬间失灵——旧商业闭环在机器用户身上彻底断路。技术时机也刚好成熟：模型推理成本两年内降了一个数量级，agent 框架普及，“让机器替人读网”第一次算得过账。

## 三、Google 为什么难转身：现金牛与创新者窘境

Google 不是没看见。AI Overviews 已经把直接答案顶在结果页最上方，Gemini 也在全面铺开。但它面对的是教科书级的 innovator's dilemma：

- 答案给得越完整，用户越少点链接 → 广告曝光下降；
- 流量回流越少，站长和媒体收入越受损 → 内容生态反弹；
- 而搜索广告贡献了约四分之三的营收，激进改造等于亲手挤压现金牛。

新玩家没有这个包袱：没有历史收入要保护，可以直接从 Agent 的需求倒推产品。这就是“重新造”的经济学理由——不是 Google 技术做不到，而是旧账本不允许它全力以赴。

## 四、新玩家到底在造什么：从“网页”到“能力”

各家切入点不同，共识却很清晰：搜索不再是一个“页面”，而是一个可被程序调用的“能力”（capability）。

- **Perplexity**：答案引擎，先给带引用的答案、再列来源，还把这套能力打包成 Sonar API 卖给其他开发者。
- **Exa**（前 Metaphor）：索引从建库起就按 embedding 语义组织，目标是“方便 LLM 消费”，而不是关键词匹配。
- **Tavily、Brave Search API、Serper**：干脆做纯基础设施，把搜索变成 Agent 框架里一行代码的事。
- **配套协议在生长**：llms.txt 试图给模型一份“站点说明书”；Anthropic 推出的 MCP（Model Context Protocol）在统一模型调用外部工具与数据源的接口。

数据侧同样在变：Reddit 与 Google 的授权合作据报道约每年 6000 万美元，OpenAI 也与多家媒体签署内容协议。内容变现正在“广告分成”之外，多出一条“授权费”路径。

## 五、绕不开的三道坎

方向对了不代表生意成立，新搜索至少要翻过三座山：

1. **成本坎**。返回十条链接边际成本近乎为零；合成一条答案 = 检索 + 多次模型推理，贵几个数量级。过去二十年是广告在补贴“免费搜索”，订阅和 API 计费能否填平推理成本，账还没算完。
2. **索引坎**。全网持续抓取是重资产工程，Google 二十年的索引规模是真护城河。多数新玩家走“通用引擎 + 自有抓取”的混合路线，新鲜度和覆盖面仍在补课。
3. **生态坎**。Agent 直接给答案、不回流点击 → 创作者没有收益 → 优质内容变少 → 答案质量跟着塌。这是个死结，目前两类解法都在试验：Cloudflare 开始测试按次付费抓取（pay-per-crawl），媒体则在谈授权费。哪种跑通，决定新搜索的燃料是否可持续。

## 三条冷思考

1. **搜索正在从“产品”退后一步，变成“能力组件”**。评估新玩家别看首页好不好看，看 API 延迟、引用可验证性、单位成本曲线——这三项才是 Agent 时代的核心体验。
2. **给 Agent 选搜索服务的开发者，按五个硬指标逐项打分**：数据新鲜度、结构化输出、引用可溯源、单次调用价格、权限与范围控制。别默认“随手接一个搜索 API 就完事”，不同任务的最优解差异很大。
3. **内容创作者与媒体，把“机器可读”当作新的 SEO**：事实清楚、结构分明、来源可靠的内容更容易被 Agent 引用，也就是所谓的 GEO（Generative Engine Optimization）。同时分散流量入口——当“入口”本身在被重构时，别把生计押在任何一个闸门上。

搜索没有消失，它只是换了一批“用户”。Google 花了二十年学会服务人，接下来十年的竞争，是看谁先学会服务机器。
