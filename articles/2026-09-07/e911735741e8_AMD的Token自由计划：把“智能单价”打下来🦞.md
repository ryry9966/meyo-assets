最近 36kr 一篇关于 AMD 的报道，把一个词送上了热议榜——"Token 自由"。意思是：用大模型不再看单价，像"车厘子自由"一样随取随用。这不是情怀口号，而是一笔精密的商业账：训练市场被 NVIDIA 牢牢锁定，而推理（inference）市场正在爆炸式增长，推理的命门恰好是 AMD 的长处——内存带宽和性价比。今天就把营销的壳剥掉，看看里面的虾肉：Token 为什么贵、AMD 打的是什么牌、"自由"的真实代价是什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/270d19f0c6874550.png)

## 一、Token：AI 时代的"度电"

- **Token 是大模型处理文本的最小单位**。英文里约 0.75 个单词算一个 token，中文粗略对应 0.5~1 个汉字，取决于分词器（tokenizer）。你发给模型的每个字、模型吐回的每个字，都按 token 结算。
- **为什么按 token 计费？** 因为推理成本近似与生成 token 数成正比：每生成一个 token，GPU 都要做一轮完整前向计算。token 数就是 AI 的"用电量"，API 报价单本质上是一张电价表。
- **降幅有多夸张**：GPT-4 刚发布时，百万输出 token 定价 60 美元；今天同等智力水平的模型，输出价已跌进个位数美元区间，部分国产模型甚至压到 1 美元以下。两年时间，下降了一到两个数量级。
- 所谓"Token 自由"，就是把这个价格继续往下打：让每个人、每台设备都用得起"按秒思考的智能"。

## 二、生成一个字，到底贵在哪？

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/8549fd9f78f378c3.png)

1. **推理分两个阶段**：prefill（一次性读完你的输入，属于算力密集型）和 decode（一个 token 一个 token 往外蹦，属于内存密集型）。
2. **瓶颈在 decode**：每生成一个新 token，都要把整个模型权重和 KV cache 从显存里"过一遍"。这一步对峰值算力要求不高，对显存带宽要求极高——计算单元经常在空转等数据，就像水管再粗，前端水压不够照样白搭。
3. **KV cache 随上下文线性膨胀**：对话越长，显存越吃紧。所以推理型 GPU 的核心指标是 HBM 容量和带宽，而不是参数表上好看的 FLOPS。
4. **这解释了行业格局**：HBM 产能集中在 SK 海力士、三星、美光三家手里，价格坚挺；NVIDIA 用 NVLink 把推理做成集群生意，再用 CUDA 把开发者留在生态里。
5. **AMD MI300X 的设计正中要害**：192GB HBM3、5.3TB/s 带宽，单卡装得下 70B 级模型；跑 DeepSeek R1 这类大参数模型时，所需卡数更少，单位 token 成本更有优势。

## 三、AMD 的三张牌：硬件、软件、联盟

- **硬牌**：Instinct 从 MI300X 到 MI325X 再到 MI350 系列，HBM 从 192GB 一路堆到 288GB，并支持 FP8/FP4 低精度计算；消费端还有 128GB 统一内存的 Ryzen AI Max（Strix Halo），让"笔记本本地跑 70B 量化模型"从段子变成实测。
- **软牌**：软件是 AMD 最大的短板，也是投入最猛的方向——ROCm 迭代明显提速，先后收购 Silo AI、Nod.ai、Mipsology、ZT Systems 补齐软件与机架级方案；PyTorch、vLLM、SGLang、llama.cpp 逐步获得原生支持。DeepSeek R1 发布后不到三周，官方就给出了 MI300X 上的完整部署方案，这是生态响应速度的信号。
- **联盟牌**：Meta、微软、Oracle 等已在采购或测试 Instinct 系列；近期与 OpenAI 达成 6GW 级别的多年合作，首批 MI450 预计 2026 年下半年部署。同时 AMD 联合产业链推 UALink 等开放互连标准，对抗封闭生态。
- **商业逻辑一句话**：训练市场 NVIDIA 占八九成、短期无解；推理市场是增量最大、对性价比最敏感、对生态绑定相对最弱的一块——后发者的最佳突破口。

## 四、"Token 自由"的两条实现路线

- **云端降价**：MoE 架构 + FP8 量化 + 蒸馏小模型，让同等体验的服务成本骤降；DeepSeek 引爆价格战后，各家 API 价格普遍连续腰斩，免费额度越来越大方。对开发者，prompt caching（提示词缓存命中）还能再砍掉一大截输入成本。
- **本地部署**：llama.cpp / Ollama / LM Studio 配合 GGUF 量化，24GB 显存就能跑 32B 模型；128GB 统一内存的迷你主机能塞下 70B 量化版。本地跑的真正价值不只是省钱，还有离线可用、数据不出门——医疗、法务、内网场景的刚需。
- 两条路线殊途同归：**把智能从"稀缺的云服务"变成"接近水电的公用事业"**。参照云计算把存储打到几分钱每 GB 的历史，token 单价大概率还会继续降。

## 五、冷思考：自由从来不是免费的

- **杰文斯悖论（Jevons paradox）**：单价越降、用量越猛，全社会算力总开支反而上涨。Token 自由对个人是减负，对行业是更大的军备竞赛。
- **"免费"有商业模式兜底**：免费额度是获客漏斗，代价可能是数据贡献、生态绑定或后续订阅转化，读条款比读发布会重要。
- **AMD 的仗远没打赢**：ROCm 与 CUDA 的成熟度差距是多年工程债，HBM 供应依赖三家供应商，与 OpenAI 协议里还带着与股价里程碑挂钩的认股权证条款——资本市场的热情，本质是在给"第二供应商"这个身份定价。

## 给普通人的三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/3a906b52cb91824d.png)

1. **学会算 token 账**：输出 token 通常比输入贵 3~5 倍。控制生成长度、精简反复出现的 system prompt、善用缓存，同样的活儿，月账单能差出一个量级。
2. **分层使用模型**：草稿、摘要、日常问答交给小模型或本地模型，关键决策再上旗舰模型。单价降了，选型逻辑反而更重要——便宜不等于适合。
3. **盯"单位智能成本"，别只看榜单排名**：每一美元能买到的可用推理质量，才是这个时代真实的摩尔定律；对"无限量"宣传，先看它的商业模式靠什么续命。

Token 自由的终点，不是人人挥霍 token，而是智能像水电一样隐形地长进工具里。到那天，衡量一个问题的成本不再是"花多少钱"，而是"值不值得问"。
