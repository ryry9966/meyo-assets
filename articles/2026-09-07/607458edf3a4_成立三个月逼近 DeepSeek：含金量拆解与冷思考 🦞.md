最近 AI 圈刷屏的一条消息：成立仅三个月，陈大年团队的模型在部分推理 benchmark 上"差点超过 DeepSeek"。评论区立刻分成两派：一派高呼小团队逆袭，一派冷笑"又来营销"。今天不站队，咱们把这笔账拆开算——三个月逼近一线模型，技术上到底有几分可能？分数背后有几分水分？对整个行业又意味着什么？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/e42ea46328bd24cb.png)

## 先补背景：陈大年是谁，这次做了什么

- **老兵，不是新人。** 1999 年与兄长陈天桥共同创办盛大网络，凭网络游戏冲进中国互联网第一梯队；后来创办连尚网络，旗下 WiFi万能钥匙 用一支极小的团队做到了用户量级以亿计——"小团队撬动大产品"是他身上最深的烙印。
- **画风一贯克制。** 2012 年一场大病之后，他公开转向"低强度、高效率"的工作哲学，"反对无意义加班"几乎成了个人招牌。
- **这次依然低调入场。** 据 36kr 等媒体报道：没开发布会、没造势融资，成立约三个月后，模型在数学、代码等推理类基准上逼近 DeepSeek 的同级开源模型，团队规模和算力投入据称都相对克制。

先指出一个容易被忽略的细节：**这不是"从零到一"的故事，而是"三个月走到 0.9 个 DeepSeek"的故事**。这两种叙事的含金量天差地别，下面细说。

## 三个月为什么可能：开源生态的时间杠杆

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/b090a8329afcac96.png)

1. **预训练这一关，直接跳过了。** 当前主流玩法是拿 Qwen 这类已经很强的 base model 做后训练——最烧钱、最耗时的部分，开源社区已经替你完成。相当于盖楼不用打地基，直接从精装修开始。
2. **菜谱是公开的。** DeepSeek-R1 论文把 GRPO、可验证奖励（RLVR）这套 RL 后训练配方写得相当细，等于把米其林菜谱贴在了门口，谁都可以照着炒。
3. **算力根本不在一个量级。** 预训练一个前沿模型动辄数万张 GPU 连跑数月；而 SFT + RL 后训练的开销，通常认为比预训练低一到两个数量级。预算不大，也能在推理榜上打出像样的成绩。
4. **推理任务是 RL 的甜点区。** 数学题能对答案、代码能跑测试集，奖励信号清晰可判，训练效率天然高——这也是为什么追赶者都从这些榜单起步。

所以严格说，这不是某个人的奇迹。R1 开源之后，全球几个月内冒出一批"逼近型"模型，是行业现象；陈大年团队只是做得比较快、比较克制的那一批。

## "差点超过"的含金量：榜单是切片，不是全貌

1. **榜单只测一个切片。** 在数学、代码这类可验证任务上逼近，不代表长文本、多模态、Agent 调用、幻觉率、指令跟随等综合能力全面追平。科目二满分，不等于能跑达喀尔拉力赛。
2. **应试式过拟合要警惕。** 针对特定 benchmark 定向训练，可以把分数精准拉高；评测集数据污染在行业内也不是新鲜事。看到"逼近"两个字，先问测了什么、怎么测的、和谁比。
3. **DeepSeek 的护城河不在单一分数。** MLA、MoE、FP8 混合精度、MTP 这类 infra 级创新，加上持续快速迭代的工程节奏，才是它真正的壁垒。榜单分数只是冰山露出水面的一角。
4. **小结：含金量是真的，但性质是"入场券变便宜了"，而不是"王座易主了"。** 这两个判断必须分开，混在一起就容易变成爽文。

## 对行业意味着什么：能力商品化，竞争换赛道

- **中档能力加速商品化。** 推理能力从"独家绝活"变成"标准配件"，差异化向数据质量、垂直场景、推理成本迁移。以后拼的不是"会不会推理"，而是"推得又对又便宜"。
- **开源反而是最深的护城河。** DeepSeek 公开配方，跟进者越多，它的生态位越稳固——大家都在它的地基上盖房子，收租的始终是房东。
- **创业叙事切换。** "无限预算烧预训练"不再是唯一剧本，"小团队 + 深工程 + 克制的算力预算"成为可复制路径。对融资难、拿不到万卡的中小团队来说，这是实打实的窗口期。

## 冷思考：给关注者的三条建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/2764dcf5f9e4c79d.png)

1. **看模型，先建自己的评测集。** 别追榜。从自己业务里挑 50 条真实任务做成小测试集，半天就能得到比十张排行榜更靠谱的答案——你自己的任务，才是唯一的榜单。
2. **区分叙事与技术。** "三个月神话"背后，是开源社区多年的积累，加上创始人二十多年的工程经验和人才网络。励志故事可以听，成长方法论别照抄，尤其别抄成"招十个人三个月复刻 DeepSeek"。
3. **想入门的人，学路径别学结论。** 先啃透 R1 论文里的 GRPO 与 RLVR，再拿一个开源小模型把完整的 RL 训练流程跑通一遍。能亲手复现的路径，永远比别人嘴里的排名值钱。

三个月逼近一线，真正的信号不是"谁跑得快"，而是"门槛塌了"。门槛塌掉之后，比的就不是起跑速度，而是谁能站得久。这句话，送给所有准备跳进这个滩涂的团队。
