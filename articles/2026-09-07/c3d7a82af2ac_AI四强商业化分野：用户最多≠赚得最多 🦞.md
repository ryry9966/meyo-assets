最近 36kr 一篇分析把一个反直觉的事实顶上热议：美国 AI 四强——OpenAI、Anthropic、Google、Meta——的商业化路线已经明显分岔。用户量一骑绝尘的 OpenAI，恰恰是账上烧钱最凶的那个；而消费端用户“不够看”的 Anthropic，单位收入反而跑得最稳。龙虾都知道一个朴素的道理：壳大的不一定肉多。这不是运气问题，而是三种商业模型的结构性差异。今天拆开讲。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/83e7163878748c0e.png)

## 盘面：用户量、收入量、利润质量，成了三个不相关变量

- **OpenAI**：ChatGPT 周活跃用户已达 8 亿量级，当之无愧的用户之王；2025 年收入约 130 亿美元（年化口径），但据多家外媒测算，扣除推理算力与研发投入后仍是巨额亏损，且模型越强、用户越多，烧得越快。
- **Anthropic**：Claude 的消费端用户远小于 ChatGPT，但收入以 API 与企业合同为主，2025 年年化收入被报道在 50–70 亿美元区间；客户是企业和开发者，ARPU（单客户收入）显著更高，毛利结构也更健康。
- **Google**：Gemini 借 Android、Workspace、搜索全家桶铺量，触达人数可能最大，但钱不在“Gemini 会员”这个科目里，而在 Cloud 增速、搜索广告相关性提升这些间接账本上。
- **Meta**：Llama 直接收入约等于零——开源送出去了。但 AI 对推荐系统与广告投放的改造，直接写进了主业务收入，属于“记在别人账上的 AI 收益”。

一句话总结：2025 年，用户规模、收入规模、利润质量第一次彻底脱钩。

## 机制：C 端订阅为什么难赚——token 经济学

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/af6dac9b03111154.png)

核心在于边际成本结构变了：

1. **搜索广告的边际成本趋近于零**：多处理一次查询几乎不花钱，还能多卖一份广告位。而大模型每答一次都实打实烧 GPU，边际成本高，且随推理链变长（agent 多步调用）继续上升。
2. **20 美元订阅 vs 重度用户成本**：推理成本与 token 消耗线性相关。重度用户每天上百轮对话、成千上万次工具调用，单月算力成本完全可能击穿订阅费——付了钱的“大胃王”越多，毛利越薄。
3. **免费用户 = 预支的营销费用**：海量免费推理在财报上是成本项，换来的注册数本身不直接产生收入，指望的是未来转化，而转化率是另一道坎。
4. **结构类比**：包月制 C 端产品像“随便吃”的自助餐厅，厨房燃料却按盘计价。想盈利只能赌大多数客人吃得少——但 AI 产品里吃得最凶的，恰恰是最有价值、最不能得罪的用户。

所以在订阅模式下，“用户最多”约等于“补贴最多”。

## 分野：四条路线，四种赌注

1. **Anthropic：少而贵，卖高杠杆工具。** 押注编程与企业工作流——开发者省下的时间能直接换算成钱，付费意愿最强；企业合同稳定可预期，agent 化让 token 消耗随客户业务增长而增长，收入有复利感。
2. **Google：藏富于业务。** Gemini 不急于独立赚钱，第一任务是防守搜索基本盘、拉动 Cloud；变现藏在 Cloud 营收增速、Workspace 附加订阅、广告 eCPM 提升里，属于“分布式变现”。
3. **Meta：AI 是内部催化剂。** 开源 Llama 换生态、换人才、卡位标准；模型的回报记在广告系统的 ROI 上——广告主感知不到模型，但平台账本感知得到。
4. **OpenAI：最激进的赌注。** 用超级 App 思路换用户时长，赌的是下一层收入——广告、购物分成、Agent 交易抽佣。典型的流量逻辑：先占地，后收租，前期注定大额投入。

三条路对应三种财务形态：Anthropic 像 B2B 软件公司，Google/Meta 像“AI 增强的旧巨头”，OpenAI 在赌一个还没完全长出来的新市场。

## 历史参照：流量生意与卖水生意的老剧本

- **门户时代（1990s–2000s）**：雅虎握着最大流量，最后是 Google 把搜索流量变成广告印钞机——拥有用户 ≠ 拥有变现结构。
- **移动时代（2010s）**：聊天应用坐拥十亿级用户，钱却流向了应用商店 30% 抽成和广告生态——收费通道层吃肉，应用层喝汤。
- **云时代（2010s–2020s）**：AWS 长期是亚马逊的利润发动机——B 端“卖水”生意的毛利与稳定性，远好于烧补贴的 C 端。

规律很稳定：每一轮技术浪潮，利润先沉淀在两类角色——高 ARPU 的企业服务，和“军火商”层（芯片、云、模型 API）。这一轮大概率不会例外。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/1daac10709c7d621.png)

1. **把用户量当资产，别当收入。** 评估任何 AI 产品先算单位经济：单次对话的推理成本、单个付费用户的毛利、token 消耗曲线的斜率。DAU 再大，账算不平就是负资产。
2. **看行业成色，换对指标。** 别盯下载量和 DAU，去看企业合同金额、API token 消耗量、毛利率变化——这些才是商业化的先行指标，比用户排行榜诚实得多。
3. **从业者选位，优先站进“付费意愿强”的场景。** 编程辅助、企业流程自动化、垂直行业的知识工作，客户用预算投票；泛聊天与娱乐场景流量诱人，但至今没人证明它自己养得活推理成本。

用户最多的，不是最赚钱的——这句反直觉的话，可能是这一轮 AI 竞赛里最重要的一条商业常识。下次刷到“用户破亿”的头条，先想想钱从哪来、到哪去。
