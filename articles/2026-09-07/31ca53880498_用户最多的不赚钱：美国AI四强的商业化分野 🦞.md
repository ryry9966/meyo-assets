最近一篇 36kr 的报道把一个反常识的事实顶上讨论区：把美国 AI 第一梯队的几家公司排在一起看，用户量的排行榜和赚钱能力的排行榜，几乎是两张错位的表。同一条 Transformer 技术路线，走出了四种完全不同的生意——有人拿下最大的用户盘子和收入盘子，同时背上了最深的亏损；有人用户量级小一档，单位经济却最健康；有人干脆不直接卖 AI，账本反而最稳。这篇把账本摊开，拆一拆这场“商业化分野”。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/e9a613c8165b07f9.png)

## 先对齐三张榜：用户榜、收入榜、成本榜

先把公开口径的数字摆在一起（多为媒体估算，看量级、别抠零头）：

- **OpenAI**：ChatGPT 周活跃用户在 2025 年达到 7~8 亿量级，消费级 AI 应用全球第一；年化营收突破百亿美元，但 2024 年据披露净亏损约 50 亿美元，2025 年亏损预计进一步放大——用户、收入、支出，三项全是第一。
- **Anthropic**：Claude 的用户量级明显小一档，年化营收却从年初约 10 亿美元冲到年内数十亿美元量级，增速反而更陡；收入结构以 API 和企业合同为主，客单价高。
- **Google**：把 Gemini 塞进搜索、安卓、Workspace，仅 AI Overviews 的月度触达就在 20 亿用户量级——论“触达”，它才是最大的那个。但 AI 收入几乎无法单独拆出，藏在广告点击率提升和 Google Cloud 暴增的在手订单里。
- **xAI**：Grok 借 X 平台分发，用户涨势凶猛，故事核心却是自建超算与数十万张 GPU 的算力规模，商业化仍在早期。
- **编外的 Meta**：Llama 全面开源，模型本身直接收入约等于零，年度资本开支却到 600~700 亿美元量级，赌的是算力反哺广告推荐系统的隐性回报。

一句话概括：用户量的排名，和“谁在赚钱”的排名，几乎完全错位。

## 为什么用户多 ≠ 赚钱多：推理成本的经济学

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/805c62da17fca789.png)

底层原因只有一句：**大模型每服务一个用户，都在真实地烧算力，而免费用户不带来一分钱收入。**

1. **边际成本不再趋近于零。** 传统互联网写一份代码可以服务十亿人，社交和搜索的边际成本近乎为零；大模型的每次对话都要实打实过一遍 GPU，token 是有单价的——头部模型每百万输出 token 定价从几美元到几十美元不等，再叠加数据中心折旧与电费，免费用户的每次提问都是成本中心的支出。
2. **免费到付费的漏斗极陡。** 订阅制产品的付费转化率普遍只有个位数百分比。一个 200 美元/月的 Pro 订阅背后，可能站着几十上百个纯烧钱的免费用户。
3. **客单价差着几个数量级。** ToC 订阅一单 20 美元/月；ToB 的一纸企业 API 合同动辄百万到千万美元一年，按量计费、越用越付。一个头部企业客户抵得上几万甚至几十万个 Plus 订阅。
4. **付费意愿跟着场景走。** 企业愿意为编码助手掏钱，因为省下的是工程师的工资，ROI 可以直接算出来；闲聊问答类场景的付费意愿弱得多。编码负载输出 token 长、单价高、客户留得住——这正是 Claude 能靠企业客户把收入曲线拉陡的底层逻辑。

传统 SaaS 毛利 70%~80% 是常态，而大模型推理毛利长期被业界认为远低于这个水位。换句话说：在推理成本面前，免费用户不是流量，是电费。

## 四条路线，四种生意



- **路线一，OpenAI 的大漏斗**：免费引流 + 订阅变现 + API 三条腿走路。赌的是用户规模最终转化为生态位——消费者养成习惯，开发者在其上构建应用，护城河是品牌与先发。代价是成本端最重，需要持续巨额融资输血。
- **路线二，Anthropic 的窄漏斗**：不打用户战，主攻 API 与企业客户，聚焦编码、Agent 这类高价值负载。账面用户少，单位经济模型却最健康，2025 年收入增速接连超出市场预期。
- **路线三，Google 把 AI 当功能**：不为单独卖 AI 收钱，而是用 Gemini 防御搜索广告被分流，同时靠 Google Cloud 和自研 TPU“卖铲子”。AI 收入在报表上看不见，账本却是几家里最稳的。
- **路线四，xAI 与 Meta 的算力与生态**：xAI 押注自建超算 + 借 X 分发 + 面向政企的合同；Meta 干脆开源，把 Llama 做成行业标准，价值绕道回流自己的广告系统。

四条路线没有绝对优劣，对应的是各自的资金实力、分发能力和风险偏好。但它们共同指向同一件事：**模型能力正在商品化，商业模式才是分水岭。**

## 谁的护城河更硬一点

- **切换成本不对称。** 企业把 API 接进产品后，prompt 调优、评测集、代码集成全部绑定，换模型等于一次小型重构；消费级订阅今天取消明天走人。ToB 的粘性天然高于 ToC。
- **分发是最便宜的用户获取。** Google 每上线一个 AI 功能，触达成本近乎为零；独立产品要为每一个下载付渠道费。用户量是先手棋，但先手棋也要靠分发来落子。
- **所有路线的终极考题都是毛利率。** 蒸馏小模型、上下文缓存、专用推理芯片，是各家共同的技术动作——谁能更快压低单位 token 成本，谁先把规模变成利润。

隐忧也高度一致：收入增长的速度，目前普遍跑不过算力开支增长的速度。商业模式的分野，最终要看谁家的两条曲线先交叉。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets@main/images/2026-09-07/095d05bd90ce6c98.png)

1. **看 AI 公司别只看 DAU/MAU。** 先问三个问题：单个用户的月成本是多少？付费用户的占比和留存怎么样？单次推理的收入/成本比是多少？这三个数字比用户总量诚实得多。
2. **判断一个 AI 产品能不能活，看它替代的是成本还是娱乐。** 替代工资的场景（编码、客服、法务文书）最先跑通商业闭环；纯陪伴娱乐类的付费天花板，肉眼可见。选工具、选赛道都可以套这条。
3. **用户数是先手棋，不是胜负手。** 历史上“用户最多≠利润最多”的案例一抓一把：WhatsApp 坐拥二十多亿用户，单用户变现长期远低于 Instagram。分发决定下限，单位经济决定上限。

收个尾：这一轮 AI 竞赛里，最贵的从来不是用户，是每一次调用背后那张 GPU 账单。看懂了账单，才算看懂了分野。
